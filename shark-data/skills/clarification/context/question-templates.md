# Question Templates

Use these forms to keep clarification concise.

## Scope

- "Is {item} in scope for this change, or should it remain unchanged?"
- "Which of these cases must be supported: {A}, {B}, {C}?"

## Terms

- "What does `{term}` mean in this context?"
- "Should `{term}` be interpreted as {option A} or {option B}?"

## Outcomes

- "What observable result should happen when {condition} occurs?"
- "What should not happen under {condition}?"

## Priority

- "If we can only satisfy one of these constraints, which wins: {A} or {B}?"

Ask open questions early when the space is unknown. Ask closed questions late when choosing between known interpretations.

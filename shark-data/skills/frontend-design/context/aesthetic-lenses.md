# Aesthetic Lenses — The Five Dimensions

Detailed reference for the five dimensions through which a committed aesthetic
direction is executed. This is reusable reference material — consult it while
refining a design (`workflows/refine-aesthetics.md`).

## Typography

Choose fonts that are beautiful, unique, and interesting. Avoid generic fonts
like Arial and Inter; opt instead for distinctive, characterful choices that
elevate the interface's aesthetics. Pair a distinctive **display font** (for
headlines and impact) with a refined **body font** (for legibility at length).

## Color & Theme

Commit to a cohesive aesthetic. Use CSS variables for consistency so the whole
interface shares one source of truth for color. Dominant colors with sharp
accents outperform timid, evenly-distributed palettes — pick what leads and
what punctuates.

## Motion

Use animation for effect and micro-interaction. Prioritize CSS-only solutions
for plain HTML; use the Motion library for React when it is available. Focus on
high-impact moments: one well-orchestrated page load with staggered reveals
(via animation-delay) creates more delight than scattered micro-interactions.
Use scroll-triggering and hover states that surprise.

## Spatial Composition

Reach for unexpected layouts: asymmetry, overlap, diagonal flow, and
grid-breaking elements. Use generous negative space OR controlled density —
either can be right, depending on the committed direction — but choose
deliberately rather than defaulting to an even grid.

## Backgrounds & Visual Details

Create atmosphere and depth rather than defaulting to solid colors. Add
contextual effects and textures that match the overall aesthetic. Creative
forms include: gradient meshes, noise textures, geometric patterns, layered
transparencies, dramatic shadows, decorative borders, custom cursors, and grain
overlays.

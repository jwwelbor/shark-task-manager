# Understand Feature Output Template

Use this file when `workflows/understand-feature.md` needs the fuller report skeleton.

```markdown
# Feature Documentation: {Feature Name}

**Date**: {YYYY-MM-DD}
**Analyst**: {name}
**Version**: {version if applicable}

## Feature Overview
## Data Models
## Data Flows
## Business Rules
## Dependencies
## Consumers
## Extension Points
## Extension Recommendation
## Testing
## Known Issues And Limitations
## Files Reference
## References
```

Each section should cite concrete files or code locations. For extension recommendations, compare at least two options and name the chosen approach with rationale and implementation steps.

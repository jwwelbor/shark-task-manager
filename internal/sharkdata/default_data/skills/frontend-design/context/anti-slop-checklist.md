# Anti-Slop Checklist

The reusable list of generic patterns to never use, plus the variation mandate
that keeps successive designs distinct. Check every aesthetic choice against
this list while refining a design.

## Never Use Generic AI Aesthetics

Avoid the patterns that make an interface look machine-defaulted rather than
designed:

- **Overused font families** — Inter, Roboto, Arial, generic system fonts.
- **Cliché color schemes** — especially purple gradients on white backgrounds.
- **Predictable layouts and component patterns** — the centered card stack, the
  evenly-distributed three-column feature row, and other default arrangements.
- **Cookie-cutter design** that lacks context-specific character — anything that
  could belong to any product equally well.

## The Variation Mandate

Interpret creatively and make unexpected choices that feel genuinely designed
for the context. **No two designs should be the same.**

- Vary between light and dark themes across designs.
- Vary fonts and overall aesthetic between generations.
- **Never converge** on a single common choice across generations (for example,
  reaching for Space Grotesk every time). If a choice feels like the one you
  reached for last time, choose differently.

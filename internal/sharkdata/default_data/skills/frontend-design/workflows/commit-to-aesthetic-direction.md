# Commit to an Aesthetic Direction

## Purpose

Turn loose frontend requirements into one bold, defensible aesthetic direction
before any code is written. This is the highest-leverage design activity: a
committed direction makes every later choice (font, color, motion, layout)
follow naturally, while an uncommitted one produces generic, averaged-out
results.

Use this when starting any new component, page, or application — or when a
design feels timid, muddled, or like it could be anyone's.

## Inputs

- The frontend requirements: what to build, and any stated purpose, audience,
  or technical constraints.

## The Four Lenses

Work the four design-thinking lenses in order. Write a one-line answer for each
— vague answers here produce vague designs.

1. **Purpose** — Name the problem the interface solves and the person who uses
   it. Be specific: "let a busy nurse log a vital in under five seconds" beats
   "user dashboard."

2. **Tone** — Pick an *extreme*, not a safe middle. Candidates include:
   brutally minimal, maximalist chaos, retro-futuristic, organic/natural,
   luxury/refined, playful/toy-like, editorial/magazine, brutalist/raw,
   art deco/geometric, soft/pastel, industrial/utilitarian — and many beyond
   this list. Treat these as inspiration; design a tone that is genuinely true
   to the purpose rather than snapping to the nearest label.

3. **Constraints** — List the hard technical requirements: framework,
   performance budget, accessibility targets, supported devices. A direction
   that ignores constraints is a fantasy, not a design.

4. **Differentiation** — Name the single thing someone will remember. If you
   cannot name one memorable element, the direction is not bold enough yet.

## Committing

Synthesize the four answers into one sentence that states the direction
plainly, e.g. "An editorial, ink-on-newsprint reading experience with oversized
serif headlines and a single vermilion accent."

A good committed direction is:

- **Clear** — stated in one sentence
- **Extreme** — recognizably one thing, not a blend of three
- **True to purpose** — the tone serves the user's problem
- **Achievable** — it lives within the stated constraints
- **Memorable** — it names its one unforgettable element

If the sentence reads as generic or hedged ("clean, modern, professional"),
the direction is not committed. Push toward a sharper extreme and rewrite it.

## Output

If a missing or contested aesthetic direction remains material after the four
lenses, use `skills/question-management/SKILL.md` to create or reuse a linked
Q###. Record a non-material rationale in the design record instead. Do not
treat the absence of `TBD` text as decision closure.

A single committed-direction statement plus the four lens answers, used as the
fixed reference point while refining the five aesthetic dimensions
(`refine-aesthetics.md`). Bold maximalism and refined minimalism are equally
valid outcomes — intentionality matters, intensity does not.

# Ambiguity Taxonomy

| Type | Detection Cue | Example |
|---|---|---|
| Referential | A pronoun or label could point to multiple things | "it", "the record", "the user" |
| Scope | Boundaries are unclear | "support exports" without listing formats |
| Quantifier | Amount or threshold is undefined | "recent", "many", "fast" |
| Term definition | A key term lacks a shared meaning | "active", "complete", "secure" |
| Intent | The goal is implied but not stated | "clean up the page" |
| Conditional | Behavior depends on an unstated condition | "when needed", "if available" |
| Completeness | A list may be partial | "A, B, etc." |

Severity rises when different interpretations lead to different implementation, validation, cost, or user outcomes.

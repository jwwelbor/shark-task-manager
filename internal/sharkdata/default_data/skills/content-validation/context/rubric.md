# Content Validation Rubric

Use this rubric when a workflow needs more detail than the `SKILL.md` summary.

| Dimension | Good | Weak |
|---|---|---|
| Complete | Required sections are present and contain enough detail to use | Sections are missing, empty, or only restate headings |
| Consistent | Terms, numbers, decisions, and scope match throughout | The artifact contradicts itself or upstream material |
| Traceable | Claims cite source material or explicit assumptions | Claims appear without evidence or context |
| Specific | Requirements and recommendations can be acted on directly | Phrases like "robust", "fast", "clean", or "etc." carry key meaning |
| Audience-fit | The intended reader gets enough context without excess | The artifact assumes unavailable context or buries the main point |
| Decision-ready | Open questions, risks, and next actions are explicit | Readers must infer what to do next |

# Feature: recurring tasks

Our task manager only handles one-off tasks today. We'd like to be able to
mark a task as recurring so it keeps coming back on its own schedule instead
of us having to re-create it by hand.

Please add:

1. A way to set a recurrence rule on a task when it's created (e.g. "this
   task repeats weekly").
2. When a recurring task is completed, the next occurrence should be
   scheduled automatically, carrying forward the same title and recurrence
   rule with an appropriately advanced due date.
3. A way to list the tasks coming up soon (an "upcoming occurrences" view),
   so we can see what's due in, say, the next week, without also showing
   tasks that have already been completed.

Non-recurring tasks should keep working exactly as they do today.

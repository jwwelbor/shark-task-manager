## Open finding

**B077-R40-01 · Blocker · Unfiltered configuration can survive in saved route evidence.** The selection design expressly excludes unfiltered configuration from the record. The published Rider procedure already limits what it retains. Its reader selects three configuration fields and writes them under `readback`. Rider redirects the reader output to the attempt’s route file before inspecting its exit status. Both a successful read and a refusal therefore have a persistence boundary. Revision 40 adds an initial read, a confirmation read with the selected overrides, and a final receipt that retains or refers to the decision. C02 checks that a fresh reader can recover the right reason, inputs, effort and selected triple. C04 checks attribution and the allowed identity fields after refusal. C06 excludes raw prompts, transcripts and credentials. All can succeed if an additional field or referenced evidence file also retains a complete configuration reply containing unrelated settings.

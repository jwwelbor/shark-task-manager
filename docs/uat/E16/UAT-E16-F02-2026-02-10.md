# User Acceptance Testing Guide - E16-F02: Orchestrator Actions

## Feature Overview

E16-F02 implements **Orchestrator Actions** - a system that automatically resolves and populates instruction templates when tasks, features, or epics transition between workflow statuses. The key enhancement in T-E16-F02-008 is replacing the hardcoded string-based placeholder replacement with a **map-based replacer** that can substitute any entity field (title, file_path, status, agent_type, etc.) into instruction templates.

## Prerequisites

- Shark CLI built: `make shark`
- Database accessible (local or Turso cloud)
- Project initialized: `./bin/shark init --non-interactive`
- Advanced workflow profile applied (with orchestrator actions configured in `.sharkconfig.json`)

## Test Scenarios

### Scenario 1: Map-Based Template Population (T-E16-F02-008)

**Tasks covered:** T-E16-F02-008

**Purpose:** Verify that `PopulateTemplate` correctly replaces entity field placeholders from a map.

**Steps:**
1. Run the config package tests:
   ```bash
   go test -v ./internal/config/ -run "TestPopulateTemplate_MapBased"
   ```
2. Verify tests exist for:
   - Single field replacement (`{title}`)
   - Multiple field replacement (`{id}`, `{title}`, `{file_path}`)
   - Unknown placeholder preservation (`{foo}` left as-is)
   - Empty map (template returned unchanged)
   - Backward compatibility (`{task_id}` via map key)

**Success Criteria:**
- [ ] All `TestPopulateTemplate_MapBased_*` tests pass
- [ ] `TestPopulateTemplate_MapBased_UnknownKey` verifies `{unknown}` is preserved in output
- [ ] `TestPopulateTemplate_MapBased_EmptyMap` verifies template returned as-is

### Scenario 2: Entity Placeholder Helper Functions

**Tasks covered:** T-E16-F02-008

**Steps:**
1. Run helper function tests:
   ```bash
   go test -v ./internal/config/ -run "Test.*Placeholders"
   ```
2. Verify `TaskPlaceholders` includes all expected fields:
   - Required: id, task_id, epic_id, feature_id, title, status, priority, created_at, updated_at
   - Optional (when present): slug, file_path, agent_type, description, execution_order, blocked_reason, depends_on, completion_notes, files_changed
3. Verify `FeaturePlaceholders` includes: id, feature_id, title, status, created_at, updated_at, slug, description, file_path, execution_order
4. Verify `EpicPlaceholders` includes: id, epic_id, title, status, priority, created_at, updated_at, slug, description, file_path, business_value

**Success Criteria:**
- [ ] `TestTaskPlaceholders_AllFields` passes - all expected keys present
- [ ] `TestFeaturePlaceholders_AllFields` passes
- [ ] `TestEpicPlaceholders_AllFields` passes
- [ ] Nil pointer fields are correctly omitted from the map

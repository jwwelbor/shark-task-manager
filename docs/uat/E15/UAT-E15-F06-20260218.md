# User Acceptance Testing Guide - E15-F06 Repository Layer Cleanup

## Feature Overview

Feature E15-F06 removes business logic from the repository layer, completing the service layer architecture refactoring for Epic E15. Specifically:

- **T-E15-F06-002**: Progress calculation methods removed from `FeatureRepository`; `FeatureService` owns `RecalculateAndSetProgress` / `RecalculateAndSetProgressByKey`
- **T-E15-F06-003**: Progress calculation methods removed from `EpicRepository`; `status_calculator.go` deleted; `EpicService` owns all progress logic
- **T-E15-F06-004**: Status enrichment methods removed from `TaskRepository` (`GetStatusBreakdown`, `GetStatusBreakdownMap`, `getOrderedStatuses`, `getStatusMetadata`); `FeatureService.GetEnrichedTaskStatusBreakdown` handles workflow-enriched breakdowns; pure SQL batch method `GetStatusBreakdownMapBatch` retained in repository

---

## Prerequisites

- Built binary: `make build` or `go build ./...`
- Shark project with epics, features, and tasks available for testing
- Working directory: project root with `shark-tasks.db`

## Test Scenarios

### Scenario 1: Feature Progress Recalculation (T-E15-F06-002)

**Tasks covered:** T-E15-F06-002

**Steps:**

1. List available features: `./bin/shark feature list`
2. Pick a feature with tasks (e.g., `E15-F06`): `./bin/shark feature get E15-F06`
3. Verify progress percentage is displayed
4. Start a task in that feature: `./bin/shark task start <task-key>`
5. Re-check feature progress: `./bin/shark feature get E15-F06`

**Success Criteria:**
- [ ] Feature progress displays correctly (e.g., "40%")
- [ ] Progress updates after task status changes
- [ ] No errors referencing `CalculateProgress` or `UpdateProgress` on feature repository
- [ ] JSON output works: `./bin/shark feature get E15-F06 --json`

### Scenario 2: Epic Progress Rollup (T-E15-F06-003)

**Tasks covered:** T-E15-F06-003

**Steps:**

### Scenario 3: Task Status Breakdown Display (T-E15-F06-004)

**Tasks covered:** T-E15-F06-004

**Steps:**

1. Get a feature with multiple tasks: `./bin/shark feature get E15-F06`
2. Verify task status breakdown is shown (counts by status)
3. Get JSON: `./bin/shark feature get E15-F06 --json`
4. Check that status breakdown includes enriched metadata (color, phase)
5. Complete a feature (or use a feature with tasks in various statuses): `./bin/shark feature get E15-F05`

**Success Criteria:**
- [ ] Feature get shows task status breakdown (e.g., "todo: 2, in_progress: 1, completed: 3")
- [ ] Status breakdown includes color/phase metadata in JSON
- [ ] No errors referencing `GetStatusBreakdown` or `GetStatusBreakdownMap` on task repository
- [ ] `./bin/shark status E15-F06` works correctly

## Feature Overview

This feature establishes the foundational architecture for the service layer refactoring (Epic E15). It delivers:

1. **TaskService Interface** - Complete service interface with 18 methods for CRUD, lifecycle, and query operations
2. **Dependency Injection Patterns** - Global service accessors for CLI and explicit wiring for HTTP API
3. **Architecture Documentation** - Comprehensive guides for service design, CLI/HTTP integration, testing, and migration

These deliverables provide the foundation for implementing service methods (F02-F07) and refactoring CLI commands from fat controllers to thin wrappers.


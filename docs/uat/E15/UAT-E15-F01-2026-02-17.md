## Implementation Notes

**What was delivered:**
1. **TaskService interface** (`internal/services/task_service.go`):
   - 17 method signatures covering CRUD, lifecycle, query, and dependency operations
   - Two constructors: `NewTaskService` and `NewTaskServiceWithRelationships`
   - Interface-based repository dependencies for testability
   - Comprehensive Godoc comments on all methods

2. **Input/Output DTOs** (`internal/services/task_dto.go`):
   - CreateTaskInput, TaskUpdates, TaskFilters, NextTaskFilters
   - DependencyTree, TaskNode
   - All DTOs support JSON serialization

3. **Global service accessor** (`internal/cli/services_global.go`):
   - `GetTaskService()` function following existing pattern
   - Lazy initialization with panic on DB failure
   - Reuses global DB and workflow service instances

4. **Architecture documentation** (`.claude/rules/architecture.md`):
   - Expanded service layer section with examples
   - Dependency injection patterns with constructor examples
   - Global accessor pattern for CLI usage
   - Mock injection pattern for testing
   - Repository interface pattern

**What was NOT implemented (future tasks):**
- Method implementations (all methods return `fmt.Errorf("not implemented")`)
- Integration with CLI commands (E15-F02)
- Task creation logic implementation (E15-F03)
- Task lifecycle operations implementation (E15-F04)
- HTTP API handlers (future epic)

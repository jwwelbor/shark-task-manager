# User Acceptance Testing Guide - E16-F04: Notes and Context for Epic and Feature

## Feature Overview

E16-F04 extends the notes and context system from task-level to epic and feature levels. This enables:
- Adding notes (comments, decisions, blockers, etc.) to epics and features
- Storing structured context data on epics and features
- Resume commands that aggregate notes/context for quick orientation
- Enhanced `get` commands that display notes and context inline
- Entity-type filtering in notes search
- A polymorphic `entity_notes` table replacing the old `task_notes` table

## Prerequisites

- Shark CLI built: `make shark`
- Database initialized: `./bin/shark init --non-interactive`
- At least one epic and feature exist (E16 and E16-F04 will be used in examples)

## Test Scenarios

### Scenario 1: Epic Notes - Add, List, and View
**Tasks covered:** T-E16-F04-004, T-E16-F04-005, T-E16-F04-008, T-E16-F04-011

**Steps:**
1. Add a comment note to an epic:
   ```bash
   ./bin/shark epic note add E16 --type=comment --content="UAT test comment for epic" --created-by="uat-tester"
   ```
2. Add a decision note:
   ```bash
   ./bin/shark epic note add E16 --type=decision --content="Decided to use polymorphic notes table" --created-by="uat-tester"
   ```
3. List notes for the epic:
   ```bash
   ./bin/shark epic note list E16
   ```
4. View epic details (should include notes section):
   ```bash
   ./bin/shark epic get E16
   ```
5. View in JSON format:
   ```bash
   ./bin/shark get E16 --json
   ```

**Success Criteria:**
- [ ] Notes added without errors
- [ ] `note list` displays notes with type, timestamp, content, and author
- [ ] `epic get` shows a "Notes" section with recent notes
- [ ] JSON output includes a `notes` array with all note fields

### Scenario 6: Notes Search with Entity-Type Filter

1. Search for notes without filter:

   ```bash
   ./bin/shark notes search "test" --entity-type=invalid
   ```
4. Test JSON output:
   ```bash
   ./bin/shark notes search "test" --entity-type=epic --json
   ```

**Success Criteria:**
- [ ] Unfiltered search returns notes from all entity types
- [ ] `--entity-type=epic` returns only epic notes
- [ ] `--entity-type=feature` returns only feature notes
- [ ] `--entity-type=task` returns only task notes
- [ ] Invalid entity type returns clear error message
- [ ] JSON output includes `entity_type` field

## Feature Overview

This feature enhances the Shark CLI display infrastructure by:

1. **Creating unified rendering helpers** (`render_common.go`) with 8 reusable functions for common display sections
2. **Adding valid transitions to JSON output** for epic and feature get commands, enabling AI agents and users to discover allowed status transitions without reading workflow config
3. **Fixing related documents visibility** in planning mode (was previously only visible in aggregation mode)

**Impact**:
- AI agents can now see valid workflow transitions directly in JSON output
- Related documents (PRDs, design docs) visible in planning mode (100% visibility, up from 50%)
- Foundation for E15-F07 rendering consolidation with 8 helper functions

**Changes Made**:
- Created `internal/cli/commands/render_common.go` with 8 helper functions
- Modified `internal/cli/commands/epic.go` to include valid_transitions in JSON (~17 lines)
- Modified `internal/cli/commands/feature.go` to include valid_transitions in JSON (~4 lines)
- Modified `internal/services/display_service.go` to populate ValidTransitions field (~10 lines)
- Added `internal/cli/commands/render_common_test.go` with 39 unit tests (100% coverage)
- Added integration tests to epic_get_integration_test.go and feature_get_integration_test.go

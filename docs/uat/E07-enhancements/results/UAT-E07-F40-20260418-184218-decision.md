## 2. Intended Outcome

- **Business outcome (Epic level):** Support operator-friendly configuration of
  shark's observability pipeline — including eventual file-based log destinations
  so operators don't have to scrape stderr.
- **User outcome (Feature level):** Allow users of `shark` to configure a
  `log_file` path in `.sharkconfig.json` and have log output written to that file.
- **Task outcome (T-001 slice):** Expose `log_file` in the observability config
  struct, ensure it round-trips through JSON load/save, and ensure `shark admin init`
  emits `"log_file": ""` so operators discover the option. Filesystem I/O, path
  handling, and actual file-handle lifecycle are explicitly deferred to
  T-E07-F40-002.

## 2. Intended Outcome

- **Business outcome:** When a developer or AI agent regresses a task (UAT rejection, QA failure), the parent feature and epic automatically reopen to their correct prior status. The dashboard no longer shows "completed" parents while active child work is ongoing.
- **User outcome:** Developers see accurate status on the dashboard. Orchestrator agents receive correct signals about which entities need attention. Manual re-opening of parent chain is eliminated.

## 5. Risks and Issues

### Blocking

**B-01 — REQ-F-003 / AC-12 violation: maybeReopenParentEpic not using cascade**
- File: `internal/services/feature_service.go:847-869`
- Finding: `maybeReopenParentEpic` always calls `legacyMaybeReopenParentEpic` even when `cascadeEnabled()` = true. The cascade helper is never invoked for the `CreateFeature` reopen path.
- Impact: CreateFeature uses aggregation-status fallback (not history-based target). The `auto-reopened:` notes format doesn't match `auto_reopen:` (no label in `shark status history`). REQ-F-003 requires elimination of parallel implementations.
- Spec reference: spec.md:57 ("MUST be refactored"), spec.md:478, T-E07-F38-003 AC-T4

**B-02 — AC-12 NOT MET: No profile-parameterized cascade tests**
- Finding: `TestCascade_BasicProfile` and `TestCascade_AdvancedProfile` do not exist in any test file.
- Impact: AC-12 requires verified behavior under both basic and advanced workflow profiles. Current tests only use one embedded test workflow config.
- Spec reference: spec.md:132, spec.md:643

**B-03 — AC-15 NOT MET: No performance benchmark**
- Finding: `BenchmarkCascade_BothLegs` does not exist in any test file.
- Impact: AC-15 requires measuring ≤50ms P95 for worst-case cascade path. No empirical performance data exists.
- Spec reference: spec.md:135, spec.md:649

### High (Non-blocking for correctness, but quality gap)

**H-01 — AC-14 PARTIAL: Legacy auto-reopen notes not labeled in status history**
- `status_group.go:533` checks `strings.HasPrefix(notes, "auto_reopen:")` (underscore). Legacy path (`legacyMaybeReopenParentEpic`) writes notes starting with `"auto-reopened:"` (hyphen). The label is not applied to legacy-path history rows.
- Impact: CreateFeature reopen events invisible in `shark status history` audit trail with the `[auto-reopen]` label.

**H-02 — Code review quality gap**
- T-E07-F38-003 code review rated AC-T4 PASS despite the implementation showing otherwise. The review did not verify the runtime code path of `maybeReopenParentEpic` when cascade deps are wired.

### Missing Evidence

- Performance data (AC-15/REQ-N-001): no benchmark run results
- Basic/Advanced profile verification (AC-12): no parameterized test output

## 6. UAT Decision

**VERDICT: REJECT**

Three spec-mandated ACs are not met (AC-12, AC-15, REQ-F-003). The feature's primary correctness story for the `TransitionStatus` backward-trigger path is solid — all cascade core tests pass. 2. **Fix B-02**: Add `TestCascade_BasicProfile` and `TestCascade_AdvancedProfile` (table-driven, parameterized over both workflow configs).
3. **Fix B-03**: Add `BenchmarkCascade_BothLegs` and verify ≤50ms P95.

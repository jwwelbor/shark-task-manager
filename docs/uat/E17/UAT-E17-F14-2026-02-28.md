# User Acceptance Testing Guide - Service SRP Refactoring (E17-F14)

## Feature Overview

Split oversized services (TaskService 2,279 lines, FeatureService 1,400 lines, EpicService 1,386 lines) into focused sub-services following SRP, with a shared EntityDocumentService. This is a pure structural refactoring - no behavior changes.

## Prerequisites

- Project builds successfully: `make build`
- All tests pass: `make test`
- Shark CLI binary available at `./bin/shark`

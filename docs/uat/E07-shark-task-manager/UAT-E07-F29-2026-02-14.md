## Feature Overview

This feature adds template variable support for related documents, tasks, features, and epics in orchestrator action instruction templates. When AI agents receive task instructions, they can now automatically see references to related documentation and dependencies.

**Key Capabilities:**
- `{related_docs}` placeholder populates with comma-separated file paths of linked documents
- `{related_tasks}` placeholder populates with comma-separated task keys from context data
- `{related_features}` placeholder populates with comma-separated feature keys
- `{related_epics}` placeholder populates with comma-separated epic keys
- Automatic sync of task frontmatter `related_docs` to database

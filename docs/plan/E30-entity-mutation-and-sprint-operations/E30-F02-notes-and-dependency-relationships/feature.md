# Notes and Dependency Relationships

**Feature Key**: E30-F02-notes-and-dependency-relationships
Notes and Dependency Relationships adds note management and normalized entity relationship handling for dependency-style links across supported entity types. It uses the existing note and entity-relationship services so the viewer can add, remove, and validate relationships without splitting dependency logic across multiple stores.

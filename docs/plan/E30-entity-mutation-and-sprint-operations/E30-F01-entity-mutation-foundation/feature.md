# Entity Mutation Foundation

**Feature Key**: E30-F01-entity-mutation-foundation

Entity Mutation Foundation adds the viewer mutation surface for editable epic, feature, and task fields plus status transitions. It reuses the existing entity update and workflow services so the viewer can submit explicit writes without bypassing validation, history, or orchestrator actions.

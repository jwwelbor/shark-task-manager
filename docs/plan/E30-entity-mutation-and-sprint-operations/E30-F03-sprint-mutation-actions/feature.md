# Sprint Mutation Actions

**Feature Key**: E30-F03-sprint-mutation-actions
Sprint Mutation Actions adds Sprint-mode mutation controls for staging, removing, and reassigning work while keeping capacity and navigation context visible. It reuses the Sprint service so planning actions remain workflow-aware, auditable, and consistent with the existing read-only Sprint overview and report surfaces.

# Task: Add path traversal validation for workflow file path (M-3)

## Goal

The configurable `workflow_config` path in `.sharkconfig.json` (which specifies the location of `.sharkworkflow.json`) is not validated for path traversal attacks. A malicious config could set `workflow_config` to `../../../../etc/passwd` or an absolute path outside the project. Add validation to ensure the resolved workflow file path stays within the project root directory.

## Requirements

### Functional Requirements

- [ ] Validate that the workflow file path does not contain `..` segments that escape the project root
- [ ] Reject absolute paths that point outside the project root
- [ ] Return a clear error message if path traversal is detected
- [ ] Validation should happen in the config loading path before the file is read

### Non-Functional Requirements

- [ ] Should not break relative paths like `config/workflow.json` that stay within the project
- [ ] Should work on both Unix and Windows path separators

## Implementation Plan

### Steps

1. [ ] In `internal/config/workflow_parser.go`, add a path validation function that resolves the workflow file path relative to the project root and checks it stays within bounds
2. [ ] Call this validation in `LoadMultiLevelWorkflow()` when processing the workflow_config setting
3. [ ] Use `filepath.Abs()` and `strings.HasPrefix()` to verify containment
4. [ ] Add tests for: normal relative path, `../` escape, absolute path outside project, symlink edge cases

### Files to Modify

- `internal/config/workflow_parser.go`

## Acceptance Criteria

- [ ] Path `../../../etc/passwd` is rejected with a clear error
- [ ] Path `/tmp/malicious.json` is rejected
- [ ] Path `config/workflow.json` is accepted
- [ ] Path `.sharkworkflow.json` is accepted (default)
- [ ] `make fmt && make lint && make test` passes

## Testing Strategy

- [ ] Table-driven tests with various path traversal attempts
- [ ] Test with valid relative paths that contain `..` but resolve within project (e.g., `subdir/../workflow.json`)

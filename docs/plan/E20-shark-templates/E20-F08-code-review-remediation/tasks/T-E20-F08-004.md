# Task: Add test coverage for ValidateWorkflowFiles and loadWorkflowFile edge cases (M-2, M-7)

## Goal

Two gaps in test coverage:

**M-2**: `ValidateWorkflowFiles()` in `internal/config/workflow_validator.go` lacks test coverage for edge cases such as: empty workflow file, workflow file with valid JSON but no workflow blocks, conflicting definitions between `.sharkconfig.json` and `.sharkworkflow.json`.

**M-7**: `loadWorkflowFile()` in `internal/config/workflow_parser.go` lacks test coverage for edge cases: file exists but is not valid JSON, file exists but contains unexpected top-level structure, file read permission errors.

## Requirements

### Functional Requirements

- [ ] Add tests for `ValidateWorkflowFiles` with: empty file, JSON with no workflow blocks, conflicting entity definitions across both files
- [ ] Add tests for `loadWorkflowFile` with: invalid JSON content, unexpected structure (array instead of object), permission-denied scenario, very large file
- [ ] Verify existing tests in `workflow_file_loading_test.go` and `workflow_validation_dx_test.go` and add missing edge cases

### Non-Functional Requirements

- [ ] Tests must use temp directories (no modifications to project files)
- [ ] Tests should follow existing table-driven patterns in the codebase

## Implementation Plan

### Steps

1. [ ] Review existing tests in `internal/config/workflow_file_loading_test.go` and `internal/config/workflow_validation_dx_test.go`
2. [ ] Add edge case tests for `ValidateWorkflowFiles` in `workflow_validation_dx_test.go`
3. [ ] Add edge case tests for `loadWorkflowFile` in `workflow_file_loading_test.go`

- `internal/config/workflow_validation_dx_test.go`

# Task: Create docs/guides/ops-as-entities.md convention document

## Goal

Create `docs/guides/ops-as-entities.md` documenting the convention that recurring operational work (deploys, devops, infra changes) belongs as shark tasks or change-cards — not in the project checklist — and stating the membership rule that keeps the `/shark project` namespace clean.

## Requirements

### Functional Requirements

- [ ] Document states the convention: recurring operational work = shark tasks or change-cards, optionally under an "Ops" epic
- [ ] Document states the `/shark project` namespace membership rule: activities belong here only if they are pre-epic, one-time, human-driven, and produce durable docs
- [ ] Document explains the rationale: a checkbox cannot model recurrence; shark entities provide history, status, and queryability
- [ ] Document follows the pattern of existing guides in `docs/guides/` (see route-based-workflow.md, observability.md for style)
- [ ] No new mechanism, no Go code, no schema changes

### Non-Functional Requirements

- [ ] Concise — under 150 lines (this is a convention doc, not a reference manual)
- [ ] Readable by both humans and AI agents
- [ ] Actionable — includes examples of what to do vs. not do

## Implementation Plan

### Steps

1. [ ] **Create `docs/guides/ops-as-entities.md`** with:
   - **Overview**: One paragraph explaining the problem (checklists can't model recurrence; ops work becomes invisible)
   - **The convention**: Recurring ops (deploy runs, infra changes, devops tasks) → shark tasks or change-cards
   - **The Ops epic pattern**: Optionally group under an "Ops" epic for visibility; use change-cards for individual deploy events
   - **The project namespace rule**: Pre-epic, one-time, human-driven, produces durable docs → belongs in `/shark project`; everything else → entity
   - **Rationale**: 3–4 bullets explaining why (history, status, queryability vs. static checkbox)
   - **Examples section**: Table or bullet list — "Do this / Not that"

2. [ ] **Add cross-reference** in `skills/shark/verbs/project.md` (created in T-E36-F02-001): a brief note or section pointing to `docs/guides/ops-as-entities.md` for recurring ops guidance

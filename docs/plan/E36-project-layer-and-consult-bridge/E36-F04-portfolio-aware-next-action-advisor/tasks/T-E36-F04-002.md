# Add non-mutating active claim reader

## Goal
Add the claim-service read path that filters expired leases at a caller-supplied time without reclaiming or otherwise mutating claim state.

## Scope
- Modify: `internal/services/claim_service.go`, `internal/services/claim_service_test.go`
- Preserve the existing mutating `ClaimService.List` behavior for claim-management commands.

## Acceptance Criteria
- Satisfy REQ-F-006, REQ-NF-001, and AC-004 claim-source behavior.
- `ListActiveReadOnly` lists once, applies the configured TTL and `EntityClaim.IsExpired`, and never calls `ReclaimExpired` or session/history write paths.

## Test Cases
Implement `test-plan.md` TC-004, including TTL disabled, TTL-1/TTL/TTL+1 boundaries, repository errors, and zero mutation calls. T-E36-F04-006 owns service-output sanitization.

## Integration Contracts
No I-## or X-## contract is registered. T-E36-F04-006 consumes this narrow read interface.

## Design Reference
See `spec.md` Service contracts, Error handling, and the read-only claim decision.

## Brownfield Context
Reuse `ClaimService.ttl`, `ClaimRepository.List`, and `models.EntityClaim.IsExpired`; do not route portfolio advice through the existing sweeping `List` method.

## Notes for Agent
Tests use the existing claim repository mock and fail-on-call mutation counters; no real database belongs in this service test.

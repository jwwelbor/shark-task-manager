# Research plan

## Scope

Define the additive `ClaimService.ListActiveReadOnly` behavior and its focused
service tests. Preserve the mutating `ClaimService.List` contract and exclude
repository, model, CLI, database, session-journal, and workflow changes.

## Recipe

Use the universal SIMPLE recipe with the backend and workflow-operations
modules. Trace the current claim-list and expiry paths, reuse the established
TTL policy, and specify the smallest non-mutating service addition.

## Source set

Read the task, feature research, specification, and TC-004. Inspect the claim
service, its mocks and tests, the claim model's expiry predicate, the claim
repository's list and reclaim methods, TTL wiring, the claim-management caller,
and the route-based claim lifecycle guide.

## Steps

1. Trace current list, reclaim, expiry, TTL-resolution, and session-journal
   behavior.
2. Identify the read-only subset of the existing claim repository interface.
3. Define fixed-time filtering and repository-error behavior.
4. Define boundary and mutation-counter tests without mocking the expiry
   predicate.
5. Record the exact implementation boundary and preserved behaviors.

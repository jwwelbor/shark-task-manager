# Research plan

## Scope

Define the feature-level SQLite test that proves the complete portfolio advice
path stays below one second and uses no more than four set-oriented reads at the
specified 200-epic, 5,000-descendant, and 10,000-relationship scale. Include
determinism, empty and one-epic boundaries, query observation, fixture cleanup,
and no-write evidence. Exclude production optimizations, schema changes, mocks
of repository results, and parallel execution.

## Recipe

Use the universal STANDARD recipe with the supported backend and data
categories. Exercise production repositories and service assembly through the
public `Advise` entry point; instrument only dependency call counts and time.

## Source set

- T-E36-F04-009 and TC-020 caller-path and scale contracts.
- Current portfolio repository integration tests and fixture helpers.
- Production epic, portfolio, claim, workflow, graph, and advice code.
- Isolated SQLite test-database construction and cleanup conventions.

## Steps

1. Map the four production read methods and choose delegating counters.
2. Design exact-scale deterministic epic, descendant, relationship, and claim
   fixtures seeded outside the measured interval.
3. Define the single-call timing and count assertions.
4. Define repeated-output and table-count no-write assertions.
5. Add empty and one-epic lower-bound subtests without weakening the scale gate.
6. Keep the test non-parallel and ensure transaction-backed setup and automatic
   isolated-database cleanup.
7. Verify no production or schema file is required by the test design.

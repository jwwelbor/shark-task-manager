# Task: Add Description field to BundleContentEntry and populate in agent/skill list

## Goal

Extend the `BundleContentEntry` struct in `internal/services/content_bundle_service.go` with a `Description` field populated from frontmatter, and surface it in both the text and JSON output of `shark agent list` / `shark skill list` so the `/shark consult` verb can show a useful menu.

## Requirements

### Functional Requirements

- [ ] `BundleContentEntry` has a new `Description string` field (`json:"description,omitempty"`)
- [ ] `List()` extracts the description from YAML frontmatter (`description:` key) for each entry
- [ ] Text output of `runBundleContentList` renders `name — description` (or just `name` when description is empty)
- [ ] JSON output includes `description` automatically (struct field is exported)
- [ ] A lightweight `extractFrontmatterDescription(content string) string` helper is added (no external YAML library needed — plain string scan)

### Non-Functional Requirements

- [ ] Helper must not panic on malformed frontmatter; return `""` on any parse failure
- [ ] No new dependencies introduced

## Implementation Plan

### Steps

1. [ ] **`internal/services/content_bundle_service.go` lines 56-59** — add `Description string \`json:"description,omitempty"\`` to `BundleContentEntry`
2. [ ] **Same file** — add `extractFrontmatterDescription(content string) string` helper:
   - Trim leading whitespace, check for `---` fence
   - Scan lines until closing `---`, look for a line matching `description:` (or `description: `)
   - Return the trimmed value after the colon; return `""` if not found or on any error
3. [ ] **`List()` method (lines 166-201)** — after reading file content, call `entry.Description = extractFrontmatterDescription(content)` before appending
4. [ ] **`internal/cli/commands/content_bundle.go` lines 105-131** — in `runBundleContentList` text branch:
   - If `entry.Description != ""`, print `  name — description`
   - Otherwise print `  name` (existing behaviour)
5. [ ] Run `make fmt && make lint && make test`

### Technical Approach

- Frontmatter parsing is a simple line scan — the YAML block is always at the top of the file between two `---` fences. A regex or split-based scan is sufficient; no `gopkg.in/yaml.v3` import needed.
- The `Description` field uses `omitempty` so existing JSON consumers that don't expect it are unaffected.

## Acceptance Criteria

- [ ] `shark agent list` shows descriptions next to agent names in text output
- [ ] `shark agent list --json` includes `"description"` in each entry when present
- [ ] `shark skill list` behaves identically for skills
- [ ] `extractFrontmatterDescription` returns `""` for files with no frontmatter
- [ ] All existing tests pass; add a unit test for the helper covering: no frontmatter, empty description, populated description, malformed fence

## Files Changed

- `internal/services/content_bundle_service.go`
- `internal/cli/commands/content_bundle.go`
- `internal/services/content_bundle_service_test.go` (new or updated)

## Dependencies

None — this is a self-contained Go change with no schema migration.

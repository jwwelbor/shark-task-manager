# Task: Create verbs/consult.md skill verb for /shark consult <agent>

## Goal

Create `skills/shark/verbs/consult.md` — the implementation of the `/shark consult <agent> [referent]` verb. The verb lets the user drop into a persona-driven inline consultation with any named agent bundle (architect, qa, security, etc.) without spawning a subagent.

## Implementation Plan

Create the file `skills/shark/verbs/consult.md` with the following logic:

### 1. Argument resolution

- Parse `args`: first token is `<agent>` (optional), remaining tokens form `[referent]` (optional context/question to seed the conversation).
- If no `<agent>` given, print the agent menu and stop:
  - Show output of `shark agent list` (names + descriptions after T-E36-F01-001 lands)
  - Prompt: `Ask again: /shark consult <agent>`

### 2. Agent lookup

- Run `shark agent list` to get all agent names + descriptions.
- Try **exact match** on name first (case-insensitive).
- If no exact match, try **fuzzy match**: agent whose name or description contains the token.
- If still no match, list agents and return: `Agent "<token>" not found. Available: ...`

### 3. Load persona

- Run `shark agent get <resolved-name>` to fetch the agent's content.
- Strip YAML frontmatter (the `---` block at the top) — the remainder is the raw persona prompt.

### 4. Adopt persona inline

- Do NOT spawn a subagent. Adopt the persona in the current conversation context.
- Announce briefly: `[Consulting <DisplayName>]` on its own line.
- Respond in-voice to any `[referent]` the user passed, or prompt them to ask their question if none was given.

### 5. Graceful degradation

- If `shark agent get` fails, return: `Agent "<name>" found in list but content could not be loaded. Check that shark-data is installed.`
- If the agent list itself is empty, suggest `shark admin install-shark-data`.

## Acceptance Criteria

- [ ] `/shark consult` with no args shows the agent menu
- [ ] `/shark consult architect` loads the architect agent and adopts the persona
- [ ] `/shark consult arch` fuzzy-matches to `architect` (or whichever agent contains "arch")
- [ ] `/shark consult architect "is this design sound?"` seeds the opening question
- [ ] Unknown agent name gives a helpful error listing available agents
- [ ] File lives at `skills/shark/verbs/consult.md`

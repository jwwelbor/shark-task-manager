# Task: Wire consult into query.md recognizer and SKILL.md allowlist

## Goal

Register the inline `consult` verb in the two places that gate NL routing and explicit-verb dispatch: the intent recognizer in `skills/shark-rider/verbs/query.md` and the verb allowlist in `skills/shark-rider/SKILL.md`.

## Implementation Plan

### 1. `skills/shark-rider/verbs/query.md` — add consult-intent recognizer

In the NL routing section, maintain a consult-intent recognizer alongside the existing routing guidance:

```
**consult-intent**: user wants to talk to / get advice from a named agent persona
  Trigger phrases: "ask <agent> to/about", "have <agent> review", "consult <agent>",
    "get <agent>'s opinion", "talk to <agent>", "run this by <agent>",
    "what would <agent> say about"
  Route to: verbs/consult.md
  Extract: agent name (first noun after trigger verb), referent (remainder of sentence)
```

### 2. `skills/shark-rider/SKILL.md` — add `consult` row to verb allowlist

In the **Plan & advise** section, register the inline `consult` row alongside the other advice recipes. Keep delegated advice registered separately as `consult-agent`:

```
| consult | `/shark-rider consult <agent> [question]` | Drop into an inline persona consultation with the named agent |
```

Place the inline row after sprint-retrospective guidance and before workflow/status inspection.

# Migrate AddEntityToSprint sprint-status guard from hardcoded strings to workflow.Service delegation

## Description

AddEntityToSprint (sprint_service.go lines 559/565) uses hardcoded 'todo'/'in_progress' strings to guard against assignments to non-planning/non-active sprints (spec §4.2.1). This works correctly but violates the project idiom of delegating status logic to workflow.Service. If the sprint workflow is reconfigured with different planning/active status names, this guard requires a manual update. Surfaced during UAT of T-E19-F03-005.

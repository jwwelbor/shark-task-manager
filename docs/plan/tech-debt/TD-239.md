# Define cross-platform review process descendant lifecycle

## Description

CC-044 review: define and validate cancellation/descendant cleanup for Unix escaped sessions and Windows Git/helper processes across Python and Go. Native Windows behavior is unverified; existing Unix process-group and Windows direct-process boundaries do not ensure descendant retirement. Fingerprints: skills/shark-rider/skills/deep-review/scripts/bounded_git.py#ARCHITECTURE#escaped-session-survives; skills/shark-rider/skills/deep-review/scripts/bounded_git.py#SIBLING#windows-descendant-retirement. See candidate-04a7f37f-review/final-reviewed-pass-with-triage.md in local dev-artifacts.

## Impact

A timed-out review command can return while a detached Unix child or a Windows descendant continues to run. The current deadline is bounded, but it is not a guarantee that every descendant has retired. The Windows behavior needs native verification.

## Resolution Plan

Define the supported process-lifecycle contract for the existing Python and Go Git helpers, assess appropriate platform-specific containment against that contract, and validate the selected behavior with real filter descendants, including native Windows coverage.

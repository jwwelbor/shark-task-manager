# Go/Python adapter --include selection lacks explicit path containment check

## Description

bench/adapters/go/adapter.sh and bench/adapters/python/adapter.sh both forward a caller-supplied --include selection to their underlying test runner (go list / pytest) with no explicit containment check of their own. Go's is incidentally bounded by go list's module-boundary enforcement; Python's has no equivalent boundary. Flagged during T-E40-F05-009's UAT rework (path-containment defect-class sweep) as a possible follow-up outside that task's cited scope. Fix: add the same canonicalized-path containment check admit-scenario.sh now applies to p2p_selection.include, at the adapter layer itself.

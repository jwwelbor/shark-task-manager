# Move FeatureUpdates out of internal/services/epic_dto.go

## Description

FeatureUpdates DTO (used by 'shark feature update' and the new --parallel flag) is defined inside internal/services/epic_dto.go. Confusing for any reader chasing the file name when looking for feature-specific DTOs.

Two cleanup options:
1. Rename epic_dto.go to feature_dto.go (or split EpicUpdates and FeatureUpdates into separate files).
2. Move just FeatureUpdates into a new internal/services/feature_dto.go.

Pre-existing structural quirk that predates the output-sizing branch (PR #79); only flagged because the --parallel work touched FeatureUpdates and the file-name mismatch became visible. Trivial mechanical refactor.

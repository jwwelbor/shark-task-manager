# Fix GetSprintReadiness Factor 2 Detail string: says 'assigned or already completed' but only checks assigned

## Description

AC-2 spec says 'assigned or already completed' but AC-10 two-query constraint means only sprint assignment is checked (not completion status). Detail string in GetSprintReadiness Factor 2 is misleading — should say 'assigned to this sprint' not 'assigned or already completed'. No runtime impact, documentation debt only.

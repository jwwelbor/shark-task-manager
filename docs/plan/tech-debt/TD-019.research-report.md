## Scope

TD-019 proposed extracting common entity-notes rebuild helpers. This research
checks whether those migrations still share a safe, current contract.

## Findings

The reported three-way duplication is no longer a shared contract. The
entity-type and note-type expansion migrations are historical compatibility
paths with different trigger inventories and CHECK semantics. The current
schema removes both polymorphic entity and note-type CHECKs; tests explicitly
protect that state. `rebuildEntityNotesTx` is the only current rebuild caller.
Extracting one helper would either hide those historical differences or alter
their old-database recovery behavior without a current consumer benefit.

## Decisions

Do not add the four proposed helpers. Keep the current rebuild explicit and
defer broader migration infrastructure work to CC-034. If a new live
entity-notes rebuild appears, extract only after two current callers share the
same schema and trigger contract.

**Recommended outcome: wont_fix; the premise is superseded by the current
schema and CC-034 remains the appropriate larger owner.**

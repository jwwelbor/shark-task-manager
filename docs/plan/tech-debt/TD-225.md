# tc115 missing two test-plan-required coverage cases (dry-run mode, evaluator_access round-trip)

## Description

E40-F12 deep-review (angle-E) found two coverage gaps against the feature's own approved test-plan.md in bench/scripts/tests/tc115_i05_producer_test.sh: (1) TC-016's reset-scope regression case only runs under --mode contract (lines 557, 584); test-plan.md's own approved red-team correction explicitly requires repeating it for --mode contract AND --mode dry-run with the option supplied, not only --mode live. Confirmed low real-world risk today since the reset logic has one mode-independent call site, but the shipped test deviates from the approved plan. (2) TC-010's required negative case -- a snapshot's evaluator_access entries must appear verbatim in access.jsonl -- is never exercised; the producer's own _append_access_events() non-empty-list branch has zero coverage across tc115/tc116/tc117 (its own docstring admits events is empty on every real run today). Add a --mode dry-run repetition of TC-016, and a case that constructs/monkeypatches a non-empty evaluator_access list before I05BundleWriter finalizes, asserting entries land verbatim in access.jsonl.

## Impact

Both gaps are in code paths not exercised by real dispatch today (the reset scope's single call site is mode-independent; `_append_access_events()`'s non-empty branch never fires on a live run), so there is no active production risk. But a future mode-conditional regression in the reset path, or a bug in the non-empty `access.jsonl` append path, would ship undetected until it actually triggers — precisely the scenario the test-plan's own prior red-team correction was written to guard against.

## Resolution Plan

1. Add a `--mode dry-run` repetition of both TC-016 sub-cases (stale-entry reset and symlink refusal) with `--i05-bundle-dir` supplied, matching test-plan.md's explicit "contract and dry-run" requirement — or update test-plan.md to record why dry-run coverage was intentionally dropped.
2. Add a TC-010 case that constructs or monkeypatches a snapshot carrying a non-empty `evaluator_access` list before `I05BundleWriter` finalizes it, and assert the same entries land verbatim in `access.jsonl`, mirroring the mutation-based fixture style already used elsewhere in the suite (e.g. TC-008's `mutate_ledger_copy` helper).

# Extract shared walkEmbedded markdown-scan helper for TestEmbedded_* bundle gates

## Description

The four TestEmbedded_* bundle-purity gates in internal/sharkdata/embed_test.go (AgentsDescribeRoleNotWorkflow, SkillsHaveNoStaleAgentSlugs, SkillsHaveNoDeadCollaborationLink, SkillsContainNoBareSharkCLIRefs) repeat the same walkEmbedded + prefix/.md filter + substring-scan + require/assert.Empty skeleton. Extract scanEmbeddedMarkdown(t, prefix, scanFn) so each gate declares only its prefix + banned list + special case. Non-blocker from /deep-review on chore/embedded-default-data-cleanup (2026-06-30); test code, correctness unaffected.

## Impact

Low, isolated to test code. The duplicated skeleton across four gates makes the
bundle-purity tests harder to maintain: any change to the walk/filter logic must
be made in four places, and adding a fifth gate means copying the boilerplate
again. Correctness of the gates is unaffected today.

## Resolution Plan

Extract `scanEmbeddedMarkdown(t, prefix, scanFn)` in
`internal/sharkdata/embed_test.go` that does the `walkEmbedded` + prefix/`.md`
filter + substring scan once, then rewrite the four `TestEmbedded_*` gates
(AgentsDescribeRoleNotWorkflow, SkillsHaveNoStaleAgentSlugs,
SkillsHaveNoDeadCollaborationLink, SkillsContainNoBareSharkCLIRefs) to declare
only their prefix + banned list + any special case. Keep each gate's existing
`require`/`assert.Empty` failure messages.

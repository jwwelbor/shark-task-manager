## Findings

The parser recognizes checklist entries by their first physical line but requires evidence on that same line. Markdown treats a nonblank continuation as part of the preceding list item, so the parser disagrees with rendered document structure.

## Decisions

Join nonblank, non-list continuation lines to the active checklist item before extracting the module ID and evidence. Stop at blank lines or subsequent list items so separate content is not absorbed.

# CLI display commands hardcode status strings for icons, colors, and iteration

## Description

Five CLI command files hardcode workflow status strings for display-only purposes: task_deps.go (status-to-icon map + legend text), task_history.go (status-to-color map), task_resume.go (switch on status for next-steps guidance text), epic_helpers.go (hardcoded status list for breakdown display iteration), feature_helpers.go (status map key access for health/notes display). No business logic impact — output may look incomplete or wrong on custom workflows. Fix: drive display from workflow.Service.GetAllStatuses() + status_metadata config (color/phase fields already exist in config).

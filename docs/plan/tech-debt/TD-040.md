# Decompose E38 team scheduler execution helpers

## Description

Deferred from PR-128 E38 review. internal/team/scheduler.go still keeps executeItem as a large orchestration method. Extract focused helpers for dispatch-step/gate resolution, coordinator actions, claim/CAS acquisition, worker execution/result mapping, claim cleanup, ledger persistence, and event emission. Preserve behavior and keep executeItem as orchestration only. Parent context: E38-F02 / PR-128.

## Impact

The scheduler is harder to review and extend because ownership, dispatch, cleanup,
and persistence decisions are interleaved in one method. This increases the risk
that future lifecycle changes bypass a safety seam.

## Resolution Plan

Extract behavior-preserving helpers around the existing injected interfaces. Keep
the top-level method responsible only for sequencing and ensure each helper has
focused unit coverage.

## Ubiquitous vocabulary

A *transcript entity directory* is the entity-scoped source directory beneath
a run. *Flattening* copies its logs into the collector's flat destination.
A *spawn-agent StageLog* must carry a non-empty `entity_key` so its transcript
and execution evidence retain identity.

## Findings

The runtime already refuses to flatten more than one entity directory. The
canary checks an empty `entity_key` only on its first spawn-agent StageLog, so
a later spawn-agent stage can still carry an empty key. TC-016 confirms the
real canary output mentions the field, but does not prove the shell declaration
still lists it in `STAGELOG_REQUIRED`. TC-014 exercises only a one-directory
success path. The canary fixture override exits before the StageLog-level
empty-key check, so neither negative behavior has a direct regression fixture.

## Decisions

TD-156 remains a small runtime-and-test hardening item. Validate every
spawn-agent StageLog's non-empty key, then add deterministic regressions for
the multi-directory refusal, a later empty StageLog key, and
`STAGELOG_REQUIRED` membership of `entity_key` before resolving the debt.

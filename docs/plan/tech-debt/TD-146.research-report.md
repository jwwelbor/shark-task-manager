# TD-146 research: I-08 per-gate elapsed and cost measurements

## Scope and vocabulary

TD-146 concerns per-review-gate `elapsed_seconds`, `provider_cost_usd`, and
`resolution_cost_usd`. It does not concern the valid run-level I-08 metrics:
`elapsed_time` and `provider_cost`. A gate-level number requires both an
authoritative gate identity join and producer-owned semantics for the portion
of time and cost attributable to that gate.

## Ubiquitous vocabulary

A *per-gate measure* is attributable to one stable review-gate identity. A
*run-level metric* describes the whole retained evaluation. *Resolution cost*
requires an owner-defined lifecycle boundary and cannot be inferred from a
run total.

## Findings

I-08 defines run-level elapsed time and provider cost, not per-gate measures
or resolution cost ([i08-schema.yaml](../../../bench/evaluation/i08-schema.yaml)).
I-07 review-gate records preserve identity and findings but have no measurement
fields ([i07-schema.yaml](../../../bench/runs/i07-schema.yaml)); lifecycle
capture therefore leaves downstream consumers unable to reconstruct a truthful
attribution from retained records. The I-07 producer must record the
owner-defined join during capture, after which downstream consumers can use
it. The F10 aggregator deliberately renders the schema-owned
`GATE_TIME_COST_UPSTREAM_GAP` for every gate rather than deriving numbers from
run totals ([aggregate-lifecycle.sh](../../../bench/scripts/aggregate-lifecycle.sh)).

TC-085 proves this is a permanent contract-gap state: the three per-gate
fields must use the named reason, never `unavailable` or zero
([tc085_review_value_report_test.sh](../../../bench/scripts/tests/tc085_review_value_report_test.sh)).

## Dependency and cross-boundary impact

The producer change would span I-07 capture, I-08 evaluation, the retained
comparison/evidence contract, F10 aggregation, schema tests, and UAT. A local
aggregator change would either select an arbitrary join or synthesize cost and
time allocation, contradicting the current F10 contract and making the report
look measured when it is not.

## Alternatives

1. Preserve the named gap — correct current behavior, but AC-008 stays
   staged.
2. Extend I-07/I-08 with a stable gate identity plus producer-owned elapsed,
   provider-cost, and resolution-cost semantics — viable only after an owner
   specifies attribution and lifecycle boundaries.
3. Allocate run-level totals in F10 — rejected: it invents a statistic and
   has no authoritative join.

## Decisions

Research passes: TD-146 is a real upstream measurement-contract gap, not a
local reporting defect. Advance it to `triaged` to record the classification.
Do not implement until the owner decides the stable per-gate join and
`resolution_cost` semantics. This is an F08/I-07 producer decision, separate
from TD-147's F09/I-08 comparison-semantics decision; neither local consumer
should silently change F10.

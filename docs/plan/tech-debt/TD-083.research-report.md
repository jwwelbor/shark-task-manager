## Findings

Bands and comparisons are per item, so a gate from another corpus item is neither a missing observation nor a zero for the current item's metric. The implementation already uses this correct boundary; the broad wording was ambiguous.

## Decisions

Clarify REQ-F-015 to say the union is per item and variant, and add a cross-item regression test. No aggregation behavior changes.

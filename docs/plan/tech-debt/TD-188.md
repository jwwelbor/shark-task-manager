# run_test.go: GateIngest wiring guard is AST-only, no execution-level companion

## Description

TestRunRunRunControllerDepsAlwaysSetsGateIngest in internal/cli/commands/run_test.go is a source-invariant (AST) test, not an execution-level test proving buildRunControllerGateIngestDeps yields a working coordinator through a real runRun gate dispatch. controller_gate_e2e_test.go already proves controller-side wiring end-to-end (just not via run.go's own construction). Add an execution-level run_test.go case for defense in depth. From E34-F05 code-review round 2, finding R2-F2.

## Impact

Low. `TestRunRunRunControllerDepsAlwaysSetsGateIngest` proves, via `go/parser`,
that both `runner.RunControllerDeps` construction sites in `runRun` set
`GateIngest` to a non-nil value. It guards the exact bug that shipped in
E34-F05-004, where neither site set the field and every `gate_result_v1` step
failed closed the moment an operator ran `shark run` in the foreground. The
residual concern was that a structural check could pass while the coordinator
it builds is non-functional.

## Resolution Plan

Closed `wont_fix`, on the same basis as [[TD-165]]. An execution-level
companion is not reachable and would add nothing:

- Same blocker: `buildTransitioner` (run.go:245) runs on every entity-type
  branch and needs a real database, which `.claude/rules/testing/cli-tests.md`
  forbids; `run_test.go:633-639` records that `test-plan.md` rejected
  seam-injecting those six-plus call sites as disproportionate, and that
  decision D7 sanctions `go/parser` source-invariant checks for this class of
  syntactic wiring property.
- Behavioural coverage of gate ingestion already exists in
  `internal/runner/controller_gate_e2e_test.go`
  (`TestRunController_Run_GateResultV1StepRoutesThroughGateIngest`, plus its
  legacy-step and multi-stage `run_id` siblings). An execution-level test here
  could only re-prove what those already prove.
- The AST guard cannot pass vacuously: it asserts `sitesChecked >= 2`, so it
  fails if its own detection breaks and matches zero construction sites.

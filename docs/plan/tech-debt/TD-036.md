## Context

Deep-review finding N8 on PR #126 (see docs/review/fix-positional-selection-class/code_review/2026-07-11-fix-positional-selection-class-overall-review.md).

`WorkflowConfig.DefaultTransition` (internal/config/workflow/selectors.go) and its `workflow.Service` wrapper document the pass-first StatusFlow contract and are unit-tested, but no production code calls them — the six sound `AvailableTransitions[0]` consumers kept direct picks with //shark:ordered annotations (they consume the NextStatusInfo DTO, not the config). Its EqualFold map scan also subtly diverges from the direct StatusFlow access real sites use.

## Fix

Either migrate one of the annotated [0] sites that has config access to the selector, or delete the selector + wrapper and let the //shark:ordered annotations plus uniqueSortedOutcomeTargets docs carry the contract.

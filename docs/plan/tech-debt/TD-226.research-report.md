# TD-226 research report

## Scope

Investigate the held-back-oracle failure path in `evaluate-lifecycle.sh` and
the retained artifact contract it feeds. The affected capability is the I-08
evaluation record and its `oracle.json` sidecar. The repair extends the
existing synthetic-oracle persistence path; it does not replace the oracle,
the I-08 schema, or byte-preserving retention.

## Findings

`run_oracle()` creates `oracle_output` beside the requested evaluation output
and already centralizes synthetic sidecar writes in `persist_synthetic_oracle()`.
It uses that helper for terminal-stop and missing-checkout `not_run` results.

When the held-back oracle is invoked, `run_oracle()` reads its output file. An
`OSError` or `json.JSONDecodeError` creates the correct in-memory `not_run`
result with a `missing_oracle` reason, but the except branch does not persist
it. The following `isinstance` branch does not correct that result because the
synthetic value is already a dictionary; the `isfile` branch also does not run
because the malformed file exists. Consequently, its corrupt bytes remain at
`oracle_output` even though I-08 receives the synthetic `not_run` verdict.

The retained-artifact boundary is nevertheless strict. `retain_pair` requires
the evaluator sidecar at `evaluation.jsonl + ".oracle.json"`, copies it without
re-serializing it, and records its raw-byte digest in `manifest.json`. F10 then
reads I-08 verdicts verbatim. Any evaluator/sidecar disagreement would become
durable, diagnosable retention evidence rather than being repaired downstream.

`TC-067` proves two existing synthetic-sidecar cases: unavailable checkout and
terminal stop. The added regression executes the evaluator's `run_oracle()`
implementation with a controlled oracle that writes malformed JSON. It asserts
that the returned synthetic `not_run` result equals the rewritten sidecar.

## Decisions

1. Extend the existing `persist_synthetic_oracle()` pattern by calling it in
   the `except (OSError, json.JSONDecodeError)` branch at
   `bench/scripts/evaluate-lifecycle.sh:727-728`. This overwrites the malformed
   sidecar with the exact synthetic result that I-08 records.
2. Do not change `retain_pair`, I-08, or F10 aggregation. They correctly retain
   and consume the evaluator-owned bytes and must not mask an upstream mismatch.
3. Add a regression to `bench/scripts/tests/tc067_lifecycle_evaluation_truth_test.sh`
   before resolving the debt. It must execute the evaluator's `run_oracle()`
   implementation with a controlled malformed held-back-oracle output and
   assert that the returned result equals `evaluation.jsonl.oracle.json`.
4. The report is registered through `TD-226.md` front matter. `shark related-docs
   add --help` supports no tech-debt parent, so no unsupported database link is
   created.

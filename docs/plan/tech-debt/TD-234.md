# Question owner-mismatch error message leaks CLI flag syntax into HTTP API responses

## Description

loadClosableQuestion()'s owner-mismatch error (internal/services/question_workflow_service.go:340) hardcodes '--resolution-owner=%q' CLI flag syntax. This message is shared by both the CLI (internal/cli/commands/question.go) and the HTTP API's resolve/withdraw/supersede handlers (internal/api/question_handler.go), which return err.Error() verbatim in JSON error bodies. API callers see CLI-only flag syntax in their error responses instead of the JSON field name ('owner'). Found by deep-review (canonical-six-angle) on B062 fix branch as non-blocker F1; triaged rather than fixed in-branch to keep the B062 fix surgical (question_service_test.go:737,939 and question_handler_test.go:425-435 already assert this exact wording as part of B062's fix). Related to TD-158 (question CLI flag-surface inconsistency).

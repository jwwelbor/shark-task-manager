# TD-078 research report

## Scope

Preserve a completed benchmark invocation as a collectible record when a ledger builder or diff fails after agent spend.

## Research checklist

- [x] `scope_vocabulary` — Evidence: `docs/plan/tech-debt/TD-078.md`; `bench/scripts/run-one.sh:589-700`.

- [x] `dependency_impact` — Evidence: `bench/scripts/aggregate-runs.sh:461-480` consumes explicit abort explanations.

## Capability map

| Capability | Decision |
| --- | --- |
| Toolchain abort marker | EXTEND with a general post-run abort marker. |

## Findings

The toolchain guard already records a failed post-run phase and lets the collector emit an explainable record. Later ledger commands instead exited the driver, losing the run and its cost.

## Decisions

Write `post/postrun-abort.json` for failed ledger/diff steps and let the collector emit `postrun_check_aborted`; only collector failure remains fatal.

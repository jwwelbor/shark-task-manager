# yaml_loader.go silently falls back to embedded defaults on missing entity YAML (no log)

## Description

internal/config/workflow/yaml_loader.go:119-122 silently skips missing workflow YAML files at dispatch time, falling back to embedded defaults without a log. B023 fixed the validate-time gap (shark validate now errors on missing files), but the loader itself is still silent if validate is bypassed or a YAML is moved after validation. Defense-in-depth: emit a verbose-only trace log naming each missing file and 'using built-in default' so operators can diagnose divergence between expected and actual dispatch behavior. Surfaced during code review of B022/B023 — see docs/review/bugs/code_review/20260511-190456-B023-review.md.

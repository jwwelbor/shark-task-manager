# Repository fallback default terminal statuses hardcoded in bug and change-card repos

## Description

Two repository files define hardcoded fallback terminal status lists: internal/repository/bug/repository.go line 229 (defaultBugTerminalStatuses = ['resolved', 'wont_fix', 'duplicate']) and internal/repository/changecard/repository.go line 18 (defaultChangeCardTerminalStatuses = ['completed', 'declined']). These are used when the workflow service does not provide terminal statuses. At minimum these fallbacks should log a warning; ideally the callers should always provide workflow-derived statuses so the fallback is never reached.

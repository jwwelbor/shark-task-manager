# F06 evidence-root scan skips .git and swallows scan OSErrors

## Description

Frozen E40-F06 bench/scripts/verify-evidence-roots.sh walk_files() excludes every directory named .git and check_root() silently continues after OSError while reading files. A planted byte-identical disclosure copy below .git is therefore hidden, and an unreadable directory or file produces CLEAN instead of a scan error. The identical defect class was fixed in F07 verify-replay-isolation.sh during code review round 3; keep F06 frozen and remediate this separately.

## Impact

F06 can certify an evaluator root as clean while a byte-identical disclosure
copy is reachable below `.git`. It can also certify CLEAN when the scan could
not inspect part of the root, making the evidence-root isolation verdict
non-authoritative under filesystem errors. The surface is frozen for the F07
change, so this remains an independently scheduled hardening item.

## Resolution Plan

Add structural coverage for `.git`-hidden copies and unreadable directories
and files, then remove the `.git` pruning and convert scan/read `OSError`s into
a fail-closed script error. Preserve F06's existing root vocabulary and
matching semantics. Re-run the complete F06 guard test suite before changing
the frozen script.

# TD-026 research report

## Scope

Make an unqualified `shark get --field status` work for single-entity response envelopes without changing explicit dot-notation or top-level lookups.

## Capability map

## Findings

Single-entity command responses wrap their scalar fields under an entity key, while `OutputField` only checks the envelope. A constrained fallback avoids flattening response JSON and rejects ambiguous multi-entity envelopes.

## Decisions

After a direct single-segment lookup fails, inspect known entity envelope keys and return the field only when exactly one nested entity supplies it. Keep top-level and dotted accesses unchanged.

# Replace hardcoded status strings in task dependency auto-block/unblock cascade

## Description

internal/repository/task/dependency.go hardcodes workflow status strings ('in_progress', 'blocked', 'completed', 'archived', 'todo') across 10 sites (lines 222, 229, 348, 355, 362, 399, 463, 490, 502, 509) in the auto-block/unblock cascade logic. Repository layer should not know about workflow semantics. Fix requires either injecting workflow.Service into a service-layer wrapper that owns the cascade logic, or passing terminal/blocked/initial statuses as parameters from the caller. This is the most complex fix in the audit.

# TC-030 never verifies input.agent_visible/replay_reference resolve to an existing file

## Description

AC-001 claims every referenced path exists is asserted by TC-030 but this is not true for these two fields. Fix: resolve both relative to the package directory and assert the resolved file exists, using the same helper already used for predicate-operand/evaluator-path existence checks.

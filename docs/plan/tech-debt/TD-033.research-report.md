# TD-033 research report

## Scope

Eliminate the ActionService loader's duplicate workflow-source resolution while retaining the deprecated JSON guard, one-read startup contract, route-index support, partial-YAML behavior, and canonical defaults.

## Capability map

| Capability | Decision |
| --- | --- |
| Workflow-source resolution | REUSE `LoadMultiLevelWorkflowFromBytes` as the sole resolver. |
| Action-service status map | EXTEND only by projecting each resolved workflow with the existing `workflowToStatusActionData`. |

## Findings

The old ActionService loader duplicated master-index detection, YAML-directory loading, inline parsing, and defaults that the strict parser already owns. That duplication caused the prior master-index wiring omission. The bytes parser preserves TD-023's single-read contract, carries B026 partial YAML results, and gives all omitted entity types the same canonical fallback through `GetWorkflowForLevel`.

## Decisions

Keep the explicit deprecated JSON target guard at the action boundary, then propagate strict parser errors rather than using an `OrDefault` swallowing variant. A targeted regression now proves malformed config is surfaced through the action loader; existing index, single-read, and embedded-default suites cover the remaining historical contracts.

# Preserve Claude provider telemetry while routing worker outcomes

## Description

CC-044 found that Claude JSON output wraps worker text in a provider envelope, while legacy research outcome handling expects the worker outcome directly. Text output exposes the outcome but loses provider metadata needed by E40 transcripts, including verified model and cost. Preserve the raw provider envelope and correctly deliver worker outcomes through an explicitly owned transport contract; do not infer model or cost. Distinct from B083 model-route compatibility and TD-146 upstream per-gate measurement. Local probe failed OAuth authentication, so no successful live Claude execution was verified. Context: CC-044 and dev-artifacts/2026-11-03-cc-044-workflow/defect-sweep-rework.md.

## Impact

Claude-backed research can fail to route its outcome, while text-only output leaves provider model and cost unavailable to transcript consumers. The observed local probe failed authentication and does not establish a successful provider run.

## Resolution Plan

Define the provider transport boundary with the E40 and runner owners, then validate it with a successful provider capture. Preserve explicit missing-data results when metadata is unavailable.

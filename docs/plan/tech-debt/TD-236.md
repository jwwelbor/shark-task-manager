# Task listing prints 'No results found' for all-completed features without hinting --all

## Description

Running 'shark list <epic> <feature>' when all tasks are completed outputs 'INFO No results found'. It does not indicate that completed tasks exist or that '--all' is needed to view them, misleading users into thinking no tasks exist.

## Impact

When all tasks in a feature are completed, running `shark list <epic> <feature>` prints `INFO No results found`. Users and AI agents interpreting this output infer that the feature has zero tasks rather than completed tasks, causing unnecessary confusion or re-generation attempts unless `--all` is explicitly passed.

## Resolution Plan

Update task list formatting in `internal/cli/commands/list.go` (and empty message handling in `internal/cli/root.go`) so that when the total task count is greater than zero but all tasks are filtered out due to completion, the output explicitly states how many completed tasks were omitted and provides the hint to pass `--all` (e.g., `8 completed tasks hidden; run with --all to display`).

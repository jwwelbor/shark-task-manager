# TD-079 research report

## Scope

Pin outcome precedence when the watchdog cap fires while `shark run` is delivering a result.

## Findings

The collector preferred a delivered RunResult over the cap marker. That classified a cap-fired run as completed while the driver correctly skipped post-run metrics, producing an unexplained absence.

## Decisions

Make `exit_status.timed_out` authoritative. A result delivered during grace is not used because the cap invalidates the settled-checkout measurement contract.

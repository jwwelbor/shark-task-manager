## Findings

### Finding 1: Regression test DOES exist and is committed

**Status**: RESOLVED ✓  
**Location**: bench/scripts/tests/tc007_ledger_reproducibility_test.sh, lines 230-262

**Evidence**:
- Commit b3198e21 (2026-08-05 19:23:19) adds tc007_ledger_reproducibility_test.sh as a new file with 474 lines
- Lines 230-262 contain the regression block labeled "Regression: package that fails to BUILD (TD-075)"
- Test structure:
  ```bash
  # Line 237: label
  echo "TC-007: regression - go test -json build failure (TD-075)"
  
  # Lines 239-242: checkout setup
  buildfail_dir="$WORKDIR/buildfail"
  buildfail_checkout="$buildfail_dir/checkout"
  buildfail_output="$buildfail_dir/ledgers"
  "$CHECKOUT_SCRIPT" "$BASE_SHA" "$buildfail_checkout" >/dev/null
  
  # Lines 244-246: inject failure (invalid Go syntax)
  buildfail_cart_go="$buildfail_checkout/pkg/cart/cart.go"
  [[ -f "$buildfail_cart_go" ]] || fail "..."
  printf '\nthis is not valid go syntax {{{\n' >>"$buildfail_cart_go"
  
  # Lines 249-251: invoke build-ledgers.sh and capture exit
  set +e
  "$BUILD_LEDGERS_SCRIPT" "$buildfail_checkout" "$buildfail_output" >"$buildfail_dir/build.log" 2>&1
  buildfail_exit=$?
  set -e
  
  # Line 253: assert non-zero exit
  [[ "$buildfail_exit" -ne 0 ]] || fail "..."
  
  # Lines 255-257: assert no ledger written (all-or-nothing guarantee)
  if [[ -e "$buildfail_output/tests.json" || -e "$buildfail_output/lint.json" ]]; then
    fail "..."
  fi
  
  # Lines 259-260: assert diagnostic names failure and package
  grep -qi "build failure" "$buildfail_dir/build.log" || fail "..."
  grep -qi "pkg/cart" "$buildfail_dir/build.log" || fail "..."
  
  # Line 262: closure statement
  echo "TC-007: build-failure regression correctly rejected (exit $buildfail_exit, no ledger written) -- closes TD-075"
  ```

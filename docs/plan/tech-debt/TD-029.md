# Schema columns started_at/completed_at/blocked_at are coupled to specific hardcoded status names

## Description

internal/repository/task/repository.go has DB timestamp columns (started_at, completed_at, blocked_at) that are tied to hardcoded status names at lines 1179, 1182, 1185, 1232, 1287, 1290, 1293, 1340. The columns are set when status transitions to 'in_progress', 'completed', or 'blocked'. In configurable workflows these status names may differ. This is a schema design issue — a DB migration would be required to make it fully status-agnostic (e.g. rename to first_active_at, terminal_at, etc. or use a generic event log). Requires design discussion before implementation.

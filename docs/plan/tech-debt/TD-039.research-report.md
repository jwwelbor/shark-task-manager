# TD-039 research report

## Scope

Replace raw fatal and non-fatal assertions in the three named workflow-config test files with the repository-standard testify helpers without changing test behavior.

- [x] `scope_vocabulary` — Evidence: `docs/plan/tech-debt/TD-039.md:1-12`; `docs/architecture/coding-standards/testing.md` requires `require` for fatal and `assert` for non-fatal checks.

## Findings

The raw assertions are mechanical replacements. `require` preserves immediate failure for setup and error-type assertions; `assert` preserves accumulated diagnostics for value checks.

# Consolidate triage-routing prose into a single shared contract reference

## Description

B066's research report (Decision #3) called for a shared contract document describing how non-blocker findings route through the triage skill's decision tree. The actual fix instead inlines near-duplicate prose independently across `review-code.md` (multiple call sites), `tech-lead.md`, and `consolidator.md`. Found during B066 code review (finding F6/F7).

## Impact

The next time this contract changes (e.g. triage gains a new step, or the outcome vocabulary changes), a maintainer must find and edit every independent prose copy by hand across these files. Missing one silently reproduces B066's original symptom (a review-finding producer that no longer routes findings correctly).

## Resolution Plan

Extract the triage-routing contract into one canonical reference doc (e.g. under `skills/shark-rider/skills/triage/` or a shared `context/` doc) and have `review-code.md`, `tech-lead.md`, and `consolidator.md` reference it instead of repeating the prose.

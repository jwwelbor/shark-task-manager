# shark get --field status should auto-resolve to type.status (envelope-shape leak)

## Description

--field status returns exit 4 because top-level envelope is {display_mode, feature|task|epic, notes, orchestrator_action}. Status nests under feature.status etc. E27-F11 hit same shape with --field size. Options: (1) auto-resolve unfound top-level field to single entity key prefix, (2) flatten common fields. Workaround: --field feature.status. Surfaced 2026-05-12 by /shark run E01-F06 in wormwoodGM. Ref: dev-artifacts/2026-05-12-shark-debugging/shark-run-e01-f06-issues.md Issue 1.

# Consolidate truncate helpers around rune-aware fitColumn/truncateRunes

## Description

Five near-identical truncate-with-ellipsis helpers exist across two packages. The new rune-aware truncateRunes/fitColumn (added by CC-036) supersede them. Consolidate so callers stop reaching for byte-based variants.

In internal/cli/commands/:
- truncateString at status_group.go:522
- truncateBugString at bug.go:627
- truncateTdString at tech_debt.go:603
- truncateTitleWithEllipsis at epic_helpers.go:110 (docstring claims byte-level slicing is intentional for legacy parity — verify before swapping; ASCII titles unchanged, non-ASCII output may shift one byte boundary)

In internal/runner/:
- TruncateOutput at output_format.go:19 — rune-based but uses '…' (U+2026) and flattens newlines. Behavior differs from truncateRunes ('...' and preserves newlines).

Plan: delete the four byte-based dupes in commands/, swap callers to truncateRunes/fitColumn. Optional second step: extract a shared util in internal/utils/ that both runner and commands use, with a flag for ellipsis style.

Net: ~30 lines removed, parallel implementations collapsed.

## Ubiquitous vocabulary

*Compact* Question projections omit workflow state. *Full* projections are limited to the current responder or resolution owner. A *workflow read* that bypasses this split is a new disclosure contract, not help text.

## Findings

Current `question resolve --help` documents claim → respond → resolve, all resolution kinds and pointer formats. Alias compatibility and conflict rejection are covered by `question_test.go`; commit `af347262` already delivered the actionable correction. B062's owner mismatch is separately resolved. No live CLI documentation defect remains.

## Decisions

Mark TD-158 `wont_fix` as already remediated. Do not add an unauthenticated workflow read: it requires an explicit product/security owner decision and separate change scope.

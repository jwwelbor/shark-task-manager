# advance_guard: enforceAdvanceGuard compares raw status, callers populate normalized status

## Description

internal/services/entity_service.go's enforceAdvanceGuard is called with the raw stored status (currentStatus := entity.GetStatus(), line 269), but every documented caller convention (gatepersist/adapters.go, runner/controller.go via NextStatusInfo.CurrentStatus) populates opts.FromStatus with the normalized/alias-resolved status. An entity still parked under a legacy alias name would fail every guarded transition with ErrAdvanceGuardStaleFromStatus once advance_guard.enabled is true. Pre-existing from PR #133 (2293f198), predates E34-F05, not introduced or fixable by any E34-F05 task. Found by Codex red-team during E34-F05 code-review round 5, verified as real and out of scope.

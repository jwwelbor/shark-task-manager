# Add direct E38 team-run item lookup and CAS support

## Description

Deferred from PR-128 E38 review. Ledger transitions in internal/team/ledger_service.go repeatedly load and scan complete item lists before CompareAndSetItem. Add a repository GetItemByID seam and use direct lookup/CAS where the contract permits, preserving ownership, attempt, idempotency, and race behavior. Parent context: E38-F01/F02 / PR-128.

## Impact

Full-list scans add unnecessary database work for every result transition and
make the CAS path less explicit. The cost is currently modest for small runs,
but grows with run membership and retry activity.

## Resolution Plan

Add a narrowly scoped repository item lookup by run and item ID, then route
validation and post-CAS reloads through it. Preserve the existing status,
attempt, ownership, and idempotency checks and retain race-focused tests.

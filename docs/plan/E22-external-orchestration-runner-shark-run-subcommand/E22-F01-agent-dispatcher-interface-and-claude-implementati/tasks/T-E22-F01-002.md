# Define AgentDispatcher interface, DispatchInput, DispatchResult, and error types

## Goal

Create the new `internal/runner/` package and define the foundational types that the entire E22 dispatcher subsystem depends on. This is a pure type-definition task with no subprocess logic — it establishes the interface contract that ClaudeDispatcher (T-E22-F01-003) and all future dispatchers implement.

## Scope

- Files to create:
  - `internal/runner/dispatcher.go` — AgentDispatcher interface, DispatchInput struct, DispatchResult struct, ToolNotFoundError struct, AgentFailedError struct

## Acceptance Criteria

See spec.md Functional Requirements REQ-F01-001 through REQ-F01-003, REQ-F01-007, REQ-F01-008.

- AC-T1: `AgentDispatcher` interface has exactly `Dispatch(ctx, DispatchInput) (*DispatchResult, error)` and `Name() string`
- AC-T2: `DispatchInput` has all 10 fields from REQ-F01-002 (Instruction, WorkingDir, EntityKey, EntityType, Status, AgentType, Model, MaxTurns, AllowedTools, DisallowedTools)
- AC-T3: `DispatchResult` has all 5 fields from REQ-F01-003 (ExitCode, Stdout, Stderr, Duration, Command)
- AC-T4: `ToolNotFoundError` implements error with message format from REQ-F01-007 and is matchable via errors.As
- AC-T5: `AgentFailedError` implements error with exit code in message from REQ-F01-008 and is matchable via errors.As
- AC-T6: Package compiles with `go build ./internal/runner/`

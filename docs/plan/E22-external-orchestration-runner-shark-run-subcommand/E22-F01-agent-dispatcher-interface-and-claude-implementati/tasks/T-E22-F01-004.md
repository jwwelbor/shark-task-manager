# Write unit tests for dispatcher types, error types, and ClaudeDispatcher command construction

## Goal

Write the complete test suite for the `internal/runner` package and the config extension tests. Tests must use `cmdFactory` function field substitution (no real subprocess execution) for command construction verification, and the `TestHelperProcess` pattern for output capture and exit code tests. Config tests extend existing test files in `internal/config/`.

## Scope

- Files to create:
  - `internal/runner/dispatcher_test.go` — type tests TC-001 through TC-006, interface satisfiability INT-F01-1, DefaultDisallowedTools INT-F01-2
  - `internal/runner/claude_dispatcher_test.go` — command construction tests TC-007 through TC-020
- Files to modify:
  - `internal/config/orchestrator_action_test.go` — add TC-021, TC-022
  - `internal/config/action_service_test.go` — add TC-023

## Acceptance Criteria

See spec.md Section 6 (Testing Strategy) for the full test table.

- AC-T1: All 20 unit test cases (TC-001 through TC-020) are implemented in `internal/runner/`
- AC-T2: All 3 integration scenario checks (INT-F01-1, INT-F01-2, INT-F01-3) are implemented
- AC-T3: All 3 config extension tests (TC-021 through TC-023) are added to existing `internal/config/` test files
- AC-T4: No test invokes a real `claude` binary — all command construction tests use `cmdFactory` override
- AC-T5: TC-015, TC-017, TC-018, TC-019 use the `TestHelperProcess` pattern for subprocess behavior simulation
- AC-T6: TC-016 uses PATH manipulation or a `lookPathFunc` override to simulate missing `claude` binary
- AC-T7: `make fmt && make lint && make test` passes with zero failures across all packages

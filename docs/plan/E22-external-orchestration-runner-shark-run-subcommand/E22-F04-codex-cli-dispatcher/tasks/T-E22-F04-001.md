# Task: Implement CodexDispatcher following ClaudeDispatcher pattern

## Goal

Create `internal/runner/codex_dispatcher.go` implementing `AgentDispatcher` for the
OpenAI Codex CLI, mirroring `ClaudeDispatcher` structurally (same fields, same
dispatch loop, same error types).

## Reference

Pattern source: `internal/runner/claude_dispatcher.go`

## Implementation

Create `internal/runner/codex_dispatcher.go` with:

- `CodexDispatcher` struct with `cmdFactory` and `lookPathFunc` fields (same
  testability hooks as `ClaudeDispatcher`)
- `NewCodexDispatcher()` constructor wiring `exec.CommandContext` and `exec.LookPath`
- `Name() string` returning `"codex"`
- `Dispatch(ctx, input) (*DispatchResult, error)` — identical flow to
  `ClaudeDispatcher.Dispatch`:
  1. `lookPath("codex")` — return `&ToolNotFoundError{Tool: "codex"}` if missing
  2. Build args via `buildCodexArgs(input)`
  3. Create cmd, set `cmd.Dir` when `WorkingDir != ""`
  4. Capture stdout/stderr via concurrent goroutines (prevent pipe deadlock)
  5. Call `cmd.Wait()`, measure duration
  6. Return `&AgentFailedError{...}` on non-zero exit, `*DispatchResult` on success
- `buildCodexArgs(input DispatchInput) []string`:
  - `-p <instruction>` (prompt flag — verify against `codex --help` if available,
    fall back to `-p` matching claude convention)
  - `--model <model>` when `input.Model != ""`
  - `--max-turns <n>` when `input.MaxTurns > 0`
  - `--allowedTools <tool>` for each entry in `input.AllowedTools`
  - `--disallowedTools <tool>` for each entry in `DefaultDisallowedTools` then
    `input.DisallowedTools`

## Acceptance Criteria

- `CodexDispatcher` implements `AgentDispatcher` interface (compile-time verified)
- `Name()` returns `"codex"`
- `ToolNotFoundError{Tool: "codex"}` returned when binary absent
- `DefaultDisallowedTools` always included in disallowed args
- Context cancellation kills subprocess (inherited from `exec.CommandContext`)
- `DispatchResult.Duration` set to wall-clock time
- `make build` passes with no new warnings

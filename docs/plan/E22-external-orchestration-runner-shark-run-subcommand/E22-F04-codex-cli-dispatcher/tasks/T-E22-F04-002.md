## Implementation

Create `internal/runner/codex_dispatcher_test.go` with parallel coverage:

| Test | Verifies |
|------|----------|
| `TestCodexDispatcher_Name` | `Name()` returns `"codex"` |
| `TestCodexDispatcher_BasicCommand` | binary name = `"codex"`, `-p` present, instruction as single arg |

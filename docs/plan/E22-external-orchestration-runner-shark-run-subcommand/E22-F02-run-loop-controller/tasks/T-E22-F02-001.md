# T-E22-F02-001: Define RunController data types: RunOptions, RunResult, StageLog, interfaces

## References
- spec.md §2 REQ-F02-002 (EntityTransitioner), REQ-F02-003 (PlaceholderGenerator), REQ-F02-005 (RunOptions), REQ-F02-006 (RunResult), REQ-F02-007 (StageLog)
- spec.md §5.3 (Interface Contracts, RunControllerDeps)
- test-plan.md §2 TC-F02-001, TC-F02-002, TC-F02-003

## Goal

Define all data types and interfaces used by the RunController in `internal/runner/controller.go`. This task produces the type foundation consumed by T-E22-F02-002 (constructor) and T-E22-F02-003 (run loop).

## File

`internal/runner/controller.go` (new file — types section only, ~80 lines)

## Deliverables

- `EntityTransitioner` interface with `TransitionStatus` and `GetNextStatus` methods matching existing service signatures (spec.md §5.3)
- `PlaceholderGenerator` interface with `GeneratePlaceholders` method (spec.md §5.3)
- `RunControllerDeps` struct with fields: `Transitioner`, `Placeholders`, `ActionSvc`, `WorkflowSvc`, `Dispatchers` (spec.md §5.3)
- `RunOptions` struct: `DryRun bool`, `Verbose bool`, `WorkingDir string` (REQ-F02-005)
- `RunResult` struct with all fields: `EntityKey`, `FinalStatus`, `StagesCompleted`, `Stages`, `Outcome`, `TotalDuration`, `Error` — all JSON-tagged (REQ-F02-006)
- `StageLog` struct: `Status`, `Action`, `AgentType`, `Provider`, `Duration`, `ExitCode` — all JSON-tagged (REQ-F02-007)

## Acceptance Criteria

- [ ] All interfaces match signatures in spec.md §5.3 exactly
- [ ] `RunResult.Outcome` valid values documented as constants or comments: `"completed"`, `"paused"`, `"failed"`, `"already_terminal"`, `"no_action"`
- [ ] All structs have `json` struct tags
- [ ] File compiles with `make build`
- [ ] No database schema changes (REQ-F02-NF-002)

## Dependencies

- E22-F01 (AgentDispatcher interface must exist in `internal/runner/dispatcher.go`)
- `internal/services` TransitionOptions, TransitionResult, NextStatusInfo types
- `internal/config` ActionService interface
- `internal/workflow` Service type

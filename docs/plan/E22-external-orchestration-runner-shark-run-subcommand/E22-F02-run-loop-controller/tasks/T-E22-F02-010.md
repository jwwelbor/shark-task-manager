## Goal

Write `internal/cli/commands/run_test.go` covering argument parsing, output formatting, and error-to-exit-code mapping for the `shark run` command. Also write a minimal test for `GetActionService()` caching behavior.

## Files

- `internal/cli/commands/run_test.go` (new file, ~100 lines)
- Accessor test added to `internal/cli/services_global_test.go` or inline (~20 lines)

## Test Cases

CLI command tests (mocked RunController — no real DB):
- Valid task key parsed and passed to controller
- Valid feature key parsed and passed to controller
- `--dry-run`, `--verbose`, `--workdir` flags passed to `RunOptions`
- `--json` flag causes JSON output of `RunResult`
- `AgentFailedError` from controller → exit code 2
- Entity-not-found error → exit code 1
- Human-readable output includes stage progress lines

Accessor tests:
- `GetActionService` returns non-nil on second call (sync.Once caching)
- Same instance returned on repeated calls

- [ ] Exit code mapping verified for AgentFailedError and not-found
- [ ] Accessor sync.Once caching verified

# T-E22-F02-002: Implement RunController struct with constructor injection and dependency validation

## References
- spec.md §2 REQ-F02-001 (constructor injection, nil validation)
- spec.md §5.3 (RunControllerDeps)
- test-plan.md §2 TC-F02-001-1 through TC-F02-001-5

## Goal

Define the `RunController` struct and `NewRunController` constructor in `internal/runner/controller.go`. The constructor validates required dependencies and panics on nil, matching patterns in existing service constructors.

## File

`internal/runner/controller.go` (extends T-E22-F02-001 file, ~40 additional lines)

## Deliverables

- `RunController` struct with unexported fields matching `RunControllerDeps` fields
- `NewRunController(deps RunControllerDeps) *RunController` constructor
- Constructor panics with descriptive message when `Transitioner`, `ActionSvc`, or `WorkflowSvc` is nil (REQ-F02-001 AC)
- Constructor initializes empty map for `Dispatchers` if nil (prevents nil map panic at dispatch time)
- Stub `Run(ctx context.Context, key string, opts RunOptions) (*RunResult, error)` method — returns `nil, nil` as placeholder (implementation in T-E22-F02-003 through T-E22-F02-006)

## Acceptance Criteria

- [ ] `NewRunController(deps)` returns non-nil `*RunController` when all required deps provided
- [ ] Panics with message containing dependency name when Transitioner, ActionSvc, or WorkflowSvc is nil
- [ ] `Run` stub compiles and returns `(nil, nil)`
- [ ] `make build` passes

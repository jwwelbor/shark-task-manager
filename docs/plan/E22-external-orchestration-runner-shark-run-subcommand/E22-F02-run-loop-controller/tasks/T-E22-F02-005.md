## Goal

Implement the non-spawn_agent branches of the action routing switch within the `Run` method, plus dry-run mode logic, all in `internal/runner/controller.go`.

## File

`internal/runner/controller.go` (action routing switch branches, ~50 lines)

## Action Routing

Uses `config.ActionSpawnAgent`, `config.ActionPause`, `config.ActionAdvanceStatus`, `config.ActionCascade`, `config.ActionArchive`, `config.ActionWaitForTriage`, `config.ActionCheckOrResume` constants.

- `pause` / `wait_for_triage` / `check_or_resume`: return `RunResult{Outcome: "paused", FinalStatus: currentStatus}`
- `advance_status`: call `GetNextStatus`, take `AvailableTransitions[0]`, call `TransitionStatus` (no agent dispatch), continue loop
- `archive`: return `RunResult{Outcome: "completed"}` (terminal)
- `cascade`: treat as advance_status for loop purposes (fire-and-forget cascade is future work)

## Dry-Run Mode (REQ-F02-014)

When `RunOptions.DryRun == true` at start of iteration:
- Print status, action type, agent type, provider, and first 200 chars of instruction to stderr
- Skip `dispatcher.Dispatch()` call
- Skip `transitioner.TransitionStatus()` call
- Simulate advancement via `GetNextStatus()` and `AvailableTransitions[0]`
- Continue loop; return `RunResult{Outcome: "completed"}` with all stages marked dry-run

## Acceptance Criteria

- [ ] `pause` action returns `Outcome: "paused"` with no dispatch, no transition
- [ ] `wait_for_triage` and `check_or_resume` behave same as `pause`
- [ ] `advance_status` calls `TransitionStatus` but not `Dispatch`, continues loop
- [ ] `archive` returns terminal result
- [ ] Dry-run: no `Dispatch` or `TransitionStatus` calls made
- [ ] Dry-run: stderr output contains status, action, and truncated instruction
- [ ] Dry-run returns `Outcome: "completed"` with all stages listed

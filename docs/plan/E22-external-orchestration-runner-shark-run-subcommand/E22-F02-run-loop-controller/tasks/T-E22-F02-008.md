# T-E22-F02-008: Implement shark run Cobra command with entity-type adapters in run.go

## References
- spec.md §2 REQ-F02-010 (shark run Cobra command), REQ-F02-011 (Controller Wiring)
- spec.md §5.4 Decision 2 (per-entity-type adapter), Decision 3 (bug/change_card wrapping)
- spec.md §5.5 (Services Consumed table), §5.6 (file organization)
- test-plan.md §2 TC-F02-010, TC-F02-011

## Goal

Create `internal/cli/commands/run.go` with the `shark run` Cobra command, entity-type adapter implementations for `EntityTransitioner` and `PlaceholderGenerator`, and controller wiring.

## Files

- `internal/cli/commands/run.go` (new file, ~150 lines)

## Deliverables

- `runCmd` Cobra command registered via `init()` as `cli.RootCmd.AddCommand(runCmd)`
- Flags: `--dry-run bool`, `--verbose bool`, `--workdir string`
- Uses `ParseGetArgs(args)` from `internal/cli/commands/helpers.go` to detect entity type and key
- `entityTransitionerAdapter` struct implementing `EntityTransitioner`:
  - task/feature/epic: delegates to `GetTaskService().TransitionStatus` / `GetFeatureService().TransitionStatus` / `GetEpicService().TransitionStatus` and corresponding `GetNextStatus`
  - bug: wraps `GetBugService().AdvanceBugStatus` to construct `TransitionResult` (per spec.md Decision 3)
  - change_card: wraps `GetChangeCardService().AdvanceChangeCardStatus` similarly
- `placeholderGenAdapter` struct implementing `PlaceholderGenerator`: dispatches to `config.TaskPlaceholders()` / `config.FeaturePlaceholders()` etc. based on entity type
- Controller wiring: builds dispatchers map `{"": runner.NewClaudeDispatcher(nil), "anthropic": runner.NewClaudeDispatcher(nil)}`, calls `GetActionService(ctx)`, calls `GetWorkflowService().ForLevel(level)`
- Output: on `--json`, marshals `RunResult` to JSON; on human output, prints stage-by-stage progress and final summary
- Error handling: `AgentFailedError` or `ToolNotFoundError` → exit code 2; entity-not-found → exit code 1

## Acceptance Criteria

- [ ] `shark run E07-F01-001` command registered and callable
- [ ] All three flags parsed and passed to `RunOptions`
- [ ] Thin wrapper pattern: parse → wire → call `controller.Run()` → format
- [ ] `--json` outputs valid JSON `RunResult`
- [ ] `make build` passes

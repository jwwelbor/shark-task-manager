# T-E22-F02-004: Implement dispatcher selection by provider and DispatchInput construction

## References
- spec.md §2 REQ-F02-008 (Dispatcher Selection by Provider), REQ-F02-009 (DispatchInput Construction)
- spec.md §5.4 Decision 1 (PlaceholderGenerator adapter)
- test-plan.md §2 TC-F02-008-1 through TC-F02-008-4, TC-F02-009-1 through TC-F02-009-2

## Goal

Implement dispatcher selection logic and `DispatchInput` construction within the `Run` method in `internal/runner/controller.go`. This is the spawn_agent branch of the action routing switch.

## File

`internal/runner/controller.go` (spawn_agent branch within the Run method, ~30 lines)

## Deliverables

- Helper method or inline logic `selectDispatcher(provider string) (AgentDispatcher, error)` that:
  - Uses `""` key when provider is empty (REQ-F02-008)
  - Uses `"anthropic"` key for explicit anthropic provider
  - Returns descriptive error listing available keys when provider has no matching dispatcher
- `DispatchInput` construction from `PopulatedAction` and entity context per REQ-F02-009:
  - `Instruction` from `PopulatedAction.Instruction`
  - `WorkingDir` from `RunOptions.WorkingDir`
  - `EntityKey`, `EntityType`, `Status`, `AgentType` from entity context and action
  - `Model` from `PopulatedAction.Model`

## Acceptance Criteria

- [ ] Empty provider selects `""` dispatcher key
- [ ] `"anthropic"` provider selects `"anthropic"` dispatcher key
- [ ] Unknown provider returns error containing provider name and available keys
- [ ] All `DispatchInput` fields populated per REQ-F02-009 AC list
- [ ] `make build` passes

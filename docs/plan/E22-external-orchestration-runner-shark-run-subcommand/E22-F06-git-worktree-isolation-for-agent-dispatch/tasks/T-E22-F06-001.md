# Task: Add worktree isolation support to run command

## Goal

Add a `--worktree` flag to `shark run` that creates an isolated git worktree
for each agent dispatch, so agents work in a dedicated branch and directory
without polluting the main working tree.

## Requirements

### Functional Requirements

- [ ] Add `--worktree` flag to `shark run` command (bool, default false)
- [ ] When `--worktree` is set, create a git worktree at `.shark-run-worktrees/<entity-key>-<timestamp>` on a new branch `shark-run-<entity-key>-<timestamp>` before dispatching any agents
- [ ] Set `RunOptions.WorkingDir` to the worktree path so agents run inside the isolated tree
- [ ] On completion (success or error), clean up the worktree with `git worktree remove <path>`
- [ ] Expose worktree creation and cleanup as injectable helper functions for testability

### Non-Functional Requirements

- [ ] Tests use mocks — no real git worktrees created in tests
- [ ] Cleanup is deferred so it always runs even on error paths
- [ ] Worktree path and branch name include both entity key and timestamp for uniqueness

## Implementation Plan

### Steps

1. [ ] Add `--worktree` flag registration in `run.go` `init()`
2. [ ] Add `WorktreeCreator` interface and `GitWorktreeCreator` implementation in `internal/runner/worktree.go`
3. [ ] Integrate worktree creation before `controller.Run()` and cleanup via `defer` in `runRun()`
4. [ ] Add `worktree_test.go` with mock-based tests for flag handling and cleanup behavior

### Technical Approach

- Worktree path: `.shark-run-worktrees/<sanitized-key>-<unix-timestamp>`
- Branch name: `shark-run-<sanitized-key>-<unix-timestamp>`
- Git command: `git worktree add <path> -b <branch>`
- Cleanup: `git worktree remove --force <path>`
- Inject a `WorktreeCreator` interface so tests can stub without real git

## Acceptance Criteria

- [ ] `--worktree` flag exists on `shark run`
- [ ] When flag is set, worktree is created before agent dispatch and removed after
- [ ] `RunOptions.WorkingDir` is set to the worktree path
- [ ] Tests pass without creating real git worktrees
- [ ] `make fmt && make lint && make test` pass

## Testing Strategy

- [ ] Unit tests for `worktree.go` helpers using a mock `WorktreeCreator`
- [ ] Test that worktree cleanup is called even when an error occurs
- [ ] Test flag parsing (worktree flag present vs absent)

# Task: Wire tech-debt into all modern shark dispatch verbs

## Goal

Make `tech-debt` (and short alias `td`) a first-class entity in every modern `shark <verb> <entity>` dispatch path, so it has CRUD parity with `feature`, `task`, `bug`, `change`, and `idea`. The native `shark td` namespace already exists; this task closes the gaps in the cross-cutting dispatch verbs.

## Background — what already works

Verbs that route by **key format** (via `DetectEntityType` in `internal/cli/commands/helpers.go:695`) already handle `TD-###` correctly because the detector was wired in earlier:

| Verb | TD-### routing | Notes |
|---|---|---|
| `shark get TD-###` | works | helpers.go:724-727 |
| `shark update TD-###` | works | update_dispatch.go:99 |
| `shark delete TD-###` | works | delete_dispatch.go:56 |
| `shark status set/advance TD-###` | works | dispatches via key |
| `shark link TD-### …` | works | link.go:118 |
| `shark search --type=tech_debt` | works | already supported |

For these verbs the only gap is **help text drift** (covered in T-004) and **tests** (T-005).

## Scope of THIS task — what needs wiring

Three explicit dispatcher changes. Each is small but lives in a different file:

### 1. `shark create tech-debt` / `shark create td`

`internal/cli/commands/create.go:235-242` registers per-entity create subcommands but omits tech-debt:

```go
createCmd.AddCommand(createEpicCmd)
createCmd.AddCommand(createFeatureCmd)
createCmd.AddCommand(createTaskCmd)
createCmd.AddCommand(createBugCmd)
createCmd.AddCommand(createChangeCmd)
createCmd.AddCommand(createChangeCardCmd)   // alias
createCmd.AddCommand(createIdeaCmd)
createCmd.AddCommand(createNoteCmd)
// MISSING: createTdCmd + 'tech-debt' alias
```

- Add `createCmd.AddCommand(tdCreateCmd)` (re-use the cmd from `internal/cli/commands/tech_debt.go`).
- Register a `tech-debt` alias the same way `change-card` aliases `change` (createChangeCardCmd pattern).
- Verify the registered command's `Use:` string accepts both `td` and `tech-debt` invocations (Cobra `Aliases:` slice is the cleanest way).

### 2. `shark create note TD-###`

`internal/cli/commands/create.go:180-187` has its own type map that's missing tech-debt:

```go
var entityTypeMap = map[string]models.EntityType{
    "epic":        models.EntityTypeEpic,
    "feature":     models.EntityTypeFeature,
    "task":        models.EntityTypeTask,
    "bug":         models.EntityTypeBug,
    "change":      models.EntityTypeChange,
    "change_card": models.EntityTypeChange,
    // MISSING: "tech_debt": models.EntityTypeTechDebt
}
```

- Add the `"tech_debt"` entry. `models.EntityTypeTechDebt` already exists (referenced from `internal/cli/commands/note_generic.go:35`).
- Update the error message at `create.go:200` to include `TD-### (tech-debt)` in the expected-formats list.

### 3. `shark list td` / `shark list tech-debt`

`internal/cli/commands/helpers.go:226-238` (`ParseListArgs`) recognizes `idea/ideas`, `bug/bugs`, `change/changes/change-card/change-cards` but not tech-debt. The `case "tech_debt":` branch already exists in `internal/cli/commands/list.go:121` — it's just unreachable from positional args.

- Extend `ParseListArgs` to normalize `TD / TDS / TECH-DEBT / TECH-DEBTS / TECH_DEBT` → `tech_debt`.
- Update the error message at `helpers.go:267` ("expected E##, E##-F##, bugs, changes, or ideas") to include `tech-debt`.
- Update the example list at `helpers.go:268-273` to include `shark list tech-debt`.

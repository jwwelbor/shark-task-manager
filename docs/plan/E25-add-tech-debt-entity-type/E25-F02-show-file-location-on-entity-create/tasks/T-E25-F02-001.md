# Add file path display to bug and change-card create commands

## Goal
Add file path display after successful entity creation for bug and change-card commands, matching the existing pattern used by task create. This fulfills epic SC-6.

## Scope
- Files to modify:
  - internal/cli/commands/bug.go (bug create handler)
  - internal/cli/commands/change.go (change create handler)
  - internal/cli/commands/change_card_commands.go (shark create change handler)

## Acceptance Criteria
See spec.md FR-01, FR-02, NFR-01.
- AC-T1: `shark bug create` displays "File: <path>" after success message
- AC-T2: `shark change create` displays "File: <path>" after success message
- AC-T3: `shark create change` displays "File: <path>" after success message
- AC-T4: Pattern uses inline `cli.Info()` matching task create style

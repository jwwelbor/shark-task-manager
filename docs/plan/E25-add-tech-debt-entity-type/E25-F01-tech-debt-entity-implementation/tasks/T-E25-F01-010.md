# Search and Analytics Integration

## Goal
Include tech-debt entities in shark search results and shark analytics output by extending the
search UNION query and adding tech-debt summary methods to the dashboard analytics service.

## Scope
- Files to modify: internal/repository/search/repository.go,
  internal/services/dashboard_analytics_service.go

## Acceptance Criteria
Reference spec.md: "See spec.md FR-06 (Search Integration), FR-07 (Analytics Integration)"
- AC-T1: SearchAll() UNION ALL block added for tech_debts table matching title, key, description
- AC-T2: Search returns entity_type "tech_debt" with category in the severity/tag display column
- AC-T3: TechDebtSummaryRepository interface added with CountByStatus() and CountByCategory()
- AC-T4: techDebtRepo field added to DashboardAnalyticsService struct and constructor
- AC-T5: GetTechDebtAnalytics() method returns total count, count by status, count by category
- AC-T6: shark analytics output includes tech-debt summary section
- AC-T7: Search with --type=tech_debt filter returns only tech-debt entities

# Database Migration - tech_debts Table (Schema v11)

## Goal
Add the tech_debts table to the database schema via an additive migration function that is
idempotent and safe. Bump CurrentSchemaVersion from 10 to 11 so existing databases run the migration.

## Scope
- Files to modify: internal/db/db.go

## Acceptance Criteria
Reference spec.md: "See spec.md FR-09 (Database Migration) and Section 2.3 (Data Model)"
- AC-T1: migrateTechDebtTable() creates tech_debts table with all columns (key, title, slug,
  description, status, category, severity, effort_estimate, context_data, file_path, timestamps)
- AC-T2: CHECK constraints on category and severity match ValidTechDebtCategories/ValidTechDebtSeverities
- AC-T3: Five indexes created (key unique, status, severity, category, slug)
- AC-T4: updated_at trigger created for auto-timestamp
- AC-T5: CurrentSchemaVersion bumped from 10 to 11
- AC-T6: Migration is idempotent (CREATE TABLE IF NOT EXISTS, CREATE INDEX IF NOT EXISTS)
- AC-T7: No ALTER TABLE on existing tables; purely additive

## Test Cases

TestDatabaseConstraints_SeverityCheck"

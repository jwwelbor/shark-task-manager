# Templates, File Operations, and Template Helpers

## Goal
Create the six per-status markdown templates for tech-debt entity files and add TechDebtPlaceholders()
to the template helpers so the td create command generates properly structured entity files.

## Scope
- Files to create: shark-templates/tech_debt/identified.tmpl, triaged.tmpl, in_progress.tmpl,
  resolved.tmpl, wont_fix.tmpl, cancelled.tmpl
- Files to modify: internal/config/template/helpers.go

## Acceptance Criteria
Reference spec.md: "See spec.md Section 2.1 (template files) and Section 2.2 (helpers.go)"
- AC-T1: TechDebtPlaceholders() returns map with category, severity, effort_estimate placeholders
- AC-T2: Each of 6 templates contains YAML frontmatter with key, title, status, category, severity, effort_estimate, description, created_at
- AC-T3: Templates include markdown body sections: Description, Impact, Resolution Plan
- AC-T4: Template names match the 6 default workflow status values exactly
- AC-T5: shark td create generates a file using the "identified" template by default
- AC-T6: Template placeholder substitution replaces {{.category}} etc. with actual field values

## Test Cases
Reference spec.md: "See spec.md FR-01 Create success: CLI prints entity key and file path"
Pattern: copy shark-templates/bug/*.tmpl, substitute bug fields for tech-debt fields (add category, effort_estimate; remove linked_entity)

# Key Validation and Entity Key Detection

## Goal
Add TD-### key format recognition to the keys package and CLI helpers so all auto-detection
dispatch paths can route tech-debt entities correctly without colliding with task keys (T- prefix).

## Scope
- Files to modify: internal/keys/validation.go, internal/cli/commands/helpers.go

## Acceptance Criteria
Reference spec.md: "See spec.md Section 2.4 (Key Format) and Section 2.2 (helpers.go)"
- AC-T1: IsTechDebtKey() in keys/validation.go matches ^TD-\d{3}$ case-insensitively
- AC-T2: IsTechDebtKey() wrapper added in helpers.go
- AC-T3: DetectEntityType() returns "tech_debt" for TD-001, TD-042, td-001
- AC-T4: TD- check placed BEFORE task key checks in DetectEntityType() to prevent T-prefix collision
- AC-T5: scopeTechDebt type and ParseGetArgs case added for TD keys

# TechDebt CLI Command Group (shark td)

## Goal
Implement the full shark td command group with all subcommands: create, get, list, update, delete,
triage, note add, notes, context set/get/clear. All subcommands support --json and --field flags.

## Scope
- Files to create: internal/cli/commands/tech_debt.go,
  internal/cli/commands/tech_debt_test.go

## Acceptance Criteria
Reference spec.md: "See spec.md FR-01 through FR-04, FR-08, Section 2.1 (tech_debt.go CLI)"
- AC-T1: tdCmd registered under root with GroupID "advanced"
- AC-T2: td create parses title positional arg plus --category, --severity, --effort-estimate, --description flags
- AC-T3: td list accepts --category, --severity, --status filter flags; outputs table or JSON
- AC-T4: td update does NOT accept --status flag; status changes via shark status set
- AC-T5: td delete prompts for confirmation; --force skips it
- AC-T6: td triage updates severity/category/effort-estimate and advances status if currently "identified"
- AC-T7: td note add and td notes delegate to generic note infrastructure
- AC-T8: td context set/get/clear delegates to generic context infrastructure
- AC-T9: All 10 CLI test cases pass using mocked services (no real DB)

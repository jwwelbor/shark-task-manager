# TechDebt Model and Entity Type Registration

## Goal
Create the TechDebt model struct with domain fields (category, severity, effort_estimate) and
register the entity type so notes, history, and entity-level infrastructure recognize it.

## Scope
- Files to create: internal/models/tech_debt.go
- Files to modify: internal/models/entity_note.go, internal/models/entity.go

## Acceptance Criteria
Reference spec.md: "See spec.md Section 2.1 (tech_debt.go) and Section 2.2 (entity_note.go, entity.go)"
- AC-T1: TechDebt struct embeds BaseEntity with Status, Category, Severity, EffortEstimate fields
- AC-T2: ValidTechDebtCategories and ValidTechDebtSeverities maps defined as allowlists
- AC-T3: Validate() rejects empty title, invalid category, invalid severity
- AC-T4: GetEntityType() returns EntityTypeTechDebt constant
- AC-T5: EntityTypeTechDebt registered in ValidEntityTypes map
- AC-T6: Compile-time interface check added in entity.go

## Test Cases
Reference test-plan.md: "See test-plan.md Section 3.2 TestCreate_ValidationError, TestCreate_InvalidCategory"
Pattern: copy internal/models/bug.go, substitute Bug->TechDebt, add Category, remove linked_entity fields

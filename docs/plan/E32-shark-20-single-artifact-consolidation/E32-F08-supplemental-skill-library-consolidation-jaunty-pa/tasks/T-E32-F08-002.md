# Task: Run Batch C Skill Purity Audit

## Goal

Audit the original shark-coupled skills for layer purity and file-shape compliance after the broader skill-library consolidation.

## Skills In Scope

- `architecture`
- `assessment`
- `implementation`
- `quality`
- `research`
- `specification-writing`
- `test-driven-development`
- `uat`

## Requirements

- [ ] Every in-scope skill has `SKILL.md`.
- [ ] Canonical craft files are free of direct `shark` commands.
- [ ] Canonical craft files do not own status transition operations.
- [ ] Any remaining workflow scaffolding is isolated to `_extracted/` sidecars or reported as an E32-F04 migration issue.
- [ ] Audit output distinguishes true craft violations from examples/templates that mention host integration as illustrative context.

## Acceptance Criteria

- [ ] Audit report exists under the E32-F08 feature directory.
- [ ] Violations include file path, line number, rule violated, and recommendation.
- [ ] E32-F08 receives a note summarizing Batch C audit results.
- [ ] If violations require prompt/workflow migration, E32-F04 receives a note with the follow-on list.

## Verification

```bash
for skill in architecture assessment implementation quality research specification-writing test-driven-development uat; do
  test -f "shark-data/skills/$skill/SKILL.md" || echo "MISSING SKILL.md: $skill"
done

grep -R -n "shark " shark-data/skills/{architecture,assessment,implementation,quality,research,specification-writing,test-driven-development,uat}/ --exclude-dir=_extracted
grep -R -n -E "status advance|status set|next-status" shark-data/skills/{architecture,assessment,implementation,quality,research,specification-writing,test-driven-development,uat}/ --exclude-dir=_extracted
```

# Task: Verify E1 — IncludeResolver correctness

## Context

`internal/templates/includes.go` implements `IncludeResolver` (E1). Tests exist in
`includes_test.go`. This task verifies coverage is complete for all safety guards
and that the existing tests pass as the canonical verification record.

Reference: feature spec §E1, research.md §1 (E1), architecture.md ADR-7.

## Requirements

- Cycle detection fires and returns error when `{{include:}}` forms a cycle.
- Depth cap at `IncludeDepthCap = 5` is enforced (error on exceed).
- Size warning emitted via `warnFn` when resolved content exceeds `IncludeSizeWarnBytes = 50KB`.
- Override path: `<dataRoot>/overrides/<path>` is tried before `<dataRoot>/<path>`.
- `{{augment:}}` is resolved by the same resolver; behavior difference is documented.

## Implementation Plan

1. Run `go test ./internal/templates/ -run IncludeResolver -v` and confirm all cases pass.
2. Check coverage for cycle detection, depth-cap, size-warn, and override-precedence paths.
3. Add targeted test cases for any uncovered branch (should be minimal given existing test file).
4. Confirm `warnFn` injection is exercised in at least one test.

## Acceptance Criteria

- `go test ./internal/templates/ -run Include` passes with zero failures.
- Cycle detection, depth cap (5), size warn (50KB), and override-first resolution each
  have at least one test case exercising the path.
- `make fmt && make lint` clean.

## Dependencies

None — standalone unit verification.

# Task: Verify override resolution — overrides/ takes full precedence

## Context

The ADR-3 contract states: `shark-data/overrides/<path>` **fully replaces** the
corresponding default at render time — never merges. `IncludeResolver.resolvePath()`
implements this. This task verifies the contract has test coverage and cannot
silently regress (feature spec AC item 6).

Reference: feature spec AC item 6, research.md §1 (E1), architecture.md ADR-3.

## Requirements

- `resolvePath()` checks `<dataRoot>/overrides/<path>` before `<dataRoot>/<path>`.
- When an override file exists, its full content is returned; the default is NOT read.
- When no override exists, the default path content is returned.
- `shark upgrade` must NOT touch `overrides/` (guarded in `sharkdata/embed.go`; verify not regressed).

## Implementation Plan

1. Confirm `includes_test.go` has a test placing a file under `overrides/` and verifying
   the override content (not default content) is returned.
2. If missing, add a minimal test using `t.TempDir()` with both default and override files.
3. Verify `embed.go` `Upgrade()` skips `overrides/` by reviewing `SkippedOverrides` field in `DiffSummary`.
4. Run `go test ./internal/templates/ -run Override` and confirm pass.

## Acceptance Criteria

- At least one test exercises override-wins-over-default path.
- At least one test exercises no-override-fallback-to-default path.
- `go test ./internal/templates/` and `go test ./internal/sharkdata/` pass.
- `make fmt && make lint` clean.

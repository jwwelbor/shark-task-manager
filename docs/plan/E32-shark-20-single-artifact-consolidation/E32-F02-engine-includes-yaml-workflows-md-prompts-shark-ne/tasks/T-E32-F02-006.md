# Task: Integration smoke test — full feature AC gate

## Context

This is the integration capstone for F02. All six feature acceptance criteria
(feature.md §Acceptance Criteria) must pass against a `shark-data/`-backed workflow
configuration. The project `.sharkconfig.json` currently points to
`shark-templates/.sharkworkflow-codex.json` (1.x JSON). This task configures a test
environment using `shark-data/workflow/` and runs the full AC checklist.

Reference: feature.md AC items 1-6, research.md §Priority Actions item 1, architecture.md §6.1.

## Requirements

- AC1: Manual `shark-data/` for one feature in the test environment works.
- AC2: `shark next <task> --json` returns a rendered prompt with skill content inlined.
- AC3: Rendered prompt is semantically equivalent to existing `.tmpl` output (diff passes).
- AC4: Old `shark-templates/` path still works when `shark-data/` is absent (fallback).
- AC5: `{{include:}}` cycle detection fires on a deliberate cycle test fixture.
- AC6: Override resolution: `shark-data/overrides/<path>` wins over `shark-data/<path>`.

## Implementation Plan

1. Configure a scratch `shark-data/workflow/` pointing at the YAML files; update
   `workflow_config` in `.sharkconfig.json` (or use a test-only config file).
2. Run `./bin/shark next <task-key> --json` and pipe to `jq .prompt` — confirm non-empty.
3. Diff prompt output against `shark-templates/` tmpl output for the same entity/status.
4. Temporarily rename `shark-data/` to confirm fallback to `shark-templates/` kicks in.
5. Plant a cycle in a temp `shark-data/` and confirm `shark next` returns an error (not hang).
6. Place a file under `shark-data/overrides/` and confirm the override content appears in prompt.
7. Document results as notes on this task via `shark create note`.

## Acceptance Criteria

- All six AC items from feature.md produce a passing result.
- `./bin/shark next <task> --json | jq .prompt` is non-empty and contains inlined skill text.
- `make test` remains green after any test fixtures added.
- Results documented as a note on this task.

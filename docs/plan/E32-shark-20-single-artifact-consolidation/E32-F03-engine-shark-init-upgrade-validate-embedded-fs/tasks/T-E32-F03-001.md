# Task: Verify shark init idempotency and ErrAlreadyInitialized

## Context

E6 is implemented in internal/sharkdata/embed.go (Init()). Unit tests exist in
embed_test.go (TestInit_FreshProject, TestInit_AlreadyInitialized). CLI wrapper
is in internal/cli/commands/sharkdata_cmd.go. This task verifies the
implementation is correct and all tests pass, then confirms behavior via the
built binary.

## Requirements

- All existing TestInit_* tests pass under `make test`
- `./bin/shark init` in a temp dir creates shark-data/ with 5 subdirs
- Second `./bin/shark init` in same dir exits non-zero with "already initialized"
  message (not a crash, not silent no-op)
- ErrAlreadyInitialized is the sentinel; callers should use errors.Is, not string match

## Implementation Plan

1. Run `make test ./internal/sharkdata/...` — confirm TestInit_* pass
2. Run `make lint` — confirm no lint warnings in embed.go or sharkdata_cmd.go
3. Smoke test: `tmp=$(mktemp -d) && ./bin/shark init --db "$tmp/shark.db" 2>&1`
   — confirm shark-data/ appears and exit code is 0
4. Run init again in same dir — confirm error message references "already
   initialized" and exit code is non-zero
5. If any test or smoke test fails, fix the gap in embed.go/sharkdata_cmd.go

## Acceptance Criteria

- [ ] `make test ./internal/sharkdata/...` passes with no failures

# Task: Delete 9 in-scope agents from ~/.claude/agents/

## Goal

Remove 9 agent definition files from `~/.claude/agents/` that are now canonical in `shark-data/agents/`. After F4, these agents ship via `internal/sharkdata/default_data/agents/` and are loaded at dispatch time from `shark-data/`. The harness should retain only 6 harness-level helper agents.

## Implementation Plan

### Step 1 — Delete the 9 agent files

```bash
rm ~/.claude/agents/architect.md
rm ~/.claude/agents/business-analyst.md
rm ~/.claude/agents/developer.md
rm ~/.claude/agents/qa.md
rm ~/.claude/agents/tech-lead.md
rm ~/.claude/agents/product-manager.md
rm ~/.claude/agents/tech-director.md
rm ~/.claude/agents/researcher.md
rm ~/.claude/agents/uat-agent.md
```

### Step 2 — Verify deletion and keeper count

```bash
# 9 deleted agents — each must be absent
for a in architect.md business-analyst.md developer.md qa.md tech-lead.md \
          product-manager.md tech-director.md researcher.md uat-agent.md; do
  [ -f ~/.claude/agents/$a ] && echo "FAIL: $a still exists" || echo "PASS: $a absent"
done

# List remaining files
ls ~/.claude/agents/
# Expected exactly: client.md  code-simplifier.md  cx-designer.md  devops.md  human-checkpoint.md  ux-designer.md

# Verify count is exactly 6
[ "$(ls ~/.claude/agents/ | wc -l)" -eq 6 ] && echo "PASS: 6 agents" || echo "FAIL: wrong count"
```

## Notes

- `Explore`, `Plan`, and `general-purpose` are built-in Claude Code agent types — they do not appear as files in `~/.claude/agents/` and are not affected by this task.
- The 6 keeper files are harness-level helpers not managed by shark: `client.md`, `code-simplifier.md`, `cx-designer.md`, `devops.md`, `human-checkpoint.md`, `ux-designer.md`.

## Acceptance Criteria

- [ ] All 9 in-scope agent files absent from `~/.claude/agents/`
- [ ] Exactly 6 files remain: `client.md`, `code-simplifier.md`, `cx-designer.md`, `devops.md`, `human-checkpoint.md`, `ux-designer.md`
- [ ] `$(ls ~/.claude/agents/ | wc -l)` equals 6

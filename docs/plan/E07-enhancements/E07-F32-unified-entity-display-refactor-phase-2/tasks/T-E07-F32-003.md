# Task: Fix: Byte-based note truncation in epic_helpers and feature_helpers

## Goal

Fix byte-based string truncation that corrupts multi-byte UTF-8 characters when truncating note content for display. Both `epic_helpers.go` and `feature_helpers.go` use `content[:77]` which slices by bytes, not characters. The unified `renderNotes` function in `render_common.go` already handles this correctly using rune-safe truncation.

## Requirements

### Functional Requirements

- [ ] Replace `content[:77]` in `epic_helpers.go` (line 328) with rune-safe truncation: `string([]rune(content)[:77])`
- [ ] Replace `content[:77]` in `feature_helpers.go` (line 528) with rune-safe truncation: `string([]rune(content)[:77])`
- [ ] Truncation must handle content shorter than 77 runes without panicking
- [ ] Append `"..."` suffix after truncation (matching existing behavior)

### Non-Functional Requirements

- [ ] Notes with emoji, CJK characters, or other multi-byte Unicode display correctly
- [ ] No performance impact (rune conversion is negligible for short strings)

## Implementation Plan

### Steps

1. [ ] Open `internal/cli/commands/epic_helpers.go`, find line ~328 with `content[:77]`
2. [ ] Replace with rune-safe truncation: convert to runes, check length, truncate, convert back to string
3. [ ] Open `internal/cli/commands/feature_helpers.go`, find line ~528 with `content[:77]`
4. [ ] Apply the same rune-safe truncation fix
5. [ ] Run `make fmt && make lint && make test`

### Technical Approach

- **Architecture decision ADR-003**: Extract a shared `truncateRunes(s string, maxLen int) string` helper in `render_common.go`
- The helper should be ~5-6 lines, reusable from all truncation sites
- Update `renderNotes()` in `render_common.go` to also use `truncateRunes()` for consistency
- Replace byte-based truncation in `epic_helpers.go` and `feature_helpers.go` with calls to `truncateRunes()`
- Reference implementation: `render_common.go:249` uses `string(runes[:77])` with proper length check
- Pattern for the shared helper:
  ```go
  func truncateRunes(s string, maxLen int) string {
      runes := []rune(s)
      if len(runes) <= maxLen {
          return s
      }
      return string(runes[:maxLen]) + "..."
  }
  ```
- Ensure the length check prevents index-out-of-range panics when content has fewer than maxLen runes

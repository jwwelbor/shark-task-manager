### AC-T2: No function bodies for ContainsHyphen, IsNumeric, SplitAtFirstHyphen, SplitAtNthHyphen, ResequenceOrders remain in root package Go files

**Status: FAIL**

The TC-F001-4 verification method from the test plan:

```bash
grep -rn "func ContainsHyphen\|func IsNumeric\|func SplitAt\|func resequenceOrders" internal/repository/*.go
```

Returns:

```
internal/repository/key_lookup.go:36:func ContainsHyphen(s string) bool {
internal/repository/key_lookup.go:42:func IsNumeric(s string) bool {
internal/repository/key_lookup.go:55:func SplitAtFirstHyphen(key string) (prefix, suffix string, ok bool) {
internal/repository/key_lookup.go:70:func SplitAtNthHyphen(key string, n int) (prefix, suffix string, ok bool) {
internal/repository/order_resequence.go:29:func resequenceOrders(items []orderedItem, changedID int64, newOrder *int) []orderedItem {
```

The grep must return empty. It does not. This is a clear failure of AC-T2.

**Root cause**: The developer retained thin wrapper functions in the root `key_lookup.go` and `order_resequence.go` to preserve backward compatibility for internal callers within the package. While the intent is understandable (no code duplication of logic), the acceptance criterion explicitly prohibits any function body for these names in root package files.

**What these files look like** (not duplication per se, but wrapper bodies still exist):

- `key_lookup.go` line 36-38: `func ContainsHyphen(s string) bool { return repoutil.ContainsHyphen(s) }`
- `key_lookup.go` line 42-52: `func IsNumeric(s string) bool { return repoutil.IsNumeric(s) }`
- `key_lookup.go` line 55-57: `func SplitAtFirstHyphen(...)` delegating to repoutil
- `key_lookup.go` line 70-72: `func SplitAtNthHyphen(...)` delegating to repoutil
- `order_resequence.go` line 29-31: `func resequenceOrders(...)` delegating to repoutil

**Required fix**: The internal callers within `internal/repository/*.go` that call `ContainsHyphen`, `IsNumeric`, `SplitAtFirstHyphen`, `SplitAtNthHyphen`, and `resequenceOrders` must be updated to call `repoutil.XXX` directly. Once all callers are updated to use the `repoutil.` prefix, the wrapper functions in `key_lookup.go` and `order_resequence.go` can be removed (or the files can be deleted entirely if they contain nothing else after the wrapper functions are removed).

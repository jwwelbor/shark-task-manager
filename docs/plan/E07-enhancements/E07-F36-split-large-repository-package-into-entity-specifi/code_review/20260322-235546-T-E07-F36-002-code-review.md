## 7. Minor Observations (Non-Blocking)

1. **Test files not co-located for worksession, document, search**: Three sub-packages
   (`worksession/`, `document/`, `search/`) have no test files within the sub-package itself.
   Their tests remain in root `package repository`. This is the correct pattern for a phased
   migration, and the tests pass. Future work should move these alongside Phase 4 cleanup.

2. **changecard/ missing repository_test.go**: The `changecard` sub-package has `aggregate_test.go`
   but no `repository_test.go`. The repository itself is exercised via root-level tests using
   the alias. This is consistent with other sub-packages in this phase.

3. **polymorphic_doc_adapter.go uses alias, not direct import**: The adapter references
   `*EntityDocumentRepository` (the alias), not `entitydoc.EntityDocumentRepository` directly.
   The spec (section 2.3, Decision 5) says to update the adapter to import from the `entitydoc`
   sub-package, but using the alias achieves the same result functionally and is acceptable.
   A direct import would be marginally cleaner but is not required.

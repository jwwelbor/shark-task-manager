# Phase 4: Extract Core Entity Repositories and Clean Up Root Package

## Goal
Move the three core entity repositories (EpicRepository with relationship, FeatureRepository with relationship, TaskRepository with dependency/relationship/history) into their respective sub-packages, update aliases.go with all remaining type and constructor aliases, verify sub-package test DB path resolution, and reduce the root package to at most 5 production Go files (REQ-F-008). This is the largest phase by file count.

## Scope
- Files to create/populate: `internal/repository/epic/repository.go`, `epic/relationship.go`, and test counterparts; `feature/repository.go`, `feature/relationship.go`, and test counterparts; `task/repository.go`, `task/dependency.go`, `task/relationship.go`, `task/history.go`, and 19 corresponding test files
- Files to create: `internal/repository/task/db_path_test.go` (verify GetTestDB path resolves from sub-package before bulk test move)
- Files to modify: `internal/repository/aliases.go` — add EpicRepository, FeatureRepository, TaskRepository, all DTO type aliases (TaskDisplayDataRaw, HistoryFilters, EpicDisplayDataRaw, FeatureDisplayDataRaw, FeatureProgressData) and constructors
- Files to delete: All moved root-level production files; `task_repository.go.backup`; confirm no empty dirs remain

## Acceptance Criteria
See spec.md REQ-F-006, REQ-F-008, and REQ-F-009 for full criteria.
- AC-T1: `ls internal/repository/*.go | grep -v _test.go | wc -l` returns 5 or fewer
- AC-T2: Each sub-package builds and passes tests independently via `go test ./internal/repository/<pkg>/...`
- AC-T3: `make fmt && make lint && make test` passes after this task

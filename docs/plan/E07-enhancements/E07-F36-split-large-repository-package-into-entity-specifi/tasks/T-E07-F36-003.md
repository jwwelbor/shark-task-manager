# Phase 3: Resolve NoteCreator Coupling and Extract note Sub-Package

## Goal
Break the concrete dependency of TaskRepository on EntityNoteRepository by defining a NoteCreator interface in the task sub-package, modifying the TaskRepository constructor to accept an optional NoteCreator, and then moving EntityNoteRepository to `internal/repository/note/`. This resolves the import cycle that would otherwise block Phase 4. The root `aliases.go` constructor wrapper wires EntityNoteRepository as the NoteCreator so existing callers of `repository.NewTaskRepository(db)` retain full rejection-note behavior.

## Scope
- Files to modify: `internal/repository/task_repository.go` — add NoteCreator interface definition and inject into constructor; replace two direct `NewEntityNoteRepository` instantiations with interface calls
- Files to create: `internal/repository/note/repository.go`, `internal/repository/note/repository_test.go` (moved from root)
- Files to modify: `internal/repository/aliases.go` — add `type EntityNoteRepository = note.EntityNoteRepository`, `var NewEntityNoteRepository`, and update the `NewTaskRepository` wrapper to inject the note repo as NoteCreator
- Files to delete: `internal/repository/entity_note_repository.go` (after note sub-package is in place)

# Phase 2: Extract Standalone Repositories into Sub-Packages

## Goal
Move the nine standalone entity repositories (idea, bug, changecard, worksession, document, entitydoc, entityhistory, entityrel, search, templateenrich) and EntityRelationshipRepository into dedicated sub-packages, create `internal/repository/aliases.go` with full type-alias and constructor-alias re-exports, and update `polymorphic_doc_adapter.go` to import from the `entitydoc` sub-package. All 74 external callers continue to compile unchanged.

## Scope
- Files to create: `internal/repository/idea/repository.go`, `bug/repository.go`, `bug/aggregate.go`, `changecard/repository.go`, `changecard/aggregate.go`, `worksession/repository.go`, `document/repository.go`, `entitydoc/repository.go`, `entityhistory/repository.go`, `entityrel/repository.go`, `search/repository.go`, `templateenrich/repository.go` (plus corresponding `_test.go` files for each)
- Files to create: `internal/repository/aliases.go` (type aliases and constructor vars per spec section 2.5)
- Files to modify: `internal/repository/polymorphic_doc_adapter.go` (update import to `entitydoc` sub-package)
- Files to delete: root-level production files for the moved repositories after aliases are in place

See spec.md REQ-F-003, REQ-F-007, and REQ-F-009 for full criteria.
- AC-T1: Each sub-package builds with `go build ./internal/repository/<pkg>/...` independently
- AC-T2: `make fmt && make lint && make test` passes after this task

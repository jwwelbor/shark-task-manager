# Phase 1: Create repoutil Package and Activate dbconn Alias

## Goal
Create `internal/repository/repoutil/` by moving and exporting shared utilities (key_lookup.go, order_resequence.go, tracing.go), and activate the dbconn.DB type alias in repository.go. This establishes the foundation all subsequent phases depend on while keeping the codebase fully compilable throughout.

## Scope
- Files to create: `internal/repository/repoutil/key_lookup.go`, `repoutil/order_resequence.go`, `repoutil/tracing.go`, and their `_test.go` counterparts
- Files to modify: `internal/repository/repository.go` (add `type DB = dbconn.DB` and `var NewDB = dbconn.NewDB`), root `key_lookup.go`, `order_resequence.go`, `tracing.go` (remove bodies; redirect to repoutil or delete after repoutil tests pass)
- Files unchanged: All 74 files outside `internal/repository/`

See spec.md REQ-F-001 and REQ-F-002 for full criteria.

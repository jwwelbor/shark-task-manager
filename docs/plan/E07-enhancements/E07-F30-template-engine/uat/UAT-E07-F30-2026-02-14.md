## Feature Overview

This feature moves orchestrator instruction templates from embedded JSON strings in `.sharkconfig.json` to external `.tmpl` files using Go's stdlib `text/template` engine. This provides:

- **Readability**: Multiline formatting, syntax highlighting, inline comments
- **Maintainability**: Line-by-line git diffs, easier editing
- **Conditionals**: Show/hide sections based on data (e.g., hide "Related docs:" when empty)
- **Reusability**: Shared partials for common patterns (TDD process, exit gates, READ sections)
- **Validation**: Pre-compilation catches syntax errors at startup

1. **Task Templates (5)**:

## Comparison: Before vs After

### Before (Inline in .sharkconfig.json):
```json
{
  "instruction_template": "Research epic {id}: \"{title}\". STRATEGIC RESEARCH -- assess system-wide impact and feasibility against the defined epic PRD. LOAD: discovery skill (market-research, feasibility-analysis) + research skill (analyze-codebase, find-patterns). READ: All 6 epic PRD files at {file_path} (epic.md, personas.md, user-journeys.md, requirements.md, success-metrics.md, scope.md) -- research must be scoped to these defined requirements and boundaries. Read all sibling epic docs under docs/plan/ to identify overlap and interactions. Check existing system capabilities in codebase. PRODUCE: Research report containing: (1) Market/competitive landscape relevant to defined requirements, (2) Feasibility assessment against each requirement area, (3) System-wide impact -- how this epic interacts with other epics, (4) Existing capability overlap with defined scope, (5) Risk assessment with mitigations mapped to specific requirements, (6) Recommendations. EXIT GATE: - All 6 sections complete - Research scoped to PRD boundaries - No unresolved feasibility blockers - Overlap explicitly addressed. Advance: shark epic next-status {id}."
}
```

**Problems**:
- 200+ character single-line JSON string
- No formatting or readability
- JSON escaping nightmare (quotes, braces)
- Terrible git diffs (entire line changes for 1-word edit)

### After (External Template):
**File**: `templates/epic/ready_for_research.tmpl`
```go
Research epic {{.id}}: "{{.title}}".

STRATEGIC RESEARCH -- assess system-wide impact and feasibility against the defined epic PRD.

LOAD: discovery skill (market-research, feasibility-analysis) + research skill (analyze-codebase, find-patterns).

READ:
All 6 epic PRD files at {{.file_path}} (epic.md, personas.md, user-journeys.md, requirements.md, success-metrics.md, scope.md) -- research must be scoped to these defined requirements and boundaries.

Read all sibling epic docs under docs/plan/ to identify overlap and interactions.

Check existing system capabilities in codebase.

PRODUCE: Research report containing:
(1) Market/competitive landscape relevant to defined requirements
(2) Feasibility assessment against each requirement area
(3) System-wide impact -- how this epic interacts with other epics
(4) Existing capability overlap with defined scope
(5) Risk assessment with mitigations mapped to specific requirements
(6) Recommendations

EXIT GATE:
- All 6 sections complete
- Research scoped to PRD boundaries
- No unresolved feasibility blockers
- Overlap explicitly addressed

Advance: shark epic next-status {{.id}}.
```

**Benefits**:
- ✅ Multiline formatting (readable!)
- ✅ No JSON escaping
- ✅ Clean git diffs (line-by-line changes)
- ✅ Syntax highlighting in editors
- ✅ Can add conditionals in future (when relational variables added)

# Task: Add template_directory configuration to .sharkconfig.json

## Goal

Make the template directory path configurable via `.sharkconfig.json` so teams can organize templates in custom locations. Currently `shark-templates` is hardcoded in 6+ locations across the codebase.

## Design Decision: Single Config Field

The original spec proposed two fields (`template_directory` + `markdown_template_directory`). After codebase analysis, **one field is sufficient** because both the orchestrator `.tmpl` system and the entity `.md` system share the same `shark-templates/` root directory. The directory structure within it (`entity/`, `epic/`, `feature/`, `task/`, `partials/`) is what differentiates them. Users who want custom paths only need to change the root.

## Implementation Plan

### Step 1: Add config field (`internal/config/config.go`)

Follow the existing `Viewer *string` + `GetViewer()` pattern exactly:

```go
type Config struct {
    // ... existing fields ...
    TemplateDirectory *string `json:"template_directory,omitempty"` // Default: "shark-templates"
}

func (c *Config) GetTemplateDirectory() string {
    if c == nil || c.TemplateDirectory == nil || *c.TemplateDirectory == "" {
        return "shark-templates"
    }
    return *c.TemplateDirectory
}
```

### Step 2: Update OrchestratorRenderer (`internal/templates/orchestrator_renderer.go`)

Update `GetOrchestratorEngine()` to check config before walk-up fallback:

```go
func GetOrchestratorEngine() *OrchestratorRenderer {
    engineOnce.Do(func() {
        var templateDir string
        if testTemplateDir != "" {
            templateDir = testTemplateDir
        } else if dir := getConfiguredTemplateDir(); dir != "" {
            templateDir = dir
        } else {
            templateDir = findTemplateDir()
        }
        engineInstance, engineError = NewOrchestratorRenderer(templateDir)
        // ...
    })
    return engineInstance
}
```

Also update `findTemplateDir()` to use the configured name instead of hardcoded `"shark-templates"`.

### Step 3: Update Loader (`internal/templates/loader.go`)

`NewLoader` already accepts `templateDir`. Update the default in `NewLoader("")` to read config:

```go
func NewLoader(templateDir string) *Loader {
    useEmbedded := templateDir == ""
    if templateDir == "" {
        templateDir = getConfiguredTemplateDir() // reads config, falls back to "shark-templates"
    }
    return &Loader{templateDir: templateDir, useEmbedded: useEmbedded}
}
```

## What Was Dropped From Original Spec

| Original | Decision | Reason |
|----------|----------|--------|
| Two config fields (`template_directory` + `markdown_template_directory`) | Single field | Both systems share same root dir |
| Absolute path support | Relative only | Simpler, safer, project-portable |
| Elaborate path allowlist security | Simple `filepath.Rel` check | Sufficient for the use case |

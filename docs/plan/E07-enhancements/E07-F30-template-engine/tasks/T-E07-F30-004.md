# Task: Extend placeholder builders with complexity_tier field

## Goal

Extend the `*PlaceholdersWithRelated()` functions to include `complexity_tier` field from entity metadata, enabling templates to use tier-based conditional logic (SIMPLE/STANDARD/COMPLEX branching).

## Requirements

### Functional Requirements

- [ ] Add `complexity_tier` field to `TaskPlaceholdersWithRelated()` output
- [ ] Add `complexity_tier` field to `FeaturePlaceholdersWithRelated()` output
- [ ] Extract tier from entity `Metadata` map (key: `"complexity_tier"`)
- [ ] Default to empty string if metadata missing or tier not set
- [ ] Preserve all existing placeholder fields (no breaking changes)

### Non-Functional Requirements

- [ ] Minimal code changes (add tier extraction only)
- [ ] No performance impact (simple map lookup)
- [ ] Test Coverage: 90%+ for modified functions

## Implementation Plan

### Steps

1. [ ] Open `internal/config/template_helpers.go`
2. [ ] Locate `TaskPlaceholdersWithRelated()` function
3. [ ] After building base placeholders, add complexity tier extraction:
   ```go
   // Add complexity_tier from metadata
   if task.Metadata != nil {
       if tier, ok := task.Metadata["complexity_tier"].(string); ok {
           placeholders["complexity_tier"] = tier
       } else {
           placeholders["complexity_tier"] = ""
       }
   } else {
       placeholders["complexity_tier"] = ""
   }
   ```
4. [ ] Repeat for `FeaturePlaceholdersWithRelated()` and `EpicPlaceholdersWithRelated()`
5. [ ] Write unit tests for tier extraction (with tier, without tier, nil metadata)

### Technical Approach

- **Minimal Extension**: Only add complexity tier field to existing functions
- **Type Safety**: Use type assertion `.(string)` to extract tier from metadata map
- **Default Empty**: Return empty string if tier not set (templates handle gracefully)
- **No Schema Changes**: Metadata already exists, just extracting known key

## Notes

**Why This Matters:**
- Templates need tier to scale output depth:
  - `{{if eq .complexity_tier "SIMPLE"}}Brief instructions{{end}}`
  - `{{else if eq .complexity_tier "STANDARD"}}Focused instructions{{end}}`
  - `{{else}}Comprehensive instructions{{end}}`
- Example: Feature BA refinement produces 1-page PRD for SIMPLE, 2-3 pages for STANDARD, 6 files for COMPLEX

**Integration:**
- Service layer calls `*PlaceholdersWithRelated()` → gets tier in vars
- `PopulateTemplate(vars)` passes tier to template engine
- Template uses `{{.complexity_tier}}` for conditional logic

**Phase:** Phase 1 Foundation (MVP)

# Task: FIX: Add ValidTransitions field to DisplayService structs

## Goal

**Populate in GetFeatureDisplayInfo**:

```go
func (s *DisplayService) GetFeatureDisplayInfo(ctx context.Context, feature *models.Feature) (*FeatureDisplayInfo, error) {
    // ... existing code ...

    // Get valid transitions from workflow
    validTransitions := []string{}
    if workflowCfg, err := s.workflowSvc.GetConfig(); err == nil {
        if transitions, exists := workflowCfg.StatusFlow[string(feature.Status)]; exists {
            validTransitions = transitions
        }
    }

    return &FeatureDisplayInfo{
        // ... existing fields ...
        ValidTransitions: validTransitions,
    }, nil
}
```

# Task: Add valid transitions to JSON output (epic.go and feature.go)

## Goal

Add `valid_transitions` field to JSON output for epic and feature get commands, enabling AI agents and users to discover allowed status transitions from the current state without manually reading workflow configuration.

Make surgical additions (~2-3 lines each) to `runEpicGet()` and `runFeatureGet()` functions in `internal/cli/commands/epic.go` and `feature.go` to:
1. Call `GetValidTransitions()` helper to extract transitions from workflow config
2. Include `valid_transitions` array in JSON response structure

**Impact**: Users and AI agents can now see actionable next steps directly in command output, eliminating need to consult `.sharkconfig.json` for workflow decisions.

## Notes

**Workflow Config Loading**: Both epic.go and feature.go already load workflow config early in the function. GetValidTransitions() just needs to be called with the loaded config.

**Code Example for epic.go** (~line 644):
```go
// In runEpicGet(), before return cli.OutputJSON(result)

// Get valid transitions for epic status
validTransitions := GetValidTransitions(string(epic.Status), workflowCfg)

result := map[string]interface{}{
    // ... existing fields ...
    "orchestrator_action":    displaySvc.ResolveEpicAction(ctx, epic),
    "valid_transitions":      validTransitions, // NEW FIELD
}

return cli.OutputJSON(result)
```

**Code Example for feature.go** (~line 796):

```go
// In runFeatureGet(), before return cli.OutputJSON(result)
```

**JSON Response Example**:
```json
{
```

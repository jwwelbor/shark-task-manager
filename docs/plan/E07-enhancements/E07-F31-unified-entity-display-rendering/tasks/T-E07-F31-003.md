# Task: Add related documents to feature planning mode (feature.go)

## Goal

Fix the planning mode bug for features where related documents (PRDs, architecture docs, test plans, triage reports) are not displayed when feature status is in planning phases (ready_for_refinement_ba, in_refinement_ba, ready_for_test_planning, etc.).

Add a single line to `renderFeaturePlanning()` function in `internal/cli/commands/feature.go` calling `renderRelatedDocuments(info.RelatedDocs)` to display related documents section after orchestrator action.

**Impact**: AI agents and QA engineers can now discover PRDs, architecture documents, and test plans during planning phases, enabling complete context for workflow decisions.

# Task: Add related documents to epic planning mode (epic.go)

## Goal

Fix the planning mode bug for epics where related documents (PRDs, research reports, decomposition plans) are not displayed when epic status is in planning phases (ready_for_decomposition, in_decomposition, etc.).

Add a single line to `renderEpicPlanning()` function in `internal/cli/commands/epic.go` calling `renderRelatedDocuments(info.RelatedDocs)` to display related documents section after orchestrator action.

**Impact**: AI agents and users can now see related documents during planning phases, increasing visibility from 0% to 100% for planning mode entities.

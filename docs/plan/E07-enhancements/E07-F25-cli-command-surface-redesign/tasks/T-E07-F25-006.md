# Task: Update help text and command groups

## Goal

Reorganize the `shark --help` output to prioritize verb-first commands and aliases. The current grouping is noun-oriented; the new grouping should lead with actions and make the daily workflow commands most prominent.

## Requirements

### Functional Requirements

- [ ] Add or rename command group for quick-access aliases
- [ ] Reorder groups so action-oriented commands appear first
- [ ] Update group titles to be more descriptive
- [ ] Ensure new commands (aliases, create, delete dispatchers) appear in correct groups
- [ ] Root command Long description updated to mention both verb-first and noun-first styles

### Non-Functional Requirements

- [ ] Only modifies `internal/cli/root.go` (and possibly group IDs in individual command files)
- [ ] No functional changes to any command behavior
- [ ] Help output fits standard terminal width (80 cols)

## Implementation Plan

### Steps

1. [ ] Read current `internal/cli/root.go` to understand existing group definitions (lines 78-95)
2. [ ] Redesign group structure. Current groups:
   ```
   essentials  - Essential Commands (epic, feature, task, list, get, view, idea)
   details     - Details & Discovery (notes, related-docs, search)
   status      - Status & Analytics (analytics, history, status)
   setup       - Setup & Maintenance (cloud, config, init, migrate, validate, workflow)
   ```

3. [ ] Proposed new group structure:
   ```
   quick       - Quick Commands (next, start, done, block, unblock)
   essentials  - Core Commands (list, get, create, delete, view, status)
   entities    - Entity Management (epic, feature, task, idea)
   details     - Details & Discovery (notes, related-docs, search, history, analytics)
   setup       - Setup & Maintenance (cloud, config, init, migrate, validate, workflow)
   ```

4. [ ] Update `root.go` AddGroup calls:
   ```go
   RootCmd.AddGroup(
       &cobra.Group{ID: "quick", Title: "Quick Commands:"},
       &cobra.Group{ID: "essentials", Title: "Core Commands:"},
       &cobra.Group{ID: "entities", Title: "Entity Management:"},
       &cobra.Group{ID: "details", Title: "Details & Discovery:"},
       &cobra.Group{ID: "setup", Title: "Setup & Maintenance:"},
   )
   ```

5. [ ] Update GroupID assignments in command files:
   - `aliases.go`: all aliases get `GroupID: "quick"`
   - `create.go`: `GroupID: "essentials"`
   - `delete_dispatch.go`: `GroupID: "essentials"`
   - `list.go`, `get.go`, `view.go`, `status.go`: keep `GroupID: "essentials"`
   - `epic.go`, `feature.go`, `task.go`, `idea.go`: change to `GroupID: "entities"`
   - `history.go`, `analytics.go`: move to `GroupID: "details"`

6. [ ] Update root command Long description to mention both command styles:
   ```
   Shark supports two command styles:
     Quick:     shark next, shark start, shark done
     Standard:  shark task next, shark task start, shark task complete

   Both styles work identically. Use whichever you prefer.
   ```

## Notes

- The `GroupID` field on a cobra.Command determines which group it appears under in `--help`. Commands without a GroupID appear under "Additional Commands".
- This task should be done AFTER the alias and dispatcher commands exist, so it can assign proper group IDs in one pass.
- If the proposed 5-group structure makes `shark --help` too long, consider collapsing "Quick Commands" into "Core Commands" with the aliases listed first.

# Task: Add unified create dispatcher

## Goal

Add a `shark create <type> [args]` command that dispatches to the existing entity-specific create handlers. This provides a verb-first alternative for creation:

```
shark create epic "Epic Title"              # dispatches to: shark epic create "Epic Title"
shark create feature E07 "Feature Title"    # dispatches to: shark feature create E07 "Feature Title"
shark create task E07 F01 "Task Title"      # dispatches to: shark task create E07 F01 "Task Title"
```

## Requirements

### Functional Requirements

- [ ] `shark create epic "Title" [flags]` -- dispatches to `runEpicCreate`
- [ ] `shark create feature E07 "Title" [flags]` -- dispatches to `runFeatureCreate`
- [ ] `shark create task E07 F01 "Title" [flags]` -- dispatches to `runTaskCreate`
- [ ] All flags from underlying create commands are supported
- [ ] `shark create --help` shows all entity types and their argument formats
- [ ] `shark create epic --help` shows epic-specific flags
- [ ] `shark create` with no args shows helpful usage message
- [ ] Error messages guide users to correct syntax

### Non-Functional Requirements

- [ ] Uses Cobra subcommand pattern (`createCmd` with `createEpicCmd`, `createFeatureCmd`, `createTaskCmd` children)
- [ ] No duplication of business logic -- delegates to existing RunE handlers
- [ ] Registered in "essentials" command group
- [ ] Zero breaking changes to existing create commands

## Implementation Plan

### Steps

1. [ ] Create `internal/cli/commands/create.go`
2. [ ] Define parent `createCmd`:
```go
var createCmd = &cobra.Command{
    Use:     "create <type> [args]",
    Short:   "Create an epic, feature, or task",
    GroupID: "essentials",
    Long:    `Create a new entity. Dispatches to the appropriate create handler based on type.

Examples:

  shark create feature E07 "User Authentication"

```

3. [ ] Define subcommands that delegate to existing handlers:
```go
var createEpicCmd = &cobra.Command{
    Use:   "epic <title> [flags]",
    Short: "Create a new epic",
    Long:  `Create a new epic. Equivalent to 'shark epic create'.`,
    Args:  cobra.ExactArgs(1),
    RunE:  runEpicCreate,  // Direct delegation
}

var createFeatureCmd = &cobra.Command{
    Use:   "feature [EPIC] <title> [flags]",
    Short: "Create a new feature",
    Long:  `Create a new feature. Equivalent to 'shark feature create'.`,
    Args:  cobra.RangeArgs(1, 2),
    RunE:  runFeatureCreate,  // Direct delegation
}

var createTaskCmd = &cobra.Command{
    Use:   "task [EPIC] [FEATURE] <title> [flags]",
    Short: "Create a new task",
    Long:  `Create a new task. Equivalent to 'shark task create'.`,
    Args:  cobra.RangeArgs(1, 3),
    RunE:  runTaskCreate,  // Direct delegation
}
```

4. [ ] Register subcommands and copy flag definitions:
```go
func init() {
    cli.RootCmd.AddCommand(createCmd)
    createCmd.AddCommand(createEpicCmd)
    createCmd.AddCommand(createFeatureCmd)
    createCmd.AddCommand(createTaskCmd)

    // Copy flags from underlying commands
    // Epic flags: --key, --file, --force, --priority, --business-value, --description, --status
    // Feature flags: --epic, --key, --file, --force, --description, --execution-order, --status
    // Task flags: --epic, --feature, --agent, --description, --priority, --depends-on, --execution-order, --key, --force, --file
}
```

### Technical Approach

**Subcommand pattern** (not runtime dispatch): Use Cobra's built-in subcommand tree so that `shark create epic` is a proper subcommand with its own Args validation and help text. This is cleaner than runtime string matching and gives better help output.

**Flag copying**: Since the underlying RunE handlers read flags from `cmd.Flags()`, each create subcommand must define the same flags. This is the same pattern as the aliases in T-E07-F25-003.

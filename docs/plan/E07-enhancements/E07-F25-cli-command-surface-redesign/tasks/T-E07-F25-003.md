# Task: Add top-level aliases (next, start, done, block, unblock)

## Goal

Create 5 new top-level commands that alias the most frequently used task lifecycle commands. These make the daily developer loop as short as possible:

```
shark next                    # instead of: shark task next
shark start E07-F01-001       # instead of: shark task start E07-F01-001
shark done E07-F01-001        # instead of: shark task complete E07-F01-001
shark block E07-F01-001       # instead of: shark task block E07-F01-001
shark unblock E07-F01-001     # instead of: shark task unblock E07-F01-001
```

## Requirements

### Functional Requirements

- [ ] `shark next` -- delegates to `runTaskNext` with all flags forwarded
- [ ] `shark start <key>` -- delegates to `runTaskStart` with all flags forwarded
- [ ] `shark done <key>` -- delegates to `runTaskComplete` with all flags forwarded (note: "done" not "complete" -- shorter verb)
- [ ] `shark block <key>` -- delegates to `runTaskBlock` with all flags forwarded
- [ ] `shark unblock <key>` -- delegates to `runTaskUnblock` with all flags forwarded
- [ ] All aliases support `--json` output (inherited from root)
- [ ] All aliases support the same flags as their underlying commands
- [ ] Help text for each alias explains it's a shortcut and references the full command

### Non-Functional Requirements

- [ ] Each alias is ~15-25 lines of Go (command definition + init registration)
- [ ] All aliases in a single new file: `internal/cli/commands/aliases.go`
- [ ] No duplication of business logic -- pure delegation to existing RunE handlers
- [ ] Zero breaking changes to existing commands

## Implementation Plan

### Steps

1. [ ] Create `internal/cli/commands/aliases.go`
2. [ ] Define 5 cobra commands that delegate to existing handlers:

```go
// Pattern for each alias:
var nextCmd = &cobra.Command{
    Use:     "next",
    Short:   "Get next available task (alias for 'task next')",
    GroupID: "essentials",
    Long:    `Shortcut for 'shark task next'. Gets the next available task based on priority and dependencies.`,
    RunE:    runTaskNext,  // Direct delegation -- same handler
}
```

3. [ ] Register all aliases in `init()`:
```go
func init() {
    cli.RootCmd.AddCommand(nextCmd)
    cli.RootCmd.AddCommand(startCmd)
    cli.RootCmd.AddCommand(doneCmd)
    cli.RootCmd.AddCommand(blockCmd)
    cli.RootCmd.AddCommand(unblockCmd)
}
```

4. [ ] Copy flag definitions from the underlying commands:
   - `nextCmd`: `--agent`, `--epic` (same as `taskNextCmd`)
   - `startCmd`: `--agent`, `--force` (same as `taskStartCmd`)
   - `doneCmd`: `--notes`, `--agent`, `--force`, `--files-created`, `--files-modified`, `--tests`, `--summary`, `--verified`, `--agent-id`, `--time-spent` (same as `taskCompleteCmd`)
   - `blockCmd`: `--reason`, `--agent`, `--force` (same as `taskBlockCmd`)
   - `unblockCmd`: `--agent`, `--force` (same as `taskUnblockCmd`)

### Technical Approach

**Key Decision: Direct RunE delegation vs wrapper function**

- **Direct delegation** (`RunE: runTaskNext`): Simplest. The existing handler reads flags from `cmd.Flags()`, so the alias command must define the same flags. Since Cobra binds flags to the specific command, each alias needs its own flag definitions that match the underlying command.

- This means we need to duplicate the flag registration (but NOT the handler logic). This is acceptable because:
  - Flag definitions are declarative (just names, types, defaults)
  - The business logic (the RunE handler) is shared -- zero duplication
  - If a flag is added to the underlying command, it needs to be added to the alias too (documented in notes)

## Notes

- **Why "done" instead of "complete"?** It's 4 chars vs 8 chars. The daily loop command should be as short as possible. `shark done E07-F01-001` feels natural. The underlying `shark task complete` still works for those who prefer it.
- **Flag duplication concern**: Each alias must re-declare its flags because Cobra binds flags per-command. This is a maintenance consideration -- when flags change on the underlying command, aliases need updating too. Mitigate with a comment in aliases.go linking to the source command.
- **GroupID**: All aliases go in `"essentials"` group to appear prominently in `shark --help`.
- The existing task.go handlers (`runTaskNext`, `runTaskStart`, `runTaskComplete`, `runTaskBlock`, `runTaskUnblock`) are exported-ish (lowercase but in same package) and can be referenced directly since aliases.go is in the same `commands` package.

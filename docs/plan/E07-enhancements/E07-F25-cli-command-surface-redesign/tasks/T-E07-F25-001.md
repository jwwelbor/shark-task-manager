# Task: Promote existing dispatchers in docs

## Goal

Update all user-facing documentation to promote the existing smart dispatchers (`shark list`, `shark get`, `shark status`, `shark history`, `shark view`, `shark search`) as the **primary** way to interact with shark, instead of the noun-first equivalents (`shark task list`, `shark epic get`, etc.).

This is a docs-only task -- zero code changes. It lays the groundwork for the CLI surface redesign by training users (and AI agents) to prefer the shorter forms that already exist.

## Requirements

### Functional Requirements

- [ ] CLAUDE.md Quick Commands section shows `shark list`, `shark get`, `shark status` as primary examples
- [ ] CLAUDE.md Key Concepts section references dispatchers for read operations
- [ ] `.claude/rules/quickref.md` lists dispatcher commands before noun-first equivalents
- [ ] `.claude/rules/cli/commands.md` reorders to show dispatchers first
- [ ] `docs/CLI_REFERENCE.md` restructured to lead with smart commands
- [ ] Noun-first commands explicitly documented as "also works" alternatives, not primary
- [ ] No existing command examples are removed -- only reordered/annotated

### Non-Functional Requirements

- [ ] Documentation remains accurate for all existing commands
- [ ] AI agent prompts continue to work (JSON output examples preserved)
- [ ] All existing examples still valid

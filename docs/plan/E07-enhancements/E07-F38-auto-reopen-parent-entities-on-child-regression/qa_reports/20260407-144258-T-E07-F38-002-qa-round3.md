## 3. BUG-QA-001 — DATA RACE Verification

### Root Cause (per QA Round 2)

The concurrent cascade test `TestCascade_ConcurrentCascadeOnSameAncestorWritesExactlyOneHistoryRow` shared a single `mockCascadeEpicRepo` and a single `mockParentReopenHistoryQuerier` between two goroutines. The call-counter fields `getByIDCalls++` and `m.calls++` were mutated concurrently with no mutex protection, producing two data races at lines 80 and 123 of the test file.

### Fix Applied (Round 4 code review confirmed)

BUG-QA-001 Option 1 was implemented: `epicRepo` and `histQuerier` construction was moved **inside** the `makeDeps` closure (`cascade_reopen_test.go:1675-1694`), so each goroutine receives its own instance. The unsynchronized call-counter fields are now goroutine-local — no concurrent mutation, no race, no mutex needed.

`sharedHistTx` remains shared (intentionally) because the primary assertion `featureRows == 1` requires both goroutines to write into the same sink. Its `CreateTxFunc` already protects all mutations with `mu.Lock()`/`defer mu.Unlock()` and the final read at line 1714 is also under the lock.

### Evidence

```
$ go test -race -count=1 -run TestCascade_ConcurrentCascadeOnSameAncestorWritesExactlyOneHistoryRow ./internal/services/
ok  	github.com/jwwelbor/shark-task-manager/internal/services	1.049s

$ go test -race -count=1 ./internal/services/...
ok  	github.com/jwwelbor/shark-task-manager/internal/services	3.180s
```

No `WARNING: DATA RACE` output in either run. **BUG-QA-001 is RESOLVED.**

### Test Intent Preserved

The fix is purely mechanical. The test still proves the in-tx isolation contract for REQ-F-008 / AC-T2:

- Cascade 1 receives a `featureRepo` whose `GetByIDTxFunc` returns `"completed"` (still terminal) → proceeds and writes the history row.
- Cascade 2 receives a `featureRepo` whose `GetByIDTxFunc` returns `"in_qa"` (non-terminal, simulating that Cascade 1 already committed) → idempotent skip, no feature history row.
- Final assertion `featureRows == 1` confirms exactly one feature history row was written, proving the in-tx re-fetch enforces idempotency under concurrent cascades.

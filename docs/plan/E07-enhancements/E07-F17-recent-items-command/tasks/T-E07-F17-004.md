# CLI: implement shark recent command and service accessor

## Goal

Wire everything together at the CLI layer: register the `shark recent` Cobra
command in the `inspect` group, implement `parseRecentFilters` (limit
precedence, bounds check, type flags), implement `renderRecentTable` (table or
empty-state line), and add `GetRecentService()` to the service accessor file.
This is the final task; all underlying layers are complete in earlier tasks.

## Scope

- Files to create:
  - `internal/cli/commands/recent.go` — Cobra command, `init()`, `runRecent`, `parseRecentFilters`, `renderRecentTable`
  - `internal/cli/commands/recent_test.go` — mocked-service CLI tests
- Files to modify:
  - `internal/cli/service_accessors.go` — add `GetRecentService()` following the `GetEpicService` pattern (lines 138-167)

## Acceptance Criteria

See spec.md REQ-F-001 through REQ-F-009; Architecture Section 5.3.4 and 5.3.5.

- AC-T1: `shark recent --help` exits 0 and lists `recent` in help text
- AC-T2: Positional `N` sets limit; `--limit` flag overrides positional
- AC-T3: A non-integer, zero, or negative positional exits with code 3
- AC-T4: `--tasks`, `--features`, `--epics` flags populate `RecentFilters` correctly
- AC-T5: Table output has columns Type, Key, Title, Created, Status
- AC-T6: Empty result prints `No recent items found.` and exits 0
- AC-T7: `--json` emits a valid JSON array; conflict warning suppressed in JSON mode

# Add capture_agent_transcripts and log_truncate_bytes config fields

## Goal

Extend ObservabilityConfig with two new fields so downstream tasks can read them when deciding whether to write transcript files and how many bytes to cap in error events. Fields must have sensible defaults and must not break existing configs that omit them.

## Scope

- Files to modify:
  - `internal/config/config.go` — add fields to ObservabilityConfig struct
  - `internal/config/config_test.go` — add tests for defaults and parsing
  - `internal/config/config_observability_test.go` — extend existing observability tests

## Acceptance Criteria

See feature.md REQ-F-020 and Error Story 2 for authoritative criteria.

- AC-T1: `CaptureAgentTranscripts bool` added to ObservabilityConfig; JSON tag `capture_agent_transcripts`; defaults false when absent.
- AC-T2: `LogTruncateBytes int` added; JSON tag `log_truncate_bytes`; zero value treated as 4096 via a getter helper.
- AC-T3: `shark admin config validate` succeeds with configs that omit both new keys.
- AC-T4: `GetObservability()` on nil pointer returns defaults (false / 4096).

## Test Cases

Derive from feature.md REQ-F-020 acceptance criteria.
- Parse config JSON with both fields present; verify values read correctly.
- Parse config JSON with both fields absent; verify defaults (false, 4096) apply.
- GetObservability() on nil config pointer returns zero-value struct with effective LogTruncateBytes == 4096.

## Design Reference

See feature.md "Requirements — Category: Configuration" (REQ-F-020) and "Dependencies & Integrations" for scope constraints. No DB changes.

# Write tests for run execution logging events and transcript capture

## Goal

Add unit and integration-style tests verifying all slog events emitted by T-E07-F41-002 through T-E07-F41-004, covering the happy path, error path (AgentFailedError with truncation), transcript capture on/off, and transcript write failures. Run `make fmt && make lint && make test` and confirm clean.

## Scope

- Files to create/modify:
  - `internal/runner/controller_logging_test.go` — new file; controller logging tests using mock dispatcher
  - `internal/config/config_observability_test.go` — extend with new config field tests
  - `internal/cli/commands/run_test.go` — run.start / run.end event tests if not already covered in controller tests

## Acceptance Criteria

See feature.md Scenarios 1-4 (feature-level acceptance) for authoritative criteria.

- AC-T1: Test verifies run.start and run.end events appear in slog output for a successful run (observability enabled).
- AC-T2: Test verifies no slog events when observability.enabled is false.
- AC-T3: Test verifies run.stage.error with AgentFailedError includes truncated stderr; content over LogTruncateBytes is cut and truncated: true is set.
- AC-T4: Test verifies transcript file written with correct format when capture enabled; absent when disabled.
- AC-T5: Test verifies run continues and run.transcript.warning emitted when transcript directory is unwritable.
- AC-T6: `make test` passes; `make lint` passes with no new warnings.

## Test Cases

Derive from feature.md Scenarios 1, 2, 3, and 4 (feature-level acceptance criteria) and from error stories 1 and 2.

## Design Reference

See feature.md "Acceptance Criteria" (Scenarios 1-4) and "Non-Functional Requirements" REQ-NF-001/REQ-NF-010. Follow project testing patterns in `.claude/rules/testing/architecture.md`; use mock dispatchers, not real agent processes.

# Update observability guides for capture_agent_transcripts and log_truncate_bytes

## Goal

Document the two new observability config keys (`capture_agent_transcripts`, `log_truncate_bytes`) in the published observability guides so operators can discover and configure them. Gap identified during T-E07-F41-001 UAT — the code and schema accept the keys but no published reference mentions them.

## Scope

- Files to modify:
  - `docs/guides/observability-config-reference.md` — add entries in the config reference table for both keys (type, default, description, example)
  - `docs/guides/observability.md` — add a short section explaining when to enable `capture_agent_transcripts`, the `.shark/runs/` layout, and the `log_truncate_bytes` truncation behavior

## Acceptance Criteria

See feature.md REQ-F-020 and Story 4 for authoritative config-key definitions.

- AC-T1: `docs/guides/observability-config-reference.md` lists both keys with type, default (`false` and `4096`), and one-line description matching the Go struct tags.
- AC-T2: `docs/guides/observability.md` includes a paragraph describing transcript capture behavior (directory layout, opt-in default, non-fatal write failures) and truncation behavior (stderr/stdout_tail cap applies on error events).
- AC-T3: An example `.sharkconfig.json` snippet in at least one of the two guides shows the two keys in context.
- AC-T4: Cross-references between the two guides updated where relevant.
- AC-T5: No broken markdown links introduced (`make lint` or equivalent markdown check clean).

## Test Cases

- Manual: read both guides end-to-end and confirm the new keys surface in the table of contents / reference table.
- Manual: follow the example snippet in a fresh `.sharkconfig.json` and confirm `shark admin config validate` returns success.

## Design Reference

See feature.md "Requirements — REQ-F-020" for the config-key contract. See `internal/config/config.go` `ObservabilityConfig` for the authoritative field names, JSON tags, and defaults. See `internal/runner/controller.go` transcript write logic (T-E07-F41-004) for the runtime behavior to describe.

# Task: Remove extractRelatedTasksFromContext and Dead Code from template_helpers.go

## Goal

Clean up dead code from `internal/config/template_helpers.go` by removing the obsolete `extractRelatedTasksFromContext` helper function and related unused helper functions (`extractRelatedFeaturesFromContext`, `extractRelatedEpicsFromContext`, `formatFeatureKeysAsCSV`, `formatEpicKeysAsCSV`). These functions were designed to parse relationships from context_data JSON but became obsolete when task T-E07-F29-029 refactored the system to use formal relationship tables instead.

**Context**: Task T-E07-F29-029 refactored `TaskPlaceholdersWithRelated` to query the `task_relationships` table directly instead of parsing `ContextData.RelatedTasks` from JSON. This eliminated the need for `extractRelatedTasksFromContext` and related helper functions. The same pattern applies to features and epics using formal relationship tables.

# Add SHARK_LOG_FILE env override and CLI lifecycle file closer

## Goal

Wire the `SHARK_LOG_FILE` env override into `ApplyEnvOverrides` (consistent
with `SHARK_LOG_LEVEL` and `SHARK_LOG_FORMAT`), and store the `io.Closer`
returned by `InitLoggerWithRoot` in `obsContainer` so it is closed on
`ShutdownObservability` and `ResetObservability`.

## Scope

- Files to modify:
  - `internal/observability/provider.go` — add `SHARK_LOG_FILE` override
  - `internal/cli/observability_global.go` — store closer, call close on shutdown/reset, pass project root to `InitLoggerWithRoot`

## Acceptance Criteria

See feature.md REQ-F-007, REQ-F-008, and Scenarios 5 and 7.

Additional task-specific criteria:
- AC-T1: `SHARK_LOG_FILE` non-empty overrides `cfg.LogFile` in `ApplyEnvOverrides`
- AC-T2: `obsContainer` gains a `logFile io.Closer` field
- AC-T3: `ShutdownObservability` closes `logFile` if non-nil
- AC-T4: `ResetObservability` also closes `logFile` if non-nil

# Add log_file field to ObservabilityConfig and init scaffold

## Goal

Add the `LogFile` string field to `ObservabilityConfig` and `ObservabilityConfigDefault`
so the field is part of the config contract and scaffolded into new projects by
`shark admin init`. This is the foundation all other tasks depend on.

## Scope

- Files to modify:
  - `internal/config/config.go`
  - `internal/init/types.go`
  - `internal/init/config.go`

## Acceptance Criteria

See feature.md REQ-F-001, REQ-F-009, and Scenario 6.

Additional task-specific criteria:
- AC-T1: `ObservabilityConfig.LogFile` round-trips through JSON marshal/unmarshal
- AC-T2: `ObservabilityConfigDefault` emits `"log_file": ""` in scaffolded JSON output
- AC-T3: Existing config fields are unaffected

See feature.md Test Plan cases 9 and 10 (`internal/init/config_test.go`).

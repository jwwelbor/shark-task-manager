# Implement file-writing in InitLoggerWithRoot

## Goal

Introduce `InitLoggerWithRoot(cfg, projectRoot string) io.Closer` in
`internal/observability/logger.go`. When `cfg.LogFile` is set, the function
opens the file in append mode (creating parent dirs if missing) and wires it
as the slog writer. On failure it falls back to stderr with a raw warning.
`InitLogger` is kept as a wrapper for backward compatibility.

## Scope

- Files to modify:
  - `internal/observability/logger.go`

## Acceptance Criteria

See feature.md REQ-F-002, REQ-F-003, REQ-F-004, REQ-F-005, REQ-F-006,
REQ-NF-001, REQ-NF-002, and Scenarios 1–4.

Additional task-specific criteria:
- AC-T1: `InitLogger` signature unchanged; delegates to `InitLoggerWithRoot`
- AC-T2: Open mode is `O_APPEND|O_CREATE|O_WRONLY`, perm `0644`
- AC-T3: Parent dirs created with `MkdirAll` perm `0755`
- AC-T4: Fallback warning is a raw `fmt.Fprintln` to stderr, not via slog

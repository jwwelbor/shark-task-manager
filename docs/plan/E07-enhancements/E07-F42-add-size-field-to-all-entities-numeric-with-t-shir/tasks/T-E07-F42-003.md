# DB migration: add size column to 6 entity tables, schema version 15

## Goal
Add the `size INTEGER NULL` column to all six entity tables via an idempotent `migrateAddSizeColumns` migration function, and bump `CurrentSchemaVersion` from 14 to 15 so `ApplySchemaIfNeeded` triggers the migration on existing databases. This is the persistence foundation all repository work depends on.

## Scope
- Files to modify:
  - `internal/db/db.go` (bump `CurrentSchemaVersion` to 15; add `migrateAddSizeColumns` function; call it from `runMigrations()`)
- Files to modify (tests):
  - `internal/db/db_test.go` (add TC-F008-A, TC-F008-B, TC-F009-A, TC-F009-B, TC-F009-C)

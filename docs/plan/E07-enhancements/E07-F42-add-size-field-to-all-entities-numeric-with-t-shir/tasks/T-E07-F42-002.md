# Size field on BaseEntity, Idea struct, and per-entity Validate()

## Goal
Integrate the `Size *int` field into `BaseEntity` and the standalone `Idea` struct, add `GetSize`/`SetSize` to the `Entity` interface, and extend each entity's `Validate()` to reject invalid sizes. This makes `Size` a first-class field across all six typed entities and ensures model-layer validation fires before any persistence attempt.

## Scope
- Files to modify:
  - `internal/models/entity.go` (add `Size *int` to `BaseEntity`; `GetSize`/`SetSize` on interface and struct)
  - `internal/models/idea.go` (add `Size *int` directly; add accessors; extend `Validate()`)
  - `internal/models/epic.go`, `internal/models/feature.go`, `internal/models/task.go`, `internal/models/bug.go`, `internal/models/change_card.go` (extend `Validate()` in each)
- Files to modify (tests):
  - `internal/models/entity_test.go` (add TC-F001-A, TC-F001-B, TC-F001-C)
  - Each per-entity `*_test.go` — assert `Validate()` rejects `Size = ptr(4)`, accepts `nil` and `ptr(5)`

# CLI --size flag on all 6 create commands with ParseSize integration

## Goal
Add `--size <value>` (StringVar, default `""`) to the `create` subcommand of each of the six entity command files, wire flag parsing through `models.ParseSize`, and pass the resulting `*int` into the corresponding `CreateXInput.Size` field. Flag absent → `Size = nil`; invalid value → return error before calling service.

## Scope
- Files to modify (implementation + flags):
  - `internal/cli/commands/epic.go`
  - `internal/cli/commands/feature.go`
  - `internal/cli/commands/task.go`
  - `internal/cli/commands/bug.go`
  - `internal/cli/commands/change.go`
  - `internal/cli/commands/idea.go`
- Files to modify (tests):
  - `internal/cli/commands/epic_test.go`, `internal/cli/commands/feature_test.go`, `internal/cli/commands/task_test.go`
  - `internal/cli/commands/bug_test.go`, `internal/cli/commands/change_test.go`, `internal/cli/commands/idea_test.go`

## Acceptance Criteria
See spec.md REQ-F-004.
Additional task-specific criteria:
- AC-T1: Flag uses `StringVar` not `IntVar` per Decision D4 (must accept both `"5"` and `"L"`)
- AC-T2: `ParseSize` is called in the handler, not in the flag definition; error returned before calling service
- AC-T3: `--size clear` on a create command returns an error (not a valid size value)

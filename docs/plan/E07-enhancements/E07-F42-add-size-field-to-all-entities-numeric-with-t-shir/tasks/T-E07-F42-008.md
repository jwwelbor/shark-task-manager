# Template layer: applySizePlaceholders helper and entity template content updates

## Goal
Add `{{ .size }}` and `{{ .size_label }}` template placeholders to every entity-aware placeholder builder in `internal/config/template/helpers.go` via a shared `applySizePlaceholders` helper, and optionally surface those placeholders in the default `shark-templates` content files. The `complexity_tier` mapping must remain unchanged (REQ-F-012).

## Scope
- Files to modify (implementation):
  - `internal/config/template/helpers.go` (add `applySizePlaceholders(size *int, m map[string]string)` shared helper; call it from each per-entity placeholder builder: feature, task, and any epic/bug/change/idea helpers that exist)
- Files to modify (templates — optional content update):
  - `shark-templates/feature_short/*.tmpl`
  - `shark-templates/task/*.tmpl` (if applicable)
- Files to modify (tests):
  - `internal/config/template/helpers_test.go` (extend with TC-F011-A, TC-F011-B, TC-F011-C, TC-F012-A, TC-F012-B)

## Acceptance Criteria
See spec.md REQ-F-011, REQ-F-012.
Additional task-specific criteria:
- AC-T1: `complexity_tier` map entry is unchanged after this task — no override, no removal
- AC-T2: Nil `size` produces empty string for both `"size"` and `"size_label"` map entries (no `"<nil>"` rendered in templates)

# Repository layer: add size to INSERT/SELECT/UPDATE on all 6 entity repos

## Goal
Wire the `size` column into every INSERT, SELECT (all variants), and UPDATE statement across the six entity repositories so that `Size *int` flows without information loss from the model through to the database and back. This task ensures the persistence layer is complete before service and CLI layers are built on top of it.

- Files to modify (implementation):

  - `internal/repository/idea/repository.go`

See test-plan.md Section 1: TC-F010-A through TC-F010-F (one `TestXRepository_SizeRoundTrip` per entity).

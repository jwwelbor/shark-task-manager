# CLI --size flag on all 6 update commands with 'clear' literal support

## Goal
Add `--size <value>` to the `update` subcommand of each of the six entity command files with three-way dispatch: flag absent → no mutation; valid value → set `Size`; literal `"clear"` → set `ClearSize = true`. Pass the result into the corresponding `UpdateXInput`. This completes the full CRUD CLI surface for the size field.

## Scope
- Files to modify (implementation + flags):
  - `internal/cli/commands/epic.go`
  - `internal/cli/commands/feature.go`
  - `internal/cli/commands/task.go`
  - `internal/cli/commands/bug.go`
  - `internal/cli/commands/change.go`
  - `internal/cli/commands/idea.go`
- Files to modify (tests):
  - `internal/cli/commands/epic_test.go`, `internal/cli/commands/feature_test.go`, `internal/cli/commands/task_test.go`
  - `internal/cli/commands/bug_test.go`, `internal/cli/commands/change_test.go`, `internal/cli/commands/idea_test.go`

## Acceptance Criteria
See spec.md REQ-F-005 and Acceptance Scenario 4.
Additional task-specific criteria:
- AC-T1: Only exact lowercase `"clear"` triggers `ClearSize = true`; `"Clear"` and `"CLEAR"` go through `ParseSize` and return an error
- AC-T2: Flag absent (empty string) leaves `Size = nil` and `ClearSize = false` in the DTO — no accidental overwrites

## Test Cases
See test-plan.md Section 1: TC-F005-A through TC-F005-E for all 6 entities.
CLI tests use mock services per `.claude/rules/testing/cli-tests.md`.
TC-F005-E explicitly verifies `"Clear"` is rejected as an invalid size value, not treated as a clear sentinel.

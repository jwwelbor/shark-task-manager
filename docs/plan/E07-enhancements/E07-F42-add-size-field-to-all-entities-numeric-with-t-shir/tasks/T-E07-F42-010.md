# Documentation: CLI reference --size flag docs and CHANGELOG complexity_tier deprecation

## Goal
Update all six CLI reference pages to document the `--size` flag on `create` and `update` commands, and add a CHANGELOG entry announcing the `--size` feature and the `complexity_tier` deprecation. This is a documentation-only task; no Go code changes are made. It unblocks the feature from UAT and user-facing release.

## Scope
- Files to modify:
  - `docs/cli-reference/epic-commands.md` (add `--size` to create and update)
  - `docs/cli-reference/feature-commands.md`
  - `docs/cli-reference/task-commands.md` (or `docs/cli-reference/core-commands.md` for `shark task`)
  - `docs/cli-reference/bug-commands.md`
  - `docs/cli-reference/change-commands.md`
  - `docs/cli-reference/idea-commands.md`
  - `CHANGELOG.md` (new entry: `--size` flag; `complexity_tier` deprecation per spec.md OOS-1 and Decision D6)
- No test files (documentation only)

## Acceptance Criteria
See spec.md REQ-F-004, REQ-F-005, REQ-F-012, OOS-1.
Additional task-specific criteria:
- AC-T1: CHANGELOG entry names both numeric (`1,2,3,5,8,13`) and label (`XS,S,M,L,XL,XXL`) forms
- AC-T2: CHANGELOG advises `complexity_tier` users that the field is deprecated and announces removal in a future release
- AC-T3: `--size clear` behavior is documented in each update command reference

## Test Cases
No automated tests for this task (documentation only).

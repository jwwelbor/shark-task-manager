# Task: Update EpicPlaceholders

## Goal

Update EpicPlaceholders in internal/config/template_helpers.go to add the "key" variable (same value as "id") and remove the misleading "epic_id" alias that was redundant with "id".

## Rationale

See 02-architecture.md ADR-2 (canonical variable names) and ADR-3 (enrich existing functions). The epic_id key was redundant with id and had a misleading name implying database ID.

## Scope

- File: internal/config/template_helpers.go -- modify EpicPlaceholders function
- File: internal/config/template_helpers_test.go -- add/update tests

## Acceptance Criteria

- EpicPlaceholders returns map containing "key" with the epic's key value
- EpicPlaceholders returns map containing "id" (backward compat alias, same value as "key")
- EpicPlaceholders does NOT return "epic_id" key
- Nil epic input returns empty map without panic
- All existing fields still present: title, status, priority, business_value, slug, file_path, created_at, updated_at
- Test cases: see 09-test-plan.md AC-3 (TC-EP-01 through TC-EP-05)
- make fmt and make lint and make test all pass

## Dependencies

None. EpicPlaceholders does not need key-parsing helpers since epics are top-level entities.

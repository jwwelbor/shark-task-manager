# Task: Add Key-Parsing Helpers with Tests

## Goal

Add two unexported helper functions to internal/config/template_helpers.go that extract parent entity keys from child entity keys by string parsing. These helpers enable TaskPlaceholders and FeaturePlaceholders to correctly populate epic_key and feature_key without database lookups.

## Rationale

See 02-architecture.md ADR-5: Task key format (T-E##-F##-### or E##-F##-###) deterministically encodes parent keys. String parsing avoids adding database dependencies to pure utility functions and avoids changing function signatures (10+ callers).

## Scope

- File: internal/config/template_helpers.go -- add parseEpicKeyFromEntityKey and parseFeatureKeyFromTaskKey
- File: internal/config/template_helpers_test.go -- add table-driven tests

## Acceptance Criteria

- parseEpicKeyFromEntityKey extracts E## from task keys (T-E07-F01-001, E07-F01-001), feature keys (E07-F01), and epic keys (E07)
- parseFeatureKeyFromTaskKey extracts E##-F## from task keys; returns empty string for non-task keys
- Handles slugged keys (e.g., T-E07-F01-001-implement-jwt returns E07)
- Empty string input returns empty string (no panic)
- Test cases: see 09-test-plan.md Section 3.1 (TC-PK-01 through TC-PK-11)
- make fmt and make lint and make test all pass

## Dependencies

None. This is the foundation task with no prerequisites.

# Task: Update FeaturePlaceholders

## Goal

Update FeaturePlaceholders in internal/config/template_helpers.go to add "key" and "epic_key" variables, remove the misleading "feature_id" alias, and add "description" when present.

## Rationale

See 02-architecture.md ADR-2 and Section 2 (Component Design, item 2 for FeaturePlaceholders). The epic_key is parsed from the feature key using parseEpicKeyFromEntityKey (from T-E07-F33-001).

## Scope

- File: internal/config/template_helpers.go -- modify FeaturePlaceholders function
- File: internal/config/template_helpers_test.go -- add/update tests

## Acceptance Criteria

- Returns "key" with the feature's key value
- Returns "epic_key" parsed from feature key (e.g., E07-F01 produces epic_key=E07)
- Returns "id" as backward compat alias
- Does NOT return "feature_id"
- Returns "description" when feature description is non-nil
- Nil feature input returns empty map without panic
- Handles slugged feature keys (e.g., E07-F01-my-feature)
- Test cases: see 09-test-plan.md AC-2 (TC-FP-01 through TC-FP-06)
- make fmt and make lint and make test all pass

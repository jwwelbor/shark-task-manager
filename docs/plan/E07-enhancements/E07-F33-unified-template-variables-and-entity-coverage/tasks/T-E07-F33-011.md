# Task: Update Template Files and Config for Variable Name Changes

## Goal

Search and replace old variable names in all .tmpl files and .sharkconfig.json orchestrator_action instruction fields. Replace task_id with key (or task_key), epic_id with epic_key, and feature_id with feature_key.

## Rationale

See 02-architecture.md Section 4 (Migration Approach). The old variable names are being removed from the placeholder functions; templates must use the new names.

## Scope

- All .tmpl files under internal/templates/ or similar template directories
- .sharkconfig.json orchestrator_action instruction strings
- Any workflow profile JSON files that contain template placeholders

## Acceptance Criteria

- No occurrences of {task_id}, {epic_id}, or {feature_id} in any .tmpl file (search verification)
- No occurrences of {task_id}, {epic_id}, or {feature_id} in .sharkconfig.json orchestrator_action instructions
- {id} alias is preserved (NOT replaced -- it remains for backward compat)
- Template rendering produces correct output with new variable names
- See 09-test-plan.md Section 4.2 (TM-01 through TM-06) for migration scenarios
- make fmt and make lint and make test all pass

## Dependencies

- T-E07-F33-002, T-E07-F33-007, T-E07-F33-008 (placeholder functions must be updated so the new variable names are populated)

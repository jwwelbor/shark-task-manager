# Task: Expand ChangeCardPlaceholders

## Goal

Expand ChangeCardPlaceholders in internal/config/template_helpers.go to include the full set of change-card-specific fields: slug, created_at, updated_at, requested_by, assigned_to, justification, impact_analysis, and rollback_plan.

## Rationale

See 02-architecture.md Section 2 (Component Design, item 5 for ChangeCardPlaceholders). Currently ChangeCardPlaceholders only populates a minimal set. Expanding it allows orchestrator action templates to reference all change card fields.

## Scope

- File: internal/config/template_helpers.go -- modify ChangeCardPlaceholders function
- File: internal/config/template_helpers_test.go -- add/update tests

## Acceptance Criteria

- Returns all common fields: key, id, title, status, description, priority, file_path
- Returns expanded fields: slug, created_at, updated_at
- Returns change-card-specific fields: requested_by, assigned_to, justification, impact_analysis, rollback_plan
- Nil optional fields degrade gracefully (no panic)
- Nil change card input returns empty map without panic
- Test cases: see 09-test-plan.md AC-5 (TC-CC-01 through TC-CC-08)
- make fmt and make lint and make test all pass

## Dependencies

None. ChangeCard placeholders are independent of the key-parsing helpers.

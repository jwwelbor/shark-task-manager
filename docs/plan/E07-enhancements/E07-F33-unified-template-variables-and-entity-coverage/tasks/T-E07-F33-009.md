# Task: Expand BugPlaceholders

## Goal

Expand BugPlaceholders in internal/config/template_helpers.go to include the full set of bug-specific fields: description, slug, created_at, updated_at, linked_entity_type, and linked_entity_key.

## Rationale

See 02-architecture.md Section 2 (Component Design, item 4 for BugPlaceholders). Currently BugPlaceholders only populates a minimal set. Expanding it allows orchestrator action templates to reference all bug fields.

## Scope

- File: internal/config/template_helpers.go -- modify BugPlaceholders function
- File: internal/config/template_helpers_test.go -- add/update tests

## Acceptance Criteria

- Returns all common fields: key, id, title, status, severity, file_path
- Returns expanded fields: description, slug, created_at, updated_at
- Returns linked entity fields: linked_entity_type, linked_entity_key
- Nil optional fields degrade gracefully (absent from map or empty string, no panic)
- Nil bug input returns empty map without panic
- Test cases: see 09-test-plan.md AC-4 (TC-BP-01 through TC-BP-07)
- make fmt and make lint and make test all pass

## Dependencies

None. Bug placeholders are independent of the key-parsing helpers.

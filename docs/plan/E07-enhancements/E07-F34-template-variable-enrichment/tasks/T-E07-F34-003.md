# Task: Update PlaceholdersWithRelated signatures and add applyEnrichmentData helper

## Goal

Modify the three `*PlaceholdersWithRelated()` function signatures in `internal/config/template_helpers.go` to accept an optional `*TemplateEnrichmentData` parameter. Create the `applyEnrichmentData()` helper that merges enrichment data into the placeholder map. Update all 6 call sites in services to pass `nil` for backward compatibility. This is the compile-breaking change that bridges infrastructure (T-002) with wiring (T-004).

## Scope

- Add `*TemplateEnrichmentData` as final parameter to `TaskPlaceholdersWithRelated()`, `FeaturePlaceholdersWithRelated()`, `EpicPlaceholdersWithRelated()`
- Implement `applyEnrichmentData()` helper per architecture doc section 6.2
- Update all 6 call sites to pass `nil` as the enrichment parameter
- Add nil-safety unit tests to verify backward compatibility

## Requirements

### Functional Requirements

- [ ] `TaskPlaceholdersWithRelated()` accepts `enrichment *TemplateEnrichmentData` as final parameter
- [ ] `FeaturePlaceholdersWithRelated()` accepts `enrichment *TemplateEnrichmentData` as final parameter
- [ ] `EpicPlaceholdersWithRelated()` accepts `enrichment *TemplateEnrichmentData` as final parameter
- [ ] `applyEnrichmentData(enrichment *TemplateEnrichmentData, placeholders map[string]string)` function implemented
- [ ] applyEnrichmentData maps: PreviousStatus -> `previous_status`, ParentTitle -> `parent_title`, GrandparentTitle -> `grandparent_title`, LatestNoteContent -> `latest_note`, LatestNoteType -> `latest_note_type`, NotesCount -> `notes_count`, RejectionCount -> `rejection_count`, SiblingTotal -> `sibling_total`, SiblingCompleted -> `sibling_completed`, SiblingBlocked -> `sibling_blocked`
- [ ] Empty string fields (PreviousStatus, ParentTitle, etc.) are NOT added to the map
- [ ] Integer fields (counts) are always added as string representations (even when 0)
- [ ] All 6 call sites updated to pass nil

### Non-Functional Requirements

- [ ] Passing nil enrichment produces identical output to pre-change behavior
- [ ] `make build` succeeds after all call site updates (compile-time verification)
- [ ] All existing tests pass without modification (other than adding nil parameter)

### Technical Approach

- The signature change is a compile-time break -- every caller must be updated in the same commit
- `applyEnrichmentData()` is called at the end of each `*PlaceholdersWithRelated()` function, after all other placeholder population
- Nil check is the first line of `applyEnrichmentData()` for safety
- Follow exact field mapping from architecture doc section 6.2

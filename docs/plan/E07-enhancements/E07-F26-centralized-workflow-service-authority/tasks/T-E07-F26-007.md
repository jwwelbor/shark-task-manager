# Task: Remove deprecated status constants and standalone helpers

## Goal

Final cleanup: remove the deprecated `TaskStatus*` constants from `models/task.go` and the standalone `IsDefaultStatus()`/`DefaultStatuses()` functions from `config/workflow_default.go`. By this point, all consumers should be using `workflow.Service` methods, so these are dead code.

## Files to Modify

### `internal/models/task.go`
- **Lines 26-33**: Remove the deprecated `TaskStatus*` constants (`TaskStatusTodo`, `TaskStatusInProgress`, `TaskStatusBlocked`, `TaskStatusReadyForReview`, `TaskStatusCompleted`, `TaskStatusArchived`). These are marked deprecated but still referenced.
- Update any remaining references to use string literals in test fixtures, or `workflow.Service` methods in production code.

### `internal/config/workflow_default.go`
- **`IsDefaultStatus()` (lines 78-87)**: Remove. Callers should use `workflow.Service.IsValidStatus()`.
- **`DefaultStatuses()` (lines 89-92)**: Remove. Callers should use `workflow.Service.GetAllStatuses()`.
- **`DefaultWorkflow()` stays** - this IS the single default definition and is correct.

### `internal/workflow/service.go`
- **Lines 53, 63, 73**: Remove fallbacks to `models.TaskStatusTodo` and `models.TaskStatusCompleted`. The service should rely on `config.DefaultWorkflow()` for defaults, not model constants.

## Prerequisites

This task must run AFTER tasks 004, 005, and 006 are complete, since those tasks migrate all callers away from the deprecated code.

## Acceptance Criteria

- [ ] No `TaskStatus*` constants exist in `models/task.go` (or they are fully unused)
- [ ] No `IsDefaultStatus()` or `DefaultStatuses()` in `config/workflow_default.go`
- [ ] `workflow/service.go` has no imports of `models.TaskStatus*` constants
- [ ] `make build` compiles cleanly (no unused import/variable errors)
- [ ] `make test` passes
- [ ] `grep -r "TaskStatusTodo\|TaskStatusCompleted\|TaskStatusBlocked\|TaskStatusInProgress\|TaskStatusReadyForReview" internal/` returns only test files (if any)

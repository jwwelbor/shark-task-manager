# Task: Remove sync command and related code

## Goal

The `shark sync` command and its underlying code (`internal/sync/`, `internal/cli/commands/sync.go`, `internal/discovery/`) were supposed to have been removed previously but are still present in the codebase. Remove the command registration, the sync engine, and all supporting code that is only used by sync.

## Requirements

- [ ] `shark sync` no longer appears in help output or as a registered command
- [ ] `internal/sync/` package removed (if no other code depends on it)
- [ ] `internal/cli/commands/sync.go` removed
- [ ] `internal/discovery/` removed if only used by sync (verify dependencies first)
- [ ] Any imports of removed packages cleaned up
- [ ] No orphaned test files remain
- [ ] Build succeeds (`make build`)
- [ ] All tests pass (`make test`)

## Implementation Plan

1. [ ] Identify all files registering the sync command (`init()` in sync.go)
2. [ ] Trace imports of `internal/sync/` and `internal/discovery/` to confirm they are sync-only
3. [ ] Remove `internal/cli/commands/sync.go` and its test file
4. [ ] Remove `internal/sync/` package (all files)
5. [ ] Remove `internal/discovery/` if sync-only; if shared, leave it
6. [ ] Remove any CLI reference docs for the sync command
7. [ ] Run `make build && make test` to verify clean removal

## Acceptance Criteria

- [ ] `shark --help` does not list a `sync` subcommand
- [ ] `shark sync` returns "unknown command"
- [ ] `make build` succeeds with no compilation errors
- [ ] `make test` passes with no failures
- [ ] No dead imports remain

## Notes

- The sync command was previously slated for removal but the code was never deleted.
- Discovery package may be used by other code (e.g., init) - verify before removing.

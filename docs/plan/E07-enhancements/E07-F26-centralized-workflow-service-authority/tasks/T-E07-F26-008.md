# Task: Update task create help text to promote --order over --priority

## Goal

The `shark task create` and `shark task list` help text should promote `--order` / `--execution-order` as the primary way to sequence tasks, with `--priority` as secondary. Currently `--priority` is more prominent in examples and documentation. Execution order is the intended mechanism for defining task sequence within a feature.

## Files to Modify

- `internal/cli/commands/task.go` (or wherever task create flags are registered) - Reorder flags so `--order` appears before `--priority`, update description text
- `internal/cli/commands/task_create.go` (if separate) - Same
- Help text / Long description for `task create` command - Show `--order` in examples first
- `.claude/rules/quickref.md` - Update examples to include `--order`
- `.claude/rules/development-workflows.md` - Mention `--order` in task creation workflow
- `docs/cli-reference/task-commands.md` - Update reference docs

## Acceptance Criteria

- [ ] `shark task create --help` shows `--order` prominently with clear description
- [ ] Examples in help text demonstrate `--order` usage
- [ ] `--priority` still works but is presented as secondary to `--order`
- [ ] Documentation updated to match

# Foundation: extract validation and template sub-packages

## Goal

Extract the two leaf-node sub-packages — `validation/` and `template/` — from `internal/config/` into their own focused sub-packages. These files have zero internal config dependencies, making them the safest first extraction and establishing the pattern for subsequent phases.

## Scope

- Files to create: `internal/config/validation/error.go`, `internal/config/template/helpers.go`
- Files to create: `internal/config/aliases.go` (initial, covering validation and template symbols)
- Test files to move: `template_helpers_test.go` -> `internal/config/template/helpers_test.go`
- Files to remove: `internal/config/validation_error.go`, `internal/config/template_helpers.go`

## Acceptance Criteria

See spec.md AC-005, AC-006, AC-008 (template and validation symbols)

- AC-T1: `go build ./internal/config/validation/` compiles with stdlib-only imports
- AC-T2: `go build ./internal/config/template/` compiles importing only `internal/models`
- AC-T3: `aliases.go` uses import alias for `template` sub-package (avoids conflict with stdlib `text/template`)
- AC-T4: `make fmt && make lint && make test` passes at end of this task (see test-plan.md 1.1)

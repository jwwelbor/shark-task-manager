# Extract action sub-package (orchestrator action + action service)

## Goal

Extract `action/` sub-package from `internal/config/` containing the orchestrator action types, action service interface, and mock. This phase depends on Task 001 (`validation/` complete) because `action/` imports `OrchestratorValidationError` from `validation/`. The `workflow/` extraction is deferred to Task 004 — `action/` will temporarily import root `config` for workflow types until Task 004 completes.

## Scope

- Files to create: `internal/config/action/orchestrator.go`, `internal/config/action/service.go`, `internal/config/action/mock_service.go`
- Test files to move: `orchestrator_action_test.go`, `orchestrator_action_validation_test.go`, `action_service_test.go` -> `internal/config/action/`
- Files to update: `internal/config/aliases.go` — add all `action/` symbol aliases
- Files to remove: `internal/config/orchestrator_action.go`, `internal/config/action_service.go`, `internal/config/mock_action_service.go`

See spec.md AC-004, AC-008 (action symbols)

- AC-T2: `var _ ActionService = (*DefaultActionService)(nil)` compiles (interface satisfaction)
- AC-T3: `make fmt && make lint && make test` passes (see test-plan.md 1.2)

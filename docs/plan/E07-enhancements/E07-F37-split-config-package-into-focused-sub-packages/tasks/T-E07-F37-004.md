# Extract workflow sub-package with backward-compat alias shim

## Goal

Extract the `workflow/` sub-package — the largest extraction at 1,521 LOC across 5 files — and complete `aliases.go` with all remaining symbols. Update `config.go` and `manager.go` to import `workflow/` and `action/` directly. This phase delivers the zero-breakage guarantee: all 97 external callers continue using `config.WorkflowConfig`, `config.LoadWorkflowConfig`, etc. via the type alias shim.

## Scope

- Files to create: `internal/config/workflow/schema.go`, `workflow/parser.go`, `workflow/validator.go`, `workflow/defaults.go`, `workflow/multilevel.go`
- Test files to move: all workflow test files -> `internal/config/workflow/` (see test-plan.md Section 4 table)
- Files to update: `internal/config/config.go` (import `workflow/` for StatusMetadata), `internal/config/manager.go` (import `action/`), `internal/config/aliases.go` (complete all workflow symbols + re-declare constants)
- Files to remove: `workflow_schema.go`, `workflow_parser.go`, `workflow_validator.go`, `workflow_default.go`, `workflow_multilevel.go`

## Acceptance Criteria

See spec.md AC-001, AC-002, AC-003, AC-007, AC-008 (workflow symbols)

- AC-T4: `make fmt && make lint && make test` passes (test-plan.md 1.3)

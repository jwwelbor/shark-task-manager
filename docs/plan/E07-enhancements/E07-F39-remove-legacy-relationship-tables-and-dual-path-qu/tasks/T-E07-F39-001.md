# Remove Legacy Relationship Table References

## Goal

The canonical store for all entity relationships is `entity_relationships` (added in E21-F11).
Data was migrated from the three legacy tables into it. This task removes all surviving
read/write paths that still target `task_relationships`, `feature_relationships`, and
`epic_relationships` so no code can silently write to or read from a stale source.

## Scope

Files to delete or replace with entityrel shims:
- `internal/repository/task/relationship.go` — still writes/reads task_relationships
- `internal/repository/feature/relationship.go` — still writes/reads feature_relationships
- `internal/repository/epic/relationship.go` — still writes/reads epic_relationships

Files to update (dual-path query removal):
- `internal/repository/task/dependency.go` — fallback queries against task_relationships
- `internal/config/template/helpers.go` — queries task_relationships, feature_relationships, epic_relationships; adapters already exist in `internal/repository/entityrel/`
- `internal/cli/commands/migrate_relationships.go` — remove or gate behind a one-time flag

Models to remove once callers are gone:
- `internal/models/task_relationship.go` (marked LEGACY)
- `internal/models/feature_relationship.go` (marked LEGACY)
- `internal/models/epic_relationship.go` (marked LEGACY)

Schema (do last, after all code paths removed):
- Add DROP TABLE migration in `internal/db/db.go` for task_relationships, feature_relationships, epic_relationships

## Acceptance Criteria

- AC-1: `grep -r "task_relationships\|feature_relationships\|epic_relationships" internal/ --include="*.go"` returns only db.go migration/DROP code
- AC-2: `shark task link` and `shark task deps` work correctly via entity_relationships
- AC-3: Three legacy tables are dropped via a new numbered migration
- AC-4: `make fmt && make lint && make test` passes clean

## Test Cases

See feature.md. Run `shark task link` / `shark task deps` round-trip after migration.
Run `make test` across all packages — zero regressions.

## Design Reference

See E21-F11 for the original migration and `internal/repository/entityrel/repository.go`
for the EntityRelTaskKeyAdapter pattern to use when replacing legacy query sites.

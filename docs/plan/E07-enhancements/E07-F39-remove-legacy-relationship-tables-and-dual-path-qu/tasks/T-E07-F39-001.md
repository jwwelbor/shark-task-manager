# Remove Legacy Relationship Table References

## Goal

Remove all surviving read/write code paths that target the three legacy relationship
tables. After E21-F11, `entity_relationships` is the canonical store. This task
eliminates stale callers, deletes legacy repo/model files, and adds the DROP TABLE
migration so no code can silently write to or read from a stale source.

## Scope

Files to delete:
- `internal/repository/task/relationship.go`
- `internal/repository/task/relationship_test.go`
- `internal/repository/feature/relationship.go`
- `internal/repository/epic/relationship.go`
- `internal/repository/task_relationship_repository_test.go`
- `internal/repository/relationship_repositories_test.go`
- `internal/cli/commands/migrate_relationships.go`
- `internal/models/task_relationship.go`
- `internal/models/feature_relationship.go`
- `internal/models/epic_relationship.go`

Files to modify:
- `internal/repository/task/dependency.go` — remove dual-path fallbacks at lines 311–319 and 467–475; delegate to `entityrel` repository via `EntityRelTaskKeyAdapter`
- `internal/config/template/helpers.go` — replace legacy table queries at lines 316, 425, 468, 503 with new adapters
- `internal/repository/entityrel/repository.go` — add `EntityRelFeatureKeyAdapter` and `EntityRelEpicKeyAdapter` mirroring the existing `EntityRelTaskKeyAdapter` shape
- `internal/db/db.go` — add `migrateDropLegacyRelationshipTables` migration; bump `CurrentSchemaVersion` 11 → 12
- `internal/repository/task/dependency_test.go` — update fixtures to seed `entity_relationships` instead of `task_relationships`

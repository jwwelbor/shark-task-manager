## Observations / Non-Blocking Notes

1. **Schema DDL still defines legacy tables at db.go:289–316.** The `CREATE TABLE IF NOT EXISTS task_relationships` schema block runs before `migrateDropLegacyRelationshipTables` on fresh databases, which means a fresh init briefly creates the table and then drops it in the same session. Functionally correct (idempotent, ends in desired state) and explicitly allowed by REQ-N-002 which whitelists `db.go`. Consider removing the CREATE block in a follow-up to avoid the create-then-drop dance — not required by this task.
2. **`migrate.go` still contains FK-fix logic for `task_relationships`.** Per REQ-N-002 this is explicitly allowed. Will become dead code once all production DBs advance past version 12; safe to prune later.
3. **Adapter design:** `EntityRelFeatureKeyAdapter.ListRelatedFeatures` and `ListRelatedFeatureKeys` are the same method under two names to satisfy both the `config.FeatureRelationshipRepository` interface and the naming convention used by the task adapter. Reasonable compat shim.

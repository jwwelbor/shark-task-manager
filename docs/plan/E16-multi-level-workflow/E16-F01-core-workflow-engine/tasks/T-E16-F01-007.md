# Task: Workflow Validate Extension and Integration Testing

## Goal

Extend `shark workflow validate` to validate all three workflow levels (epic, feature, task) and verify the complete E16-F01 implementation through integration testing across all layers. This is the final verification task ensuring everything works end-to-end.

## Success Criteria

- [ ] `shark workflow validate` reports validation results for all three levels
- [ ] Output format: `Epic workflow: valid (N statuses, custom/default)`
- [ ] Invalid workflow at any level shows specific errors with fix suggestions
- [ ] `_aggregation_` special status entries validated (if present, must exist in status_flow)
- [ ] Default workflows display as "(N statuses, default)"
- [ ] Custom workflows display as "(N statuses, custom)"
- [ ] `--json` flag returns structured validation results for all levels
- [ ] End-to-end: epic next-status advances through custom workflow
- [ ] End-to-end: feature next-status advances through custom workflow
- [ ] End-to-end: existing task workflow behavior completely unchanged
- [ ] Backward compatibility: config without epic/feature workflows works identically to before

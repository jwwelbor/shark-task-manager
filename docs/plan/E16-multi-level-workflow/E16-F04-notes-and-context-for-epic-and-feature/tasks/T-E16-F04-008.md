# Task: Epic Note and Context CLI Commands

## Goal

Add CLI commands for adding/listing notes and setting/getting/clearing context on epics. These are thin wrappers that call `NoteService` and `ContextService`.

## Requirements

### Functional Requirements

- [ ] `shark epic note add <key> --type <type> "<content>" [--created-by <agent>] [--json]`
- [ ] `shark epic note list <key> [--type <types>] [--json]`
- [ ] `shark epic context set <key> --field <field> --value "<value>" [--json]`
- [ ] `shark epic context get <key> [--json]`
- [ ] `shark epic context clear <key> [--json]`
- [ ] Case insensitive epic keys (E16, e16, E16-multi-level-workflow)
- [ ] JSON output for all commands
- [ ] Human-readable output for all commands

### Non-Functional Requirements

- [ ] Commands are thin wrappers: parse args, call service, format output
- [ ] No business logic in command handlers
- [ ] Follow existing Cobra command registration pattern

## Implementation Plan

### Steps

1. [ ] Create `internal/cli/commands/epic_note.go`:
   - Define `epicNoteCmd` parent command
   - Define `epicNoteAddCmd` with flags: `--type` (required), `--created-by` (optional)
   - Positional arg: epic key, content as remaining args or final positional
   - Handler: parse args -> call `NoteService.AddNote(ctx, "epic", key, type, content, createdBy)` -> format output
   - Define `epicNoteListCmd` with flags: `--type` (optional, comma-separated filter)
   - Handler: parse args -> call `NoteService.ListNotes(ctx, "epic", key, types)` -> format output
   - Register as subcommands of `epicCmd`
2. [ ] Create `internal/cli/commands/epic_context.go`:
   - Define `epicContextCmd` parent command
   - Define `epicContextSetCmd` with flags: `--field` (required), `--value` (required)
   - Handler: call `ContextService.SetContextField(ctx, "epic", key, field, value)`
   - Define `epicContextGetCmd`
   - Handler: call `ContextService.GetContext(ctx, "epic", key)` -> format JSON or human-readable
   - Define `epicContextClearCmd`
   - Handler: call `ContextService.ClearContext(ctx, "epic", key)`
   - Register as subcommands of `epicCmd`
3. [ ] Register commands in `init()` functions

### CLI Output Patterns

**Note add (human-readable)**:
```
Added decision note to epic E16
```

**Note add (JSON)**:
```json
{"id": 42, "entity_type": "epic", "entity_id": 16, "note_type": "decision", "content": "...", "created_at": "..."}
```

**Note list (human-readable)**:
```
Notes for epic E16:

  [decision] 2026-02-09 10:30  Chose polymorphic notes table
  [comment]  2026-02-09 11:00  Research phase complete
```

**Context get (human-readable)**:
```
Context for epic E16:

  Progress:
    Current Step: Feature decomposition
    Completed: Research, BA refinement
    Remaining: Build, QA

  Open Questions:
    - Should completion be auto-detected?
```

# Task: Feature Note and Context CLI Commands

## Goal

Add CLI commands for adding/listing notes and setting/getting/clearing context on features. Mirrors the epic note/context commands (T-E16-F04-008) but for features.

## Requirements

### Functional Requirements

- [ ] `shark feature note add <key> --type <type> "<content>" [--created-by <agent>] [--json]`
- [ ] `shark feature note list <key> [--type <types>] [--json]`
- [ ] `shark feature context set <key> --field <field> --value "<value>" [--json]`
- [ ] `shark feature context get <key> [--json]`
- [ ] `shark feature context clear <key> [--json]`
- [ ] Case insensitive feature keys (E16-F04, e16-f04, F04, E16-F04-notes-and-context)
- [ ] JSON output for all commands
- [ ] Human-readable output for all commands

### Non-Functional Requirements

- [ ] Commands are thin wrappers: parse args, call service, format output
- [ ] No business logic in command handlers
- [ ] Follow existing Cobra command registration pattern

## Implementation Plan

### Steps

1. [ ] Create `internal/cli/commands/feature_note.go`:
   - Define `featureNoteCmd` parent command
   - Define `featureNoteAddCmd` with flags: `--type` (required), `--created-by` (optional)
   - Positional arg: feature key, content
   - Handler: call `NoteService.AddNote(ctx, "feature", key, type, content, createdBy)`
   - Define `featureNoteListCmd` with flags: `--type` (optional)
   - Handler: call `NoteService.ListNotes(ctx, "feature", key, types)`
   - Register as subcommands of `featureCmd`
2. [ ] Create `internal/cli/commands/feature_context.go`:
   - Define `featureContextCmd` parent command
   - Define `featureContextSetCmd`, `featureContextGetCmd`, `featureContextClearCmd`
   - Handlers call `ContextService` methods with `entityType = "feature"`
   - Register as subcommands of `featureCmd`
3. [ ] Register commands in `init()` functions

### CLI Output

Same patterns as epic commands (T-E16-F04-008) but with "feature" entity type.

# Task: Add note timeline command for epics and features

## Goal

Implement a `shark history` style command that interleaves status changes with notes for epics and features, similar to the existing `shark task note timeline` command for tasks. This requires status history tracking at the epic/feature level (which may come from E16-F01).

## Context

From E16-F04 Architecture Open Design Question #1:
> The existing `shark task note timeline` command interleaves status changes with notes. Should we implement this for epics and features?

Decision: Yes, implement eventually. Low priority now. Depends on epic/feature status history tracking being available (E16-F01 may add this).

## Requirements

### Functional Requirements

- [ ] `shark epic note timeline <key>` shows interleaved status changes and notes
- [ ] `shark feature note timeline <key>` shows interleaved status changes and notes
- [ ] JSON and human-readable output formats supported

### Dependencies

- Requires epic/feature status history tracking (E16-F01 or similar)
- Requires entity_notes table (E16-F04 core tasks)

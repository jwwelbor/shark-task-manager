// Parse entity type filter
var entityType *models.EntityType
if entityTypeStr != "" {
    entityTypeStr = strings.ToLower(strings.TrimSpace(entityTypeStr))
    et := models.EntityType(entityTypeStr)
    if !models.ValidEntityTypes[et] {
        return fmt.Errorf("invalid entity-type: %s (must be one of: epic, feature, task)", entityTypeStr)
    }
    entityType = &et
}

**Strengths:**
- Efficient SQL filtering
- Optional filter (only adds WHERE clause when needed)
- Proper parameterized query (SQL injection safe)
- Works for non-epic/feature filtered searches

**Design Decision:**
The implementation correctly handles two query paths:
1. **Epic/Feature filtering:** Joins through tasks→features→epics (lines 193-211)
2. **Entity-type filtering:** Direct query on entity_notes (lines 213-224)

This is correct because epic/feature filters only make sense for tasks, while entity-type filtering works across all entities.

# Task: Extract displayOrchestratorAction to shared file and surface in epic/feature next-status

## Goal

Move the `displayOrchestratorAction()` function out of `internal/cli/commands/task.go` into a new shared file so it can be reused by the epic and feature `next-status` commands. Then add calls to this function in the epic and feature human-readable transition output so orchestrator actions are visible to human operators (not just in JSON mode).

This is a pure CLI-layer refactor plus two small display additions. No service or config changes.

### Technical Approach

#### New File: `internal/cli/commands/orchestrator_display.go`

```go
package commands

import (
    "fmt"
    "strings"

    "github.com/jwwelbor/shark-task-manager/internal/config"
)

// displayOrchestratorAction displays the orchestrator action summary in human-readable format.
// This function is shared across task, epic, and feature next-status commands.
// It handles nil action gracefully by printing "Next Action: None configured".
func displayOrchestratorAction(action *config.PopulatedAction) {
    if action == nil {
        fmt.Println("Next Action: None configured")
        return
    }

    fmt.Println("\nNext Action:")
    fmt.Printf("  Type: %s\n", action.Action)
    if action.AgentType != "" {
        fmt.Printf("  Agent: %s\n", action.AgentType)
    }
    if len(action.Skills) > 0 {
        fmt.Printf("  Skills: %s\n", strings.Join(action.Skills, ", "))
    }
    fmt.Printf("\nInstruction: %s\n", action.Instruction)
}
```

This is an exact copy of the current implementation from `task.go` lines 2652-2667. No logic changes.

#### Modification: `internal/cli/commands/task.go`

Delete the `displayOrchestratorAction` function (lines 2651-2667). The comment block above it can remain or be removed. The call site at line 1690 (`displayOrchestratorAction(orchestratorAction)`) is unchanged.

#### Modification: `internal/cli/commands/epic_next_status.go`

In the `performEntityTransition()` function (line 169), after the human-readable success message, add the orchestrator action display. The current code at lines 186-188:

```go
    cli.Success(fmt.Sprintf("Transitioned: %s -> %s", transResult.FromStatus, transResult.ToStatus))
    return nil
```

Changes to:

```go
    cli.Success(fmt.Sprintf("Transitioned: %s -> %s", transResult.FromStatus, transResult.ToStatus))
    displayOrchestratorAction(transResult.OrchestratorAction)
    return nil
```

This single change covers both epic and feature because `performEntityTransition` is the shared helper used by both `runEpicNextStatus` and `runFeatureNextStatus`. No separate change to `feature_next_status.go` is needed.

Note: The `TransitionResult` struct must already have the `OrchestratorAction *config.PopulatedAction` field (added by T-E16-F02-002). If that field is nil (no action configured for the target status), `displayOrchestratorAction` prints "Next Action: None configured".

# Task: Integration testing and CLI reference documentation

## Goal

Verify end-to-end backward transition behavior and update CLI reference documentation with new commands and flags.

## Requirements

### Functional Requirements

- [ ] End-to-end test: backward transition with reason -> verify note created
- [ ] End-to-end test: backward transition without reason -> verify error
- [ ] End-to-end test: forward transition without reason -> succeeds
- [ ] End-to-end test: force bypass for backward transition
- [ ] Verify JSON output includes all new fields (is_backward, reason, child_count)
- [ ] Update CLI_REFERENCE.md with `epic set-status` command
- [ ] Update CLI_REFERENCE.md with `feature set-status` command
- [ ] Document `--reason` flag on `epic/feature next-status`

### Non-Functional Requirements

- [ ] Documentation follows existing CLI_REFERENCE.md patterns
- [ ] All tests pass: `make fmt && make lint && make test`

## Implementation Plan

### Steps

1. [ ] Write integration tests exercising the full command -> service -> repo chain
2. [ ] Verify JSON serialization of TransitionResult with new fields
3. [ ] Test error messages are user-friendly
4. [ ] Update `docs/CLI_REFERENCE.md` or relevant sub-files
5. [ ] Update `docs/cli-reference/epic-commands.md` if it exists
6. [ ] Update `docs/cli-reference/feature-commands.md` if it exists
7. [ ] Final `make fmt && make lint && make test` pass

### Documentation Updates

Add to Epic Commands section:
```
shark epic set-status <epic-key> <status> [--reason="..."] [--force] [--agent="..."] [--json]
```

Add to Feature Commands section:
```
shark feature set-status <feature-key> <status> [--reason="..."] [--force] [--agent="..."] [--json]
```

Note `--reason` flag addition on:
```
shark epic next-status <epic-key> [--status=<status>] [--reason="..."] [--force] [--agent="..."]
shark feature next-status <feature-key> [--status=<status>] [--reason="..."] [--force] [--agent="..."]
```

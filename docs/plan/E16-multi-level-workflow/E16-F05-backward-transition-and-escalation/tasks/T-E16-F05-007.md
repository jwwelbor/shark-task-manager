# Task: Feature set-status CLI command

## Goal

Create `shark feature set-status <key> <status>` command that allows setting any valid feature status with workflow validation and backward transition guards.

## Requirements

### Functional Requirements

- [ ] New file: `internal/cli/commands/feature_set_status.go`
- [ ] Command: `shark feature set-status <feature-key> <status>`
- [ ] Flags: `--reason`, `--force`, `--agent`
- [ ] Parse key and status from positional args
- [ ] Call `featureSvc.TransitionStatus()` with `TransitionOptions`
- [ ] Display success message with from/to status
- [ ] Display reason when backward transition
- [ ] Display child count warning showing task count
- [ ] JSON output support via `cli.GlobalConfig.JSON`
- [ ] Error handling: not found (exit 1), invalid state (exit 3)

### Non-Functional Requirements

- [ ] Identical pattern to epic set-status for consistency
- [ ] Thin wrapper: no business logic in command

## Implementation Plan

### Steps

1. [ ] Create `internal/cli/commands/feature_set_status.go`
2. [ ] Define `featureSetStatusCmd` cobra command
3. [ ] Register flags and as subcommand of `featureCmd`
4. [ ] Implement `runFeatureSetStatus()` - same pattern as epic set-status
5. [ ] Create `internal/cli/commands/feature_set_status_test.go`

### Technical Approach

Same pattern as T-E16-F05-006, substituting:
- `cli.GetFeatureService()` for service
- "Feature" for entity type in messages
- "tasks" for child entity in warning message

**Output format**:
```
Human: Feature E16-F01: draft -> active
Human (backward): Feature E16-F01: active -> draft
  Reason: Requirements changed
  Warning: 15 tasks remain in current states.
```

### Dependencies

- T-E16-F05-004 (FeatureService with TransitionOptions)
- T-E16-F05-005 (entityTransitioner interface updated)
- Can be done in parallel with T-E16-F05-006

## Acceptance Criteria

- [ ] `shark feature set-status E16-F01 active` performs forward transition
- [ ] `shark feature set-status E16-F01 draft --reason "text"` performs backward transition
- [ ] `shark feature set-status E16-F01 draft` without reason returns error for backward
- [ ] `shark feature set-status E16-F01 draft --force --reason "text"` bypasses validation with reason
- [ ] `shark feature set-status E16-F01 draft --force` without reason returns error
- [ ] `shark feature set-status E16-F01 active --json` returns JSON TransitionResult
- [ ] Child count warning shows task count
- [ ] `make fmt && make lint && make test` passes

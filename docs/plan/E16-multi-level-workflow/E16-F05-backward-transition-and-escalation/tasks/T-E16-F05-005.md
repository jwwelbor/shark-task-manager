# Task: Update epic and feature next-status CLI commands with reason flag

## Goal

Add `--reason` and `--agent` flags to existing `shark epic next-status` and `shark feature next-status` commands. Update the shared `entityTransitioner` interface and `performEntityTransition()` helper to pass `TransitionOptions`. Display backward transition warnings.

## Requirements

### Functional Requirements

- [ ] Add `--reason` flag to `epic next-status` command
- [ ] Add `--agent` flag to `epic next-status` command
- [ ] Add `--reason` flag to `feature next-status` command
- [ ] Add `--agent` flag to `feature next-status` command
- [ ] Update `entityTransitioner` interface to use `TransitionOptions`
- [ ] Update `performEntityTransition()` to accept and pass `TransitionOptions`
- [ ] Display backward transition warning when `result.IsBackward` is true
- [ ] Display child count warning when `result.ChildCount > 0`
- [ ] Display reason in output when present

### Non-Functional Requirements

- [ ] Forward transitions continue to work unchanged (no reason required)
- [ ] JSON output includes new fields when present

## Implementation Plan

### Steps

1. [ ] Update `entityTransitioner` interface signature in `epic_next_status.go`
2. [ ] Update `performEntityTransition()` to accept `services.TransitionOptions` instead of `force bool`
3. [ ] Add `--reason` and `--agent` flags to `epicNextStatusCmd` in `init()`
4. [ ] Update `runEpicNextStatus()` to build `TransitionOptions` and pass it
5. [ ] Add `--reason` and `--agent` flags to `featureNextStatusCmd` in `init()`
6. [ ] Update `runFeatureNextStatus()` to build `TransitionOptions` and pass it
7. [ ] Add backward warning display logic after transition

### Technical Approach

**Interface change** in `epic_next_status.go`:
```go
type entityTransitioner interface {
    TransitionStatus(ctx context.Context, key string, targetStatus string, opts services.TransitionOptions) (*services.TransitionResult, error)
}
```

**performEntityTransition() change**:
```go
func performEntityTransition(ctx context.Context, svc entityTransitioner, entityKey string, targetStatus string, opts services.TransitionOptions, result *EntityNextStatusResult) error
```

**Backward warning display**:
```go
if result.IsBackward {
    cli.Info(fmt.Sprintf("Reason: %s", result.Reason))
}
if result.ChildCount > 0 {
    cli.Warning(fmt.Sprintf("%d child entities remain in current states.", result.ChildCount))
}
```

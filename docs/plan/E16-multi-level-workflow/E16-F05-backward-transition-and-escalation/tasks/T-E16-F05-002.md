# Task: workflow.Service.IsBackwardTransition() wrapper method

## Goal

Expose the existing `WorkflowConfig.IsBackwardTransition()` via `workflow.Service` as the single canonical entry point for backward transition detection. This consolidates three existing implementations into one access path.

## Requirements

### Functional Requirements

- [ ] Add `IsBackwardTransition(fromStatus, toStatus string) (bool, error)` method to `workflow.Service`
- [ ] Method delegates to `s.workflow.IsBackwardTransition()` (the WorkflowConfig method)
- [ ] Returns `(false, nil)` when workflow config is nil (graceful degradation)

### Non-Functional Requirements

- [ ] No changes to existing callers of `WorkflowConfig.IsBackwardTransition()`
- [ ] Consistent with existing `workflow.Service` method patterns

## Implementation Plan

### Steps

1. [ ] Open `internal/workflow/service.go`
2. [ ] Add `IsBackwardTransition()` method
3. [ ] Handle nil workflow config case
4. [ ] Add tests in existing or new test file

### Technical Approach

**File**: `internal/workflow/service.go`

```go
func (s *Service) IsBackwardTransition(fromStatus, toStatus string) (bool, error) {
    if s.workflow == nil {
        return false, nil
    }
    return s.workflow.IsBackwardTransition(fromStatus, toStatus)
}
```

This wraps `config.WorkflowConfig.IsBackwardTransition()` which already:
- Looks up phase for each status from status metadata
- Compares phase ordering: planning(0) < development(1) < review(2) < qa(3) < approval(4) < done(5)
- Returns false for transitions involving "any"(-1) or "blocked"(-1) phases
- Returns error if status not found in metadata

### Consolidation Note

Three backward detection implementations exist:
1. `config.WorkflowConfig.IsBackwardTransition()` - canonical, phase-based
2. `validation.IsBackwardTransition()` - alternative, slightly different algorithm
3. `config.Config.IsBackwardTransition()` - weight-based, legacy

This task establishes #1 as the canonical path via `workflow.Service`. Deprecating #2 and #3 is out of scope.

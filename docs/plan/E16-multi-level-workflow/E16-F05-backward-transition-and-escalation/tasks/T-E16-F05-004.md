# Task: FeatureService backward transition support

## Goal

Extend `FeatureService.TransitionStatus()` with backward transition detection, reason enforcement, rejection notes, and child task counting. Mirrors the EpicService changes from T-E16-F05-003.

## Requirements

### Functional Requirements

- [ ] Change `TransitionStatus()` signature to accept `TransitionOptions` instead of `bool force`
- [ ] Detect backward transitions using `workflowSvc.IsBackwardTransition()`
- [ ] Enforce `--reason` for backward transitions when `RequireRejectionReason` is true
- [ ] Create rejection note via `EntityNoteRepository.CreateRejectionNote()` for backward + reason
- [ ] Count child tasks (not features) and populate `ChildCount` on `TransitionResult`
- [ ] Set `IsBackward` and `Reason` on `TransitionResult`
- [ ] Force bypasses workflow validation but still requires reason
- [ ] Force without reason returns clear error: "--force requires --reason"
- [ ] Graceful degradation when noteRepo or taskRepo is nil

### Non-Functional Requirements

- [ ] Same pattern as EpicService for consistency
- [ ] All existing callers updated for new signature

## Implementation Plan

### Steps

1. [ ] Define `FeatureNoteRepository` interface in `feature_service.go`
2. [ ] Define `FeatureTaskCounter` interface in `feature_service.go`
3. [ ] Add `noteRepo` and `taskRepo` fields to `FeatureService` struct
4. [ ] Update `NewFeatureService()` constructor signature
5. [ ] Change `TransitionStatus()` to accept `TransitionOptions`
6. [ ] Add backward detection, reason enforcement, note creation, child count
7. [ ] Update `internal/cli/service_accessors.go` `GetFeatureService()` to pass new deps
8. [ ] Update all callers of `TransitionStatus()` to use `TransitionOptions{Force: force}`
9. [ ] Update existing tests

### Technical Approach

Same pattern as T-E16-F05-003, substituting:
- `models.EntityTypeFeature` for entity type
- `FeatureTaskCounter` interface with `ListByFeature(ctx, featureID)` for child counting
- `models.FeatureStatus()` for status type cast
- Task count instead of feature count for ChildCount

**Callers to update**:
- `internal/cli/commands/feature_next_status.go` - change `force` to `TransitionOptions{Force: force}`
- `internal/services/feature_service_test.go` - update all test calls

### Dependencies

- T-E16-F05-002 (IsBackwardTransition wrapper)
- Can be done in parallel with T-E16-F05-003

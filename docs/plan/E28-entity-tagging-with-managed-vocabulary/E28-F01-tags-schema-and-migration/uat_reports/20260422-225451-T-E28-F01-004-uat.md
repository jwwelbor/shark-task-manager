### Non-blocking
- Duplicate-name tests (`TestTagRepository_Create_DuplicateName_ReturnsError`, `TestTagRepository_Create_CaseNormalized`) could tighten the assertion to verify the error is a UNIQUE-constraint error (e.g., `strings.Contains(err.Error(), "UNIQUE")`). None. All evidence cross-verified at source.

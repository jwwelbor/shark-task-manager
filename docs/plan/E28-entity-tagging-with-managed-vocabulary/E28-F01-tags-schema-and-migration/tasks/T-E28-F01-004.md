# Write repository integration tests for TagRepository and EntityTagRepository

## Goal

Provide a complete integration test suite for the two new repositories in `internal/repository/tag/`, using the real test database with proper cleanup. These tests verify SQL correctness, uniqueness constraints, cascade-delete trigger behavior, and the `force` delete path — none of which can be exercised by mocks.

## Scope

- Files to create: `internal/repository/tag/tag_repository_test.go`, `internal/repository/tag/entity_tag_repository_test.go`

## Acceptance Criteria

See architecture.md §6 (testing — repository tests use real DB with cleanup), §3.1 (indexes and unique constraints under test), §3.2 (cascade-delete triggers verified via integration test).

Additional task-specific criteria:
- AC-T1: Each test function cleans test-prefixed rows before running (per `.claude/rules/testing/repository-tests.md` pattern).
- AC-T2: `TagRepository` tests cover: Create succeeds, duplicate name returns UNIQUE error, GetByName (case-insensitive lookup), Rename succeeds and leaves entity_tag IDs unchanged, Rename to existing name returns `ErrTagConflict`, Delete without `force` and with active links returns `ErrTagInUse`, Delete with `force` removes links and tag atomically.
- AC-T3: `EntityTagRepository` tests cover: Attach links tag to entity, duplicate attach is idempotent (UNIQUE constraint), Detach removes one link, ListByEntity returns all tags for an entity, CountByTag returns accurate count.
- AC-T4: Cascade-delete trigger verified: deleting a parent entity row (e.g., an epic) causes `entity_tags` rows for that entity to disappear.
- AC-T5: `make test` passes with no new test failures.

## Test Cases

All test cases implied by AC-T2 and AC-T3 above. Cascade trigger test: insert a real epic, attach a tag to it, delete the epic via the epic repository, assert the entity_tags row is gone. Run `make test` as final gate.

## Design Reference

See architecture.md §6 (cross-cutting testing notes). Patterns from `.claude/rules/testing/repository-tests.md` (cleanup-before pattern, seed helpers, defer cleanup).

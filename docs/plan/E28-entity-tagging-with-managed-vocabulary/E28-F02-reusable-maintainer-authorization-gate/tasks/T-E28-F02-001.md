# Auth Maintainer Core Package

## Goal
Create the `internal/auth/maintainer` package with the `Gate` interface and `FileGate`
implementation: SHA-256 password verification, sudo-style file-backed cache with
atomic write, XDG-aware cache path, clock injection, and OTel spans. This is the
foundational deliverable that all other F02 tasks depend on.

## Scope
- Files to create:
  - `internal/auth/maintainer/doc.go`
  - `internal/auth/maintainer/gate.go`
  - `internal/auth/maintainer/errors.go`
  - `internal/auth/maintainer/cache.go`
  - `internal/auth/maintainer/clock.go`

## Acceptance Criteria
See spec.md AC-1, AC-2, AC-3, AC-4, AC-5, AC-6, AC-7, AC-8, AC-9, AC-10, AC-14.
- AC-T1: Package imports no shark-domain packages (models, repository, services,
  workflow, cli).
- AC-T2: `Gate` interface exposes exactly `Authorize(ctx, providedPass) error` and
  `RecordSuccess(ctx) error`; `NewFileGate` signature matches spec.md §2.2.
- AC-T3: Hash comparison uses `crypto/subtle.ConstantTimeCompare` only.
- AC-T4: `RecordSuccess` writes via temp-file + `os.Rename`; dir mode 0700, file
  mode 0600.
- AC-T5: Cache path resolves under `XDG_CACHE_HOME` or `os.UserCacheDir()` fallback.
- AC-T6: `*UnauthorizedError` for nil/no-config includes literal
  `"shark admin maintainer set-password"` in `Error()`.
- AC-T7: OTel span `maintainer.authorize` emits only `maintainer.authorized` (bool);
  no password or hash appears in any span field.

# Auth Maintainer Unit Tests

## Goal
Write the complete test suite for `internal/auth/maintainer`, covering all 14 acceptance
criteria and the additional mandatory tests from spec.md §2.7. Tests use a real isolated
filesystem (`t.TempDir()`) and an injected fake clock — no database, no mocking framework.

## Scope
- Files to create:
  - `internal/auth/maintainer/gate_test.go`

## Acceptance Criteria
See spec.md AC-1 through AC-14.
See test-plan.md Section 1 (all AC test cases), Section 2.1–2.3, Section 3 INT-4.
- AC-T1: All 14 ACs have at least one passing test function matching the names in
  test-plan.md §1.
- AC-T2: `fakeClock` struct and `sha256hex` helper implemented inline in the test file.
- AC-T3: Concurrent test (`TestFileGate_RecordSuccess_Concurrent`) runs 8 goroutines;
  passes `go test -race`.
- AC-T4: OTel span test uses `tracetest.NewSpanRecorder()`; asserts no secret substring
  in serialized span data.
- AC-T5: Static import firewall test (`TestPackage_HasNoSharkDomainImports`) uses
  `go list -json` at test time and asserts forbidden prefixes are absent.
- AC-T6: `t.Setenv("XDG_CACHE_HOME", ...)` used for path isolation; no environment
  pollution between test cases.

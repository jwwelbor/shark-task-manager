# Document --tag flag in discovery-commands.md for shark search

## Goal
Add documentation for the repeatable `--tag` flag on `shark search` so users can discover that full-text and file-mode searches can be narrowed by tag. The flag is implemented in E28-F05 (REQ-F-011 / REQ-F-018) but discovery-commands.md currently has zero mentions of tags. Closes part of the assessment gap "core-commands.md and discovery-commands.md --tag documentation for shark list / shark search (currently 0 mentions)".

## Scope
- Files to modify:
  - `docs/cli-reference/discovery-commands.md` (add `--tag` row to the `shark search` flags table and at least one example combining tag filtering with a full-text query)

## Acceptance Criteria
- The `shark search` section in `docs/cli-reference/discovery-commands.md` documents `--tag <name>` as repeatable with AND semantics across values.
- At least one example combines a query and tags (e.g. `shark search "login" --tag=auth --tag=voice`).
- One example demonstrates `--tag` works in both full-text query mode and file-search mode (or this is stated in prose).
- A cross-reference to `tags.md` is added under "Related Documentation".
- Wording matches the phrasing used on the per-entity command pages and the `shark list` documentation produced by T-E28-F07-001.

## Test Cases
1. `grep -c -- "--tag" docs/cli-reference/discovery-commands.md` returns >= 2.
2. `grep -n "tags.md" docs/cli-reference/discovery-commands.md` shows a link to the tags reference.
3. Manual read: the `shark search` flags table includes a `--tag` row.

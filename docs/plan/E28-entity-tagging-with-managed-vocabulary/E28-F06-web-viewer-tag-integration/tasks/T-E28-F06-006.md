# Wire TagService into ViewerService and update ViewerServicer interface

## Goal
Add `Tags(ctx) (*services.TagsResponse, error)` to the `ViewerServicer` interface
in `service.go` and update the `Hierarchy` signature to accept
`services.HierarchyOptions`. Add one line in `wire.go` to call
`viewerService.WithTagService(tagSvc)` after the viewer service is constructed.
Verify the compile-time assertion `var _ ViewerServicer = (*services.ViewerService)(nil)`
still passes. Assert `MaintainerGate` is absent from viewer wiring.

## Scope
- Files to modify:
  - `internal/api/viewer/service.go`
  - `internal/viewer/server/wire.go`
  - `internal/viewer/server/wire_test.go`

## Acceptance Criteria
See spec.md REQ-F-014, REQ-F-015, REQ-NF-007; AC-14, AC-15; §2.5.6 (wiring
pseudocode).

Additional task-specific criteria:
- AC-T1: `ViewerServicer` interface compiles with the new `Tags` method and
  updated `Hierarchy` signature.
- AC-T2: `wire.go` contains `viewerService.WithTagService(tagSvc)` and zero
  references to `MaintainerGate` or `maintainer.Gate`.
- AC-T3: `wire_test.go` asserts that after `WireServices()` the viewer service
  has a non-nil tag reader (or equivalent compile check passes).
- AC-T4: No new dependency on `internal/auth/maintainer` is introduced anywhere
  in the viewer package.

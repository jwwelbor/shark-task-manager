# Filter DTO Tags field and filterByTagIDs generic helper

## Goal
Add `Tags []string` to the seven entity filter DTOs and create the `filterByTagIDs` generic
helper function in `tag_filter_helper.go`. These changes provide the uniform pre/post filter
pattern that all seven entity List methods (T-006) will use without code duplication.

## Scope
- Files to modify:
  - `internal/services/task_dto.go` (TaskFilters)
  - `internal/services/epic_dto.go` (EpicFilters, FeatureFilters)
  - `internal/services/bug_dto.go` (BugFilters)
  - `internal/services/change_dto.go` (ChangeCardFilter)
  - `internal/services/idea_dto.go` (IdeaFilter)
- Files to create:
  - `internal/services/tag_filter_helper.go` (filterByTagIDs generic function + unit test)

## Acceptance Criteria
See spec.md §2.5.1 for the DTO field name (`Tags []string`), JSON tag (`json:"tags,omitempty"`), and
the ChangeCardFilter/IdeaFilter decision (introduce service-layer DTO or add field to existing DTO).
See spec.md §2.5.2 for the `filterByTagIDs[E any]` generic function signature and in-place filtering.
Additional task-specific criteria:
- AC-T1: `filterByTagIDs` with `taggedIDSet==nil` returns the input slice unchanged.
- AC-T2: `filterByTagIDs` with an empty `taggedIDSet` map returns an empty non-nil slice.
- AC-T3: All seven DTOs gain `Tags []string`; no existing field is renamed or removed.

# Six entity GetXxxWithTags service methods

## Goal
Add `GetXxxWithTags(ctx, key) (*Entity, []string, error)` sibling methods to each of the six
entity services. Each calls the existing `GetXxx` then `tagSvc.ListTagsForEntity`. When
`tagSvc` is nil the method returns `(entity, nil, nil)` for graceful degradation (REQ-F-014).
The original `GetXxx` signatures are unchanged so existing callers are unaffected.

## Scope
- Files to modify:
  - `internal/services/task_service.go` and `internal/services/task_service_test.go`
  - `internal/services/epic_service.go` and `internal/services/epic_service_test.go`
  - `internal/services/feature_service.go` and `internal/services/feature_service_test.go`
  - `internal/services/bug_service.go` and `internal/services/bug_service_test.go`
  - `internal/services/change_card_service.go` and `internal/services/change_card_service_test.go`
  - `internal/services/idea_service.go` and `internal/services/idea_service_test.go`

## Acceptance Criteria
See spec.md §2.5.3 for the `GetTaskWithTags` method body pattern (OTel span, GetTask call, nil-tagSvc guard).
See spec.md §2.5.3 for the `ListTagsForEntity` call with the correct `models.EntityType<X>` per entity.
Additional task-specific criteria:
- AC-T1: Each `GetXxxWithTags` method emits an OTel span named `<Entity>Service.GetXxxWithTags`.
- AC-T2: When `tagSvc` is nil, returns `(entity, nil, nil)` — not an error.
- AC-T3: `ListTagsForEntity` error is wrapped and returned as `(nil, nil, wrappedErr)`.

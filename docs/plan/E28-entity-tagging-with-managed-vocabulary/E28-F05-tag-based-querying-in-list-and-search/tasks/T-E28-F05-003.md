# TagFilterUnavailableError typed error and TagAttacher interface extension

## Goal
Add the `TagFilterUnavailableError` typed error (AC-30) and extend the `TagAttacher` interface
to include `ListTagsForEntity`. These changes enable entity services and the CLI error handler
to respond correctly when tag filtering is requested but `tagSvc` is nil, and allow
`GetXxxWithTags` wrappers (T-007) to use a single interface for both attach and query operations.

## Scope
- Files to modify:
  - `internal/services/tag_errors.go`
  - `internal/services/bug_service.go` (TagAttacher interface declaration; compile-time check)
  - `internal/services/mock_tag_service_test.go` (add `ListTagsForEntityFn` stub)
  - `internal/cli/commands/tags.go` (add `TagFilterUnavailableError` case to `tagsErrorCode`)
- Files to create:
  - `internal/services/tag_errors_test.go` (if not already present)

## Acceptance Criteria
See spec.md §2.5.4 for `TagFilterUnavailableError` struct, `Error()` string, and exit-code mapping.
See spec.md §2.5.3 for the `ListTagsForEntity` addition to `TagAttacher` interface.
Additional task-specific criteria:
- AC-T1: `(&TagFilterUnavailableError{}).Error()` returns exactly `"tag filtering is not available (TagService not wired)"`.
- AC-T2: `var _ TagAttacher = (*TagService)(nil)` compile-time check passes after adding `ListTagsForEntity`.
- AC-T3: `tagsErrorCode` in `tags.go` maps `*TagFilterUnavailableError` to exit code 3.

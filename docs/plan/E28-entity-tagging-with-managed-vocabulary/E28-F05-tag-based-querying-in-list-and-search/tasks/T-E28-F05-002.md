# TagService: EntityIDsByTags, ListTagsForEntity, AttachedTagNamesByIDs and TagQueryOp

## Goal
Add three new query methods to `TagService` and the `TagQueryOp` typed-string constant. These
methods provide the tag-ID resolution, single-entity tag lookup, and batched entity-to-tag-names
map that service and CLI layers consume. Each method emits an OTel span per REQ-NF-003.

## Scope
- Files to modify:
  - `internal/services/tag_service.go`
  - `internal/services/tag_service_test.go`
  - `internal/services/mock_tag_service_test.go`
- Files to create:
  - `internal/services/tag_query.go` (TagQueryOp type and TagQueryOpAnd constant)

## Acceptance Criteria
See spec.md §2.4.1 for `TagQueryOp` type, `TagQueryOpAnd` constant, and `normalize()` helper.
See spec.md §2.4.2 for `EntityIDsByTags` algorithm (normalize → deduplicate → resolve IDs → FilterEntityIDs).
See spec.md §2.4.3 for `ListTagsForEntity` algorithm and empty-slice guarantee.
See spec.md §2.4.4 for `AttachedTagNamesByIDs` algorithm and every-input-ID-in-map guarantee.
Additional task-specific criteria:
- AC-T1: `EntityIDsByTags` calls `FilterEntityIDs` exactly once for N≥1 unique tag names.
- AC-T2: `EntityIDsByTags` never calls `FilterEntityIDs` when any name is unregistered.
- AC-T3: `MockTagService` in `mock_tag_service_test.go` gains the three new method stubs per test-plan.md §3.2.

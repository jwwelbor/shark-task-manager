# CLI --tag flag on shark list, shark search, and six entity list commands

## Goal
Wire the `--tag` repeatable flag onto `shark list` (top-level dispatcher), `shark search`, and
each of the six entity-specific `list` subcommands. Each command reads the flag slice, sets
`filters.Tags`, and routes errors through `handleEntityServiceError` which already renders
`*UnregisteredTagError` with the vocabulary snippet (F04 reuse). Also update `docs/cli-reference/tags.md`
with AND conjunction documentation per REQ-F-018.

## Scope
- Files to modify:
  - `internal/cli/commands/list.go` (listTags var, StringSliceVar, forward to dispatched runners)
  - `internal/cli/commands/search.go` (searchTags var, StringSliceVar, pass to SearchAll)
  - `internal/cli/commands/task.go` (taskListTags var, StringSliceVar, filters.Tags)
  - `internal/cli/commands/feature.go` (featureListTags, filters.Tags)
  - `internal/cli/commands/epic.go` (epicListTags, filters.Tags)
  - `internal/cli/commands/bug.go` (bugListTags, filters.Tags)
  - `internal/cli/commands/change.go` (changeListTags, filters.Tags)
  - `internal/cli/commands/idea.go` (ideaListTags, filters.Tags)
  - `docs/cli-reference/tags.md` (add --tag flag AND semantics documentation)
  - Corresponding `*_test.go` files for each command file above

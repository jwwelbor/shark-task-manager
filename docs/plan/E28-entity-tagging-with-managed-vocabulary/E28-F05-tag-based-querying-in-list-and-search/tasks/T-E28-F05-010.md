# CLI entity get commands: GetXxxWithTags and tag rendering

## Goal
Switch each of the six entity `get` commands from `GetXxx` to `GetXxxWithTags` and add tag
rendering to both rich-text and JSON output. Rich display shows `Tags: voice, auth` or
`Tags: (none)`. JSON envelope adds `"tags": ["voice","auth"]` (always present, never null).
Formatting matches existing detail-line style (`Notes: N`, `Related docs: N`).

## Scope
- Files to modify:
  - `internal/cli/commands/task.go` and `internal/cli/commands/task_test.go`
  - `internal/cli/commands/feature.go` and `internal/cli/commands/feature_test.go`
  - `internal/cli/commands/epic.go` and `internal/cli/commands/epic_test.go`
  - `internal/cli/commands/bug.go` and `internal/cli/commands/bug_test.go`
  - `internal/cli/commands/change.go` and `internal/cli/commands/change_test.go`
  - `internal/cli/commands/idea.go` and `internal/cli/commands/idea_test.go`

## Acceptance Criteria
See spec.md §2.7.4 for the call-site pattern: `svc.GetTaskWithTags(ctx, key)` and the rich/JSON
display instructions including `Tags: (none)` for empty slice and `"tags": []` in JSON.
See spec.md REQ-F-015 for the JSON envelope shape (`"tags"` field ALWAYS present).
Additional task-specific criteria:
- AC-T1: Rich display: non-empty tags render `Tags: voice, auth` (comma-space separated, sorted).
- AC-T2: Rich display: empty tags render `Tags: (none)`.
- AC-T3: JSON: `"tags"` field is always an array, never null — empty is `[]`.

# Integrate TagService into TaskService

## Goal
Replicate the bug-entity pattern from T-005 into the Task path: extend the
Task DTOs with `Tags []string`, add the optional `tagSvc` field to
`TaskService`, invoke `EnforceRequired` before persistence and `AttachMany`
after persistence in `CreateTask`, add additive `AttachMany` to `UpdateTask`,
wire the `--tag` flag through the two CLI parse helpers, and register the
shared `makeEntityTagCmd(models.EntityTypeTask, resolveTaskID)` subcommand.

## Scope
- Files to modify: `internal/services/task_dto.go`,
  `internal/services/task_service.go`,
  `internal/services/task_service_test.go`,
  `internal/cli/commands/task.go`, `internal/cli/commands/task_helpers.go`,
  `internal/cli/commands/task_test.go`,
  `internal/cli/services_global.go` (TaskService accessor)
- Files to create: none (reuses `entity_tag_cmd.go` from T-005)

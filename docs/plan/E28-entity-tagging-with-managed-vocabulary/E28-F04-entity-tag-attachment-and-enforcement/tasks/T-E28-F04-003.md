# Add AttachMany DetachOne EnforceRequired to TagService

## Goal
Extend `TagService` with the three attach/detach/enforce methods, grow its
constructor to accept a `TagEnforcementConfig` (narrow interface over
`Config.TagRequiredFor`), and add the corresponding table-driven unit tests.
This task is the service-layer core of F04; every later entity-integration
task calls into these three methods.

## Scope
- Files to modify: `internal/services/tag_service.go`,
  `internal/services/tag_service_test.go`
- Files to create: none

## Acceptance Criteria
Reference spec.md AC-1 through AC-14.
Additional task-specific criteria:
- AC-T1: `NewTagService` panics with the `requires a non-nil` substring when
  any of the four dependencies is nil (regression for tagRepo, entityTagRepo,
  gate; new for cfg).
- AC-T2: All three new methods emit OTel spans with the names and attributes
  listed in REQ-NF-002 (verified via in-memory exporter).
- AC-T3: `TagEnforcementConfig` is defined in `tag_service.go` and
  `*config.Config` satisfies it (compile-time assertion via a `var _` in the
  test file).

rows for `Emits*Span*` tests, and regression rows AC-13b).

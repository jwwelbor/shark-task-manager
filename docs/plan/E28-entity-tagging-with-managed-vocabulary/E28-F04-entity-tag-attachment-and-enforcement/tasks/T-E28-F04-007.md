# Integrate TagService into FeatureService

## Goal
Replicate the bug-entity pattern from T-005 into the Feature path: extend
`CreateFeatureInput` and `FeatureUpdates` with `Tags []string`, add optional
`tagSvc` to `FeatureService`, add the `EnforceRequired` + `AttachMany` hooks
to `CreateFeature`, add additive `AttachMany` to `UpdateFeature`, wire `--tag`
through the feature CLI parse helpers, and register the shared
`makeEntityTagCmd(models.EntityTypeFeature, resolveFeatureID)` subcommand.

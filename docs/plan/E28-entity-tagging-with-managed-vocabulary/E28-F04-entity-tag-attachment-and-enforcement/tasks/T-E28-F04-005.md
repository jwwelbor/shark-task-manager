# Integrate TagService into BugService (end-to-end proof of concept)

## Goal
Wire tag attachment through the full Bug path as the proof-of-concept entity
referenced in research.md Section 6.1. This task introduces the shared
`entity_tag_cmd.go` factory (reused by T-006..T-010), the shared
`mock_tag_service_test.go` helper (reused by every entity-service test file),
and validates the ordering/idempotency/enforcement contracts end-to-end before
replicating the pattern to the remaining five entities.

## Scope
- Files to modify: `internal/services/bug_dto.go`,
  `internal/services/bug_service.go`, `internal/services/bug_service_test.go`,
  `internal/cli/commands/bug.go`, `internal/cli/commands/bug_test.go`,
  `internal/cli/services_global.go` (BugService accessor)
- Files to create: `internal/cli/commands/entity_tag_cmd.go`,
  `internal/cli/commands/entity_tag_cmd_test.go`,
  `internal/services/mock_tag_service_test.go`

# Update HTTP server service wiring

## Goal
Extend `cmd/server/services.go` so `WireServices` constructs one `TagService`
with the four dependencies (tag repo, entity-tag repo, maintainer gate, and
config) and passes it into every entity service constructor alongside the
existing dependencies. Add a smoke test that asserts the returned bundle
includes a non-nil `*TagService` and every entity service has its `tagSvc`
field populated, guaranteeing Turso/local parity at wire time.

## Scope
- Files to modify: `cmd/server/services.go`, `cmd/server/services_test.go`
  (create if absent)
- Files to create: `cmd/server/services_test.go` if the package has no
  existing test file

## Acceptance Criteria
Reference spec.md Section 2.9 (HTTP service wiring).
Additional task-specific criteria:
- AC-T1: `WireServices` compiles and returns a bundle in which every entity
  service holds a non-nil `*TagService`.
- AC-T2: The smoke test instantiates `WireServices` with a throwaway in-
  process DB and asserts non-nil service fields (matches the
  `TestWireServices_ConstructsTagService` sketch in test-plan.md Section
  2.5).

## Test Cases
See test-plan.md Section 2.5 "CLI→Wiring boundary" bullet 3 (HTTP smoke
test). Covers REQ-NF-006 Turso parity via the shared wiring path.

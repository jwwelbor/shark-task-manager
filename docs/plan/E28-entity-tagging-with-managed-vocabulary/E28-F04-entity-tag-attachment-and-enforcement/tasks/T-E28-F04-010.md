# Integrate TagService into IdeaService

## Goal
Replicate the bug-entity pattern from T-005 into the Idea path: extend
`CreateIdeaInput` and `UpdateIdeaInput` with `Tags []string`, add optional
`tagSvc` to `IdeaService`, add the `EnforceRequired` + `AttachMany` hooks to
`CreateIdea`, add additive `AttachMany` to `UpdateIdea`, wire `--tag` through
the idea CLI parse helpers, and register the shared
`makeEntityTagCmd(models.EntityTypeIdea, resolveIdeaID)` subcommand. Covers
AC-26 (idea behaves identically to other entities) explicitly.

## Scope
- Files to modify: `internal/services/idea_dto.go`,
  `internal/services/idea_service.go`,
  `internal/services/idea_service_test.go`,
  `internal/cli/commands/idea.go`, `internal/cli/commands/idea_test.go`,
  `internal/cli/services_global.go` (IdeaService accessor)
- Files to create: none (reuses `entity_tag_cmd.go` from T-005)

# Integrate TagService into EpicService

## Goal
Replicate the bug-entity pattern from T-005 into the Epic path: extend
`CreateEpicInput` and `EpicUpdates` with `Tags []string`, add optional
`tagSvc` to `EpicService`, add the `EnforceRequired` + `AttachMany` hooks to
`CreateEpic`, add additive `AttachMany` to `UpdateEpic`, wire `--tag` through
the epic CLI parse helpers, and register the shared
`makeEntityTagCmd(models.EntityTypeEpic, resolveEpicID)` subcommand. This
task also covers the AC-22 epic-side (no enforcement when `tag_required_for`
only lists `task`).

# Integrate TagService into ChangeCardService

## Goal
Replicate the bug-entity pattern from T-005 into the ChangeCard path: extend
`CreateChangeCardInput` and `ChangeCardUpdates` with `Tags []string`, add
optional `tagSvc` to `ChangeCardService`, add the `EnforceRequired` +
`AttachMany` hooks to `CreateChangeCard`, add additive `AttachMany` to
`UpdateChangeCard`, wire `--tag` through the change CLI parse helpers, and
register the shared `makeEntityTagCmd(models.EntityTypeChange,
resolveChangeID)` subcommand.

## Scope
- Files to modify: `internal/services/change_dto.go`,
  `internal/services/change_card_service.go`,
  `internal/services/change_card_service_test.go`,
  `internal/cli/commands/change.go`,
  `internal/cli/commands/change_test.go`,
  `internal/cli/services_global.go` (ChangeCardService accessor)
- Files to create: none (reuses `entity_tag_cmd.go` from T-005)

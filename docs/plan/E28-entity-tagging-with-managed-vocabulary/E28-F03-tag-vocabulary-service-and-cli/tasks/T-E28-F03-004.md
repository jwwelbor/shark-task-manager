# Add GetTagService CLI accessor in tag_global.go

## Goal
Create `internal/cli/tag_global.go` exporting `GetTagService()`, which wires the
real database, tag repositories, and maintainer gate into a `*services.TagService`
instance. Also create the integration smoke test in `internal/cli/tag_global_test.go`
that runs against a real `t.TempDir()` project.

## Scope
- Files to create:
  - `internal/cli/tag_global.go`
  - `internal/cli/tag_global_test.go`

## Acceptance Criteria
See spec.md AC-12, REQ-F-012.

Additional task-specific criteria:
- AC-T1: Accessor follows the lazy-init pattern of `GetTaskService`:
  new service instance per call, shared global DB, panics on DB failure.
- AC-T2: Wires `tag.NewTagRepository(db)`, `tag.NewEntityTagRepository(db)`,
  and `cli.GetMaintainerGate()` — no other constructors.
- AC-T3: Integration test calls `cli.GetTagService().ListTags(ctx)` against a
  real initialized DB in `t.TempDir()`; asserts no error and empty result.
- AC-T4: Two successive `GetTagService()` calls return distinct pointer values.
- AC-T5: `defer cli.ResetDB()` is used in the integration test to clean global
  DB state (matches `maintainer_global_test.go` precedent from F02).

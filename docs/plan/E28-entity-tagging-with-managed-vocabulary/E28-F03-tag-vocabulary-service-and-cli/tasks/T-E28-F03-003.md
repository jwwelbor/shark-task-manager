# Write TagService unit tests with OTel tracing coverage

## Goal
Create `internal/services/tag_service_test.go` with full AC coverage for the
service layer using function-field mocks, a call-order recorder, and an in-memory
OTel span recorder. No real database is used — all dependencies are mocked.

## Scope
- Files to create:
  - `internal/services/tag_service_test.go`

## Acceptance Criteria
See spec.md AC-1 through AC-11 and AC-22.
See spec.md REQ-NF-003 (testability via interfaces, function-field mocks).

Additional task-specific criteria:
- AC-T1: In-file mocks for all three interfaces: `mockTagRepo`,
  `mockEntityTagRepo`, `mockGate` — using the function-field pattern from
  `.claude/rules/services/testing.md`.
- AC-T2: `callRecorder` helper verifies gate → create → RecordSuccess call
  ordering in `AddTag` and equivalent mutating methods.
- AC-T3: AC-11 tests capture swallowed `RecordSuccess` error via a test logger
  or by verifying the method's nil return value.
- AC-T4: AC-22 OTel tests use `sdktrace/tracetest` in-memory recorder; assert
  span name and attribute presence/absence.
- AC-T5: `go test ./internal/services/...` passes with no real DB dependency.

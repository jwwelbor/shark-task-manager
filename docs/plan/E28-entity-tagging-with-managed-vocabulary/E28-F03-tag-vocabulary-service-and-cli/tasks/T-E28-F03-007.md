# Write CLI reference docs for shark tags and update README index

## Goal
Create `docs/cli-reference/tags.md` documenting all four subcommands, the
`--pass` flag, `--force` on `rm`, and all JSON output shapes. Update
`docs/cli-reference/README.md` to add `shark tags` to the command index.

## Scope
- Files to create:
  - `docs/cli-reference/tags.md`
- Files to modify:
  - `docs/cli-reference/README.md`

## Acceptance Criteria
See spec.md AC-21, REQ-F-013.

Additional task-specific criteria:
- AC-T1: `tags.md` contains headings (or sections) for `list`, `add`, `rm`,
  and `rename` subcommands.
- AC-T2: `tags.md` documents the `--pass <value>` flag for all mutating commands.
- AC-T3: `tags.md` documents the `--force` flag specifically on `rm`.
- AC-T4: `tags.md` documents all four JSON output shapes from spec.md REQ-F-011
  (`list`, `add`, `rm`, `rename` success; error shape).
- AC-T5: `tags.md` includes a cross-reference to
  `docs/cli-reference/configuration.md#maintainer` (the F02 maintainer config
  section).
- AC-T6: `docs/cli-reference/README.md` has a link or table entry pointing at
  `tags.md` under the appropriate command group (Vocabulary or Advanced).

## Test Cases
See test-plan.md AC-21 (cases 21.1–21.6): existence check, subcommand sections,
flag documentation, JSON shape documentation, README link.

## Design Reference
See spec.md REQ-F-011 for the exact JSON output shapes to document.
See spec.md REQ-F-013 for the complete documentation requirements.
See `docs/cli-reference/README.md` for the existing table structure to extend.

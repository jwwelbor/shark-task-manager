# Define TagService typed errors in tag_errors.go

## Goal
Create `internal/services/tag_errors.go` exporting the four typed error structs
that `TagService` methods return and CLI handlers map to exit codes. This
foundational file must land before the service implementation so both compile
independently.

## Scope
- Files to create:
  - `internal/services/tag_errors.go`

## Acceptance Criteria
See spec.md REQ-F-007 for the complete error type table and exit code mapping.

Additional task-specific criteria:
- AC-T1: All four types exported: `*ValidationError`, `*NotFoundError`,
  `*ConflictError`, `*TagInUseError` — each implements `error`.
- AC-T2: `ValidationError.Error()` returns `"invalid <Field>: <Message>"`.
- AC-T3: `NotFoundError.Error()` returns `"tag not found: <Name>"`.
- AC-T4: `ConflictError.Error()` returns `"tag already exists: <Name>"`.
- AC-T5: `TagInUseError.Error()` includes count and `"--force"` hint text.
- AC-T6: Package compiles clean: `go build ./internal/services/...`.

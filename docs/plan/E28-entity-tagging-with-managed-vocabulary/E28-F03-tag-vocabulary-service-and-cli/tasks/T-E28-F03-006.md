# Write CLI command tests and static import checks for tags

## Goal
Create `internal/cli/commands/tags_test.go` with table-driven CLI tests covering
all AC-13 through AC-18 scenarios, plus in-process static import checks for
AC-19 and AC-20. No real database; all service calls go through a `mockTagService`
that implements `tagServiceIface`.

## Scope
- Files to create:
  - `internal/cli/commands/tags_test.go`

## Acceptance Criteria
See spec.md AC-13 through AC-20, REQ-NF-001, REQ-NF-003.

Additional task-specific criteria:
- AC-T1: `buildTagsCmdWithMock(svc)` helper constructs a cobra root with injected
  mock — mirrors `buildSetPasswordCmdWithMock` in `admin_maintainer_test.go`.
- AC-T2: `mockTagService` struct uses function-field pattern; all four service
  methods covered.
- AC-T3: Table-driven test for INT-3 exercises all six error-to-exit-code rows
  with a single test function.
- AC-T4: AC-17 / INT-5 test verifies that on `*NotFoundError`, the CLI calls
  `ListTags` and puts vocabulary snippet in stderr.
- AC-T5: Static check (AC-19): in-process `go list` run asserts `internal/services/`
  imports `internal/repository/tag` and `internal/auth/maintainer`, excludes
  `internal/cli` and `cobra`.
- AC-T6: Static check (AC-20): `go list` on `internal/cli/commands/` asserts
  `internal/repository/tag` and `database/sql` are absent.
- AC-T7: `go test ./internal/cli/commands/...` passes with no real DB.

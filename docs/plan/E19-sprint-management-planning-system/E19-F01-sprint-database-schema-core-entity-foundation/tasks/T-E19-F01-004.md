# Task: Add migrateSprintTables: sprints table, indexes, trigger, slug column (db.go)

## Goal

Add the `migrateSprintTables` function to `internal/db/db.go` containing the DDL for the `sprints` table, its three indexes (`idx_sprints_key`, `idx_sprints_status`, `idx_sprints_slug`), and the `sprints_updated_at` trigger. The function must be idempotent (checks `sqlite_master` before creating, using `CREATE TABLE IF NOT EXISTS` / `CREATE INDEX IF NOT EXISTS` / `CREATE TRIGGER IF NOT EXISTS`). This task covers the `sprints` table only; `sprint_assignments` and `sprint_capacity` are in T-E19-F01-005 and T-E19-F01-006.

## Acceptance Criteria

- [ ] `migrateSprintTables` function exists in `internal/db/db.go` and uses `CREATE TABLE IF NOT EXISTS` / `CREATE UNIQUE INDEX IF NOT EXISTS` / `CREATE INDEX IF NOT EXISTS` / `CREATE TRIGGER IF NOT EXISTS` throughout (idempotent per AC-8).
- [ ] `sprints` table created with columns: `id INTEGER PRIMARY KEY AUTOINCREMENT`, `key TEXT NOT NULL UNIQUE`, `name TEXT NOT NULL`, `goal TEXT`, `start_date DATE NOT NULL`, `end_date DATE NOT NULL`, `status TEXT NOT NULL DEFAULT 'planning'`, `slug TEXT`, `file_path TEXT`, `created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP`, `updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP`, `CHECK (start_date < end_date)`.
- [ ] `idx_sprints_key UNIQUE INDEX ON sprints(key)` created.
- [ ] `idx_sprints_status INDEX ON sprints(status)` created.
- [ ] `idx_sprints_slug INDEX ON sprints(slug)` created.
- [ ] `sprints_updated_at` trigger created: `AFTER UPDATE ON sprints`, sets `updated_at = CURRENT_TIMESTAMP WHERE id = NEW.id`.
- [ ] Function is placed in `db.go` after the existing tech-debt migration and before the tags migration (per spec §3.1 location guidance).
- [ ] Function signature matches the existing migration pattern (takes `*sql.DB`, returns `error`).

## Implementation Notes

- Mirror `migrateEntityNotes` (`db.go:1698-1811`) for the function structure and idempotency pattern.
- The `CHECK (start_date < end_date)` constraint is a standard SQLite CHECK — include it in the CREATE TABLE statement directly.
- Do NOT register in `runMigrations()` yet — that is T-E19-F01-007 to keep the version bump atomic.
- The `slug` column intentionally has no UNIQUE constraint (sprint slugs are not required to be globally unique, per database/schema.md slug architecture).

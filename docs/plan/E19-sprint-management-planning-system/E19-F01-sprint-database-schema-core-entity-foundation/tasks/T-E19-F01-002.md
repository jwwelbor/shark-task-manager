# Task: Add Sprint model and validators (models/sprint.go + models/validation.go)

## Goal

Create the `Sprint`, `SprintAssignment`, and `SprintCapacity` Go structs in a new `internal/models/sprint.go` file, and add `ValidateSprintKey`, `ValidateSprintAssignmentEntityType`, and `Validate()` methods to `internal/models/validation.go`. This is the app-layer type foundation; no repository or service logic is included.

## Acceptance Criteria

- [ ] `internal/models/sprint.go` is a new file containing `Sprint`, `SprintAssignment`, `SprintCapacity` structs as specified in spec §4.3.
- [ ] `SprintStatus` is a typed alias (`type SprintStatus string`); valid values are NOT hardcoded — they are workflow-defined and validated at the service layer (mirrors `TaskStatus` pattern).
- [ ] `internal/models/validation.go` gains:
  - `sprintKeyPattern = regexp.MustCompile(` "`" `^S\d{3}$` "`" `)` at package level.
  - `ErrInvalidSprintKey` sentinel error.
  - `ValidateSprintKey(key string) error` — returns `ErrInvalidSprintKey` via `%w` if pattern doesn't match.
  - `ErrInvalidSprintAssignmentEntityType` sentinel error.
  - `ValidateSprintAssignmentEntityType(entityType string) error` — map-based allowlist: `task`, `bug`, `change_card`, `tech_debt`; no DB CHECK mirrored here per post-B018 convention.
  - `Sprint.Validate()` — checks: `ValidateSprintKey`, non-empty `Name` (use existing `ErrEmptyTitle`), `EndDate.After(StartDate)`, non-empty `Status`.
  - `SprintAssignment.Validate()` — checks: `SprintID > 0`, `EntityID > 0`, `ValidateSprintAssignmentEntityType(EntityType)`.
- [ ] `make fmt && make lint` pass with no new issues.
- [ ] `SprintCapacity` struct has `AllocatedPoints *float64` (nullable — not maintained by triggers in this feature).

## Implementation Notes

- Use `strings.TrimSpace` before checking empty strings (per input-sanitization rules).
- `ValidateSprintKey` receives an already-normalised (uppercase) key; lowercase `s024` should fail — the caller is responsible for normalising via `keys.Normalize()` upstream.
- Do NOT add a check function for sprint status values here; that is service-layer responsibility (mirrors how `TaskStatus` is validated).
- `SprintAssignment.RemovedAt` is `*time.Time` (nullable).

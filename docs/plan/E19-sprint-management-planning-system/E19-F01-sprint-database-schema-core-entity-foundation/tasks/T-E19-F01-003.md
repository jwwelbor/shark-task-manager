# Task: Add IsSprintKey helper to keys/validation.go

## Goal

Add an `IsSprintKey(s string) bool` function to `internal/keys/validation.go` for symmetry with `IsEpicKey`, `IsBugKey`, `IsTechDebtKey`, etc. The function normalises its input and matches the strict `^S\d{3}$` pattern. This helper is used by callers that need a simple boolean check rather than a full `KeyService.Parse()` call.

## Acceptance Criteria

- [ ] `sprintKeyPattern = regexp.MustCompile("^S\\d{3}$")` added at package level in `keys/validation.go` (note: a *separate* package-level var from the one in `models/validation.go`; each package owns its own compiled regex).
- [ ] `IsSprintKey(s string) bool` function added; it calls `Normalize(s)` before matching (mirrors `IsTechDebtKey` pattern).
- [ ] `IsSprintKey("S001")` returns `true`; `IsSprintKey("s001")` returns `true` (case-insensitive via `Normalize`); `IsSprintKey("S1")`, `IsSprintKey("S0001")` return `false`.
- [ ] `make fmt && make lint && make test` all pass (no regressions).

## Implementation Notes

- File: `internal/keys/validation.go` only — one small addition.
- Mirror `IsTechDebtKey` exactly in structure: `regexp.MustCompile` at package level, `Normalize(s)` inside the function body.
- The regex is `^S\d{3}$` (not anchored with capture groups — this is a boolean check, not a parser).

# Task: Write key parser and model unit tests: S### Parse/Format/IsSprintKey, Sprint/SprintAssignment validators (keys tests + models/sprint_test.go)

## Goal

Write pure unit tests (no database) for the S### key parser additions and the Sprint model validators. Tests go in two places: new cases added to `internal/keys/service_test.go` and `internal/keys/validation_test.go`, plus a new `internal/models/sprint_test.go`. These cover spec §6.2, §6.3, and §6.4.

## Acceptance Criteria

Key parser tests (added to existing `internal/keys/service_test.go`):

- [ ] `TestKeyService_Parse` includes sprint cases: `"S001"` → `EntityTypeSprint`, `SprintNum="001"`, `Normalized="S001"`; `"s024"` → `EntityTypeSprint`, `Normalized="S024"` (case-insensitive).
- [ ] `TestKeyService_Parse` includes negative sprint cases: `"S1"`, `"S0001"`, `"SPRINT-1"` → `EntityTypeUnknown`.
- [ ] `TestKeyService_Format` includes: `Format(ParsedKey{EntityType: EntityTypeSprint, SprintNum: "024"})` → `"S024"`.
- [ ] `TestKeyService_DetectEntityType` or equivalent test covers `EntityTypeSprint` detection.

`IsSprintKey` tests (added to existing `internal/keys/validation_test.go`):

- [ ] `TestIsSprintKey` mirrors `TestIsTechDebtKey` in structure.
- [ ] Valid: `"S001"`, `"s001"` (case-insensitive via Normalize), `"S999"` all return `true`.
- [ ] Invalid: `"S0"`, `"S1"`, `"S0001"`, `""`, `"E07"`, `"SPRINT-1"` all return `false`.

Sprint model tests (new `internal/models/sprint_test.go`):

- [ ] `TestValidateSprintKey_Valid` — `"S001"`, `"S024"`, `"S999"` → nil.
- [ ] `TestValidateSprintKey_Invalid` — `""`, `"S0"`, `"S1"`, `"s024"` (lowercase — no Normalize called), `"E07"`, `"S0001"` → `ErrInvalidSprintKey`.
- [ ] `TestValidateSprintAssignmentEntityType_Valid` — all four: `"task"`, `"bug"`, `"change_card"`, `"tech_debt"` → nil.
- [ ] `TestValidateSprintAssignmentEntityType_Invalid` — `""`, `"epic"`, `"feature"`, `"idea"`, `"TASK"`, `" task "` → `ErrInvalidSprintAssignmentEntityType`.
- [ ] `TestSprint_Validate` table-driven: empty name → error; `EndDate == StartDate` → error; `EndDate < StartDate` → error; empty status → error; valid sprint → nil.
- [ ] `TestSprintAssignment_Validate` table-driven: `SprintID=0` → error; `EntityID=0` → error; invalid entity_type → error; valid assignment → nil.
- [ ] All tests are pure (no DB, no file I/O) — table-driven where appropriate.
- [ ] `make test ./internal/keys/... ./internal/models/...` passes.

## Implementation Notes

- Use `errors.Is(err, ErrInvalidSprintKey)` to assert error type (not just `err != nil`) in validator tests.
- For `TestSprint_Validate` dates: use concrete `time.Date(2026, 4, 1, ...)` values rather than `time.Now()` to keep tests deterministic.
- No mock DB needed — these are pure unit tests.

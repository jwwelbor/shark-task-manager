# Task: Add S### entity type constant and regex to key parser (keys/service.go)

## Goal

Extend `internal/keys/service.go` to recognise the `S###` sprint key format. Add an `EntityTypeSprint` constant, a `sprintKeyPattern` regex (strict 3-digit zero-padded: `^S(\d{3})$`), a `SprintNum` field on `ParsedKey`, and handle the new case in `Parse()` and `Format()`. This is the canonical key-routing entry point; downstream callers (CLI, services) all go through `KeyService.Parse()`.

## Acceptance Criteria

- [ ] `EntityTypeSprint EntityType = "sprint"` constant added alongside existing `EntityTypeEpic`, `EntityTypeBug`, etc.
- [ ] `ParsedKey` has a `SprintNum string` field (e.g., `"024"` from `S024`).
- [ ] `sprintKeyPattern = regexp.MustCompile(` `` `^S(\d{3})$` `` `)` defined at package level (mirrors `bugVariablePattern`).
- [ ] `Parse()` evaluates the sprint pattern before falling through to unknown; input is upper-cased via the existing `upper` variable; sets `EntityType`, `SprintNum`, `Normalized`.
- [ ] `Format()` handles `EntityTypeSprint` and returns `"S" + parsed.SprintNum`.
- [ ] `"S001"`, `"s024"` (case-insensitive) parse correctly; `"S1"`, `"S0001"`, `"SPRINT-1"` parse as `EntityTypeUnknown`.
- [ ] No existing parse cases are affected (all existing tests still pass).

## Implementation Notes

- Mirror the `bugVariablePattern` / bug case in `Parse()` — sprint case should be placed after change-card and before the final unknown fallthrough.
- `Normalized` should be `fmt.Sprintf("S%s", m[1])` where `m[1]` is the 3-digit capture group.
- File: `internal/keys/service.go` only. Do not touch `keys/validation.go` (that is T-E19-F01-003).

## Dependencies

# Task: Add sprint_capacity table with UNIQUE(sprint_id, agent_type) constraint (db.go)

## Goal

Complete the `migrateSprintTables` function by adding the `sprint_capacity` table DDL with its `UNIQUE(sprint_id, agent_type)` table constraint, a sprint-scoped index, and the `sprint_capacity_updated_at` trigger. `allocated_points` is nullable (no trigger maintains it in this feature; it will be computed at query time in E19-F04).

## Acceptance Criteria

- [ ] `sprint_capacity` table added to `migrateSprintTables` with columns: `id INTEGER PRIMARY KEY AUTOINCREMENT`, `sprint_id INTEGER NOT NULL`, `agent_type TEXT NOT NULL`, `capacity_points REAL NOT NULL DEFAULT 0`, `allocated_points REAL` (nullable), `created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP`, `updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP`, `FOREIGN KEY (sprint_id) REFERENCES sprints(id) ON DELETE CASCADE`, `UNIQUE (sprint_id, agent_type)`.
- [ ] `idx_sprint_capacity_sprint INDEX ON sprint_capacity(sprint_id)` created (`CREATE INDEX IF NOT EXISTS`).
- [ ] `sprint_capacity_updated_at` trigger created: `AFTER UPDATE ON sprint_capacity`, sets `updated_at = CURRENT_TIMESTAMP WHERE id = NEW.id`.
- [ ] The `UNIQUE (sprint_id, agent_type)` constraint is a table-level constraint (inline in the CREATE TABLE statement), not a separate index (mirrors the pattern where compound uniqueness is declared in-table).
- [ ] Inserting a duplicate `(sprint_id, agent_type)` pair raises `UNIQUE constraint failed: sprint_capacity.sprint_id, sprint_capacity.agent_type`.
- [ ] `make fmt && make lint` pass.

## Implementation Notes

- These additions go inside `migrateSprintTables`, after the `sprint_assignments` DDL from T-E19-F01-005.
- `allocated_points REAL` with no DEFAULT and no NOT NULL — it is intentionally nullable (NULL means "not yet computed").
- The in-table `UNIQUE (sprint_id, agent_type)` is separate from the `idx_sprint_capacity_sprint` index; both are needed.

## Dependencies

- T-E19-F01-005 (sprint_assignments DDL must be in `migrateSprintTables` first to maintain logical ordering).

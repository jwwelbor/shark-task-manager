# Task: Add sprint_assignments table: partial unique index and four cascade-delete triggers (db.go)

## Goal

Extend the `migrateSprintTables` function (created in T-E19-F01-004) with the `sprint_assignments` table DDL: two regular indexes, the critical partial unique index `idx_sprint_assignments_active_one` (enforces one-active-sprint-per-entity), and four cascade-delete triggers (one per parent entity type: tasks, bugs, change_cards, tech_debts). No DB CHECK on `entity_type` — this is the post-B018 convention.

## Acceptance Criteria

- [ ] `sprint_assignments` table added to `migrateSprintTables` with columns: `id INTEGER PRIMARY KEY AUTOINCREMENT`, `sprint_id INTEGER NOT NULL`, `entity_type TEXT NOT NULL`, `entity_id INTEGER NOT NULL`, `assigned_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP`, `removed_at TIMESTAMP`, `FOREIGN KEY (sprint_id) REFERENCES sprints(id) ON DELETE CASCADE`.
- [ ] NO `CHECK` constraint on `entity_type` (post-B018 convention; spec §3.4).
- [ ] NO `task_id`, `bug_id`, or other entity-specific FK columns (polymorphic design per AC-3).
- [ ] `idx_sprint_assignments_sprint INDEX ON sprint_assignments(sprint_id)` created.
- [ ] `idx_sprint_assignments_entity INDEX ON sprint_assignments(entity_type, entity_id)` created.
- [ ] `idx_sprint_assignments_active_one UNIQUE INDEX ON sprint_assignments(entity_type, entity_id) WHERE removed_at IS NULL` created (partial unique index — the core integrity guarantee for one-active-sprint-per-entity).
- [ ] Four cascade-delete triggers added (all `CREATE TRIGGER IF NOT EXISTS`):
  - `sprint_assignments_cascade_delete_task` — `AFTER DELETE ON tasks`, deletes `sprint_assignments` where `entity_type='task' AND entity_id=OLD.id`.
  - `sprint_assignments_cascade_delete_bug` — `AFTER DELETE ON bugs`.
  - `sprint_assignments_cascade_delete_change_card` — `AFTER DELETE ON change_cards`.
  - `sprint_assignments_cascade_delete_tech_debt` — `AFTER DELETE ON tech_debts`.
- [ ] Inserting two rows with same `(entity_type, entity_id)` and both `removed_at IS NULL` raises a UNIQUE constraint error (verifiable manually or via test in T-E19-F01-008).
- [ ] Inserting with one row's `removed_at` set to a non-NULL value succeeds.

## Implementation Notes

- These additions go inside `migrateSprintTables`, after the `sprints` table DDL from T-E19-F01-004.
- Trigger pattern: mirror `entity_notes` cascade-delete triggers at `db.go:1750-1773`.
- The partial unique index syntax `WHERE removed_at IS NULL` is valid SQLite — test that it compiles correctly.
- `entity_type` values to document in a comment: `task`, `bug`, `change_card`, `tech_debt`.

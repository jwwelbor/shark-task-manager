# Task: Bump CurrentSchemaVersion 17→18, register migrateSprintTables in runMigrations, update history comment (db.go)

## Goal

Wire the completed `migrateSprintTables` function into the migration pipeline by: (1) bumping `CurrentSchemaVersion` from `17` to `18`, (2) calling `migrateSprintTables` from `runMigrations()` after the tech-debt migration, and (3) updating the history comment in `db.go`. This is the final and most critical step — without it `ApplySchemaIfNeeded` will never trigger the new migration on existing databases (per `database-critical.md`).

- Do NOT change `skip_migrations` in `.sharkconfig.json`; the version bump is the only required step per `database-critical.md`.

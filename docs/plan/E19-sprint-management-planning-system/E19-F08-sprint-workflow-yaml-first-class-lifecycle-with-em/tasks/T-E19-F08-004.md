# Replace hardcoded sprint phase strings with workflow.Service calls

## Goal
Replace every hardcoded sprint status/phase string in sprint_service.go with calls through `workflow.Service` so that the sprint lifecycle is driven by sprint.yaml rather than Go source constants.

## Scope
- Files to modify:
  - `internal/services/sprint_service.go` — 8 call sites (see below)
  - `internal/services/sprint_service_test.go` — update mocks/assertions to match

## Call Sites (from spec.md mapping table — 8 total)
1. `DeleteSprint` (~412) — hardcoded `"planning"` guard → GetInitialStatusString()
2. `assignableSprintPhases` (~861) — delete this helper entirely
3. `assignableSprintStatuses` (~869) — replace literal phase loop with GetStatusesByPhase("planning") + GetStatusesByPhase("execution")
4. `GetSprintBacklog` (~1093) — hardcoded `== "active"` → GetStatusesByPhase("execution") membership check
5. `ReorderAssignment` (~1464) — hardcoded `"planning" && "active"` → assignableSprintStatuses()
6. `CloseSprintWithCarryover` (~2055) — hardcoded `"planning"` status filter → GetStatusesByPhase("planning")[0]
7. `CloseSprintWithCarryover` (~2081) — hardcoded `"planning"` target status → GetInitialStatusString()
8. `GetNextTask` (~1294) — hardcoded `"active"` filter → GetStatusesByPhase("execution")[0]
Note: add empty-slice guards before [0] indexing per spec (fail loudly on misconfigured workflow).

## Acceptance Criteria
See spec.md REQ-F-005.

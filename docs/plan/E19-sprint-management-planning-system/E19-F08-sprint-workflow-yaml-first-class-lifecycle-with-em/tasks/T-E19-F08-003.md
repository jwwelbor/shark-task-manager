# Remove single-active sprint constraint from StartSprint

## Goal
Remove the guard in `StartSprint` that prevents starting a sprint when another is already active, enabling teams to run overlapping sprints (e.g. a team sprint alongside a release sprint).

## Scope
- Files to modify:
  - `internal/services/sprint_service.go` — delete the single-active guard block in StartSprint
  - `internal/services/sprint_service_test.go` — remove tests asserting old constraint; add test confirming two sprints can be active simultaneously

## Acceptance Criteria
See spec.md REQ-F-006.
- AC-T1: Starting a sprint when another is active succeeds without error
- AC-T2: Both sprints appear with active status in list output
- AC-T3: No existing passing tests broken by the removal

## Test Cases
See test-plan.md Section on constraint removal test cases.

## Design Reference
See spec.md Architecture — Component Changes.
The guard is a short block near the start of StartSprint; delete it entirely rather than making it conditional.

# Implement /run-sprint-team skill — team sprint execution

## Goal

Create the `/run-sprint-team` slash command and workflow that drives an active sprint by grouping assigned entities into per-feature batches and dispatching each batch via `/run-agent-team` sequentially. Standalone entities (bugs, change-cards, tech-debt without feature parents) fall back to plain `/run`. The `sprint-execution/SKILL.md` created in T-E19-F06-002 is extended to reference this workflow.

## Scope

- Files to create:
  - `~/.claude/commands/run-sprint-team.md`
  - `~/.claude/skills/sprint-execution/workflows/run-sprint-team.md`
- Files to modify:
  - `~/.claude/skills/sprint-execution/SKILL.md` (add reference to run-sprint-team workflow)

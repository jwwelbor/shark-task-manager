# Implement /run-sprint skill — solo sprint pull-loop

## Goal

Create the `/run-sprint` slash command and workflow that drives an active sprint to completion by repeatedly calling `shark sprint next` and delegating entity dispatch to `/run`. The skill gates the close operation on explicit user confirmation and never auto-closes a sprint.

## Scope

- Files to create:
  - `~/.claude/commands/run-sprint.md`
  - `~/.claude/skills/sprint-execution/SKILL.md`
  - `~/.claude/skills/sprint-execution/workflows/run-sprint.md`

## Acceptance Criteria

See spec.md REQ-F-020 AC-1 through AC-11.

Additional task-specific criteria:
- AC-T1: `sprint-execution/SKILL.md` frontmatter has `name` and `description`; "What this is" paragraph notes it covers both run-sprint and run-sprint-team workflows
- AC-T2: CRITICAL INSTRUCTIONS block in command file includes "DO NOT skip the user-confirm-before-close gate"
- AC-T3: Loop body in workflow calls `/run {entity_key}`, not inline `shark status advance` or similar

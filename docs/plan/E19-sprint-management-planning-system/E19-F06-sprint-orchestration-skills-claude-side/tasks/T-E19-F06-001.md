# Implement /plan-sprint skill — mode-aware sprint planner

## Goal

Create the `/plan-sprint` slash command and its backing skill files that walk an orchestrator or human through sprint scoping. The skill reads `shark sprint plan` and `shark sprint readiness`, supports interactive and auto modes, and never calls `shark sprint start`.

## Scope

- Files to create:
  - `~/.claude/commands/plan-sprint.md`
  - `~/.claude/skills/sprint-planning/SKILL.md`
  - `~/.claude/skills/sprint-planning/workflows/plan-sprint.md`

## Acceptance Criteria

See spec.md REQ-F-019 AC-1 through AC-8.

Additional task-specific criteria:
- AC-T1: `SKILL.md` frontmatter includes `name` and `description` fields; has one "What this is" paragraph matching `orchestration/SKILL.md` style
- AC-T2: Command file has YAML frontmatter, Usage block, Arguments block, "What This Does" section, and CRITICAL INSTRUCTIONS block ending with "DO NOT use EnterPlanMode"
- AC-T3: Workflow body implements all five steps as described in spec.md Architecture §plan-sprint

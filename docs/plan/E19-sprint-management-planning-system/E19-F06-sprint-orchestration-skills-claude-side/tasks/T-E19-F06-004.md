# Implement /retro-sprint skill — post-close sprint analysis

## Goal

Create the `/retro-sprint` slash command and workflow that produces a five-section retrospective report for a completed or archived sprint by aggregating `shark sprint summary --detailed`, `shark sprint velocity`, and entity-level notes. The skill writes the report to `docs/sprints/{S###}-retro.md` and gates any overwrite on user confirmation.

## Scope

- Files to create:
  - `~/.claude/commands/retro-sprint.md`
  - `~/.claude/skills/sprint-analytics/SKILL.md`
  - `~/.claude/skills/sprint-analytics/workflows/retro-sprint.md`

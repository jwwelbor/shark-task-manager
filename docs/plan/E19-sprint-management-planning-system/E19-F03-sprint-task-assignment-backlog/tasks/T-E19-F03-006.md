# SprintService: GetSprintBacklog with status grouping and completion percentage

## Goal
Implement `GetSprintBacklog` on `SprintService`: call `repo.ListBacklog`, validate the optional entity-type filter, group results into `BacklogGroup` slices by workflow phase, compute `CompletionPercent` (float64 division, not integer), and assemble the `SprintBacklog` return value. The service must delegate blocked-status detection to `workflow.Service`.

## Scope
- Files to modify:
  - `internal/services/sprint_service.go` — add `GetSprintBacklog`, `BacklogOptions`, `SprintBacklog`, `BacklogGroup`, `BacklogItemView` types
  - `internal/services/sprint_service_test.go` — add TC-B05a through TC-B05d (BVA completion percent, division-by-zero), TC-B06, TC-B07 (type filter), TC-B08, TC-B09 (blocked filter, days-blocked), TC-B01..B04 service-level variants

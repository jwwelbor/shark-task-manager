# Repository: carryover Tx methods

## Goal
Implement the three transaction-scoped repository methods required by `CloseSprintWithCarryover`: `ReassignToSprintTx` (bulk sprint_id update), `DropAssignmentsTx` (bulk soft-delete), and `CreateCompletionTx` (insert sprint_completions row). All three accept `*sql.Tx` so the service owns the transaction boundary.

## Scope
- Files to modify:
  - `internal/repository/sprint/repository.go` — implement the three `*Tx` methods per spec §4.1.1 and §4.1.2
  - `internal/repository/sprint/repository_test.go` — add TC-C08 subset (CreateCompletionTx inserts row and is queryable after commit), TC-P03 benchmark stub

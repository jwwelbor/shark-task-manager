# Repository: assignment CRUD methods

## Goal
Implement `AddAssignment`, `RemoveAssignment`, `GetActiveAssignment`, and `ListAssignments` on `SprintRepository`. These four methods are the foundation for all entity-to-sprint assignment operations; the service layer and CLI cannot be built without them.

## Scope
- Files to modify:
  - `internal/repository/sprint/repository.go` — implement the four assignment methods per spec §4.1.1 using parameterized queries only
  - `internal/repository/sprint/repository_test.go` — add TC-R01 through TC-R10 (real test DB, seedSprintAssignment and seedEntityRow helpers)

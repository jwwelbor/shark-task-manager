# SprintService: CloseSprintWithCarryover — replace stub, atomic transaction, auto-create next sprint

## Goal
Replace the F02 `CloseSprint` stub with the full `CloseSprintWithCarryover` implementation: open a `*sql.Tx`, fetch incomplete assignments, either reassign or soft-delete them (per carryoverMode), advance sprint status to completed, insert `sprint_completions` row, and commit atomically. Auto-create the next planning sprint when carryover=next and no planning sprint exists.

## Scope
- Files to modify:
  - `internal/services/sprint_service.go` — replace stub, add `CloseSprintWithCarryover`, `CarryoverMode`, `SprintCloseResult` types; add `CarryoverNext`, `CarryoverBacklog` constants; use `defer tx.Rollback()` pattern
  - `internal/services/sprint_service_test.go` — add TC-C01 through TC-C12 (state transition, attack-class, BVA, decision table tests using mock repo and real test-DB Tx for TC-C11)

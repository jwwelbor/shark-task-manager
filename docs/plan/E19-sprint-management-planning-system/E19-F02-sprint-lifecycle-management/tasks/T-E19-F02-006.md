# Task: Tech debt: typed NotFoundError across repository layer

## Goal

From code review of T-E19-F02-001 at 20260505-210105.

Finding (non-blocker, codex-flagged blocker downgraded — see code review report Step 9.5 justification):
SprintRepository (and BugRepository, ChangeCardRepository, FeatureRepository, IdeaRepository, WorkSessionRepository, TechDebtRepository) all return plain fmt.Errorf("<entity> not found with key/id ...") strings on miss rather than a typed *NotFoundError or sentinel ErrNotFound that callers can match with errors.As/errors.Is.

docs/architecture/coding-standards.md lines 100-102 ("Define sentinel errors as package-level variables with Err prefix") and lines 989, 1003-1005 (New Module Checklist) recommend sentinel errors. AC-6 of T-E19-F02-001 says "All methods return NotFoundError when appropriate" — currently interpreted across the codebase to mean the descriptive 'not found' string, not a typed Go error.

This is a project-wide tech-debt item, NOT a sprint-specific blocker — the spec at spec.md:253 explicitly directs the developer to mirror BugRepository's existing pattern, so introducing a sprint-only sentinel would create inconsistency without solving the broader gap.

Fix: Add an ErrNotFound sentinel (or *NotFoundError typed error) in a shared repository package and migrate all repositories to wrap it with %w. Update services/CLI to map errors.Is(err, repository.ErrNotFound) to exit code 1.

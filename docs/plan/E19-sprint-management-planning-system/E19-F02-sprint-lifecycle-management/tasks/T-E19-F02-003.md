# Task: CLI commands: CRUD and lifecycle operations

## Goal
Implement thin CLI command wrappers (parse args → call service → format output) for all sprint operations: create, get, list, update, delete, start, close, archive.

## Scope
**Files to create:**
- `internal/cli/commands/sprint.go` — All 8 command handlers (parent cmd + 8 subcommands)
- `internal/cli/commands/sprint_test.go` — CLI tests with mocked SprintService

**Files to modify:**
- `internal/cli/root.go` — Register sprintCmd to RootCmd

## Acceptance Criteria
See spec.md Part 2 (CLI Commands Layer):
- AC-1: sprintCreateCmd parses --start, --end, --goal flags
- AC-2: sprintGetCmd supports key lookup and JSON output
- AC-3: sprintListCmd filters by --status and outputs table or JSON
- AC-4: sprintUpdateCmd updates name/goal/dates
- AC-5: sprintDeleteCmd validates planning status
- AC-6: sprintStartCmd, sprintCloseCmd, sprintArchiveCmd for lifecycle

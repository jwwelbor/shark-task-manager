# SprintAnalyticsRepository: Completion Events and Cycle Time Queries

## Goal

Add `GetCompletionEvents` and `GetCycleTimeByPhase` to the analytics repository, completing the full `SprintAnalyticsRepository` interface implementation. These queries support burndown actual-remaining reconstruction and the `--detailed` cycle-time summary.

## Scope

- Files to modify:
  - `internal/repository/sprint/analytics.go` — add `GetCompletionEvents` and `GetCycleTimeByPhase` methods
  - `internal/repository/sprint/analytics_test.go` — add `seedTaskHistoryEvents` helper; tests for both new methods; TC-NF-01 performance test (50 sprints / 1000 tasks)

## Acceptance Criteria

See spec.md Section 4.3 (GetCompletionEvents, GetCycleTimeByPhase method signatures and query design notes).

`GetCompletionEvents` joins `sprint_assignments` with `task_history` for task entities, filtered to within sprint date window. For non-task entity types, uses current status point-in-time approach (documented limitation). Results include entity_type for the caller to distinguish reconstruction method.

`GetCycleTimeByPhase` returns empty slice (not error) when `task_history` join produces no rows. Groups by `old_status`.

Performance test (`TestPerformance_Analytics`) seeded with 50 sprints and 1000 tasks, gated with `testing.Short()`. Each call must complete in < 2 s.

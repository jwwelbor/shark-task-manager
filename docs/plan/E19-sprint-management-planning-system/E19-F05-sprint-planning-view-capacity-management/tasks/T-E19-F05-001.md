# Config extension: SprintDefaultsConfig struct and sprint_defaults parsing

## Goal

Add `SprintDefaultsConfig` to the config package and wire it into `Config` so
that `sprint_defaults` in `.sharkconfig.json` is parsed and available to the
service layer. Add `SetSprintCapacityDefault` to `config.Manager` for the
`--default` CLI path that writes back to disk.

## Scope

- Files to modify:
  - `internal/config/config.go` — add `SprintDefaultsConfig` type with
    `Capacity`, `CarryoverBehavior`, `AutoCreate` fields; add `SprintDefaults
    *SprintDefaultsConfig` to `Config`
  - `internal/config/manager.go` — add `SetSprintCapacityDefault(agentType
    string, points float64) error` following the `SetCloudConfig` pattern
  - `internal/config/config_test.go` — TC-015-05, TC-015-06: parse with and
    without `sprint_defaults`; assert nil when absent; no panic
  - `internal/config/manager_test.go` — TC-015-07: write initial JSON to
    `t.TempDir()`, call `SetSprintCapacityDefault`, read file from disk, assert
    updated value persisted

See spec.md REQ-F-015 §1.1.5: AC-1, AC-3, AC-5, AC-6

## Test Cases

## Design Reference

See spec.md Architecture Sections 2.3.1 and 2.7. `SetSprintCapacityDefault`
reads current config, mutates `sprint_defaults.capacity` map, writes JSON back.
Tests must use `t.TempDir()` — never the real project config file.

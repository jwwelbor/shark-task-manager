# SprintService: extend struct, interfaces, constructor, and default-capacity on create

## Goal

Wire the two new repository interfaces into `SprintService`, update
`NewSprintService` to accept `assignmentRepo`, `capacityRepo`, and `cfg`
parameters, and extend `CreateSprint` to apply `sprint_defaults.capacity` rows
at creation time when config is set. Update `GetSprintService()` in
`services_global.go` to pass the new arguments.

## Scope

- Files to modify:
  - `internal/services/sprint_service.go` — add `SprintAssignmentQueryRepository`
    and `SprintCapacityRepository` interfaces; add `assignmentRepo`,
    `capacityRepo`, `cfg` fields to struct; update `NewSprintService` signature;
    extend `CreateSprint` with default-capacity logic (non-fatal on capacity
    insert error)
  - `internal/cli/services_global.go` — update `GetSprintService()` to pass
    `sprintRepo` for both new repo interfaces and `cfg`
  - `internal/services/sprint_service_test.go` — TC-015-01, TC-015-02: mock
    `SprintCapacityRepository.SetCapacity`; assert call count when cfg has
    defaults vs when absent

See spec.md REQ-F-015 §1.1.5 AC-2, AC-4; spec §2.4 constructor update and §2.8
default-capacity on create; §2.9 service accessor update

# Integration: performance test ListUnassignedBacklog and regression gate

## Goal

Add a repository-level performance test that seeds 500 tasks and asserts
`ListUnassignedBacklog` completes in under 500ms using a real SQLite test DB
(no mocks). Run `make fmt && make lint && make test` to confirm zero regressions
in existing task, feature, epic, and sprint commands after all F05 changes are
merged.

## Scope

- Files to modify:
  - `internal/repository/sprint/repository_test.go` — add
    `TestSprintRepository_ListUnassignedBacklog_Performance`: helper
    `seedBacklogTasks(db, 500)` inserts 500 tasks in `ready_for_development`;
    time `ListUnassignedBacklog`; assert elapsed < 500ms and len == 500;
    run with `-count=3` to account for warm-up variance; clean up after test
  - No new files — all test additions extend the existing test file

## Acceptance Criteria

See spec.md REQ-NF-001 §1.2 (< 500ms at 500 entities); REQ-NF-004 §1.2
(zero breaking changes to E19-F01/F02/F03 service interfaces); Acceptance Gate
§5 (make fmt && make lint && make test all pass)

-timeout=30s` to account for SQLite warm-up variance per test-plan.md §11.

- UAT, code review and QA are workflow steps driven by their existing actions, prompts and outcome maps. For example, the feature UAT red-team and task review steps request OpenAI and the bug plan review requests Anthropic. This is explicit step selection. There is no observed comparator enforcing author/reviewer independence. [Feature workflow](../../../internal/sharkdata/default_data/workflow/feature.yaml), [bug workflow](../../../internal/sharkdata/default_data/workflow/bug.yaml)

Core and Rider's `--apply-result` share `IngestGateResult` and the `gatepersist.Coordinator`. Bug admission includes approved plan, candidate/worktree and review evidence checks. A workflow fail outcome may legitimately revisit an earlier stage, which is workflow rework.

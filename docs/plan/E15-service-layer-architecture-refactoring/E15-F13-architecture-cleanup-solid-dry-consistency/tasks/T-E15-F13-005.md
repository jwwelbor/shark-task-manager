# Task: Extract CascadeStatusToTasks and SetStatusOverride from FeatureRepository to FeatureService

## Goal

Move business logic methods from FeatureRepository into FeatureService:
- `CascadeStatusToTasks()` / `CascadeStatusToTasksByKey()` (~lines 958-986) - propagates feature status changes to child tasks
- `SetStatusOverride()` / `SetStatusOverrideByKey()` (~lines 866-925) - manages feature status override rules
- `UpdateStatusIfNotOverridden()` / `UpdateStatusIfNotOverriddenByKey()` (~lines 898-925) - conditional status updates

These implement business rules for status propagation and override logic that belong in the service layer.

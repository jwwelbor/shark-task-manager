## NON-BLOCKING ISSUES

### NB1: Dummy variables to suppress unused imports (feature_service_test.go:69-71)

```go
// Suppress unused import warnings
var _ = sql.NullTime{}
var _ = time.Now
```

These dummy variables suppress `database/sql` and `time` import warnings. This is a code smell -- if the imports are not used by test code, they should be removed. If they are used indirectly (e.g., by test data construction), the relevant test should import them naturally.

**Recommendation:** Remove the unused imports and these dummy variables, or refactor tests to use `sql.NullTime` and `time.Now` directly where needed.

### NB2: Feature DTOs in epic_dto.go (epic_dto.go:41-92)

Same as NB1 in the T-E15-F05-001 review -- Feature DTOs (`FeatureFilters`, `FeatureProgressInfo`, etc.) are defined in `epic_dto.go`. Consider renaming or splitting the file.

The `ListFeatures` method documents that EpicKey filtering is not currently supported, with an explicit comment. This is acceptable for the current scope, but should be tracked as a follow-up item since `FeatureFilters.EpicKey` field exists in the DTO but is ignored.

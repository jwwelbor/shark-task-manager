# Task: Implement FeatureService with CRUD and progress/health calculations

## Goal

Expand the existing FeatureService (in `internal/services/feature_service.go`) with business logic methods for progress calculation, health analysis, work breakdown, and action item tracking. Currently FeatureService only has TransitionStatus, GetNextStatus, and ValidateStatus. This task adds the missing methods that CLI commands need to stop calling repositories and status package directly.

## Requirements

### Functional Requirements

- [ ] FR-1: Implement `GetFeature(ctx, featureKey) (*models.Feature, error)` - retrieve feature by key with error wrapping
- [ ] FR-2: Implement `ListFeatures(ctx, filters FeatureFilters) ([]*models.Feature, error)` - list features with optional epic/status filters
- [ ] FR-3: Implement `GetProgress(ctx, featureKey) (*FeatureProgressInfo, error)` - calculate weighted and completion progress using status metadata
- [ ] FR-4: Implement `GetHealth(ctx, featureKey) (*FeatureHealthInfo, error)` - determine healthy/warning/critical from task analysis

- [ ] FR-7: Implement `GetTaskStatusBreakdown(ctx, featureKey) (map[string]int, error)` - task count by status

**Workflow config access:**
The service needs access to `*config.WorkflowConfig` to pass to the pure calculation functions. Add this as a constructor dependency, sourced from the workflow service:
```go
func (s *FeatureService) getWorkflowConfig() *config.WorkflowConfig {
    return s.workflowSvc.GetWorkflow()
}
```

**Health calculation logic:**
- healthy: no blocked tasks, no approvals older than 3 days
- warning: 1+ approvals older than 3 days OR 1 blocked task
- critical: 2+ blocked tasks OR high-priority blocked task

**Progress pattern (delegating to pure functions):**
```go
func (s *FeatureService) GetProgress(ctx context.Context, featureKey string) (*FeatureProgressInfo, error) {
    feature, err := s.repo.GetByKey(ctx, featureKey)
    if err != nil {
        return nil, fmt.Errorf("failed to get feature %s: %w", featureKey, err)
    }

    statusCounts, err := s.repo.GetTaskStatusBreakdown(ctx, feature.ID)
    if err != nil {
        return nil, fmt.Errorf("failed to get task breakdown for %s: %w", featureKey, err)
    }

    // Convert to string map for pure function
    stringCounts := make(map[string]int)
    for k, v := range statusCounts {
        stringCounts[string(k)] = v
    }

    cfg := s.workflowSvc.GetWorkflow()
    progressInfo := status.CalculateProgress(stringCounts, cfg)

    return &FeatureProgressInfo{
        FeatureKey:         featureKey,
        WeightedProgress:   progressInfo.WeightedPercent,
        CompletionProgress: progressInfo.CompletionPercent,
        TotalTasks:         progressInfo.TotalTasks,
        CompletedTasks:     progressInfo.CompletedTasks,
    }, nil
}
```

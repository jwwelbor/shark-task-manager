# Task: Refactor task.go CLI commands to thin wrappers calling TaskService

## Goal

Refactor `internal/cli/commands/task.go` from 2,664 lines (fat controller with embedded business logic) to ≤400 lines (thin wrapper). All commands follow three-step pattern: parse arguments → call `cli.GetTaskService()` method → format output. Zero behavioral changes, all tests pass unchanged.

**Target**: 85% line reduction (2,664 → ≤400 lines), zero business logic in command file

## Requirements

### Functional Requirements
- **REQ-F-001**: Refactor all task commands to three-step pattern: parse → call TaskService → format
- **REQ-F-002**: Remove all business logic: no validation loops, no status checks, no progress calculations
- **REQ-F-003**: Replace all `repository.NewTaskRepository()` calls with `cli.GetTaskService()` calls
- **REQ-F-004**: File size ≤400 lines (excluding tests)

### Non-Functional Requirements
- **REQ-NF-001**: Zero behavioral changes - all existing tests pass unchanged, CLI output identical
- **REQ-NF-002**: Performance within ±10% of baseline (50ms for `task next`)

## Implementation Plan

### Three-Step Pattern (Apply to Each Command)
```go
func runTaskStart(cmd *cobra.Command, args []string) error {
    // Step 1: Parse arguments
    taskKey := args[0]
    agentID, _ := cmd.Flags().GetString("agent")

    // Step 2: Call service
    svc := cli.GetTaskService()
    task, err := svc.StartTask(cmd.Context(), taskKey, agentID)
    if err != nil {
        return err
    }

    // Step 3: Format output
    if cli.GlobalConfig.JSON {
        return cli.OutputJSON(task)
    }
    cli.Success(fmt.Sprintf("Started task %s", task.Key))
    return nil
}
```

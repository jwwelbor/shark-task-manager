# Task: Validate zero test regression and performance within baseline

## Goal

Validate that service layer refactoring is behavior-preserving: all existing tests pass (100% pass rate), CLI output unchanged, performance within ±10% of baseline. This is the quality gate before documentation updates.

## Requirements

### Functional
- **REQ-F-001**: All existing tests pass with 100% pass rate (zero modifications to test expectations)
- **REQ-F-002**: CLI output format unchanged (JSON structure, table columns identical)
- **REQ-F-003**: CLI command syntax unchanged (same flags, same arguments)

### Non-Functional
- **REQ-NF-001**: Performance within ±10% of baseline
  - `shark task next --agent=backend`: Baseline 50ms → Target 45-55ms
  - `shark task list`: Baseline 120ms → Target 108-132ms
  - `shark feature get E07-F01`: Baseline 80ms → Target 72-88ms

## Implementation

### Test Execution Plan

1. **Full Test Suite**
```bash
make test | tee test-results-E15-F12.txt
# Verify: exit code 0, 100% pass rate
```

2. **Output Format Validation**
```bash
# Before refactoring (capture baseline)
shark task get E07-F01-001 --json > baseline-task-get.json
shark feature list --json > baseline-feature-list.json

# After refactoring (compare)
shark task get E07-F01-001 --json > refactored-task-get.json
diff baseline-task-get.json refactored-task-get.json  # Must be identical
```

3. **Performance Benchmarks**
```bash
# Measure baseline before refactoring
for i in {1..100}; do time shark task next --agent=backend 2>&1; done | grep real | awk '{print $2}' > baseline-task-next.txt

# Measure after refactoring
for i in {1..100}; do time shark task next --agent=backend 2>&1; done | grep real | awk '{print $2}' > refactored-task-next.txt

# Calculate average and verify ±10%
```

4. **Code Quality Metrics**
```bash
# Line count reduction
wc -l internal/cli/commands/task.go  # Target: ≤400
wc -l internal/cli/commands/feature.go  # Target: ≤350
wc -l internal/cli/commands/epic.go  # Target: ≤300

# Business logic removed
grep -r "CalculateProgress\|GetHealthStatus\|GetStatusBreakdown" internal/repository/  # Must return 0

# Service calls only
grep -r "cli.GetTaskService\|cli.GetFeatureService\|cli.GetEpicService" internal/cli/commands/  # Must match all commands
```

**AC1: Zero Test Regression**
- [ ] `make test` exits with code 0

**AC2: Output Format Unchanged**
- [ ] JSON structure identical (field names, types, nesting)
- [ ] Table columns identical (headers, order, formatting)
- [ ] Error messages identical (same text, same exit codes)

**AC3: Performance Within ±10%**
- [ ] `shark task next`: 45-55ms (baseline 50ms)

- [ ] `shark feature get`: 72-88ms (baseline 80ms)

# Task: Refactor Fat-Controller CLI Commands to Thin Wrappers

## Goal

Refactor the seven CLI command files that still call repositories directly into thin wrappers that delegate to the service layer. After this task, no production CLI command handler function should contain `repository.New*` or `cli.GetDB()` calls.

This task depends on T-E15-F10-004 (IdeaService creation) because `idea.go` refactoring requires `IdeaService` to exist first.

## Target Files

The following files require refactoring (ordered by priority):

| File | Lines | Primary Service to Use |
|------|-------|----------------------|
| `idea.go` | 1002 | `cli.GetIdeaService()` (new — from T-E15-F10-004) |
| `task_deps.go` | 780 | `cli.GetTaskService()` (extended methods from T-E15-F10-004) |
| `related_docs.go` | 462 | `cli.GetEpicService()` / `cli.GetFeatureService()` (extended) |
| `search.go` | 176 | `cli.GetTaskService()` / relevant services |
| `task_sessions.go` | 153 | `cli.GetTaskService()` (extended) |
| `task_unlink.go` | 178 | `cli.GetTaskService()` (extended) |
| `status.go` | 141 | `cli.GetEpicService()` / `cli.GetFeatureService()` / `cli.GetTaskService()` |

### Technical Approach

Each file follows the same migration pattern:

**Before** (fat controller):
```go
func runIdeaCreate(cmd *cobra.Command, args []string) error {
    ctx := cmd.Context()
    db, err := cli.GetDB(ctx)
    if err != nil {
        return fmt.Errorf("failed to get database: %w", err)
    }
    repo := repository.NewIdeaRepository(db)
    // ... 50+ lines of business logic ...
    idea, err := repo.Create(ctx, &models.Idea{...})
    // ...
}
```

**After** (thin wrapper):
```go
func runIdeaCreate(cmd *cobra.Command, args []string) error {
    input := parseIdeaCreateInput(cmd, args)
    svc := cli.GetIdeaService()
    idea, err := svc.CreateIdea(cmd.Context(), input)
    if err != nil {
        return err
    }
    if cli.GlobalConfig.JSON {
        return cli.OutputJSON(idea)
    }
    cli.Success(fmt.Sprintf("Created idea %s", idea.Key))
    return nil
}
```

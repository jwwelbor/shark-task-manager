### Technical Approach

**IdeaService Key Generation**:

The idea key format is `I-YYYY-MM-DD-xx` where:
- `YYYY-MM-DD` is today's date when the idea is created
- `xx` is a zero-padded sequence number (01, 02, ...) for ideas created on the same date

This logic currently lives inline in `idea.go`. It must move to `IdeaService.CreateIdea`:

```go
func (s *IdeaService) CreateIdea(ctx context.Context, input CreateIdeaInput) (*models.Idea, error) {
    today := time.Now().Format("2006-01-02")
    seq, err := s.repo.GetNextSequenceForDate(ctx, today)
    if err != nil {
        return nil, fmt.Errorf("failed to get next sequence: %w", err)
    }
    key := fmt.Sprintf("I-%s-%02d", today, seq)

    idea := &models.Idea{
        Key:         key,
        Title:       input.Title,
        Description: input.Description,
        // ... other fields
    }

    if err := s.repo.Create(ctx, idea); err != nil {
        return nil, fmt.Errorf("failed to create idea: %w", err)
    }

    return idea, nil
}
```

**TaskService Dependency Methods**:

```go
func (s *TaskService) AddDependency(ctx context.Context, taskKey, depKey string) error {
    task, err := s.repo.GetByKey(ctx, taskKey)
    if err != nil {
        return fmt.Errorf("task not found: %w", err)
    }
    dep, err := s.repo.GetByKey(ctx, depKey)
    if err != nil {
        return fmt.Errorf("dependency task not found: %w", err)
    }
    if task.ID == dep.ID {
        return fmt.Errorf("task cannot depend on itself")
    }
    return s.repo.AddDependency(ctx, task.ID, dep.ID)
}
```

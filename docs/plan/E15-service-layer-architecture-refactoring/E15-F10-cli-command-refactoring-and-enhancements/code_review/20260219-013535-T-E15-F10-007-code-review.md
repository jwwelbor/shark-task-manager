## Required Changes

### 1. Remove `IdeaRepository` interface and repository import from `idea.go` (BLOCKING)

The `IdeaRepository` interface at lines 18-28 must be deleted. This interface was created before `IdeaService` existed and is now superseded. The import of `repository` package must also be removed.

### 2. Reduce handler function sizes to ≤30 lines (BLOCKING)

The handler functions are still too large because they contain inline output formatting logic that should be extracted into helper functions. The pattern to apply:

**Before (handler with inline formatting, 64 lines):**
```go
func runIdeaList(cmd *cobra.Command, args []string) error {
    // Parse flags (5 lines)
    // Call service (5 lines)
    // 50+ lines of if/else output formatting inline
}
```

**After (handler with extracted helper, ~15 lines):**
```go
func runIdeaList(cmd *cobra.Command, args []string) error {
    filters := parseIdeaListFilters(cmd, args)
    svc := cli.GetIdeaService()
    ideas, err := svc.ListIdeas(cmd.Context(), filters)
    if err != nil {
        return err
    }
    if cli.GlobalConfig.JSON {
        return cli.OutputJSON(ideas)
    }
    return printIdeaList(ideas)
}

func printIdeaList(ideas []*models.Idea) error {
    // Extracted formatting logic here
}
```

Apply this extraction pattern to all handlers exceeding 30 lines. The output formatting logic is presentation-layer code and should stay in the command file — just extracted into dedicated helper functions (not moved to services).

## Defect: BUG-001 - history.go is a fat controller

**Severity:** High
**Priority:** High
**Status:** New
**Found In:** Dev (branch E15)
**Story:** T-E15-F11 (migration of CLI commands to service layer)

### Description

`internal/cli/commands/history.go` directly instantiates repository objects and calls repository methods, bypassing the service layer. This command was supposed to be migrated in T-015 (as the `shark history` command), but the migration left the fat controller pattern intact.

### Steps to Reproduce

```bash
grep -n "repository\.New" internal/cli/commands/history.go
```

### Expected Result

No `repository.New` calls in `history.go`. The command should call `cli.GetTaskServiceWithHistory()` which already exists in `services_global.go` and wires the history repository.

### Actual Result

Two direct repository instantiations found:
- Line 106: `historyRepo := repository.NewTaskHistoryRepository(dbConn)`
- Line 107: `taskRepo := repository.NewTaskRepository(dbConn)`

The command then calls `historyRepo.ListWithFilters()` (line 153) and `taskRepo.GetByID()` (line 186) directly.

### Impact

This is a fat controller violation - the architecture pattern that E15-F11 is specifically designed to eliminate. The command contains:
- Direct database connection retrieval
- Direct repository instantiation
- Business logic (building filter structs, formatting display records)
- Multiple repository method calls

### Evidence

```
$ grep -n "repository\.New" internal/cli/commands/history.go
106:    historyRepo := repository.NewTaskHistoryRepository(dbConn)
107:    taskRepo := repository.NewTaskRepository(dbConn)
```

The `GetTaskServiceWithHistory()` accessor already exists in `services_global.go` and is ready to use. The `history.go` command was not updated to use it.

### Workaround

None - the violation exists in the code.

### Fix Required

Refactor `runHistory()` in `history.go` to:
1. Call `cli.GetTaskServiceWithHistory()` to get the service
2. Pass the `HistoryFilters` struct to a service method (may need a new `GetProjectHistory` method on TaskService)
3. Remove direct repository imports and instantiation
4. Remove repository method calls from the command

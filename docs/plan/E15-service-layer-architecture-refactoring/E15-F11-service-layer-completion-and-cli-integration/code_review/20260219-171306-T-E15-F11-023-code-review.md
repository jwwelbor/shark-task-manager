## Summary

The task was to migrate `internal/cli/commands/task_criteria.go` from a fat-controller pattern to a thin wrapper that calls `CriteriaService` methods. The `CriteriaService` has been implemented in `internal/services/criteria_service.go` and exposes exactly the right methods for this migration (`ImportCriteriaFromFile`, `GetTaskCriteriaWithSummary`, `CheckCriterionForTask`, `FailCriterionForTask`).

**The migration has NOT been performed.** The `task_criteria.go` file still contains the original fat-controller implementation calling repositories directly.

---

## Findings

### BLOCKER: Fat Controller Anti-Pattern Remains

The `task_criteria.go` file still directly instantiates and calls repositories instead of calling `CriteriaService` methods. All four command handlers are affected:

**`runTaskCriteriaImport` (lines 91-161):**
- Calls `cli.GetDB()` directly
- Instantiates `repository.NewTaskRepository()` and `repository.NewTaskCriteriaRepository()` directly
- Calls `taskRepo.GetByKey()`, `taskfile.ParseCriteriaFromFile()`, and `criteriaRepo.Create()` directly
- All of this business logic already exists in `CriteriaService.ImportCriteriaFromFile()`

**`runTaskCriteriaList` (lines 163-275):**
- Calls `cli.GetDB()` directly
- Instantiates `repository.NewTaskRepository()` and `repository.NewTaskCriteriaRepository()` directly
- Contains 80+ lines including criteria sorting logic (failed, pending, in_progress, complete, na)
- Sorting is presentation logic that belongs in the command, but task lookup + summary retrieval are now duplicated from `CriteriaService.GetTaskCriteriaWithSummary()`

**`runTaskCriteriaCheck` (lines 277-348):**
- Calls `cli.GetDB()` directly
- Instantiates both repositories directly
- Performs task lookup, criterion ownership verification, status update, and summary retrieval
- All duplicated from `CriteriaService.CheckCriterionForTask()`

**`runTaskCriteriaFail` (lines 351-423):**
- Same pattern as check - calls repositories directly
- Duplicates logic from `CriteriaService.FailCriterionForTask()`

### Missing: Global CriteriaService Accessor

No `GetCriteriaService()` global accessor exists in `internal/cli/services_global.go`. The CriteriaService needs to be wired and exposed for CLI commands to call. This is a prerequisite for the migration.

### Import Anti-Pattern

The file imports `github.com/jwwelbor/shark-task-manager/internal/repository` directly from a CLI command file. Per CLAUDE.md architecture rules, CLI commands must NOT import or call repository packages. This import should be removed once the migration is complete.

### Build Failure (Pre-existing, Not Caused By This Task)

This is an unrelated pre-existing issue. The `internal/services` package tests pass (`ok internal/services/criteria_service.go` tests all pass).

### CriteriaService Is Ready

The `CriteriaService` in `internal/services/criteria_service.go` is well-implemented and provides exactly the right methods:
- `ImportCriteriaFromFile(ctx, taskKey)` - handles file parsing and DB import
- `GetTaskCriteriaWithSummary(ctx, taskKey)` - returns TaskCriteriaWithSummary with criteria + summary + title
- `CheckCriterionForTask(ctx, taskKey, criterionID, notes)` - verifies ownership and checks criterion
- `FailCriterionForTask(ctx, taskKey, criterionID, notes)` - verifies ownership and fails criterion

All service tests pass. The service is production-ready.

## What Correct Implementation Looks Like

After migration, each handler should follow the three-step pattern:

```go
// runTaskCriteriaImport - should be ~15 lines
func runTaskCriteriaImport(cmd *cobra.Command, args []string) error {
    taskKey := args[0]

    svc := cli.GetCriteriaService()
    count, err := svc.ImportCriteriaFromFile(cmd.Context(), taskKey)
    if err != nil {
        return err
    }

    if cli.GlobalConfig.JSON {
        return cli.OutputJSON(map[string]interface{}{
            "task_key": taskKey,
            "imported": count,
            "message":  fmt.Sprintf("Imported %d acceptance criteria for %s", count, taskKey),
        })
    }

    fmt.Printf("Imported %d acceptance criteria for %s\n", count, taskKey)
    return nil
}
```

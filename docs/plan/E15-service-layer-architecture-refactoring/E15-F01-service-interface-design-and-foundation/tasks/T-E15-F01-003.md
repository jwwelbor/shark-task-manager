# Task: Create service layer architecture documentation and integration guide

## Goal

Create comprehensive architecture documentation for the service layer, including integration guides for CLI commands and HTTP API handlers, migration patterns from fat controllers to thin wrappers, and best practices for service design. This documentation enables future developers and AI agents to correctly implement service methods and integrate them into entry points.

## Requirements

### Functional Requirements

- [ ] Update `.claude/rules/architecture.md` with service layer design patterns and anti-patterns
- [ ] Create integration guide for CLI commands showing before/after refactoring examples
- [ ] Create integration guide for HTTP API handlers showing service usage patterns
- [ ] Document service interface design principles (explicit over generic, context-aware, error wrapping)
- [ ] Document testing patterns (service tests use mocks, repository tests use real DB)
- [ ] Create migration checklist for converting fat CLI commands to thin wrappers
- [ ] Document common pitfalls and anti-patterns to avoid

### Non-Functional Requirements

- [ ] Documentation targets both human developers and AI code agents (clear examples, checklists)
- [ ] Examples are executable (can be copied directly into code with minimal changes)
- [ ] Documentation follows existing `.claude/rules/*` structure and conventions
- [ ] All code examples pass `make fmt && make lint` validation
- [ ] Migration patterns reference real files in codebase (e.g., task.go at 2,664 LOC)

## Required Changes

### Build Failure: epic.go + epic_helpers.go Signature Mismatch

**Location:** `internal/cli/commands/epic.go` lines 227 and 245, `internal/cli/commands/epic_helpers.go`

**Error Messages:**
```
internal/cli/commands/epic.go:227:63: too many arguments in call to resolveEpicPlanningPath
    have (context.Context, string, *repository.DB)
    want (context.Context, string)
internal/cli/commands/epic.go:245:43: too many arguments in call to buildEpicGetData
    have (context.Context, *models.Epic, *repository.DB)
    want (context.Context, *models.Epic)
internal/cli/commands/epic_helpers.go:18:2: "github.com/jwwelbor/shark-task-manager/internal/pathresolver" imported and not used
```

**Root Cause:** Commit `85e6228` (refactor TaskRepository status enrichment) modified `epic.go` to remove `repoDb` from function signatures, but the call sites at lines 227 and 245 in `epic.go` still pass `repoDb` as an argument to `resolveEpicPlanningPath` and `buildEpicGetData`.

**Fix Required (option A — remove extra args from call sites):**

In `epic.go` line 227, change:
```go
info.ResolvedPath = resolveEpicPlanningPath(ctx, epic.Key, repoDb)
```
to:
```go
info.ResolvedPath = resolveEpicPlanningPath(ctx, epic.Key)
```

In `epic.go` line 245, change:
```go
data, err := buildEpicGetData(ctx, epic, repoDb)
```
to:
```go
data, err := buildEpicGetData(ctx, epic)
```

**Fix Required (option B — remove unused import):**

In `epic_helpers.go`, remove the unused `pathresolver` import at line 18.

**Note:** If `repoDb` is still needed inside `resolveEpicPlanningPath` or `buildEpicGetData`, the function signatures in `epic_helpers.go` need to be updated to accept it. Review both the call site intent and the function bodies to determine the correct approach.

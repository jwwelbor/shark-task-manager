# Task: Add unit tests for thin wrapper command handlers

## Goal

Add unit tests for the argument parsing helpers and the centralized error handler that were introduced during the thin wrapper refactoring (tasks T-E15-F07-003, T-E15-F07-004, T-E15-F07-005, T-E15-F07-006). Tests must use mocked services - no real database. Coverage target: all parsing helpers and all `handleServiceError` exit code paths.

## Requirements

### Functional Requirements

#### Error Handler Tests (`internal/cli/commands/helpers_test.go`)

Test `handleServiceError` for each exit code path:

- **Exit code 1** (`*repository.NotFoundError`): Pass `&repository.NotFoundError{Entity: "task", Key: "E07-F01-001"}` - verify `os.Exit(1)` is called and `cli.Error` message contains entity name and key
- **Exit code 3** (workflow/transition error): Pass a `*workflow.TransitionError` value - verify `os.Exit(3)` is called
- **Exit code 2** (generic error): Pass `fmt.Errorf("db connection failed")` - verify `os.Exit(2)` is called
- **nil error**: Pass `nil` - verify `os.Exit` is NOT called

Note: `os.Exit` calls must be tested via subprocess execution (spawn the test binary as a child process and inspect the exit code) to avoid terminating the test process.

#### Argument Parsing Helper Tests (`internal/cli/commands/task_test.go`)

Test `parseCreateTaskInput()`:

- **3-arg format**: `args = ["E07", "F01", "My Task Title"]` → `EpicKey="E07"`, `FeatureKey="F01"`, `Title="My Task Title"`
- **2-arg combined format**: `args = ["E07-F01", "My Task Title"]` → `EpicKey="E07"`, `FeatureKey="F01"` (or `FeatureKey="E07-F01"`), `Title="My Task Title"`
- **Flag format**: `args = []`, flags `--epic=E07 --feature=F01 --title="My Task Title"` → correctly populated struct
- **Optional flags**: Verify `--agent`, `--priority`, `--order`, `--file`, `--force` flags are correctly mapped to DTO fields

Test `parseTaskFilters()`:

- **No args**: Returns zero-value `TaskFilters` struct (or appropriate defaults)
- **Epic positional arg**: `args = ["E07"]` → `EpicKey="E07"`
- **Epic + feature positional args**: `args = ["E07", "F01"]` → both fields set

#### Argument Parsing Helper Tests (`internal/cli/commands/feature_test.go`)

Test `parseCreateFeatureInput()` (if extracted as a helper):

- **Positional format**: `args = ["E07", "My Feature Title"]` → `EpicKey="E07"`, `Title="My Feature Title"`
- **Flag format**: `args = []`, flags `--epic=E07 --title="My Feature Title"` → correctly populated

### Non-Functional Requirements

- Tests must NOT use real database - use mocks or pure argument parsing tests only
- Test file must compile as part of the `commands` package (package-internal access to helpers)
- All test functions must follow `TestXxx` naming convention
- Exit code tests use subprocess pattern (not direct call) to avoid killing the test process

### Subprocess Pattern for os.Exit Testing

```go
func TestHandleServiceError_NotFound_ExitsWithCode1(t *testing.T) {
    if os.Getenv("TEST_SUBPROCESS") == "1" {
        // Run actual function inside subprocess
        handleServiceError(&repository.NotFoundError{Entity: "task", Key: "E07-F01-001"}, "E07-F01-001")
        return
    }
    // Spawn subprocess and check exit code
    cmd := exec.Command(os.Args[0], "-test.run=TestHandleServiceError_NotFound_ExitsWithCode1")
    cmd.Env = append(os.Environ(), "TEST_SUBPROCESS=1")
    err := cmd.Run()
    if e, ok := err.(*exec.ExitError); ok && !e.Success() {
        assert.Equal(t, 1, e.ExitCode())
        return
    }
    t.Fatal("expected exit code 1")
}
```

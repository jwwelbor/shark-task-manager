# Task: Refactor task.go CLI commands to thin wrappers (2664→400 lines)

## Goal

Refactor `internal/cli/commands/task.go` from 2,664 lines (fat controller with ~70% business logic) to at most 400 lines (thin wrappers calling `TaskService`). Every command handler must follow the three-step pattern: parse args → call service → format output.

## Design Reference

- Architecture doc: `docs/plan/E15-service-layer-architecture-refactoring/E15-F07-cli-commands-as-thin-wrappers/02-architecture.md` Section 3 (Decisions 1, 2, 3) and Section 4 (task.go handler mapping table)
- Feature doc FR-F07-002 and FR-F07-005/006
- Test plan AC2.1-2.7 and Integration Scenario 1

## Requirements

### Handler-to-Service Mapping

Every handler must be refactored to call exactly one service method:

| Handler | Service Method | DTO/Input |
|---------|---------------|-----------|
| `runTaskCreate` | `svc.CreateTask(ctx, input)` | `services.CreateTaskInput` |
| `runTaskList` | `svc.ListTasks(ctx, filters)` | `services.TaskFilters` |
| `runTaskGet` | `svc.GetTask(ctx, key)` | string key |
| `runTaskStart` | `svc.StartTask(ctx, key, agentID)` | string key + string |
| `runTaskComplete` | `svc.CompleteTask(ctx, key, notes)` | string key + string |
| `runTaskApprove` | `svc.ApproveTask(ctx, key, notes)` | string key + string |
| `runTaskReopen` | `svc.ReopenTask(ctx, key, notes)` | string key + string |
| `runTaskBlock` | `svc.BlockTask(ctx, key, reason)` | string key + string |
| `runTaskUnblock` | `svc.UnblockTask(ctx, key)` | string key |
| `runTaskNext` | `svc.GetNextTask(ctx, filters)` | `services.NextTaskFilters` |
| `runTaskDelete` | `svc.DeleteTask(ctx, key)` | string key |
| `runTaskUpdate` | `svc.UpdateTask(ctx, key, updates)` | `services.TaskUpdates` |

### Prohibited Patterns

After refactoring, none of these may appear in any handler:
- `repository.NewTaskRepository(...)`, `repository.NewEpicRepository(...)`, `repository.NewFeatureRepository(...)`
- `cli.GetDB(...)` followed by direct repository construction
- `workflow.Service` access within command handlers
- `status.NewCalculationService(...)` calls
- Filtering loops (`for _, t := range tasks { if ... }`)
- Sorting logic (`sort.Slice(...)`)

### Required Argument Parsing Helpers

Extract complex parsing to named helpers:
- `parseCreateTaskInput(cmd, args) services.CreateTaskInput` - handles 3-arg, 2-arg, and flag formats
- `parseTaskFilters(cmd, args) services.TaskFilters` - handles epic/feature positional args
- `parseNextTaskFilters(cmd) services.NextTaskFilters` - for `task next` command flags

## Implementation Plan

### Steps

1. Run `make build` and capture baseline output BEFORE any changes:
   ```bash
   ./bin/shark task next --json > /tmp/baseline-task-next.json
   ./bin/shark task list --json > /tmp/baseline-task-list.json
   ```
2. Read all of `task.go` to identify every `func run*` handler function and its current structure
3. Start with simple handlers (get, start, complete, approve, reopen, block, unblock) - each becomes ~15 lines
4. For each handler: delete the body, replace with three-step pattern using `cli.GetTaskService()`
5. Use `handleServiceError(err, key)` from `internal/cli/commands/helpers.go` for error cases
6. Handle complex handlers (create, list, next) last - extract parsing helpers first
7. Remove unused imports after all handlers are refactored
8. Run `make fmt && make lint && make test`
9. Verify: `wc -l internal/cli/commands/task.go` ≤ 400
10. Verify: `grep -c "repository\.New" internal/cli/commands/task.go` = 0
11. Verify JSON output: `./bin/shark task next --json | diff /tmp/baseline-task-next.json -`

### Handler Template

```go
func runTaskStart(cmd *cobra.Command, args []string) error {
    // Step 1: Parse
    taskKey := args[0]
    agentID, _ := cmd.Flags().GetString("agent")

    // Step 2: Call service
    svc := cli.GetTaskService()
    task, err := svc.StartTask(cmd.Context(), taskKey, agentID)
    if err != nil {
        handleServiceError(err, taskKey)
        return nil
    }

    // Step 3: Format output
    if cli.GlobalConfig.JSON {
        return cli.OutputJSON(task)
    }
    cli.Success(fmt.Sprintf("Started task %s", task.Key))
    return nil
}
```

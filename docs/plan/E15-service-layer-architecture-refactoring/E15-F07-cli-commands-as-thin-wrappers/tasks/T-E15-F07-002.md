# Task: Fix service accessor wiring and wire taskcreation.Creator

## Goal

Resolve the three known TODO issues in `internal/cli/service_accessors.go` and `internal/cli/services_global.go` that prevent the global service accessors from being fully usable. After this task, `cli.GetTaskService()`, `cli.GetFeatureService()`, and `cli.GetEpicService()` must all return fully wired, usable service instances with no nil pointer risks.

This is the prerequisite blocker for all three command file refactorings (Tasks 003, 004, 005).

## Design Reference

- Architecture doc: `docs/plan/E15-service-layer-architecture-refactoring/E15-F07-cli-commands-as-thin-wrappers/02-architecture.md` Section 3 (Decisions 4) and Section 2 (Known Issues)
- Integration points: `internal/cli/service_accessors.go` and `internal/cli/services_global.go`

## Requirements

### Issue 1: EpicNoteRepository Interface Mismatch (`service_accessors.go:34`)

The `EpicService` expects `EpicNoteRepository` with signature:
```go
CreateRejectionNote(ctx, entityType string, entityID int64, historyID int64, fromStatus, toStatus, reason, rejectedBy, documentPath string) error
```
But `*repository.EntityNoteRepository` provides:
```go
CreateRejectionNote(ctx, entityType models.EntityType, entityID int64, historyID int64, fromStatus, toStatus, reason, rejectedBy string, documentPath *string) (*models.EntityNote, error)
```

**Fix**: Create `epicNoteAdapter` type in `service_accessors.go` that wraps `*repository.EntityNoteRepository` and translates the method signature. Wire it in `GetEpicService()`.

### Issue 2: FeatureNoteRepository Interface Mismatch (`service_accessors.go:60`)

Same root cause as Issue 1 for `FeatureService`.

**Fix**: Create `featureNoteAdapter` type using the same adapter pattern. Wire it in `GetFeatureService()`.

### Issue 3: `taskcreation.Creator` Not Wired (`services_global.go:116`)

`GetTaskService()` passes `nil` for the `taskcreation.Creator` dependency, meaning `runTaskCreate` cannot use the service for file creation.

**Fix**: Wire `taskcreation.Creator` into `GetTaskService()`. Use `cli.GetProjectRoot()` (or equivalent) to get the project root path for the Creator constructor.

### Adapter Pattern (Architecture Decision 4)

```go
// epicNoteAdapter wraps EntityNoteRepository to satisfy EpicNoteRepository interface
type epicNoteAdapter struct {
    inner *repository.EntityNoteRepository
}

func (a *epicNoteAdapter) CreateRejectionNote(ctx context.Context, entityType string, entityID int64,
    historyID int64, fromStatus, toStatus, reason, rejectedBy, documentPath string) error {
    et := models.EntityType(entityType)
    dp := &documentPath
    _, err := a.inner.CreateRejectionNote(ctx, et, entityID, historyID, fromStatus, toStatus, reason, rejectedBy, dp)
    return err
}
```

Apply same pattern for `featureNoteAdapter`.

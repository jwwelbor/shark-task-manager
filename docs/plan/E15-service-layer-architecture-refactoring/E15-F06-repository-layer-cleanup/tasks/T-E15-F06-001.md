## Migration Priority

### Phase 1 (This Feature - E15-F06): Progress & Status Calculation Cleanup
- FeatureRepository: CalculateProgress, UpdateProgress, UpdateProgressTx
- EpicRepository: CalculateProgress
- TaskRepository: GetStatusBreakdown, GetStatusBreakdownMap, getOrderedStatuses, getStatusMetadata
- status_calculator.go: CalculateStatusFromProgress

### Phase 2 (Future - E15-F10+): Status Transition & Dependency Cleanup
- TaskRepository: updateStatusForcedInternal, BlockTask, UnblockTask, ReopenTask
- TaskDependency: ReopenTaskWithAutoBlock, AutoUnblockDependents
- These are deeply coupled to CLI commands and require coordinated CLI refactoring

### Phase 3 (Future): Cascade & Orchestration Cleanup
- FeatureRepository: CascadeStatusToTasks
- EpicRepository: CascadeStatusToFeaturesAndTasks
- TaskRepository: GetNextTask, GetNextTaskForAgent, filters
- These have many CLI callers and need service wiring first

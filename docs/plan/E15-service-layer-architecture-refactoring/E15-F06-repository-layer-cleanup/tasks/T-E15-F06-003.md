# Task: Migrate EpicRepository progress calculation to EpicService

## Goal

Remove progress calculation business logic from EpicRepository and ensure EpicService.GetProgress() (already implemented in E15-F05) is used instead. Remove the following methods:

1. `CalculateProgress` (line 386) - Weighted average of feature progresses with terminal feature rule
2. `CalculateProgressByKey` (line 416) - Wrapper

Also move `repository/status_calculator.go::CalculateStatusFromProgress` to services since it derives status from progress (business logic).

## Implementation Plan

### Step 1: Identify all callers

```bash
grep -rn "epicRepo.CalculateProgress\|CalculateStatusFromProgress" internal/ --include="*.go" | grep -v "_test.go"
```

Key callers:
- `internal/cli/commands/epic.go` - Calls `epicRepo.CalculateProgress()`
- `internal/status/calculation_service.go` - May reference CalculateProgress

### Step 2: Ensure EpicService has equivalent methods

EpicService.GetProgress() already returns `EpicProgressInfo`. If callers need "recalculate and persist", add `RecalculateProgress()` to EpicService.

### Step 3: Update callers to use EpicService

Replace `epicRepo.CalculateProgress(ctx, id)` with `epicService.GetProgress(ctx, key)`.

### Step 4: Remove methods from EpicRepository

Delete CalculateProgress and CalculateProgressByKey. Keep:
- `SetProgress()` (line 424) - writes stored progress (pure data)
- `SetProgressByKey()` (line 430) - wrapper (pure data)

### Step 5: Move status_calculator.go

Move `CalculateStatusFromProgress()` from `internal/repository/` to `internal/services/` or inline into EpicService/FeatureService where used.

### Step 6: Update tests and quality gate

- `make fmt && make lint && make test`

## Acceptance Criteria

- [ ] EpicRepository.CalculateProgress() removed
- [ ] EpicRepository.CalculateProgressByKey() removed
- [ ] `repository/status_calculator.go` removed or moved to services
- [ ] All callers updated to use EpicService
- [ ] `make test` passes

## Testing Strategy

- EpicService.GetProgress() already tested from E15-F05
- Add RecalculateProgress() test if new method created
- Verify existing CLI commands still work

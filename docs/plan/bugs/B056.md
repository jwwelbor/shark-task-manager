# run-one.sh postrun phase is non-deterministically flaky (tc014_run_one_smoke_test.sh)

## Description

While driving T-E40-F09-004 to completion, running the full registered bench test suite surfaced ~50% non-deterministic flakiness in tc014_run_one_smoke_test.sh (F02 scope): run-one.sh silently exits 1 immediately after the 'phase=postrun' marker, with no diagnostic. Reproduced identically in isolated throwaway git worktrees with the E40-F09-004 fix reverted, confirming it is a pre-existing race condition unrelated to F09-004's changes — likely in the toolchain-guard/build-ledgers/collect-run hand-off inside run-one.sh. Needs its own investigation; out of scope for T-E40-F09-004 (explicitly excluded from touching F01-F08 tests).

## Expected Behavior

`bench/scripts/tests/tc014_run_one_smoke_test.sh` should pass deterministically on every run of `bench/scripts/tests/run-all.sh`.

## Actual Behavior

`run-one.sh` silently exits 1 immediately after emitting the `phase=postrun` marker, with no diagnostic output, on roughly half of runs. Reproduced identically in isolated throwaway git worktrees with the T-E40-F09-004 fix reverted, confirming this is a pre-existing race condition, not a regression from that task. Likely in the toolchain-guard / build-ledgers / collect-run hand-off inside `run-one.sh`'s post-run phase.

## Steps to Reproduce

1. Run `bench/scripts/tests/run-all.sh` (or `bench/scripts/tests/tc014_run_one_smoke_test.sh` directly) repeatedly.
2. Observe intermittent (~50%) failure: silent exit 1 right after the `phase=postrun` marker.

## Fix Notes

Needs investigation into the postrun hand-off sequencing in `run-one.sh` (toolchain-guard → build-ledgers → collect-run). Add diagnostic output on the silent exit path before attempting a fix.

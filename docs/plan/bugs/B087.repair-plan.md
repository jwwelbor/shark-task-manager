Reconcile fresh and eligible carried units against the complete manifest and rubric. Migrate readers before enabling partial dispatch. Group related producer/consumer changes together. Keep six actual angle completions and a fresh cross-file consolidation. Leave numeric thresholds and angle skipping out of this revision.
5. Implement and test through capture, native and host dispatch, retained writer, parent admission and QA in that order. Use disposable real Git repositories, the shipped scripts, and fixture reviewer responses at the model boundary. Drive the production parent admission entry point using the actual retained artifacts. Recompute eligibility at admission from trusted evidence and frozen Git objects. Apply existing bounded/path-safe reads and scope identity checks to added references. If validation fails before dispatch, widen review. If submitted evidence fails verification, reject the result and obtain fresh evidence.

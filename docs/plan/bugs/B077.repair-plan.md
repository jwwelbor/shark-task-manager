Revision 13 addresses [independent review 430](../../review/bugs/b077/plan-review-r12-20261119.md). ## Diagnosis and review baseline

At Shark Task Manager commit **`bbf490c6ec2bd597d6f3e6e4cdd93e68ca54fa50`**, keyed `shark next` already carries the persona, requested provider, optional model, effort and assembled prompt. Rider told Claude Code how to select a model. Its native Codex handoff lacked both an explicit model-selection rule and a check of the model used by the particular child. Its long-running Codex CLI example also launched without a model argument. A successful worker response could therefore enter the parent loop without establishing which route ran. The defect is at the host adapter and its result-consumption boundary. [Bug](B077.md) · [Research](B077.research-report.md) · [Baseline checks](B077.repair-plan-evidence.md#baseline-and-historical-observation)

In WWGM S010, six deep-review children recorded Luna/xhigh. Three retained parent spawn call sites omitted a model override and the parent also edited application code. The separate B101 developer/Sonnet and B100 tech-lead/Opus inspection results have no shared keyed dispatch ID with those children. The historical trace establishes inheritance risk. A new keyed capture is required to establish end-to-end behavior for the repair. It cannot establish which historical request produced a given child or why E13 failed.

The declared baseline is the parent of the first B077 implementation commit. The assigned branch already contains several attempted fixes and a separate test-capture repair. Independent plan review must resolve the full baseline to a commit in this project, inspect the pre-repair dispatch above, and verify ancestry and the complete delta to the candidate. Use the same baseline for development, review and QA, including unaccepted predecessor changes. [Baseline and prior attempts](B077.repair-plan-evidence.md#baseline-and-historical-observation)

## Decision and repair

Extend the existing Rider instruction and adapter contract, and correct deep-review CLI metadata so it reports the identity of the invocation that produced the accepted packet. Carry reasoning effort separately from model identity through each supported CLI selector and worker observation. Add caller-level checks for effort, alias resolution, preflight cost, history attribution, consultation and result admission, telemetry, retry attribution, claim races, and both published schemas. Centralize route selection in Rider's keyed dispatch procedure and keep the provider reference responsible for installed-host capability facts. Reconcile earlier implementation attempts against each assertion below. Shark retains prompt assembly and workflow authority. This repair calls for no new routing service, credential or workflow configuration, model registry, persistent route store, worker-envelope field, or change to the ordinary `shark run` dispatch interface. Its structured gates share the protected writer and must still complete under a live lease.

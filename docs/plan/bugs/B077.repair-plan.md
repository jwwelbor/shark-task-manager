## Diagnosis and review baseline

At Shark Task Manager commit **`bbf490c6ec2bd597d6f3e6e4cdd93e68ca54fa50`**, keyed `shark next` already carries the persona, requested provider, optional model, effort and assembled prompt. Rider told Claude Code how to select a model. Its native Codex handoff lacked both an explicit model-selection rule and a check of the model used by the particular child. Its long-running Codex CLI example also launched without a model argument. A successful worker response could therefore enter the parent loop without establishing which route ran. The defect is at the host adapter and its result-consumption boundary.

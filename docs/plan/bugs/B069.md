# Status transitions output obsolete orchestrator_action advice instead of shark next

## Description

In internal/cli/commands/status_shared.go:45 and next_status_generic.go:250, status transitions emit 'INFO Run shark get <key> --field orchestrator_action to get your next instructions'. This directs users and agents to pre-2.x legacy inspection rather than canonical 'shark next <key> --json' dispatch.

## Expected Behavior

Status advance commands across all CLI paths should consistently advise running `shark next <key> --json` to obtain the next step/instructions (matching `internal/cli/commands/status_group.go:385`).

## Actual Behavior

`internal/cli/commands/status_shared.go:45` and `internal/cli/commands/next_status_generic.go:250` emit:
`INFO Run 'shark get <key> --field orchestrator_action' to get your next instructions.`
This references the deprecated pre-2.x orchestrator_action inspection field instead of the route-based workflow dispatch API.

## Steps to Reproduce

1. Transition an entity via a command route exercising `status_shared.go` or `next_status_generic.go`.
2. Observe stdout/log advising the caller to run `shark get <key> --field orchestrator_action`.

## Fix Notes

Update `internal/cli/commands/status_shared.go:45` and `internal/cli/commands/next_status_generic.go:250` to format advice as:
`cli.Info(fmt.Sprintf("Run 'shark next %s --json' to get your next instructions.", result.EntityKey))`
Align existing tests that assert on this message.

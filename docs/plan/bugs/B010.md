# bug list and change list commands missing --all flag to show terminal-status items

## Description

`shark change list` and `shark bug list` only show open/non-terminal items by default. The `--all` flag (which works for `shark task list` and `shark feature list`) is not implemented for bugs or change cards. The unified `shark list` dispatcher also doesn't forward `--all` for these entity types.

## Expected Behavior

`shark change list --all` and `shark bug list --all` should show all items including those in terminal statuses (completed, cancelled, etc.), matching the behavior of task and feature list commands.

## Actual Behavior

- `shark change list` — only shows open items, no `--all` flag available
- `shark bug list` — only shows open items, no `--all` flag available
- `shark list changes --all` — `--all` flag not forwarded to change list
- Only workaround: `shark change list --status=completed` (explicit status filter)

## Steps to Reproduce

1. Create a change card and advance it to completed status
2. Run `shark change list` — completed item is hidden
3. Run `shark change list --all` — flag not recognized or has no effect

## Affected Files

- `internal/cli/commands/bug.go` — no `--all` flag registered on `bugListCmd`
- `internal/cli/commands/change.go` — no `--all` flag registered on `changeListCmd`
- `internal/cli/commands/list.go` — unified dispatcher doesn't forward `--all` for bugs/changes
- `internal/services/bug_dto.go` — `BugFilters` struct missing `ShowAll` field
- `internal/services/bug_service.go` — `ListBugs` doesn't support show-all filtering
- Change card service already has `ShowAll` in `ChangeCardFilters` DTO but CLI never passes it

# Workflow dispatch prompts can omit status instructions across entity types

## Description

Observed during assessment review: ./bin/shark next E07-F19 --preview returned only the Researcher persona body, and ./bin/shark get E07-F19 --field orchestrator_action showed instruction="" for feature status assessment. This is likely not isolated to assessment; search all workflow steps/entity types for missing or unresolved prompt instructions where dispatch returns only a persona or empty instruction. Add integration coverage that renders dispatch prompts for representative statuses across epic, feature, task, bug, change, and tech-debt workflows and asserts status-specific instructions are present when a workflow step declares a prompt. Tests MUST run against a dedicated temporary Shark test project and database, not this main project/database.

## Expected Behavior

When a workflow step declares a prompt/instruction, `shark next <key> --preview`
and the run dispatch path should return a fully rendered prompt that contains
both the selected agent persona and the status-specific workflow instructions.

Integration coverage should render representative dispatch prompts across
epic, feature, task, bug, change, and tech-debt workflows using a dedicated
temporary Shark test project and database. These tests must not read from or
mutate this repository's main Shark project/database.

## Actual Behavior

At least one live assessment dispatch rendered only the agent persona body.
`shark get E07-F19 --field orchestrator_action` also reported an empty
`instruction` field for feature status `assessment`, so the dispatched agent
would not receive the assessment workflow instructions.

## Steps to Reproduce

1. Run `./bin/shark next E07-F19 --preview`.
2. Observe that the returned `prompt` contains the Researcher persona but no
   assessment-specific instructions.
3. Run `./bin/shark get E07-F19 --field orchestrator_action`.
4. Observe `instruction=""`.
5. Audit other entity types/statuses for the same empty or persona-only
   dispatch shape.

## Fix Notes

Investigate workflow prompt resolution across the active workflow index,
template directory selection, and embedded/disk bundle fallback. Add regression
coverage against an isolated test project/database before fixing individual
prompt references.

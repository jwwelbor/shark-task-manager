# reject or clarify blocked_by relationship type

## Description

Triage source: shark-tool-failure-log.md, Entry 4. Invocation shark link T-E10-F02-005 B073 --type=blocked_by failed because blocked_by is not valid; the CLI accepts directional depends_on or blocks. The relationship UX and documentation should prevent this mismatch.

## Expected Behavior

The CLI and documentation should expose one clear directional relationship syntax for
expressing that a task is blocked by another entity.

## Actual Behavior

`--type=blocked_by` is rejected; valid directional types include `depends_on` and
`blocks`.

## Steps to Reproduce

1. Run `shark link T-E10-F02-005 B073 --type=blocked_by`.
2. Observe the invalid relationship type error.

## Fix Notes

Related workaround: use `depends_on` with the dependent first, or `blocks` with the
blocker first.

# Change-card creation rejects supplied size

## Description

shark create change with --size M or --size 3 reports size is required for change under current repository configuration. This prevented recording review-loop work as change cards. Investigate CLI-to-service size propagation.

## Expected Behavior

Creating a change card with a valid size should succeed when size is mandatory.

## Actual Behavior

Both --size M and --size 3 returned size is required for change.

## Steps to Reproduce

1. Run shark create change with a valid --size under the repository configuration.

## Fix Notes

Investigate size propagation from CLI to change-card creation service.

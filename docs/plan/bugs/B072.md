# related-docs list requires explicit entity type instead of inferring key

## Description

Triage source: shark-tool-failure-log.md, Entry 3. Invocation shark related-docs list B072 failed because one of --epic, --feature, --task, --bug, --change, or --question is required; documented keyed usage should either infer the entity type or clearly require the explicit flag.

## Expected Behavior

`shark related-docs list <key>` should infer the entity type from the key, or its
documentation should consistently require the explicit entity-type flag.

## Actual Behavior

`shark related-docs list B072` fails because one of `--epic`, `--feature`, `--task`,
`--bug`, `--change`, or `--question` must be supplied.

## Steps to Reproduce

1. Run `shark related-docs list B072`.
2. Observe the required-entity-type error.

## Fix Notes

Related workaround: use `shark related-docs list --bug B072`.

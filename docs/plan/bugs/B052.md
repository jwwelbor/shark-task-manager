# Cascading shark run: sibling agent transcripts overwrite each other

## Description

With CaptureAgentTranscripts enabled, cascade children inherit the parent RunID while each nested controller restarts iteration at 0, so relTranscriptPath produces identical filenames for sibling children and writeTranscript's os.WriteFile silently truncates prior siblings' transcripts. Additionally controller.go:615 flattens child Stages into the parent and StageLog carries no entity key, so child metrics are unattributable. Found during E40 design (see Q004 and docs/plan/E40-shark-bench-workflow-benchmarking-harness/architecture.md). Affects any cascading shark run with transcript capture, not just bench.

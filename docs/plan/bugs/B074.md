# feature task list appears empty when all tasks are completed

## Description

Triage source: shark-tool-failure-log.md, Entry 5. Invocation shark list E04-F01 --json returned null with exit code 0 although 14 tasks exist; completed tasks are filtered by default. A populated feature should not appear empty without an explicit --all request.

## Expected Behavior

Listing a feature should make its existing tasks discoverable, including when every task
is completed, or return an explicit empty collection rather than `null`.

## Actual Behavior

`shark list E04-F01 --json` returns `null` with exit code 0 because completed tasks are
filtered by default, despite 14 tasks existing.

## Steps to Reproduce

1. Use a feature containing only completed tasks.
2. Run `shark list E04-F01 --json` without `--all`.
3. Observe `null`; `--all` is required to show the tasks.

## Fix Notes

Related workaround: run `shark list E04-F01 --all --json` or inspect the feature with
`shark get E04-F01 --json`.

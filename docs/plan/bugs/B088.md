# Review findings and rubric create avoidable review noise

## Description

Evaluate requiring named impact for findings and removing Nit and per-file quality scoring, aligning report consumers while preserving substantive risk and standards evidence. See E34 note 3963 and related B085 report-contract issue.

## Expected Behavior

Review findings should communicate impact and review output should justify its cost.

## Actual Behavior

The review process includes a Nit tier and a per-file quality rubric.

## Steps to Reproduce

1. Inspect consolidator and E34 note 3963; see B085 for report contract alignment.

## Fix Notes

Evaluate impact-based admission and removing scoring and Nit without losing substantive risk evidence.

# integration review blocks on legacy candidate records missing path digests

## Description

Triage source: shark-tool-failure-log.md, Entry 7. Pre-log integration candidates contain base_commit, head_commit, event_ids, and digest but lack tracked_path_digests and untracked_path_digests, causing integration_review to block and file E04-IR-001. Legacy records need compatibility handling or an explicit migration path.

## Expected Behavior

Integration review should handle candidates created before the path-digest schema was
introduced, either by applying a documented compatibility path or by performing an
explicit migration before review.

## Actual Behavior

`integration_review` blocks and files E04-IR-001 when the candidate lacks
`tracked_path_digests` and `untracked_path_digests`, even though it has the earlier
candidate fields.

## Steps to Reproduce

1. Dispatch `integration_review` for an epic with a pre-schema candidate record.
2. Observe the missing-digest finding and blocked recommendation.
3. Run the documented backfill command to register the path digests.

## Fix Notes

Observed workaround: pause the epic and run the operator backfill command with the
epic run ID, base commit, and events file before retrying integration review.

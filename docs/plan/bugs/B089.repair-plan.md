## Diagnosis and scope

The [incident](B089.md) records two rejected inputs during review-loop intake. Before B082, both unified Cobra commands declared the size flag, but their common handler omitted the size pointer when constructing the service input. Required-size validation then rejected either spelling before allocating a key. Under optional policy the omission could silently persist NULL. Entity-first creation already forwarded the pointer. B082 fixed both unified spellings and the adjacent dropped tag input by sharing the existing parsing behavior across handlers. [B082 research](B082.research-report.md) · [B089 executable comparison](B089.research-report.md#findings)

The older project-root executable reproduces the report. The installed executable matching the baseline succeeds. The original reporter did not record executable identity. Use a verified build containing the delivered fix for intake. Verify CLI, service and storage behavior on a containing build. The expected development diff adds focused CLI regression tests. Schema changes, binary replacement and project configuration changes are outside scope. The earlier [recovery plan](../2026-10-15-sprint-integration-recovery-plan.md) assigned this repair to B082. Its configuration and caller-parity requirements still apply. CC-048 and CC-049 used the working entity-first path to record separate sprint issues.

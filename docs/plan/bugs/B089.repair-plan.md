## Diagnosis and scope

The [incident](B089.md) records two rejected inputs during review-loop intake. Before B082, both unified Cobra commands declared the size flag, but their common handler omitted the size pointer when constructing the service input. Required-size validation then rejected either spelling before allocating a key. Under optional policy the omission could silently persist NULL. Entity-first creation already forwarded the pointer. B082 fixed both unified spellings and the adjacent dropped tag input by sharing the existing parsing behavior across handlers. No source patch, migration, binary replacement or project configuration edit is planned. The earlier [recovery plan](../2026-10-15-sprint-integration-recovery-plan.md) assigned this repair to B082.

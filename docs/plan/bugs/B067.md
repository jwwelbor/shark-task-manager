# deep-review/SKILL.md missed B066's non-blocker routing fix; scoped test only covered consolidator.md

## Description

B066 (fix(B066): route review non-blockers through triage instead of tech-debt, commit 1f7be955) fixed review-code.md, tech-lead.md, and consolidator.md, and added TestConsolidatorRoutesNonBlockersThroughTriage to gate consolidator.md -- but skills/shark-rider/skills/deep-review/SKILL.md's own Consolidation contract section (line 154) still said 'fix every blocker/non-blocker or explicitly triage it before CI/merge', the same ambiguous phrasing B066 was written to eliminate, with no reference to the triage skill's decision tree. No test scoped this file, so the gap was invisible. Found 2026-09-18 during a review-triage-and-agent-attention-plan audit. Fixed by rewording the sentence to route through the triage skill's decision tree (matching the established phrase), and extending TestConsolidatorRoutesNonBlockersThroughTriage to scope both consolidator.md and deep-review/SKILL.md so this file class cannot silently drift again. All internal/... and skills/... Go tests pass.

## Expected Behavior

Every canonical review-finding producer named in B066's scope routes
non-blocking findings through the triage skill's decision tree
(fix-now gate, duplicate search, type classification), and a permanent
test gates each such file so this cannot silently regress.

## Actual Behavior

`skills/shark-rider/skills/deep-review/SKILL.md`'s Consolidation contract
section said "fix every blocker/non-blocker or explicitly triage it before
CI/merge" — vague enough to permit skipping the decision tree entirely —
and `TestConsolidatorRoutesNonBlockersThroughTriage` only read
`consolidator.md`, not this file, so the gap shipped invisibly with B066.

## Steps to Reproduce

1. `git show 1f7be955` — B066's fix touches review-code.md, tech-lead.md,
   consolidator.md only.
2. Read `skills/shark-rider/skills/deep-review/SKILL.md` line 154 (pre-fix):
   contains "explicitly triage it" with no "triage skill's decision tree"
   reference.
3. `go test ./internal/cli/commands/ -run TestConsolidatorRoutesNonBlockersThroughTriage`
   passes even with the stale wording present, because the test never reads
   this file.

## Fix Notes

Reworded the sentence to "route it through the triage skill's decision tree
(fix-now gate, duplicate search, type classification) before CI/merge",
matching the phrase established elsewhere. Extended
`TestConsolidatorRoutesNonBlockersThroughTriage` to scope both
`consolidator.md` and `deep-review/SKILL.md`. Verified:
`go test ./internal/cli/commands/ -run TestConsolidatorRoutesNonBlockersThroughTriage`
passes; `go build ./...` and `go test ./internal/... ./skills/...` pass
with no failures.

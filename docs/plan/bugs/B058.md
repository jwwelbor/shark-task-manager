# Sprint readiness treats completed external dependencies as unsatisfied

## Description

Reproduction: assign T-E11-F01-013 to S006 while its six prerequisites (T-E11-F01-005, -006, -009, -010, -011, -012) remain completed in historical S002. shark sprint readiness S006 reports six unsatisfied external task dependencies and deducts six points, despite every prerequisite being completed.

Actual: computeDependencySatisfactionFactor counts a dependency as satisfied only when its key is assigned to the current sprint; it ignores terminal task status.

Expected: a dependency in a successful terminal status satisfies readiness regardless of sprint membership. Keep completed historical work out of the active sprint and report only incomplete external dependencies as unsatisfied.

Location: internal/services/sprint_service.go, computeDependencySatisfactionFactor.

## Expected Behavior

A dependency with a successful terminal status satisfies sprint readiness even
when it belongs to an earlier, completed sprint. The active sprint does not
need to duplicate completed work to receive full dependency-satisfaction
credit.

## Actual Behavior

`computeDependencySatisfactionFactor` treats a dependency as satisfied only
when its key appears in the current sprint assignment set. It ignores the
dependency's status, so S006 reports six completed E11 prerequisites as
unsatisfied external dependencies and deducts six readiness points.

## Steps to Reproduce

1. Keep `T-E11-F01-005`, `T-E11-F01-006`, `T-E11-F01-009`,
   `T-E11-F01-010`, `T-E11-F01-011`, and `T-E11-F01-012` completed in S002.
2. Assign `T-E11-F01-013` to S006.
3. Run `shark sprint readiness S006 --json`.
4. Observe `6 unsatisfied external task dependencies` even though each listed
   prerequisite is completed.

## Fix Notes

Update `internal/services/sprint_service.go` so dependency satisfaction uses a
successful terminal dependency status in addition to current-sprint membership.
Retain the existing warning for external dependencies that are not terminally
successful. Add regression coverage for a completed prerequisite in a prior
sprint and an incomplete prerequisite outside the current sprint.

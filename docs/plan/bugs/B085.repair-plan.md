# B085 repair plan

## Diagnosis and scope

The capture example selects the author's installed Rider even when the host loaded another copy. A linked worktree can therefore review its candidate with helpers from a different revision. The native runner already checks the full manifest against each specialist's inspected paths, but its consolidator prompt flattens those paths into a union. The consolidator also accepts a finding's path as coverage and classifies a missed file as a non-blocker. Those instructions can produce a triage verdict for an unfinished review. Research established a contradiction in the procedure and a runtime rejection of partial evidence. It found no admitted incomplete candidate. [Bug](B085.md) · [Research findings](B085.research-report.md#findings)

The rendered prompts already include the craft workflow's rubric and hotspots. The mismatch arises at report selection and handoff. The tiny-diff exception discards detail even for blockers, and the closing shared and feature instructions omit craft sections and collapse verdicts. Repair the existing skill, native prompt handoff, consolidator, embedded craft and consuming prompt instructions. Update affected goldens and focused regression tests. Preserve sidecar formats, Go admission, the runner ladder, configured workflow routes and the distinction between a review finding and missing review evidence.

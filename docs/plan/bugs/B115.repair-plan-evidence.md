## EV-CALL-01 — Production caller paths

- `internal/taskcreation/creator.go`: task creation calls the shared writer
  with `UseAtomicWrite: true` before committing its database transaction. A
  writer error returns before commit. Successful creation supplies the
  `WriteResult` used by B114 commit-failure compensation.
- `internal/services/bug_service.go`: ordinary bug creation uses atomic
  publication after creating its database row. It rolls the row back and
  returns the publication error on failure; tags and search indexing follow
  success. `Force: true` uses the non-atomic path and retains its best-effort
  ordering.
- `internal/services/change_card_service.go`: change-card creation uses atomic
  publication after row creation. It rolls back and returns the publication
  error on failure; tags and indexing follow success.
- `internal/services/tech_debt_service.go`: tech-debt document creation uses
  atomic publication and returns a writer error before repository creation.
  Force reuse checks exact document bytes.
- `internal/cli/commands/epic_helpers.go`,
  `internal/cli/commands/feature_helpers.go`, and
  `internal/cli/commands/sprint.go` call the writer with
  `UseAtomicWrite: false`; they are preservation boundaries, not B115 callers.

# shark create note fails on sprint and idea entities

## Description

`shark notes add --help` advertises *"Add a typed note to any entity (auto-detects type from key)"*, but two first-class entity types fail: **sprints (S###)** and **ideas (I-YYYY-MM-DD-##)**. Tech-debt (TD-###), bugs (B###), epics (E##), features (E##-F##), tasks (E##-F##-###), and change cards (CC-###) all work correctly.

Triggered by `/triage` attempting reciprocal-note pairing for `I-2026-05-11-01` ↔ `E19` during follow-up to the bug-sizing discussion. The forward note on the idea failed; the back-pointer on the epic succeeded.

## Expected Behavior

`shark create note <key> "<content>" --type=<type>` succeeds for every entity type the rest of shark recognizes, including sprints and ideas.

## Actual Behavior

**Sprint** — rejected by the key parser before reaching the registry:

```
$ shark create note S003 "x" --type=comment
Error: cannot determine entity type from key: S003
Expected format: E## (epic), E##-F## (feature), E##-F##-### (task), B### (bug),
                 C### or CC-### (change card), TD-### (tech-debt), or
                 I-YYYY-MM-DD-## (idea)
```

Note: the error message itself omits the sprint format from the supported list, suggesting sprint never got plumbed into the note key resolver.

**Idea** — key parser accepts the key, but EntityRegistry has no repository registered:

```
$ shark create note I-2026-05-11-01 "Related to E19 ..." --type=reference
Error: failed to add note: failed to resolve entity for note operation:
       EntityRegistry: no repository registered for entity type "idea"
```

## Steps to Reproduce

1. `./bin/shark create note S003 "test" --type=comment` → "cannot determine entity type from key" error
2. `./bin/shark create note I-2026-05-11-01 "test" --type=reference` → "EntityRegistry: no repository registered for entity type 'idea'" error
3. For contrast, `./bin/shark create note TD-001 "test" --type=comment` succeeds

## Fix Notes

Two distinct root causes likely fixed in one PR:

- **Sprint (S###)**: extend the key resolver used by `notes add` to recognize the sprint key format. The error message's supported-format list also needs `S### (sprint)` added.
- **Idea (I-...)**: register an idea repository in the EntityRegistry used by the note-add path. See `T-E25-F01-009` (services-global wiring) for the analogous tech-debt repo adapter pattern.

Scope check: confirm `shark notes search` returns hits from sprints and ideas after the fix.

# RecordCommandMetrics always receives nil error

## Description

In root.go PersistentPostRunE, RecordCommandMetrics is called with nil for cmdErr because Cobra only invokes PersistentPostRunE when RunE succeeds. If RunE returns an error, PersistentPostRunE is skipped entirely, so the errors counter in CommandMetrics can never be incremented. Fix requires intercepting errors at the Execute() level or using a SilenceErrors+custom error handler pattern to ensure metrics are recorded for both success and failure paths.

# Configurable console width for CLI list views

## Description

Add a console_width config option (in .sharkconfig.json) that adjusts how description columns render across CLI list views. Width-sensitive views need to be audited and updated to respect the setting.

## Justification

CLI list views currently render at a fixed width, causing wrapped/awkward output on narrow terminals and wasted space on wide terminals. A configurable width would let users tune the experience to their environment.

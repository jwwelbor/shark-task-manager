# quality gates on developer agents
Development agents need to to pass the basic standards of passing tests, lint, formatting, etc before it leaves dev. This shouldn't have to be caught later and rejected on basic stuff.

## Description

QA agents are finding way too many basic bugs like formatting, lint, etc... those should be gates to get out of development before it even comes to qa.
The development prompts / skills need to be updated to require running the project quality gates as established in coding-standards.md or wherever the reference is from docs/architecture

Review existing prompts and projects for where quality gates are stored and reference that location in the requirements.


## Justification

Too many cycles wasted in QA and then back to dev fix things that shouldn't have to be reviewed in the first place

## Impact Analysis

Reduced time in QA and improved quality

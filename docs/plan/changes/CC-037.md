# Add Priority field to idea FlatEntity DTO and viewer UI

## Description

Follow-up to #68: appendIdeaFields in viewer.html had a premature `Priority` row referencing e.priority, but FlatEntity does not expose Priority on idea entities — the row was dead code and was removed in #68 to keep PR scope tight.

Scope of this change-card:
1. Add `Priority *int json:"priority,omitempty"` to the FlatEntity struct in internal/services/viewer_service.go
2. Populate Priority from idea.Priority in the hierarchy/flatten code path that builds FlatEntity for ideas
3. Re-add the Priority row to appendIdeaFields in internal/viewer/assets/viewer.html
4. Add tests mirroring the existing FlatEntity Size tests (e.g., TestViewerService_Hierarchy_FlatEntity_IdeaPriority_*) — populated, nil, and omitempty JSON cases

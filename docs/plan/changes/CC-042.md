# Add entity filter and compact default view to shark admin workflow list

## Description

shark admin workflow list (internal/cli/commands/workflow.go:112) always renders all levels in config.KnownWorkflowLevels with full status/transition/metadata detail for every entity. Add an entity-type parameter so it only shows the workflow for the selected entity, render a short ASCII step-flow diagram by default for non-JSON output, and provide --all for the expanded metadata view. Dedup check found T-E13-F05-008 (draft, under completed epic E13) as stale/unrelated prior art from before this command existed in its current form - not live coverage.

## Justification

Improves workflow inspection UX by letting users scope to one entity and see a compact step-flow instead of the full multi-level dump

## Impact Analysis

This changes the default non-JSON output for `shark admin workflow list` from the expanded metadata view to a compact ASCII flow. Users who need the previous expanded detail can pass `--all`. JSON output remains unchanged except for the optional entity-type filter.

## Rollback Plan

Revert the workflow list command changes and remove the `--all` flag, filter tests, CLI reference updates, and `/shark workflow` skill verb reference.

# Attempt circuit breaker on tasks

## Description

Per-task counter of failed attempts whose failure is outside the property under test (e.g. repeated live runs). At a configured threshold the workflow routes to tech-director with the fixed question 'is the harness the blocker?'. No workflow YAML today has an attempt or loop limit. Source: WWGM S010 retro 2026-11-27 (wwgm PR #195, docs/plan/sprints/S010-rehearsal-harness-plan.md). Ten live attempts on one task, each failing at the next defect, never surfaced as drift.

## Justification

WWGM S010 ran ten live attempts (a01–a10) inside one task in `development`. Each failed at a new defect unrelated to the property under test. Shark state never moved, so no drift was visible to tech-director, and a prose circuit breaker triggered on 2026-09-10 did not hold.

## Impact Analysis

New per-task counter and threshold in workflow config; a new routing outcome to tech-director. Existing workflows are unaffected while no threshold is configured.

## Rollback Plan

Remove the threshold from workflow config; the counter is then inert. Drop the field in a follow-up migration if the change is abandoned.

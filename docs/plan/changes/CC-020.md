# Integration test environment with mock agent dispatchers

## Description

shark run and other commands need a self-contained test environment at /shark-test-env/ with its own DB, config, and mock Claude/Codex dispatchers that return canned responses instantly. Enables end-to-end testing of the run loop, status transitions, and agent dispatch without real LLM calls or touching the production database.

# Sprint overrun signal

## Description

sprint.yaml never checks end_date. Flag an active sprint past end_date in shark sprint next/get and prompt for a replan or re-date. WWGM S010 ran 50 days past its end date unflagged. Source: WWGM S010 retro 2026-11-27 (wwgm PR #195, docs/plan/sprints/S010-rehearsal-harness-plan.md). Ten live attempts on one task, each failing at the next defect, never surfaced as drift.

## Justification

WWGM S010 was planned 2026-09-24 → 2026-10-08 and stayed `active` until it was re-dated on 2026-11-27, 50 days later, with no signal from Shark. S011 and S012 also carry stale October dates.

## Impact Analysis

Read-only warning in `shark sprint next` / `shark sprint get` output when today is past `end_date` for an active sprint. No state change and no blocking.

## Rollback Plan

Remove the warning; there is no stored state to revert.

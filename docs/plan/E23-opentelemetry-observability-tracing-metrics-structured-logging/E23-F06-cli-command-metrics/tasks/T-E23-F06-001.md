# Add command metrics recording to CLI lifecycle hooks

## Goal

Wire CommandMetrics (from F01) into root.go PersistentPreRunE/PostRunE so every CLI command execution is automatically tracked with duration, invocation count, and error count metrics exported via OTel.

## Scope

- Files to modify:
  - internal/cli/root.go (add start-time capture in PreRunE, record metrics in PostRunE)
  - internal/cli/observability_global.go (add GetCommandMetrics() accessor)
- Files to create: none

## Acceptance Criteria

- AC-1: PersistentPreRunE captures command start time and name in a context-scoped variable
- AC-2: PersistentPostRunE calls CommandMetrics.RecordInvocation and RecordDuration with command use string and the command's return error
- AC-3: CommandMetrics zero value (no-op) is used when OTel is not initialized, so no panic on uninitialized provider
- AC-4: Command name recorded uses cmd.CommandPath() or cmd.Use for consistency
- AC-5: Metrics are initialized once via GetMeter("shark.cli") using the GetMeter accessor from observability_global.go

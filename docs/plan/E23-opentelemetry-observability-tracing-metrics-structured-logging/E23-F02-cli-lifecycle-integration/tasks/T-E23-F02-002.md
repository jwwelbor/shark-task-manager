# Task: Wire observability init into PersistentPreRunE

## Goal

Extend `internal/cli/root.go` `PersistentPreRunE` to call `InitObservability` after `initConfig()`
completes. Add the `loadObservabilityConfig` helper that reads the ObservabilityConfig from the
already-loaded config file. Observability failure must be non-fatal.

- New imports: `internal/config` (already imported), `os` (already imported)

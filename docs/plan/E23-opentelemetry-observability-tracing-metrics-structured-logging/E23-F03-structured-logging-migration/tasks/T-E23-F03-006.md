# Write tests verifying no direct log.* or fmt.Fprintf(os.Stderr) calls remain

## Goal

Add a Go test in the `internal/observability` package (or a dedicated `migration_test.go`) that statically verifies zero legacy `log.*` and `fmt.Fprintf(os.Stderr, ...)` calls exist in `internal/` and `cmd/`, ensuring no regression reintroduces them.

## Scope

Files to create:
- `internal/observability/logging_migration_test.go` — static analysis test using `go/ast` or simple file walking + grep logic

## Acceptance Criteria

See spec.md REQ-F-001, REQ-F-002, REQ-F-003 and test-plan.md TC-001, TC-002.

- AC-T1: Test file created at `internal/observability/logging_migration_test.go`
- AC-T2: Test walks `internal/` and `cmd/` source files, fails if any match `log\.Print|log\.Fatal|log\.Println` (excluding test files and comments)
- AC-T3: Test walks same paths and fails if any match `fmt\.Fprintf\(os\.Stderr`
- AC-T4: `make test` passes with the new test included

## Test Cases

See test-plan.md TC-001 (static grep automated as Go test), TC-005 (full test suite).

## Design Reference

Use `filepath.Walk` + `os.ReadFile` + `strings.Contains` or regexp matching inside a `TestNoLegacyLogCalls` function. Follow existing test patterns in `internal/observability/` for package structure. See test-plan.md TC-001 and TC-002 for the exact patterns to detect.

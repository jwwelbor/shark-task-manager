# Migrate remaining internal/ packages and cmd/ utility binaries to slog

## Goal

Replace all remaining `log.*` and `fmt.Fprintf(os.Stderr, ...)` calls in `internal/status/`, `internal/db/`, `internal/init/`, `internal/taskcreation/` and all `cmd/` utility binaries (62 calls) with `slog.*` equivalents.

## Scope

Files to modify in `internal/`:
- `internal/status/derivation.go` (3 calls — `log.Println`, `log.Printf`)
- `internal/db/db.go` (1 call — `fmt.Fprintf`)
- `internal/init/profile_service.go` (2 calls — `fmt.Fprintf`)
- `internal/taskcreation/creator.go` (1 call — `fmt.Fprintf`)

Files to modify in `cmd/` utility binaries:
- `cmd/backfill-slugs/main.go` (8 calls)
- `cmd/cleanup/main.go` (9 calls)
- `cmd/create-epic/main.go` (2 calls)
- `cmd/demo/main.go` (8 calls)
- `cmd/migrate/main.go` (3 calls)
- `cmd/migrate-exec-order/main.go` (4 calls)
- `cmd/test-backfill/main.go` (10 calls)
- `cmd/test-db/main.go` (16 calls)

## Acceptance Criteria

See spec.md REQ-F-001 through REQ-F-007 and Sections 3.4 and 3.6 for exact replacements.

- AC-T1: `grep -r 'log\.' internal/status/ internal/db/ internal/init/ internal/taskcreation/ cmd/` returns zero results (excluding comments and test files)

# Migrate internal/services/ log calls to slog

## Goal

Replace all 13 `log.*` and `fmt.Fprintf(os.Stderr, ...)` calls in `internal/services/` with equivalent `slog.*` calls, converting WARNING-prefixed messages to `slog.Warn` and removing the `"log"` import.

## Scope

Files to modify:
- `internal/services/bug_service.go` (1 call — `fmt.Fprintf`)
- `internal/services/change_card_service.go` (2 calls — `fmt.Fprintf`)
- `internal/services/display_service.go` (3 calls — `log.Printf`)
- `internal/services/entity_service.go` (1 call — `log.Printf`)
- `internal/services/epic_service.go` (1 call — `log.Printf`)
- `internal/services/feature_service.go` (2 calls — `log.Printf`)
- `internal/services/task_service.go` (3 calls — `log.Printf`)

See spec.md REQ-F-001, REQ-F-003, REQ-F-004, REQ-F-005, REQ-F-007 and Section 3.3 for exact replacements.

- AC-T2: `grep -r 'fmt\.Fprintf(os\.Stderr' internal/services/` returns zero results

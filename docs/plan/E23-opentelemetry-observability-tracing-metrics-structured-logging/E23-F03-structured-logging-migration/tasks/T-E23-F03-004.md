# Migrate cmd/server/ log calls to slog

## Goal

Replace all 6 `log.*` calls in `cmd/server/main.go` with `slog.*` equivalents. `log.Fatal*` calls become `slog.Error` + `os.Exit(1)`. Info/Println calls become `slog.Info`. The `"log"` import is removed and `"log/slog"` added.

## Scope

Files to modify:
- `cmd/server/main.go` (6 calls: 3 `log.Fatal`, 2 `log.Println`, 1 `log.Printf`)

Files to skip (already comments):
- `cmd/server/services.go` lines 19, 37 — these are doc comments, no change needed

## Acceptance Criteria

See spec.md REQ-F-001, REQ-F-002, REQ-F-004, REQ-F-005, REQ-F-007 and Section 3.5 for exact replacements.

- AC-T1: `grep -r 'log\.' cmd/server/` returns zero results (excluding comments)
- AC-T2: `make build` passes
- AC-T3: Each former `log.Fatal` site has `os.Exit(1)` on the following line

## Test Cases

See test-plan.md TC-001 (static grep), TC-003 (build).

## Design Reference

See spec.md Section 4.3 for `log.Fatal*` → `slog.Error + os.Exit(1)` conversion rule. See spec.md Section 4.5 for notes on cmd/ binaries using default slog logger.

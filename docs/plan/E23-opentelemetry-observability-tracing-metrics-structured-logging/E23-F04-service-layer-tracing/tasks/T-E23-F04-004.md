# Wire tracers in services_global.go

## Goal
Connect the OTel tracer from the global provider to all three services by calling `SetTracer` in the `GetTaskService`, `GetFeatureService`, and `GetEpicService` accessor functions (and their `WithXxx` variants), completing the instrumentation chain from provider to service methods.

## Scope
- Files to modify: `internal/cli/services_global.go`

## Acceptance Criteria
See spec.md REQ-F-007.
- AC-T1: `GetTaskService()` calls `svc.SetTracer(GetTracer("shark/services/task"))` before returning.
- AC-T2: `GetFeatureService()` calls `svc.SetTracer(GetTracer("shark/services/feature"))` before returning.
- AC-T3: `GetEpicService()` calls `svc.SetTracer(GetTracer("shark/services/epic"))` before returning.
- AC-T4: All `GetXxxServiceWithYyy` variant accessors also wire the tracer.
- AC-T5: `make build` succeeds; `make test` passes with no new failures.

## Test Cases
See test-plan.md Regression Tests section. No new unit tests for wiring itself (covered by integration via UAT scenarios in uat-plan.md).

## Design Reference
See spec.md Architecture "Wiring in services_global.go" section. `GetTracer` is already defined in `internal/cli/observability_global.go`.

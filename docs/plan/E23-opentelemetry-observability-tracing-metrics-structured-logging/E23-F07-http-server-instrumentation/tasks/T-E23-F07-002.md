# Wrap HTTP handler with otelhttp middleware in cmd/server/main.go

## Goal
Initialize the OTel provider at HTTP server startup using observability.Init() and wrap the default HTTP mux with otelhttp.NewHandler() so every inbound request automatically generates a trace span recording method, path, and status code, and propagates W3C traceparent headers.

## Scope
- Files to modify: cmd/server/main.go

## Acceptance Criteria
- AC-T1: observability.Init() is called at server startup before http.ListenAndServe
- AC-T2: http.ListenAndServe receives the otelhttp-wrapped handler instead of nil
- AC-T3: W3C traceparent header is propagated on incoming requests
- AC-T4: A trace span is created per request with http.method, http.route, and http.status_code attributes
- AC-T5: The shark.http.request.duration histogram metric is emitted per request
- AC-T6: The server still handles /health and / routes correctly after wrapping

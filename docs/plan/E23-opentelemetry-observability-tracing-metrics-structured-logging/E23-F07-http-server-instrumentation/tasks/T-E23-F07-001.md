# Add otelhttp dependency for HTTP instrumentation middleware

## Goal
Add go.opentelemetry.io/contrib/instrumentation/net/http/otelhttp to go.mod so the HTTP server can use automatic trace span creation per request via the otelhttp middleware.

## Scope
- Files to modify: go.mod, go.sum

## Acceptance Criteria
- AC-T1: go.mod contains a require entry for go.opentelemetry.io/contrib/instrumentation/net/http/otelhttp at a version compatible with the OTel SDK already used in this project
- AC-T2: go.sum is updated with the correct hashes
- AC-T3: `go mod tidy` runs without errors after the addition
- AC-T4: The package resolves successfully in a build of cmd/server/

## Test Cases
Build verification: `go build ./cmd/server/` succeeds after adding the import.

## Design Reference
See feature.md description: the target is otelhttp.NewHandler() wrapping the HTTP mux.

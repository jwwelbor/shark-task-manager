# Migrate cmd/server/main.go logging from log.* to slog structured logging

## Goal
Replace all log.Fatal, log.Println, and log.Printf calls in cmd/server/main.go with slog equivalents so the server emits structured JSON log lines consistent with the rest of the E23 observability work.

## Scope
- Files to modify: cmd/server/main.go

## Acceptance Criteria
- AC-T1: No imports of the standard "log" package remain in cmd/server/main.go
- AC-T2: Startup and shutdown messages use slog.Info with structured key-value pairs
- AC-T3: Fatal-level errors use slog.Error followed by os.Exit(1) (or log/slog's equivalent pattern)
- AC-T4: The server builds and runs without regression in existing behavior

## Test Cases
See T-E23-F07-004 for tests verifying structured log output format.

## Design Reference
See feature.md description: "Structured logging in cmd/server/main.go is also migrated from log.Fatal/log.Println to slog equivalents."

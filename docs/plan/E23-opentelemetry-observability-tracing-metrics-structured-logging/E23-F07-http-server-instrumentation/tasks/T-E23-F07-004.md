# Write HTTP instrumentation integration tests

## Goal
Write integration tests that verify the otelhttp middleware creates spans with correct attributes, emits the shark.http.request.duration metric, and that the /health endpoint returns 200 after the middleware is applied.

## Scope
- Files to create: cmd/server/main_test.go (or cmd/server/instrumentation_test.go)

## Acceptance Criteria
- AC-T1: A test uses httptest.NewRecorder and a test OTel SDK exporter to verify a span is created with http.method and http.status_code attributes on each request
- AC-T2: A test verifies the shark.http.request.duration histogram receives a data point after a request
- AC-T3: /health endpoint returns HTTP 200 with the wrapped handler
- AC-T4: `make test` passes with the new test file included

## Test Cases
Use go.opentelemetry.io/otel/sdk/trace/tracetest and go.opentelemetry.io/otel/sdk/metric/metrictest (or sdkmetric) to capture in-memory telemetry without an external collector.

## Design Reference
See feature.md description for the target attributes and metric name.

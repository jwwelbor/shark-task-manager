# Task: Create internal/observability/noop.go - NoopProvider implementation

## Goal

Create `internal/observability/noop.go` implementing the `NoopProvider()` function. This installs OTel no-op providers globally, making it safe to call `otel.Tracer("pkg")` anywhere in the codebase without panicking — even when observability is disabled. This is the simplest file in the package and establishes the `ShutdownFunc` type.

## Requirements

### Functional Requirements

- [ ] Define `ShutdownFunc` type alias: `type ShutdownFunc func(ctx context.Context) error`
- [ ] Implement `NoopProvider() ShutdownFunc` that installs `noop.NewTracerProvider()` as the global OTel TracerProvider
- [ ] `NoopProvider()` installs `noop_metric.NewMeterProvider()` as the global OTel MeterProvider
- [ ] The returned `ShutdownFunc` returns `nil` unconditionally when called
- [ ] `NoopProvider()` is safe to call multiple times (idempotent — each call simply overwrites the global with a new no-op)
- [ ] After calling `NoopProvider()`, `otel.Tracer("test").Start(ctx, "span")` returns without panicking

### Non-Functional Requirements

- [ ] No goroutines started
- [ ] No file handles opened
- [ ] No network connections attempted (REQ-F-003)
- [ ] `go build ./internal/observability/...` passes (REQ-F-007)

## Implementation Plan

### Steps

1. [ ] Create `internal/observability/` directory if it does not exist
2. [ ] Create `internal/observability/noop.go` with package declaration `package observability`
3. [ ] Add imports:
   - `"context"`
   - `"go.opentelemetry.io/otel"`
   - `"go.opentelemetry.io/otel/metric/noop"` (as `noop_metric`)
   - `"go.opentelemetry.io/otel/trace/noop"`
4. [ ] Define `ShutdownFunc` type
5. [ ] Implement `NoopProvider()`:

```go
// ShutdownFunc gracefully shuts down the OTel provider,
// flushing any pending spans or metrics before returning.
type ShutdownFunc func(ctx context.Context) error

// NoopProvider installs no-op OTel providers globally and returns a no-op ShutdownFunc.
// Used when observability.enabled is false or in test environments.
// Safe to call multiple times.
func NoopProvider() ShutdownFunc {
    otel.SetTracerProvider(noop.NewTracerProvider())
    otel.SetMeterProvider(noop_metric.NewMeterProvider())
    return func(ctx context.Context) error {
        return nil
    }
}
```

6. [ ] Run `go build ./internal/observability/...`
7. [ ] Run `make fmt && make lint`

### Technical Approach

- `ShutdownFunc` is defined here (in `noop.go`) because `noop.go` is the simplest file and establishes the type for the whole package. `provider.go` will import nothing extra to get this type since they are in the same package.
- The no-op metric provider import path is `go.opentelemetry.io/otel/metric/noop` — alias it to `noop_metric` to avoid collision with the trace noop import `go.opentelemetry.io/otel/trace/noop`
- Do NOT define `ShutdownFunc` in both `noop.go` and `provider.go` — define it once here

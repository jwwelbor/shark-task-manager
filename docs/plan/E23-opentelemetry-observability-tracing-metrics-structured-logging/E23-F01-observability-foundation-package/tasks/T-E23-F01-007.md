# Task: Create internal/observability/metrics.go - CommandMetrics and DBMetrics instruments

## Goal

Create `internal/observability/metrics.go` implementing `CommandMetrics` and `DBMetrics` structs with their constructor functions and recording methods. These pre-register OTel metric instruments so callers can record CLI command durations and DB query durations without understanding OTel SDK internals.

## Requirements

### Functional Requirements

- [ ] Define `CommandMetrics` struct with private fields: `duration metric.Float64Histogram`, `invocations metric.Int64Counter`, `errors metric.Int64Counter`
- [ ] `NewCommandMetrics(meter metric.Meter) (CommandMetrics, error)` registers all 3 instruments
- [ ] `(m CommandMetrics) RecordDuration(ctx, command string, duration time.Duration, err error)` records histogram with `command` and `status` ("ok"/"error") attributes
- [ ] `(m CommandMetrics) RecordInvocation(ctx, command string, err error)` increments invocations counter with `command` and `status` attributes
- [ ] Define `DBMetrics` struct with private fields: `queryDuration metric.Float64Histogram`, `queryErrors metric.Int64Counter`
- [ ] `NewDBMetrics(meter metric.Meter) (DBMetrics, error)` registers both instruments
- [ ] `(m DBMetrics) RecordQueryDuration(ctx, operation, table string, duration time.Duration, err error)` records histogram with `operation` and `table` attributes, increments `queryErrors` counter when `err != nil`
- [ ] Both constructors return an error if instrument registration fails
- [ ] All methods are safe to call when the meter is a no-op meter (from `noop_metric.NewMeterProvider()`)

### Instrument Names and Specifications

| Instrument | Name | Type | Unit | Attributes |
|---|---|---|---|---|
| `CommandMetrics.duration` | `shark.cli.command.duration` | `Float64Histogram` | `ms` | `command`, `status` |
| `CommandMetrics.invocations` | `shark.cli.command.invocations` | `Int64Counter` | — | `command`, `status` |
| `CommandMetrics.errors` | `shark.cli.command.errors` | `Int64Counter` | — | `command`, `error_type` |
| `DBMetrics.queryDuration` | `shark.db.query.duration` | `Float64Histogram` | `ms` | `operation`, `table` |
| `DBMetrics.queryErrors` | `shark.db.query.errors` | `Int64Counter` | — | `operation`, `table` |

Status attribute values: `"ok"` when `err == nil`, `"error"` when `err != nil`.

```go
type CommandMetrics struct {
    duration    metric.Float64Histogram
    invocations metric.Int64Counter
    errors      metric.Int64Counter
}

func NewCommandMetrics(meter metric.Meter) (CommandMetrics, error) {
    duration, err := meter.Float64Histogram(
        "shark.cli.command.duration",
        metric.WithUnit("ms"),
        metric.WithDescription("CLI command execution duration in milliseconds"),
    )
    if err != nil {
        return CommandMetrics{}, fmt.Errorf("create command duration histogram: %w", err)
    }

    invocations, err := meter.Int64Counter(
        "shark.cli.command.invocations",
        metric.WithDescription("Total CLI command invocations"),
    )
    if err != nil {
        return CommandMetrics{}, fmt.Errorf("create command invocations counter: %w", err)
    }

    errs, err := meter.Int64Counter(
        "shark.cli.command.errors",
        metric.WithDescription("Total CLI command errors"),
    )
    if err != nil {
        return CommandMetrics{}, fmt.Errorf("create command errors counter: %w", err)
    }

    return CommandMetrics{duration: duration, invocations: invocations, errors: errs}, nil
}
```

### Technical Approach

Recording methods use `attribute.String`:
```go
func (m CommandMetrics) RecordDuration(ctx context.Context, command string, duration time.Duration, err error) {
    status := "ok"
    if err != nil {
        status = "error"
    }
    attrs := metric.WithAttributes(
        attribute.String("command", command),
        attribute.String("status", status),
    )
    m.duration.Record(ctx, float64(duration.Milliseconds()), attrs)
}
```

Duration is converted to milliseconds as `float64(duration.Milliseconds())` to match the `ms` unit.

For `RecordQueryDuration`: record the histogram AND increment `queryErrors` when `err != nil`:
```go
func (m DBMetrics) RecordQueryDuration(ctx context.Context, operation, table string, duration time.Duration, err error) {
    attrs := metric.WithAttributes(
        attribute.String("operation", operation),
        attribute.String("table", table),
    )
    m.queryDuration.Record(ctx, float64(duration.Milliseconds()), attrs)
    if err != nil {
        m.queryErrors.Add(ctx, 1, attrs)
    }
}
```

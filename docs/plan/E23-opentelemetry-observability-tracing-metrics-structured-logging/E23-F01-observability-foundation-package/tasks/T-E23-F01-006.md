# Task: Create internal/observability/logger.go - slog setup with JSON/text format

## Goal

Create `internal/observability/logger.go` implementing `InitLogger()` and `parseLogLevel()`. This configures the global `slog` structured logger based on `ObservabilityConfig`. When disabled, it installs a discard handler so that existing code calling `slog.Info()` does not panic. All output is directed exclusively to `os.Stderr`.

## Requirements

### Functional Requirements

- [ ] `InitLogger(cfg config.ObservabilityConfig)` configures the global `slog` default logger
- [ ] When `cfg.Enabled = false`: install a TextHandler on `os.Stderr` with level `slog.LevelError + 1` (effectively discards everything below that threshold; Info/Warn/Debug are suppressed)
- [ ] When `cfg.Enabled = true, cfg.LogFormat = "json"` (or empty): install `slog.NewJSONHandler(os.Stderr, opts)`
- [ ] When `cfg.Enabled = true, cfg.LogFormat = "text"`: install `slog.NewTextHandler(os.Stderr, opts)`
- [ ] Log level is controlled by `cfg.LogLevel` via `parseLogLevel()`: `"debug"` → `slog.LevelDebug`, `"info"` → `slog.LevelInfo`, `"warn"` → `slog.LevelWarn`, `"error"` → `slog.LevelError`; empty string defaults to `slog.LevelInfo`
- [ ] Every log record includes `"service.name"` attribute set to `cfg.ServiceName` (default: `"shark-task-manager"` when empty)
- [ ] `slog.SetDefault(logger)` installs the configured logger globally
- [ ] All log output goes to `os.Stderr` — never `os.Stdout`

### Non-Functional Requirements

- [ ] No OTel trace/metric imports needed — only `log/slog` and `internal/config`
- [ ] `go build ./internal/observability/...` passes (REQ-F-007)

## Implementation Plan

### Steps

1. [ ] Create `internal/observability/logger.go` with `package observability`
2. [ ] Add imports: `"log/slog"`, `"os"`, `"github.com/jwwelbor/shark-task-manager/internal/config"`
3. [ ] Implement `parseLogLevel(level string) slog.Level`:

```go
func parseLogLevel(level string) slog.Level {
    switch strings.ToLower(level) {
    case "debug":
        return slog.LevelDebug
    case "warn", "warning":
        return slog.LevelWarn
    case "error":
        return slog.LevelError
    default:
        return slog.LevelInfo
    }
}
```

4. [ ] Implement `InitLogger(cfg config.ObservabilityConfig)`:

```go
func InitLogger(cfg config.ObservabilityConfig) {
    if !cfg.Enabled {
        // Install a handler that discards everything — prevents panics on slog.Info() calls
        handler := slog.NewTextHandler(os.Stderr, &slog.HandlerOptions{
            Level: slog.Level(slog.LevelError + 1),
        })
        slog.SetDefault(slog.New(handler))
        return
    }

    level := parseLogLevel(cfg.LogLevel)
    opts := &slog.HandlerOptions{Level: level}

    serviceName := cfg.ServiceName
    if serviceName == "" {
        serviceName = "shark-task-manager"
    }

    var handler slog.Handler
    if cfg.LogFormat == "text" {
        handler = slog.NewTextHandler(os.Stderr, opts)
    } else {
        handler = slog.NewJSONHandler(os.Stderr, opts)
    }

    logger := slog.New(handler).With("service.name", serviceName)
    slog.SetDefault(logger)
}
```

5. [ ] Run `make fmt && make lint && go build ./internal/observability/...`

### Technical Approach

- Use `slog.Level(slog.LevelError + 1)` for the discard handler — this is higher than any standard level, so no records pass. Alternatively, use a custom `discardHandler` struct, but the level approach is simpler and idiomatic.
- `slog.New(handler).With(...)` returns a `*slog.Logger` pre-populated with the `service.name` attribute on every record
- JSON handler is the default (empty `cfg.LogFormat` → JSON) per spec: "When cfg.LogFormat = 'json'" and "When disabled output must be silently discarded"
- `strings.ToLower` in `parseLogLevel` makes level parsing case-insensitive
- Do NOT write anything to `os.Stdout` — all output is `os.Stderr`

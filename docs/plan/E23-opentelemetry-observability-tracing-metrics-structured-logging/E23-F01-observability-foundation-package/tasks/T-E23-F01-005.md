# Task: Create internal/observability/provider.go - TracerProvider and MeterProvider initialization

## Goal

Create `internal/observability/provider.go` implementing `InitProvider()`, `applyEnvOverrides()`, and the internal builder functions. This is the primary entry point for the observability package — it initializes OTel SDK TracerProvider and MeterProvider (or delegates to `NoopProvider()` when disabled), sets W3C propagation, and returns a flush-capable `ShutdownFunc`.

## Requirements

### Functional Requirements

- [ ] `InitProvider(cfg config.ObservabilityConfig) (ShutdownFunc, error)` is the public API
- [ ] When `cfg.Enabled = false`: delegates to `NoopProvider()`, returns its ShutdownFunc, returns nil error
- [ ] When `cfg.Enabled = true, cfg.Exporter = "stdout"`: creates TracerProvider with `stdouttrace.New()` writing to `os.Stderr` (NEVER stdout), wraps in `sdktrace.NewSimpleSpanProcessor`
- [ ] When `cfg.Enabled = true, cfg.Exporter = "otlp"`: creates gRPC OTLP exporter via `otlptracegrpc.New()` pointing at `cfg.OTLPEndpoint`; connection must be lazy (no failure if collector is unreachable at init time)
- [ ] MeterProvider initialized analogously: `stdoutmetric` writing to `os.Stderr` for "stdout", `otlpmetricgrpc` for "otlp"
- [ ] Resource built with `semconv.ServiceNameKey` set to `cfg.ServiceName` (default: `"shark-task-manager"`) and `semconv.ServiceVersionKey`
- [ ] W3C propagator set via `otel.SetTextMapPropagator(propagation.NewCompositeTextMapPropagator(propagation.TraceContext{}, propagation.Baggage{}))`
- [ ] Global providers set via `otel.SetTracerProvider(tp)` and `otel.SetMeterProvider(mp)`
- [ ] Returned `ShutdownFunc` calls `tp.Shutdown(ctx)` then `mp.Shutdown(ctx)`, collecting both errors, returning a combined error if either fails
- [ ] Calling `ShutdownFunc` twice is safe (idempotent — SDK Shutdown is idempotent per OTel spec)
- [ ] `applyEnvOverrides(cfg *config.ObservabilityConfig)` reads env vars and overwrites config fields before any provider initialization

### Environment Variable Overrides (REQ-F-006)

- [ ] `SHARK_OTEL_ENABLED=true` → `cfg.Enabled = true`
- [ ] `OTEL_EXPORTER_OTLP_ENDPOINT=<value>` → `cfg.OTLPEndpoint = <value>`
- [ ] `OTEL_EXPORTER_OTLP_PROTOCOL=<value>` → `cfg.OTLPProtocol = <value>`
- [ ] `OTEL_SERVICE_NAME=<value>` → `cfg.ServiceName = <value>`
- [ ] `SHARK_LOG_LEVEL=<value>` → `cfg.LogLevel = <value>`
- [ ] `SHARK_LOG_FORMAT=<value>` → `cfg.LogFormat = <value>`
- [ ] Unset env vars do not override config values

### Non-Functional Requirements

- [ ] All OTel output goes to `os.Stderr`, never `os.Stdout` (REQ-F-009)
- [ ] No import cycles — `internal/observability/` must not import `internal/cli/`, `internal/services/`, or `internal/repository/` (REQ-F-007)
- [ ] `go build ./internal/observability/...` and `go vet ./internal/observability/...` pass

```go
    "go.opentelemetry.io/otel/exporters/stdout/stdoutmetric"
    "go.opentelemetry.io/otel/exporters/stdout/stdouttrace"
    "go.opentelemetry.io/otel/propagation"
    sdkmetric "go.opentelemetry.io/otel/sdk/metric"
    sdkresource "go.opentelemetry.io/otel/sdk/resource"
    sdktrace "go.opentelemetry.io/otel/sdk/trace"
    semconv "go.opentelemetry.io/otel/semconv/v1.26.0"

    "github.com/jwwelbor/shark-task-manager/internal/config"
)
```

Stdout exporter must write to `os.Stderr`:
```go
// For stdout trace exporter — write to Stderr, never Stdout
exp, err := stdouttrace.New(stdouttrace.WithWriter(os.Stderr))
```

OTLP exporter uses `WithInsecure()` for development and lazy connection:
```go
exp, err := otlptracegrpc.New(ctx,
    otlptracegrpc.WithEndpoint(cfg.OTLPEndpoint),
    otlptracegrpc.WithInsecure(),
)
```

Combined ShutdownFunc:
```go
return func(ctx context.Context) error {
    var errs []error
    if err := tp.Shutdown(ctx); err != nil {
        errs = append(errs, fmt.Errorf("tracer shutdown: %w", err))
    }
    if err := mp.Shutdown(ctx); err != nil {
        errs = append(errs, fmt.Errorf("meter shutdown: %w", err))
    }
    return errors.Join(errs...)
}, nil
```

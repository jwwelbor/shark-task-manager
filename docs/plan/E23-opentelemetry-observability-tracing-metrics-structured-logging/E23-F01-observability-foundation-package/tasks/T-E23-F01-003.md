# Task: Add ObservabilityConfig parsing to internal/config/manager.go

## Goal

Wire up parsing of the `"observability"` JSON key in `internal/config/manager.go`'s `Load()` function so that `Config.Observability` is populated from `.sharkconfig.json`. This task depends on T-E23-F01-002 which defines the `ObservabilityConfig` struct.

## Requirements

### Functional Requirements

- [ ] Add parsing block in `internal/config/manager.go` `Load()` that reads all 9 `ObservabilityConfig` fields from `rawData["observability"]`
- [ ] Existing configs without `"observability"` key load without error; `Config.Observability` remains zero value
- [ ] Config with `{"observability": {"enabled": true, "log_format": "json"}}` sets `Config.Observability.Enabled = true` and `Config.Observability.LogFormat = "json"`
- [ ] All 9 fields parse correctly; unset fields remain zero

### Non-Functional Requirements

- [ ] Follows the identical type-assertion parsing pattern already used in `Load()` for other config fields
- [ ] `make test` passes without modification

## Implementation Plan

### Steps

1. [ ] Read `internal/config/manager.go` to locate the `Load()` function and understand where existing fields are parsed
2. [ ] After all existing field parsing blocks and before `m.config = config` (or equivalent assignment), add:

```go
// Parse observability config if present
if obsRaw, ok := rawData["observability"].(map[string]interface{}); ok {
    var obs ObservabilityConfig
    if enabled, ok := obsRaw["enabled"].(bool); ok {
        obs.Enabled = enabled
    }
    if tracingEnabled, ok := obsRaw["tracing_enabled"].(bool); ok {
        obs.TracingEnabled = tracingEnabled
    }
    if metricsEnabled, ok := obsRaw["metrics_enabled"].(bool); ok {
        obs.MetricsEnabled = metricsEnabled
    }
    if logLevel, ok := obsRaw["log_level"].(string); ok {
        obs.LogLevel = logLevel
    }
    if logFormat, ok := obsRaw["log_format"].(string); ok {
        obs.LogFormat = logFormat
    }
    if exporter, ok := obsRaw["exporter"].(string); ok {
        obs.Exporter = exporter
    }
    if otlpEndpoint, ok := obsRaw["otlp_endpoint"].(string); ok {
        obs.OTLPEndpoint = otlpEndpoint
    }
    if otlpProtocol, ok := obsRaw["otlp_protocol"].(string); ok {
        obs.OTLPProtocol = otlpProtocol
    }
    if serviceName, ok := obsRaw["service_name"].(string); ok {
        obs.ServiceName = serviceName
    }
    config.Observability = obs
}
```

3. [ ] Run `make fmt && make lint && make test` — all must pass

### Technical Approach

- Use the exact same `rawData["key"].(type)` pattern already present in `Load()` — do NOT introduce `json.Unmarshal` for the nested struct
- The outer `if obsRaw, ok := rawData["observability"].(map[string]interface{}); ok` guard ensures graceful handling when the key is absent (backward compat)
- Each inner field uses a separate `if` with type assertion so a missing or wrong-typed field leaves the zero value in place

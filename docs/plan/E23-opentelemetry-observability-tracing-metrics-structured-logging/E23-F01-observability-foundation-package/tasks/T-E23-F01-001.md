# Task: Add OTel dependencies to go.mod

## Goal

Add all required OpenTelemetry Go SDK and exporter dependencies to `go.mod` and `go.sum`. This is the prerequisite for all other E23-F01 tasks — no OTel code can be written until the module graph includes these packages.

## Requirements

### Functional Requirements

- [ ] Add `go.opentelemetry.io/otel` (core API)
- [ ] Add `go.opentelemetry.io/otel/sdk` (SDK — TracerProvider, MeterProvider)
- [ ] Add `go.opentelemetry.io/otel/exporters/stdout/stdouttrace` (stdout span exporter)
- [ ] Add `go.opentelemetry.io/otel/exporters/stdout/stdoutmetric` (stdout metric exporter)
- [ ] Add `go.opentelemetry.io/otel/exporters/otlp/otlptrace/otlptracegrpc` (gRPC OTLP trace exporter)
- [ ] Add `go.opentelemetry.io/otel/exporters/otlp/otlpmetric/otlpmetricgrpc` (gRPC OTLP metric exporter)
- [ ] Add `go.opentelemetry.io/otel/semconv/v1.26.0` (semantic conventions)
- [ ] Add `go.opentelemetry.io/otel/propagators/b3` or use built-in W3C propagation
- [ ] Verify `go build ./...` still compiles cleanly after additions

### Non-Functional Requirements

- [ ] Binary size increase must stay within 15MB budget (ADR-2). Verify with `du -sh ./bin/shark` before and after.
- [ ] No dependency conflicts with existing modules (check with `go mod tidy`)

## Implementation Plan

### Steps

1. [ ] Step 1: Run `go get go.opentelemetry.io/otel@latest` to add core API
2. [ ] Step 2: Run `go get go.opentelemetry.io/otel/sdk@latest` for SDK
3. [ ] Step 3: Run `go get go.opentelemetry.io/otel/exporters/stdout/stdouttrace@latest`
4. [ ] Step 4: Run `go get go.opentelemetry.io/otel/exporters/stdout/stdoutmetric@latest`
5. [ ] Step 5: Run `go get go.opentelemetry.io/otel/exporters/otlp/otlptrace/otlptracegrpc@latest`
6. [ ] Step 6: Run `go get go.opentelemetry.io/otel/exporters/otlp/otlpmetric/otlpmetricgrpc@latest`
7. [ ] Step 7: Run `go get go.opentelemetry.io/otel/semconv/v1.26.0@latest`
8. [ ] Step 8: Run `go mod tidy` to remove unused and reconcile transitive deps
9. [ ] Step 9: Run `go build ./...` and confirm zero errors
10. [ ] Step 10: Measure binary size change with `make shark && du -sh ./bin/shark`

### Technical Approach

- Use `go get` for each package individually so version constraints are explicit in go.mod
- All OTel packages should resolve to the same semver minor version (e.g., all v1.x.x) to avoid SDK/API version mismatch panics
- The gRPC OTLP exporters will pull in `google.golang.org/grpc` as a transitive dependency — this is expected and acceptable
- Verify with `go mod graph | grep opentelemetry` that there are no conflicting versions

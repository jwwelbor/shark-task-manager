# Task: ChangeCard Service DTOs

## Goal

Create the Data Transfer Objects (DTOs) for the ChangeCardService: CreateChangeCardInput, ChangeCardFilters, and ChangeCardUpdates. These define the service method contracts that CLI commands and HTTP handlers will use.

## Success Criteria

- [ ] `internal/services/change_dto.go` created with all three DTO structs
- [ ] CreateChangeCardInput has Title (required) and LinkedEntityKey (optional) fields
- [ ] ChangeCardFilters has Status, LinkedEntityKey, and ShowAll fields
- [ ] ChangeCardUpdates has pointer-typed optional fields (Title, LinkedEntityKey)
- [ ] All structs have JSON tags matching the conventions in existing DTOs
- [ ] File compiles with `go build ./internal/services/`
- [ ] `make fmt && make lint` passes

## Test Plan References

- **DTO Contracts**: CreateChangeCardInput, ChangeCardFilters, ChangeCardUpdates -- See [Test Plan - Section 3.2](../09-test-plan.md#32-dto-contracts)

## Implementation Guidance

Create the DTO structs that define the service API contracts. These are simple data containers with no methods or business logic. They decouple CLI argument parsing from service method signatures.

### Key Requirements

- All three DTO structs with exact fields and types in [Backend Design - Section 2.2](../04-backend-design.md#22-dtos)
- JSON tags follow snake_case convention matching existing DTOs in `internal/services/`
- Pointer types for optional update fields (allows distinguishing "not set" from "set to empty")

### Files to Create

- `internal/services/change_dto.go` -- All three DTO structs

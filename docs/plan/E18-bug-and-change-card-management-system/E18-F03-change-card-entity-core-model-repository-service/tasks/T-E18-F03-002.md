# Task: ChangeCard Repository Implementation

## Goal

Implement the ChangeCardRepository with pure CRUD operations, key auto-generation, dual-key lookup, linked entity filtering, and status counting. The repository is a data access layer with zero business logic.

## Success Criteria

- [ ] ChangeCardRepository struct and constructor in `internal/repository/change_card_repository.go`

- [ ] All repository integration tests pass with real database and cleanup

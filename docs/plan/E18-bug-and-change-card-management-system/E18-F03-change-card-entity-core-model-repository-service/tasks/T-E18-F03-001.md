# Task: ChangeCard Model, Entity Type, and Workflow Level

## Goal

Create the ChangeCard model struct with structural validation, add the EntityTypeChange constant to the entity notes system, and add the LevelChange constant to the workflow levels. This is the foundation layer that all subsequent tasks depend on.

## Success Criteria

- [ ] ChangeCard struct defined in `internal/models/change_card.go` with all fields from data design
- [ ] ChangeCardStatus type alias defined (string-based, no hardcoded status constants)
- [ ] Validate() method checks non-empty title and non-empty status only
- [ ] Validate() does NOT import workflow or config packages
- [ ] EntityTypeChange = "change" constant added to `internal/models/entity_note.go`
- [ ] ValidEntityTypes map updated to include EntityTypeChange
- [ ] LevelChange = "change" constant added to `internal/workflow/levels.go`
- [ ] Model unit tests pass with table-driven tests
- [ ] `make fmt && make lint && make test` passes with zero failures

## Implementation Guidance

### Overview

Implement the ChangeCard data model following the exact pattern established by existing models (Task, Epic, Feature, Idea). The model is a pure data structure with structural validation only -- no business logic, no workflow awareness.

### Key Requirements

- ChangeCard struct fields, JSON tags, and pointer types for nullable fields as specified in [Data Design - Section 2](../03-data-design.md#2-go-model-changecard)
- ChangeCardStatus type alias follows same pattern as TaskStatus in `internal/models/task.go`
- Validate() follows same structural-only pattern as Task.Validate() in `internal/models/task.go`
- Entity type constant and map entry pattern in [Data Design - Section 3](../03-data-design.md#3-entity-type-extension)
- Workflow level constant pattern in [Data Design - Section 4](../03-data-design.md#4-workflow-level-extension)

### Files to Create/Modify

- **Create**: `internal/models/change_card.go` -- ChangeCard struct + ChangeCardStatus + Validate()
- **Create**: `internal/models/change_card_test.go` -- Table-driven validation tests
- **Modify**: `internal/models/entity_note.go` -- Add EntityTypeChange constant + ValidEntityTypes entry
- **Modify**: `internal/workflow/levels.go` -- Add LevelChange constant

- DO NOT hardcode status values like "proposed" or "approved" in the model
- DO NOT add business logic to the model -- that belongs in the service layer (Task 004)

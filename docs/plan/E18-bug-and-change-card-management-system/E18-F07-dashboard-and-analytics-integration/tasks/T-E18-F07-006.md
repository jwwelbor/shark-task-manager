# Task: Analytics CLI Command Extension and Formatters

## Goal

Extend the existing `shark analytics` CLI command with a `--type` flag that routes to bug or change-card analytics, and add terminal formatters for displaying analytics results. The command calls DashboardAnalyticsService (task 005) and formats the results for both human-readable and JSON output.

## Success Criteria

- [ ] `--type` flag added to analytics command accepting values: bug, change
- [ ] `shark analytics --type=bug` shows bug-only analytics (total, by-status, by-severity, resolution time)
- [ ] `shark analytics --type=change` shows change-card-only analytics (total, by-status, approval rate, completion time)
- [ ] `shark analytics` (no type filter and no session flags) shows combined bug + change-card analytics
- [ ] `--json` flag works with all type filters, producing JSON matching architecture doc contracts
- [ ] "N/A" displayed for nil averages/rates (no panics on nil pointer dereference)
- [ ] Combined analytics degrades gracefully (omits sections when data absent)
- [ ] make fmt && make lint && make test passes

# Task: Dashboard Formatter Extension for Bugs and Change-Cards

## Goal

Add rendering functions for bug and change-card sections to the dashboard formatter. These functions read the optional BugSummary and ChangeCardSummary fields from StatusDashboard and produce human-readable terminal output following the existing section rendering pattern.

## Success Criteria

- [ ] formatBugSummary renders "BUGS" section with total, status breakdown, and open severity breakdown
- [ ] formatChangeCardSummary renders "CHANGE CARDS" section with total and status breakdown
- [ ] Both functions return empty string when input is nil (conditional display)
- [ ] Bug statuses display in defined order: reported, triaged, in_fix, in_verification, resolved, wont_fix, duplicate
- [ ] Change-card statuses display in order: proposed, approved, in_progress, completed, declined
- [ ] Severity subsection omitted when all severity counts are zero
- [ ] FormatDashboard calls new formatters after existing sections
- [ ] formatDurationFromSecs helper converts seconds to human-readable "Xd Yh" or "Xh Ym" format
- [ ] make fmt && make lint && make test passes

# Task: DashboardAnalyticsService for Bug and Change-Card Metrics

## Goal

Create a new DashboardAnalyticsService in internal/services/ that provides bug and change-card analytics data. This service queries repository aggregate methods and assembles analytics result DTOs consumed by the analytics CLI command. Per ADR-F07-002, this is a separate service from EpicAnalyticsService to maintain single responsibility.

## Success Criteria

- [ ] DashboardAnalyticsService created with optional bug and change-card repository dependencies
- [ ] GetBugAnalytics returns BugAnalyticsResult with total, by-status, by-severity, resolved count, avg resolution time
- [ ] GetChangeCardAnalytics returns ChangeCardAnalyticsResult with total, by-status, approval rate, decided count, completed count, avg completion time
- [ ] Nil repository returns descriptive error (not panic)
- [ ] Nil/zero averages handled correctly (pointer types, nil when no data)
- [ ] Analytics DTOs defined with correct JSON tags matching architecture doc contracts
- [ ] DashboardAnalyticsResult combines both for unfiltered analytics
- [ ] All service tests pass with mocked repositories
- [ ] make fmt && make lint && make test passes

# Task: Feature-Level Linked Bug Context

## Goal

Extend the feature-level status view (`shark status E07-F01`) to display linked bug information when bugs are linked to a feature. This enables product owners to assess per-feature quality by seeing bug count and severity at the feature level.

## Success Criteria

- [ ] FeatureStatusInfo struct has LinkedBugs optional pointer field with omitempty JSON tag
- [ ] BugFeatureSummary type defined (total linked, open count, open by severity)
- [ ] Feature status query populates LinkedBugs when bug repo is available and bugs are linked
- [ ] LinkedBugs is nil when no bugs are linked to the feature (clean output)
- [ ] JSON output includes linked_bugs key only when bugs are linked (omitempty)
- [ ] Terminal output shows "Linked Bugs: N (M open -- severity breakdown)" format
- [ ] make fmt && make lint && make test passes

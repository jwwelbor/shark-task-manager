# Task: Bug Triage Command Handler

## Goal

Implement the triage subcommand that allows setting severity, priority, assignee, and target version on a bug in a single operation via BugService.TriageBug.

## Success Criteria

- [ ] `shark bug triage <key>` calls BugService.TriageBug with TriageBugInput DTO
- [ ] Supports flags: --severity, --priority, --assignee, --target-version
- [ ] At least one triage flag must be provided (validate before calling service)
- [ ] Outputs updated bug details in JSON or table format
- [ ] Handler follows three-step pattern and is 15-25 lines
- [ ] Status auto-advances from "reported" to "triaged" (handled by BugService, not CLI)

## Brownfield Context

- No direct equivalent in existing codebase; closest pattern is task set-status with multiple optional flags
- Use same flag parsing and service call pattern as other bug CRUD handlers from T-E18-F04-002
- Triage is a domain-specific operation; the CLI just collects flags and passes TriageBugInput to BugService

# Task: Bug Note and Context Command Handlers

## Goal

Implement note and context subcommands that reuse NoteService and ContextService with entity_type="bug", providing add/list notes and set/get/clear context fields on bugs.

## Success Criteria

- [ ] `shark bug note add <key> --content="..." [--type=TYPE]` calls NoteService.AddNote with entity_type="bug"
- [ ] `shark bug notes <key>` calls NoteService.ListNotes with entity_type="bug" and displays results
- [ ] `shark bug context set <key> --field=NAME --value=VALUE` calls ContextService.SetField with entity_type="bug"
- [ ] `shark bug context get <key> [--field=NAME]` calls ContextService.GetField or GetAll
- [ ] `shark bug context clear <key> --field=NAME` calls ContextService.ClearField with entity_type="bug"
- [ ] All handlers follow three-step pattern (15-25 lines each)
- [ ] JSON and table output supported on all commands
- [ ] Reuses existing NoteService/ContextService -- no new service methods needed

# Task: Bug CRUD Command Handlers

## Goal

Implement the five CRUD command handlers (create, get, list, update, delete) as thin wrappers calling BugService methods, with JSON and table output support.

## Success Criteria

- [ ] `shark bug create` parses title (positional), --severity, --component, --reported-by, --epic, --feature, --task flags and calls BugService.CreateBug
- [ ] `shark bug get <key>` calls BugService.GetBug and supports --json and --field flags
- [ ] `shark bug list` calls BugService.ListBugs with --status, --severity, --component, --json filters
- [ ] `shark bug update <key>` calls BugService.UpdateBug with optional --title, --severity, --component, --description flags
- [ ] `shark bug delete <key>` calls BugService.DeleteBug with --force flag to skip confirmation
- [ ] Each handler follows the three-step pattern: parse args, call service, format output
- [ ] Each handler is 15-25 lines maximum (excluding helper functions)
- [ ] JSON output uses cli.OutputJSON; table output uses cli.OutputTable or printBugDetail/printBugTable helpers
- [ ] Error handling maps BugService errors to exit codes per 03-api-contracts.md Section 5

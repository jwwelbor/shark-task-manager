## Coverage Gaps (Noted, Non-Blocking for This Task)

The following test types specified in the test plan are NOT present in this
file and will need to be addressed in a future cycle or caught via QA:

1. **Handler tests using mocked `BugService`**: `runBugCreate`, `runBugGet`,
   `runBugList`, `runBugUpdate`, `runBugDelete`, `runBugTriage` are not tested
   with mock injection. The test plan required a `MockBugService` struct.
   This limits confidence in argument-parsing correctness for each handler.

2. **Error path coverage**: No tests verify that service errors propagate
   correctly to the caller (e.g., service returning `NotFoundError` should
   surface as a non-nil error from the handler).

3. **JSON output tests**: No tests verify that `--json` mode produces valid
   JSON for any handler.

These gaps are acceptable for this review cycle because:
- The helper functions are the only testable pure-logic units in the package
  without a mock injection mechanism.
- The broader commands package has a compile-time issue in `analytics_test.go`
  (undefined symbols from E18-F07) that blocks the full test suite. This is
  a pre-existing issue unrelated to E18-F04.
- QA testing against the running binary will provide integration-level coverage.

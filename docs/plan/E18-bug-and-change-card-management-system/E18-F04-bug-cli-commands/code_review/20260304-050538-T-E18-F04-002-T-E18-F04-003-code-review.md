**runBugTriage (bug.go lines 414–436):**

```go
func runBugTriage(cmd *cobra.Command, args []string) error {
    key := args[0]
    severity, _ := cmd.Flags().GetString("severity")

    input := services.TriageBugInput{
        Severity: severity,
    }

    svc := cli.GetBugService()
    bug, err := svc.TriageBug(cmd.Context(), key, input)
    if err != nil {
        return err
    }

    if cli.GlobalConfig.JSON {
        return cli.OutputJSON(bug)
    }
    cli.Success(fmt.Sprintf("Triaged bug %s (severity: %s, status: %s)", bug.Key, bug.Severity, bug.Status))
    return nil
}
```

Clean thin-wrapper. Follows parse → call → format. No dead code.

**TriageBug service method (bug_service.go lines 275–302):**

Service validates severity before fetching the bug (fail-fast), then updates the bug model and calls repo.Update. The conditional status advance to "triaged" only fires if "triaged" is a valid workflow transition — no hardcoded status checks beyond that workflow query.

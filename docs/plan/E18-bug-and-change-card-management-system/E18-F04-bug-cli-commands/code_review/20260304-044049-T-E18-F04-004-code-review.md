  global accessor pattern — no new wiring required.
- `models.EntityTypeBug` is used as the entity type discriminator, consistent
  with how other entity types pass through the note and context services.
- `runBugContextClear` correctly handles both "clear specific field" (sets to
  empty string via `SetContextField`) and "clear all context" (calls
  `ClearContext`) based on whether `--field` is provided.

  correct reuse of an existing helper rather than duplicating formatting code.

## Minor Observations (Non-Blocking)

  cosmetic inconsistency — the existing `runBugNotes` already uses `fmt.Printf`
  for the notes header (line 490), so this is consistent within the function.
- `runBugNoteAdd` does not output JSON for the success case (line 461 shows only
  `cli.Success`). Per the test plan TC-07 notes, this is acceptable as the note
  add is a write-only operation. The JSON output path is intentionally omitted.

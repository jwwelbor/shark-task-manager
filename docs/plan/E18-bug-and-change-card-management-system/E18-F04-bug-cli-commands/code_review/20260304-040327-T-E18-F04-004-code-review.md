## Summary

This task required implementing note and context command handlers for bugs:
- `shark bug note add <key> --content="..." [--type=TYPE]`
- `shark bug notes <key>`
- `shark bug context set <key> --field=FIELD --value=VALUE`

None of these commands exist. There is zero implementation for any note or context handler in the codebase.

### B2 — Note subcommand group not scaffolded

The note commands should be organized under a `bugNoteCmd` parent:
```
bugCmd
  └── bugNoteCmd (Use: "note")
        ├── bugNoteAddCmd (Use: "add <key>")
        └── bugNotesCmd (Use: "notes <key>") -- or directly under bugCmd
```

The task spec shows `shark bug note add` (nested subcommand) and `shark bug notes` (direct subcommand). Neither parent structure nor leaf commands exist.

### B3 — Context subcommand group not scaffolded

The context commands should be organized under a `bugContextCmd` parent:
```
bugCmd
  └── bugContextCmd (Use: "context")
        ├── bugContextSetCmd (Use: "set <key>")
        ├── bugContextGetCmd (Use: "get <key>")
        └── bugContextClearCmd (Use: "clear <key>")
```

No context command structure exists.

### B4 — NoteService and ContextService usage not implemented

The task requires using `NoteService` (for bug notes) and `ContextService` (for bug context fields) with `entity_type="bug"`. These services exist in the codebase (`internal/services/note_service.go` and `internal/services/context_service.go`) and have working implementations for other entity types.

The note handlers should call:
```go
noteSvc := cli.GetNoteService()
noteSvc.AddNote(ctx, "bug", key, content, noteType)
```

The context handlers should call:
```go
contextSvc := cli.GetContextService()
contextSvc.SetContextField(ctx, "bug", key, field, value)
contextSvc.GetContext(ctx, "bug", key)
contextSvc.ClearContextField(ctx, "bug", key, field)
```

None of these calls exist anywhere for bugs.

## Required Changes

1. Implement `runBugNoteAdd` handler:
   - Parse `key` (positional arg), `--content` (required), `--type` (optional, default "progress")
   - Call `noteSvc.AddNote(ctx, "bug", key, content, noteType)`
   - Output: "Note added to bug B001"

2. Implement `runBugNotes` handler:
   - Parse `key` (positional arg)
   - Call `noteSvc.GetNotes(ctx, "bug", key)`
   - Render table or JSON of notes

3. Implement `runBugContextSet` handler:
   - Parse `key` (positional arg), `--field` (required), `--value` (required)
   - Call `contextSvc.SetContextField(ctx, "bug", key, field, value)`
   - Output: "Context field 'field' set on bug B001"

4. Implement `runBugContextGet` handler:
   - Parse `key` (positional arg), `--field` (optional)
   - If `--field` provided: call `contextSvc.GetContextField(ctx, "bug", key, field)` and output single value
   - If no `--field`: call `contextSvc.GetContext(ctx, "bug", key)` and render all fields

5. Implement `runBugContextClear` handler:
   - Parse `key` (positional arg), `--field` (required)
   - Call `contextSvc.ClearContextField(ctx, "bug", key, field)`
   - Output: "Context field 'field' cleared on bug B001"

6. Declare all Cobra command variables at package level
7. Declare all flag variables at package level
8. Register all commands in `init()` under appropriate parent commands

# Task: Display Rendering and Error Message Updates

## Goal

Add display rendering support for bug and change-card entities in the terminal output and ensure all error messages use correct entity type names. After this task, `shark get B001` renders with a "Bug: B001" header, `shark get C001` renders with "Change Card: C001", and not-found errors say "bug not found" or "change card not found" (not "task not found").

## Success Criteria

- [ ] `shark get B001` renders with "Bug: B001" section header
- [ ] `shark get C001` renders with "Change Card: C001" section header
- [ ] Bug display includes: title, status, severity, linked entity, timestamps
- [ ] Change-card display includes: title, status, linked entity, timestamps
- [ ] `shark get B999` returns "bug not found: B999" (not "task not found")
- [ ] `shark get C999` returns "change card not found: C999"
- [ ] Invalid key `shark get B` returns error with valid format examples including B### and C###
- [ ] Error entity type mapping: "bug" renders as "Bug", "change" renders as "Change Card"
- [ ] Note search error message includes "bug" and "change" in valid types list
- [ ] `make fmt && make lint && make test` passes with zero failures

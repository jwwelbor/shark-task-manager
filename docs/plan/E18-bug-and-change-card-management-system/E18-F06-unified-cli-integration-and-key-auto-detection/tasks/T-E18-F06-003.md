# Task: Service Layer Dispatch Extension

## Goal

Extend cross-entity services (NoteService, ContextService, ResumeService, ViewService) and workflow configuration to handle bug and change-card entity types. After this task, notes, context, resume, and view operations work for bugs and change-cards through the unified command interface.

## Success Criteria

- [ ] NoteService.GetEntityDetails() handles EntityTypeBug and EntityTypeChange
- [ ] NoteService.resolveEntityID() handles "bug" and "change" entity types
- [ ] ContextService.getContextJSON()/setContextJSON() dispatches to bug/change repositories
- [ ] ViewService.GetFilePath() resolves file paths for ScopeBug and ScopeChange
- [ ] ResumeService.Resume() handles bug and change-card entities (should-have)
- [ ] GetWorkflowForLevel() returns bug and change-card workflow configs
- [ ] CLI output helpers (GetRequiredSectionsForEntityType, FormatEntityCreationJSON) handle "bug" and "change"
- [ ] `make fmt && make lint && make test` passes with zero failures

# Task: Command Layer Dispatch Extension

## Goal

Extend all unified CLI command dispatch points to route B### and C### keys to bug and change-card handlers. After this task, `shark get B001`, `shark delete B001`, `shark update B001`, `shark status advance B001`, and their C### counterparts will correctly invoke the entity-specific handlers defined in F04/F05.

## Success Criteria

- [ ] `shark get B001` dispatches to `runBugGet()` handler (from F04)
- [ ] `shark get C001` dispatches to `runChangeGet()` handler (from F05)
- [ ] `shark delete B001/C001` dispatches to correct entity handlers
- [ ] `shark update B001/C001 --title="x"` dispatches correctly
- [ ] `shark status advance/set/options/history B001/C001` dispatches to correct workflow service
- [ ] `shark context get/set/clear B001/C001` dispatches correctly
- [ ] Default case error messages include B### and C### format examples
- [ ] Service accessors `GetBugService()`/`GetChangeCardService()` exist in `services_global.go`
- [ ] `make fmt && make lint && make test` passes with zero failures

# Task: Key Detection and Model Constants

## Goal

Extend the key detection system and model constants to recognize B### (bug) and C### (change-card) key formats as first-class entity types. This is the foundation layer that all other F06 tasks depend on -- without key detection, no unified command can dispatch to bug or change-card handlers.

## Success Criteria

- [ ] `keys.EntityTypeBug` and `keys.EntityTypeChange` constants exported from `internal/keys/service.go`
- [ ] `keys.Parse()` correctly identifies B### and C### keys (case-insensitive, variable digit count)
- [ ] `keys.IsBugKey()` and `keys.IsChangeKey()` validation helpers exist in `internal/keys/validation.go`
- [ ] `commands.DetectEntityType()` in `internal/cli/commands/helpers.go` returns "bug" for B### and "change" for C###
- [ ] `scope.ParseScope()` in `internal/cli/scope/interpreter.go` handles ScopeBug and ScopeChange
- [ ] `models.EntityTypeBug` and `models.EntityTypeChange` added to `internal/models/entity_note.go`
- [ ] `models.ValidEntityTypes` map includes "bug" and "change" entries
- [ ] All existing key detection tests still pass; new tests added for bug/change patterns
- [ ] `make fmt && make lint && make test` passes with zero failures

## Notes for Agent

- B### and C### keys do NOT support slugs (per PRD out-of-scope decision)
- Entity type string is "change" (not "change-card" or "changecard") per ADR-F06-003
- Keys are case-insensitive: b001 and B001 are equivalent
- Variable digit count: B1, B42, B001, B1000 are all valid

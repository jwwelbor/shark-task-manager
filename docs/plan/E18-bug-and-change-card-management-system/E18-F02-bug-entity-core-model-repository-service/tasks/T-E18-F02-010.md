# Bug Entity Test Suite

## Goal

Verify all model, repository, and service tests are complete, passing, and meet coverage targets. Final validation gate for E18-F02.

## Rationale

Individual tasks include test requirements, but this task ensures the full suite is cohesive, covers all edge cases, and the mandatory quality gate passes.

## Scope

**Test Files:**
- `internal/models/bug_test.go` -- Model/key validation (pure unit)
- `internal/repository/bug_repository_test.go` -- CRUD + filtering (real DB)
- `internal/services/bug_service_test.go` -- Business logic (mocked repos)

**Model Tests:** ValidateBugKey valid/invalid (table-driven), Validate all error paths, severity constants. Target: 100% validation paths.

**Repository Tests:** Create+GetByKey round-trip, case-insensitive, GetNextKey (empty/increment/deletion), Update, UpdateStatus, Delete, List (all filters + combined + empty), Count aggregates, unique constraint. Use B900-B999 range with cleanup.

**Service Tests:** CreateBug (happy, link types, invalid link, severity, title, file rollback), Get/Update/Delete/List (happy + errors), AdvanceBugStatus (happy, terminal, traversal), SetBugStatus (valid, invalid), TriageBug (happy, wrong status, rollback, invalid severity). All mocks use function-field pattern.

## Success Criteria

- [ ] `go test ./internal/models/ -run TestBug -v` passes
- [ ] `go test ./internal/repository/ -run TestBugRepository -v` passes
- [ ] `go test ./internal/services/ -run TestBugService -v` passes
- [ ] Model: 100% validation paths covered
- [ ] Repository: all CRUD, filtering, key generation tested
- [ ] Service: all business logic including error paths
- [ ] No test uses real DB except repository tests
- [ ] Repository tests clean up properly
- [ ] `make fmt && make lint && make test` passes with zero failures

## Validation Gate

`make fmt && make lint && make test` -- zero failures. This is the F02 exit gate.

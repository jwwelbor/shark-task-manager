# Bug Service CRUD Operations

## Goal

Implement GetBug, UpdateBug, DeleteBug, and ListBugs on BugService, completing the basic CRUD surface that F04 CLI commands will consume.

## Rationale

These methods provide standard entity management. ListBugs includes filter conversion from the service DTO to repository filters. They are simpler than CreateBug but necessary for the complete bug lifecycle.

## Scope

**Modified:** `internal/services/bug_service.go` -- Add 4 methods

**Methods:**
- `GetBug(ctx, key)` -- retrieve by key, propagate NotFoundError
- `UpdateBug(ctx, key, BugUpdates)` -- partial update, key immutability, revalidation
- `DeleteBug(ctx, key)` -- delete by key, propagate NotFoundError
- `ListBugs(ctx, BugFilters)` -- convert DTO to repo filters, return empty slice not nil

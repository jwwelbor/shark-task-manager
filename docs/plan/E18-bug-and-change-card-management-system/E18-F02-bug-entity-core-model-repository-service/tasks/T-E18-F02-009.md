# Service Accessor and Context-Note Integration

## Goal

Add `GetBugService()` to services_global.go and update ContextService and NoteService to accept "bug" as a valid entity type.

## Rationale

The accessor is needed by F04 CLI commands. Context/note updates enable Story 7 (notes and context on bugs). These wire the bug entity into existing service infrastructure.

## Scope

**Modified Files:**
- `internal/cli/services_global.go` -- Add GetBugService()
- `internal/services/context_service.go` -- Bug case + BugContextRepo interface
- `internal/services/note_service.go` -- Bug case + BugEntityValidator interface

**GetBugService:** Follow GetTaskService() pattern. Wire BugRepository, workflow (LevelBug), epic/feature/task repos for link validation.

**ContextService:** Add bug case to get/set switch. Define BugContextRepo interface. Update constructor and GetContextService() wiring.

**NoteService:** Add bug case to validation switch. Define BugEntityValidator interface. Update constructor and GetNoteService() wiring.

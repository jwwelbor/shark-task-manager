# Bug Service CreateBug with Link Validation

## Goal

Implement BugService struct, constructor, and `CreateBug` method with auto-key generation, link validation, model validation, markdown file creation, and atomic database persistence.

## Rationale

CreateBug is the most complex service method -- it orchestrates key generation, link validation across 3 entity types, file creation, and transactional persistence. Building it first establishes the service foundation.

## Scope

**New/Modified:** `internal/services/bug_service.go`

**What to Build:**
- BugService struct with all dependencies
- NewBugService constructor (scopes workflow to LevelBug)
- `CreateBug(ctx, CreateBugInput) (*models.Bug, error)` per 04-backend-design.md Section 1.2
- `detectEntityType(key)` and `validateLinkedEntity(ctx, type, key)` private helpers
- Entity type detection: E## = epic, E##-F## = feature, E##-F##-### = task
- Atomic create: transaction wraps DB insert + file creation, rollback on file failure
- Defaults: severity "medium", status from workflow service

# Bug Markdown Template and Entity Type Registration

## Goal

Create the bug markdown template for file generation and register "bug" as a valid entity type in the models package.

## Rationale

The template is needed by CreateBug (T-004) to generate bug report files. EntityTypeBug is needed by context and note services (T-009) to accept "bug" as a valid entity type.

## Scope

**New File:** `templates/bug/bug.md.tmpl` (or the location the templates package expects)
**Modified:** `internal/models/entity_note.go`

**Markdown Template:**
- Frontmatter: key, title, status, severity, linked_entity (conditional)
- Body sections: Reproduction Steps, Expected Behavior, Actual Behavior, Environment, Additional Context
- Placeholder instructional text per section
- Must be loadable via existing templates package (check embed.FS vs filesystem)

**Entity Type Registration:**
- Add EntityTypeBug constant to entity_note.go
- Add to ValidEntityTypes map

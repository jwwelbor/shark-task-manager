# Task: Workflow Level Constants and Engine Extension

## Goal

Add `LevelBug` and `LevelChange` constants to the workflow level system and extend the `MultiLevelWorkflow` struct and `GetWorkflowForLevel()` dispatch to support bug and change-card workflow levels. This unblocks all downstream E18 features that call `workflowSvc.ForLevel("bug")` and `workflowSvc.ForLevel("change")`.

## Success Criteria

- [ ] `LevelBug = "bug"` and `LevelChange = "change"` constants exist in the workflow level const block
- [ ] `MultiLevelWorkflow` struct has `Bug *WorkflowConfig` and `Change *WorkflowConfig` fields
- [ ] `GetWorkflowForLevel("bug")` returns `m.Bug` if non-nil, else `DefaultBugWorkflow()`
- [ ] `GetWorkflowForLevel("change")` returns `m.Change` if non-nil, else `DefaultChangeCardWorkflow()`
- [ ] Existing epic/feature/task dispatch is unchanged (regression-safe)
- [ ] `make fmt && make lint && make test` passes with zero failures

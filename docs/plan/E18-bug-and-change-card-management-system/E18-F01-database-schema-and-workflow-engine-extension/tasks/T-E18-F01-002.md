# Task: Default Bug and Change-Card Workflow Definitions

## Goal

Implement `DefaultBugWorkflow()` and `DefaultChangeCardWorkflow()` functions that return fully specified `*WorkflowConfig` instances with status flows, metadata, progress weights, and special statuses. These defaults serve as fallbacks when `.sharkconfig.json` does not contain bug/change workflow sections.

## Success Criteria

- [ ] `DefaultBugWorkflow()` returns a config with 7 statuses: reported, triaged, in_fix, in_verification, resolved, wont_fix, duplicate
- [ ] Bug status flow transitions match specification (including wont_fix reachable from 4 statuses, duplicate from 2)
- [ ] Bug terminal statuses: resolved, wont_fix, duplicate; start status: reported
- [ ] Bug progress weights: reported=0, triaged=0.2, in_fix=0.5, in_verification=0.8, terminals=1.0
- [ ] `DefaultChangeCardWorkflow()` returns a config with 5 statuses: proposed, approved, in_progress, completed, declined
- [ ] Change-card terminal statuses: completed, declined; start status: proposed
- [ ] Change-card progress weights: proposed=0, approved=0.25, in_progress=0.5, terminals=1.0
- [ ] Backward transitions present: in_verification->in_fix (bug), approved->proposed (change)
- [ ] `make fmt && make lint && make test` passes

# Task: CRUD Commands -- Create, Get, List, Update, Delete

## Goal

Implement the five core CRUD command handlers in `internal/cli/commands/change.go` as thin wrappers over `ChangeCardService`. Each handler follows the three-step pattern: parse arguments/flags, call one service method, format output.

## Success Criteria

- [ ] `shark change create "Title" --link=E07` creates a change-card and outputs key + file path
- [ ] `shark change get C001` displays all fields; `--json` and `--field` work correctly
- [ ] `shark change list` displays a table; `--status` and `--link` filters work; empty results show empty table
- [ ] `shark change update C001 --title="New"` updates and outputs success or JSON
- [ ] `shark change delete C001 --force` deletes immediately; without `--force` prompts for confirmation
- [ ] All commands support `--json` output via `cli.OutputJSON()`
- [ ] Non-existent keys return exit code 1 on get, update, delete
- [ ] Invalid status filter on list returns error listing valid statuses
- [ ] Zero business logic in command handlers
- [ ] `make fmt && make lint && make test` passes

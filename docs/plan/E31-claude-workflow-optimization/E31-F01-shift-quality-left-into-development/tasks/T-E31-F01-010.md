# Measure whole edited files in lint and guard the limits config

## Goal
Make `make lint` and CI measure every function in each changed Go file, state that scope in the local standards, and guard the limits config against loosening.

## Scope
- Files to modify: `Makefile`, `.github/workflows/ci.yml`, `docs/architecture/coding-standards.md`, `internal/sharkdata/dogfood_standards_test.go` (Makefile `lint` target, CI limits step, Quality Limits text)
- Modify only if `main` has moved at the final rebase: `.golangci-limits.yml` (`new-from-rev`)

## Acceptance Criteria
See spec.md AC-14, AC-16, AC-22 (REQ-F-022, 023, 024, 033(a)).
- AC-T1: `.golangci.yml` is unchanged and a main-config failure still fails `make lint`.
- AC-T2: new assertions are seen failing before the Makefile, CI and docs edits.
- AC-T3: every TC-025 mutation fails the test and is reverted with a clean diff.

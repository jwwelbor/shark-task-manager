# Service Accessor Wiring for Bug and ChangeCard

## Goal
Update service accessor wiring in both CLI global accessors and HTTP server wiring to pass EntityService and EntityRepository to the new BugService and ChangeCardService constructors. Remove the now-unnecessary SetEntityHistoryRepo calls from both wiring sites.

## Scope
- Files to modify:
  - `internal/cli/services_global.go`
  - `internal/cli/service_accessors.go`
  - `cmd/server/services.go`

## Acceptance Criteria
See spec.md REQ-F-006 for full acceptance criteria.
- AC-T1: GetBugService() calls GetEntityService() and GetEntityRegistry().MustGetRepository(models.EntityTypeBug)
- AC-T2: GetChangeCardService() follows same pattern for change cards
- AC-T3: No SetEntityHistoryRepo calls remain for Bug or ChangeCard services
- AC-T4: cmd/server/services.go WireServices updated for new constructor signatures
- AC-T5: make build succeeds (compile-time verification of all wiring)

# ChangeCardService EntityService Delegation

## Goal
Refactor ChangeCardService to compose EntityService and delegate SetChangeCardStatus and AdvanceChangeCardStatus transition logic to EntityService.TransitionStatus using SimpleTransitionFeatures(). This follows the identical pattern established by BugService in T-E21-F09-001, ensuring consistency across all entity services.

## Scope
- Files to modify:
  - `internal/services/change_card_service.go`
  - `internal/services/change_card_service_test.go`

## Acceptance Criteria
See spec.md REQ-F-002 for full acceptance criteria.
- AC-T1: ChangeCardService constructor accepts *EntityService and EntityRepository parameters
- AC-T2: SetChangeCardStatus delegates to entitySvc.TransitionStatus with SimpleTransitionFeatures()
- AC-T3: AdvanceChangeCardStatus delegates to entitySvc.GetNextStatus then calls SetChangeCardStatus
- AC-T4: makeResolveActionFn replaces resolveAction method
- AC-T5: recordChangeCardHistory removed (EntityService handles history)
- AC-T6: SetEntityHistoryRepo and entityHistoryRepo field removed
- AC-T7: All existing ChangeCardService tests pass with updated constructor setup

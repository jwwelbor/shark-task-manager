# TaskService GetNextStatus Delegation

## Goal
Refactor TaskService.GetNextStatus to delegate to EntityService.GetNextStatus instead of duplicating the inline implementation that calls GetWorkflowService().GetTransitionInfo and wraps transitions. This eliminates the last piece of duplicated transition logic in TaskService.

## Scope
- Files to modify:
  - `internal/services/task_service.go`
  - `internal/services/task_service_test.go`

## Acceptance Criteria
See spec.md REQ-F-004 for full acceptance criteria.
- AC-T1: TaskService.GetNextStatus calls entitySvc.GetNextStatus with task EntityRepository adapter
- AC-T2: Inline GetWorkflowService().GetTransitionInfo call removed from TaskService.GetNextStatus
- AC-T3: makeResolveActionFn callback passed to entitySvc.GetNextStatus
- AC-T4: All existing GetNextStatus tests pass

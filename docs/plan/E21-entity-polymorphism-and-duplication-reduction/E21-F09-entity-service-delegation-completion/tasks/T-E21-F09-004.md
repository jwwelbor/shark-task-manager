# TaskService Full TransitionStatus Delegation

## Goal
Refactor TaskService.TransitionStatus to delegate the full transition flow to EntityService instead of calling individual helper methods (ValidateAndNormalize, DetectBackward). Create a custom taskEntityRepoAdapter whose UpdateStatus routes through StatusUpdateRaw to preserve agent/reason/documentPath handling. Implement auto-unblock as a post-hook after EntityService returns.

## Scope
- Files to modify:
  - `internal/services/task_service.go`
  - `internal/services/task_service_test.go`

## Acceptance Criteria
See spec.md REQ-F-003 for full acceptance criteria.
- AC-T1: TaskService.TransitionStatus calls entitySvc.TransitionStatus with custom adapter
- AC-T2: taskEntityRepoAdapter.UpdateStatus calls StatusUpdateRaw with agent/reason/documentPath
- AC-T3: Auto-unblock runs as post-hook after successful entitySvc.TransitionStatus
- AC-T4: Auto-unblock does NOT run when entitySvc.TransitionStatus returns error
- AC-T5: ErrForceReasonRequired check removed from TaskService (EntityService handles)
- AC-T6: recordEntityHistory call removed (EntityService handles)
- AC-T7: makeResolveActionFn replaces inline resolveAction
- AC-T8: All existing TaskService transition tests pass

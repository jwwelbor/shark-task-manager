# BugService EntityService Delegation

## Goal
Refactor BugService to compose EntityService and delegate SetBugStatus and AdvanceBugStatus transition logic to EntityService.TransitionStatus using SimpleTransitionFeatures(). This eliminates inline workflow validation, inline history recording, and the standalone resolveAction method, replacing them with the established delegation pattern already used by EpicService and FeatureService.

## Scope
- Files to modify:
  - `internal/services/bug_service.go`
  - `internal/services/bug_service_test.go`

## Acceptance Criteria
See spec.md REQ-F-001 for full acceptance criteria.
- AC-T1: BugService constructor accepts *EntityService and EntityRepository parameters
- AC-T2: SetBugStatus delegates to entitySvc.TransitionStatus with SimpleTransitionFeatures()
- AC-T3: AdvanceBugStatus delegates to entitySvc.GetNextStatus then calls SetBugStatus
- AC-T4: makeResolveActionFn replaces resolveAction method
- AC-T5: recordBugHistory removed (EntityService handles history)
- AC-T6: SetEntityHistoryRepo and entityHistoryRepo field removed
- AC-T7: All existing BugService tests pass with updated constructor setup

## Test Cases
See test-plan.md AC Group 1 (TC-F09-001 through TC-F09-017).

## Design Reference
See spec.md Architecture "BugService Refactoring" section for constructor signature, delegation patterns, and makeResolveActionFn.
Follow existing EpicService delegation pattern in `internal/services/epic_service.go`.

# Task: Update CLI wiring in services_global.go

## Goal

Add `GetEntityRegistry()` function to `services_global.go` with `sync.Once` lazy initialization, and update `GetNoteService()`, `GetContextService()`, `GetResumeService()` to use the shared registry instead of per-entity repository construction and setter method calls. Update `ResetServices()` to reset registry state.

## Requirements

### Functional Requirements

- [ ] Add `GetEntityRegistry() *EntityRegistry` function with `sync.Once` initialization
- [ ] Registry registers all 5 entity types: Epic, Feature, Task, Bug, ChangeCard
- [ ] Each registration uses the `EntityRepository` adapter from F01 wrapping the typed repository
- [ ] `GetEntityRegistry()` panics on DB failure (matching existing `GetDB()` CLI fail-fast pattern)
- [ ] Update `GetNoteService()`: call `NewNoteService(noteRepo, GetEntityRegistry())`
- [ ] Update `GetContextService()`: call `NewContextService(GetEntityRegistry())`
- [ ] Update `GetResumeService()`: pass `GetEntityRegistry()` to constructor, remove `SetBugRepo`/`SetChangeCardRepo` calls
- [ ] Update `ResetServices()`: reset `globalRegistry` and `registryOnce`
- [ ] Add `models` import for `models.EntityTypeEpic`, etc.
- [ ] All per-entity setter calls in `services_global.go` for these 3 services are removed

### Non-Functional Requirements

- [ ] `make fmt && make lint && make test` passes
- [ ] All CLI commands that use notes, context, or resume produce identical behavior
- [ ] Thread-safe: `sync.Once` ensures registry created at most once per CLI invocation

## Implementation Plan

### Files Modified

- `internal/cli/services_global.go` -- main changes

### Steps

1. [ ] Add global variables: `globalRegistry *services.EntityRegistry`, `registryOnce sync.Once`
2. [ ] Implement `GetEntityRegistry()` function:
   ```go
   func GetEntityRegistry() *services.EntityRegistry {
       registryOnce.Do(func() {
           db, err := GetDB(context.Background())
           if err != nil {
               panic(fmt.Sprintf("failed to get database for EntityRegistry: %v", err))
           }
           globalRegistry = services.NewEntityRegistry()
           globalRegistry.Register(models.EntityTypeEpic,
               services.NewEpicRepositoryAdapter(repository.NewEpicRepository(db)))
           globalRegistry.Register(models.EntityTypeFeature,
               services.NewFeatureRepositoryAdapter(repository.NewFeatureRepository(db)))
           globalRegistry.Register(models.EntityTypeTask,
               services.NewTaskRepositoryAdapter(repository.NewTaskRepository(db)))
           globalRegistry.Register(models.EntityTypeBug,
               services.NewBugRepositoryAdapter(repository.NewBugRepository(db)))
           globalRegistry.Register(models.EntityTypeChange,
               services.NewChangeCardRepositoryAdapter(repository.NewChangeCardRepository(db)))
       })
       return globalRegistry
   }
   ```
3. [ ] Update `GetNoteService()`: replace 6 repo constructions + 2 setter calls with `NewNoteService(noteRepo, GetEntityRegistry())`
4. [ ] Update `GetContextService()`: replace 5 repo constructions + 2 setter calls with `NewContextService(GetEntityRegistry())`
5. [ ] Update `GetResumeService()`: add `GetEntityRegistry()` param, remove `SetBugRepo`/`SetChangeCardRepo` calls
6. [ ] Update `ResetServices()`: add `globalRegistry = nil; registryOnce = sync.Once{}`
7. [ ] Add `models` import
8. [ ] Run `make fmt && make lint && make test`
9. [ ] Run end-to-end CLI smoke tests for note, context, and resume operations across all 5 entity types

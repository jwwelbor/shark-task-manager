# Task: Refactor NoteService to use EntityRegistry

## Goal

Refactor NoteService to accept an `*EntityRegistry` (from F01) instead of 5 per-entity repository fields. Replace the two 5-branch switch statements (`resolveEntityID`, `GetEntityDetails`) with single-line registry lookups. Remove all per-entity setter methods. Target: reduce `note_service.go` from ~227 lines to ~120 lines.

## Requirements

### Functional Requirements

- [ ] Remove 5 per-entity repository interfaces: `NoteEpicRepository`, `NoteFeatureRepository`, `NoteTaskRepository`, `NoteChangeCardRepository`, `NoteBugRepository`
- [ ] Replace NoteService struct fields (5 entity repos) with single `registry *EntityRegistry` field
- [ ] Change constructor to `NewNoteService(noteRepo NoteEntityNoteRepository, registry *EntityRegistry)`
- [ ] Constructor must panic if `registry` is nil with message "NoteService: EntityRegistry must not be nil"
- [ ] Replace `resolveEntityID` 5-branch switch with `registry.GetRepository(entityType).GetByKey()` then `entity.GetID()`
- [ ] Replace `GetEntityDetails` 5-branch switch with `registry.GetRepository(entityType).GetByID()` then return `NoteEntityDetails{Key: entity.GetKey(), Name: entity.GetTitle()}`
- [ ] Remove `SetChangeCardRepo()` and `SetBugRepo()` setter methods
- [ ] Preserve existing behavior: `AddNote`, `ListNotes`, `SearchNotes`, `SearchNotesWithTimePeriod` unchanged

### Non-Functional Requirements

- [ ] `make fmt && make lint && make test` passes
- [ ] Net reduction of ~107 lines in note_service.go
- [ ] Zero behavioral changes for existing CLI note operations

### Technical Approach

- `resolveEntityID` becomes: `repo, err := s.registry.GetRepository(entityType)` -> `entity, err := repo.GetByKey(ctx, key)` -> `return entity.GetID(), nil`
- `GetEntityDetails` becomes: `repo, err := s.registry.GetRepository(entityType)` -> `entity, err := repo.GetByID(ctx, entityID)` -> `return &NoteEntityDetails{Key: entity.GetKey(), Name: entity.GetTitle()}`
- `NoteEntityNoteRepository` interface stays unchanged (this is note-specific, not entity-specific)
- `NoteEntityDetails` struct stays unchanged

### Test Pattern

Replace per-entity mock repos with shared `MockEntityRepository` registered in mock registry:

```go
mockEntityRepo := &MockEntityRepository{
    GetByKeyFunc: func(ctx context.Context, key string) (models.Entity, error) {
        return &models.Epic{ID: 42, Key: "E01", Title: "Test Epic"}, nil
    },
}
registry := services.NewEntityRegistry()
registry.Register(models.EntityTypeEpic, mockEntityRepo)
svc := services.NewNoteService(mockNoteRepo, registry)
```

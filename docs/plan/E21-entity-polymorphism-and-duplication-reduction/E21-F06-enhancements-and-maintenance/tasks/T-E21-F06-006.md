# Task: Simplify GetContextService signature to remove vestigial error return

## Goal

After the E21-F01 refactoring, `GetContextService` in `internal/cli/services_global.go` always returns `nil` error (its only dependency is `GetEntityRegistry()` which panics on failure). The `(service, error)` return signature is vestigial. Either simplify to return only `*services.ContextService`, or add a comment explaining the inconsistency.

## Context

Found during E21-F01 code review. `GetNoteService` and `GetResumeService` still genuinely need error returns (they access DB directly), so this is specific to `GetContextService`.

## Implementation Plan

1. Change `GetContextService(ctx context.Context) (*services.ContextService, error)` to `GetContextService() *services.ContextService`
2. Update all callers to remove error handling
3. Alternatively, keep the signature for consistency with other service accessors and add a comment

## Files

- `internal/cli/services_global.go`
- All callers of `GetContextService` (grep for usage)

## Acceptance Criteria

- [ ] `GetContextService` signature simplified or documented
- [ ] All callers updated

# Task: Document Operations Unification

## Goal

Move the document linking operations (LinkDocument, UnlinkDocument, ListRelatedDocumentsByKey) from individual entity services into the shared EntityService. Each of the 5 entity services currently has its own wrapper (~30 lines each) that checks writableDocRepo, looks up the entity by key, and then calls the same shared helper. This is a straightforward extraction that removes ~150 lines of duplication.

Note: An `EntityDocumentService` already exists at `internal/services/entity_document_service.go` with LinkDocument and UnlinkDocument methods. Evaluate whether to extend that or consolidate into EntityService.

## Requirements

### Functional Requirements

- [ ] EntityService has LinkDocument, UnlinkDocument, ListRelatedDocuments methods (or EntityDocumentService is extended)
- [ ] All 5 entity services (Epic, Feature, Task, Bug, ChangeCard) delegate document operations to the shared service
- [ ] Per-entity document wrapper methods removed from entity services
- [ ] All existing document linking behavior preserved (zero behavioral changes)

### Non-Functional Requirements

- [ ] ~150 lines of duplicated code removed (5x ~30-line wrappers)
- [ ] `make fmt && make lint && make test` passes

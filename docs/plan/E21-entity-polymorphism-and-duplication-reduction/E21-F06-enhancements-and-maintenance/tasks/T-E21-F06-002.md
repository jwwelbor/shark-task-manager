# Task: Template Placeholder Unification

## Goal

Create a shared `EntityPlaceholders` base function that generates template placeholders from any `Entity` interface value. Entity-specific placeholder functions (Task, Feature, Epic, Bug, ChangeCard) currently each manually extract the same shared fields (~15 lines each). This task replaces that duplication with a single base function, with entity-specific extensions adding unique fields.

Originally scoped as E21-F05 (cancelled) — reclassified as a task under E21-F06 since scope is small (S-sized, ~75 lines removed).

## Requirements

### Functional Requirements

- [ ] `EntityPlaceholders(entity models.Entity) map[string]string` base function exists
- [ ] Base function generates placeholders for: entity_type, entity_key, entity_title, entity_slug, status
- [ ] Entity-specific placeholder functions (5 total) call `EntityPlaceholders` first, then add unique fields
- [ ] Task-specific: adds agent_type, depends_on, execution_order
- [ ] Bug-specific: adds severity, linked_entity_type, linked_entity_key
- [ ] ChangeCard-specific: adds priority, requested_by, assigned_to
- [ ] Epic/Feature-specific: minimal extensions (mostly shared fields)

### Non-Functional Requirements

- [ ] ~75 lines of duplicated shared-field extraction removed
- [ ] Existing template rendering produces identical output (zero behavioral changes)
- [ ] `make fmt && make lint && make test` passes

## Implementation Plan

### Steps

1. [ ] Create `EntityPlaceholders` base function (in `internal/config/template_helpers.go` or `internal/services/entity_service.go`)
2. [ ] Refactor 5 entity-specific placeholder functions to call base, then add unique fields
3. [ ] Write tests for base `EntityPlaceholders` with mock Entity
4. [ ] Verify existing template rendering produces identical output

### Technical Approach

- Use the Entity interface from F01 for polymorphic field extraction
- Location: likely `internal/config/template_helpers.go` where existing placeholder functions live
- Each entity-specific function becomes: `base := EntityPlaceholders(entity)` + add specific fields

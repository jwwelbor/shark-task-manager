### OBS-2: Not-found error message lacks "not found" text

When running `shark status history E99`, the error message is:
```
Error: failed to get status history: failed to get history for epic E99: sql: no rows in result set
```

The `strings.Contains(err.Error(), "not found")` check at line 574 does not match because the EntityHistoryService wraps the error with "sql: no rows in result set" text. The friendly message path (`cli.Error("Epic E99 not found")`) is never reached. The exit code is still 1 (correct), but the error message is not user-friendly. This is LOW severity and does not block QA approval since exit code behavior is correct.

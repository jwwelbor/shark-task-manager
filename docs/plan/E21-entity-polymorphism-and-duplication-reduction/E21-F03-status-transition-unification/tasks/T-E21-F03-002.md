# Task: EntityService unit tests with parameterized entity types

## Goal

Write comprehensive unit tests for `EntityService` methods (`TransitionStatus`, `ValidateAndNormalize`,
`DetectBackward`, `ResolveActionForStatus`, `GetNextStatus`) with parameterized entity types and
`TransitionFeatures` permutations. Target 85%+ coverage.

## Requirements

### Functional Requirements

- [ ] Create `internal/services/entity_service_test.go`
- [ ] Create `MockEntityRepository` implementing `EntityRepository` interface with function fields
- [ ] Parameterized `TransitionStatus` tests covering entity_types=[epic, feature, task_mock, bug, change_card]
- [ ] Test cases for: happy path forward transition, forced transition with reason, forced without reason (error), backward transition with reason, backward without reason (error), backward detection disabled (SimpleTransitionFeatures), entity not found, repo update error, repo get error, workflow validation error
- [ ] `TransitionFeatures` permutation tests: `DefaultTransitionFeatures()`, `SimpleTransitionFeatures()`, custom combinations
- [ ] `ValidateAndNormalize` tests: valid transition, invalid returns error, forced skips validation, normalization applied
- [ ] `DetectBackward` tests: forward returns false, backward returns true, same status returns false, workflow nil returns false gracefully
- [ ] `ResolveActionForStatus` tests: valid workflow + action, nil workflow returns nil, missing status metadata returns nil, nil OrchestratorAction returns nil, extra placeholders merged
- [ ] `GetNextStatus` tests: entity with available transitions, terminal status, entity not found, action resolution callback invoked per transition

### Non-Functional Requirements

- [ ] 85%+ coverage for all EntityService methods
- [ ] Tests use mocked repositories (no real database)
- [ ] `make fmt && make lint && make test` passes

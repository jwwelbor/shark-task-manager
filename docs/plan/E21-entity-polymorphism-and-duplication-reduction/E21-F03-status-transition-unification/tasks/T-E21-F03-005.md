# Task: TaskService hybrid delegation with shared validation and entity-specific StatusUpdateRaw

## Goal

Refactor `TaskService` to use hybrid delegation: shared validation (`ValidateAndNormalize`, `DetectBackward`)
and action resolution (`ResolveActionForStatus`) from `EntityService`, while retaining the task-specific
`executeStatusTransition` method that calls `StatusUpdateRaw` for atomic task status updates.

## Requirements

### Functional Requirements

- [ ] Add `entitySvc *EntityService` field to TaskService struct
- [ ] Update `NewTaskService` constructor: replace `workflowSvc *workflow.Service` with `entitySvc *EntityService`
- [ ] Remove `workflowSvc` field; route all workflow access through `s.entitySvc.GetWorkflowService()`
- [ ] Refactor `TransitionStatus` to call `s.entitySvc.ValidateAndNormalize()` for shared validation
- [ ] Refactor `TransitionStatus` to call `s.entitySvc.DetectBackward()` for shared backward detection
- [ ] Pass `skipBackwardCheck: true` to `executeStatusTransition` (already done via EntityService)
- [ ] Retain `executeStatusTransition` with `StatusUpdateRaw` call path unchanged
- [ ] Convert `resolveAction` to use `s.entitySvc.ResolveActionForStatus(status, placeholders)` for shared workflow lookup + PopulatedAction construction, keeping task-specific placeholder generation
- [ ] Replace all `s.workflowSvc.XXX` calls with `s.entitySvc.GetWorkflowService().XXX`
- [ ] TaskService does NOT route status updates through `EntityRepository.UpdateStatus` (retains typed repo call)
- [ ] Update all tests in `task_service_test.go` for new constructor signature

### Non-Functional Requirements

- [ ] `make fmt && make lint && make test` passes
- [ ] All existing TaskService tests pass with unchanged behavioral assertions
- [ ] `StatusUpdateRaw` is still called for task transitions (not EntityRepository adapter)
- [ ] Auto-unblocking behavior preserved
- [ ] Feature progress recalculation preserved
- [ ] ~21 lines removed from TaskService (per architecture doc Section 6.7)

## Implementation Plan

### Steps

11. [ ] Run `make fmt && make lint && make test`

### Technical Approach

- Hybrid delegation pattern (ADR-F03-002): shared validation helpers + task-specific atomic update
- `executeStatusTransition` is kept as-is; it already has `skipBackwardCheck` and `force` flags
- `TransitionStatus` now passes `skipBackwardCheck: true` because backward detection is done via EntityService
- `resolveAction` retains task-specific enrichment + document + relationship placeholder logic
- TaskService's `GetNextStatus` optionally uses the typed repo directly (simpler than callback pattern)
- See architecture doc Sections 6.1-6.7 for complete before/after code

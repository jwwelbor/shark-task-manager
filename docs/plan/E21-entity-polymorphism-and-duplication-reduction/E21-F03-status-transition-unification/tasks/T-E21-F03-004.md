# Task: Refactor FeatureService to delegate TransitionStatus to EntityService

## Goal

Refactor `FeatureService` to delegate `TransitionStatus`, `GetNextStatus`, and `resolveAction` to `EntityService`,
reducing inline transition logic from ~82 lines to ~20 lines. Retain only entity-specific post-hooks
(rejection note creation and child task counting).

## Requirements

### Functional Requirements

- [ ] Add `entitySvc *EntityService` and `entityRepo EntityRepository` fields to FeatureService struct
- [ ] Update `NewFeatureService` constructor: replace `workflowSvc *workflow.Service` with `entitySvc *EntityService` + `entityRepo EntityRepository`
- [ ] Remove `workflowSvc` field; route all workflow access through `s.entitySvc.GetWorkflowService()`
- [ ] Replace `TransitionStatus` body with delegation to `s.entitySvc.TransitionStatus()` + post-hooks
- [ ] Post-hook 1: Create rejection note using `s.noteRepo` when `result.IsBackward || result.IsForced` and reason provided
- [ ] Post-hook 2: Count child tasks using `s.taskRepo.ListByFeature(ctx, result.EntityID)`
- [ ] Convert `resolveAction` method to `makeResolveActionFn(ctx)` callback factory with Feature-specific placeholders
- [ ] Replace `GetNextStatus` body with delegation to `s.entitySvc.GetNextStatus()` passing `makeResolveActionFn`
- [ ] Replace all `s.workflowSvc.XXX` calls with `s.entitySvc.GetWorkflowService().XXX`
- [ ] Update all tests in `feature_service_test.go` for new constructor signature

### Non-Functional Requirements

- [ ] `make fmt && make lint && make test` passes
- [ ] All existing FeatureService tests pass with unchanged behavioral assertions
- [ ] TransitionStatus body reduced from ~82 lines to ~20 lines
- [ ] ~105 lines removed from FeatureService (per architecture doc Section 5.4)

## Implementation Plan

### Steps

1. [ ] Add `entitySvc` and `entityRepo` fields to FeatureService struct
2. [ ] Update `NewFeatureService` constructor signature and body
3. [ ] Implement `makeResolveActionFn(ctx)` callback factory (preserves Feature enrichment/placeholder logic)
4. [ ] Replace `TransitionStatus` body with: delegation call + rejection note post-hook + child count post-hook
5. [ ] Replace `GetNextStatus` body with one-line delegation
6. [ ] Replace `ValidateStatus` to route through `entitySvc.GetWorkflowService()`
7. [ ] Replace all other `s.workflowSvc` references throughout FeatureService
8. [ ] Remove `workflowSvc` field from struct and imports
9. [ ] Update `feature_service_test.go`: update all constructor calls to pass `*EntityService` and `EntityRepository` adapter
10. [ ] Run `make fmt && make lint && make test`

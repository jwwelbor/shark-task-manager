# Unify near-duplicate relationship resolution into shared private helper

## Goal

Verify and validate that `resolveTaskRelationships` correctly serves as the single shared helper for all three public service methods, eliminating the duplicated resolve-filter-build pattern and reducing total relationship resolution logic by approximately 50%.

## Scope

- Files to modify:
  - `internal/services/entity_relationship_service.go` (finalize `resolveTaskRelationships` private helper)
  - `internal/services/entity_relationship_service_test.go` (comprehensive coverage of all three public methods via shared helper)

## Acceptance Criteria

See spec.md REQ-3 for full acceptance criteria.

- AC-T1: `resolveTaskRelationships(ctx, rels, selfTaskID)` is the single private helper handling filter/resolve/build for all three public methods
- AC-T2: `GetTaskRelationships`, `GetTaskBlockedBy`, and `GetTaskBlocks` all delegate to `resolveTaskRelationships` after fetching relationships
- AC-T3: No duplicate resolve-and-build loops remain across the three public methods
- AC-T4: `GetTaskBlocks_NoDuplicates` test confirms no duplicate entries when same task appears in both relationship directions

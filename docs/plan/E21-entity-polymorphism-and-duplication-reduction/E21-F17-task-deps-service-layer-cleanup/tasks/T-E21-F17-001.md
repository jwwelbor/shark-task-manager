# Move task relationship helpers from CLI to service layer

## Goal

Extract `getTaskRelationshipsViaEntityRel`, `getTaskBlockedByViaEntityRel`, and `getTaskBlocksViaEntityRel` from `task_deps.go` into `EntityRelationshipService`, making CLI commands thin wrappers that parse args, call service methods, and format output.

## Scope

- Files to modify:
  - `internal/services/entity_relationship_service.go`
  - `internal/cli/commands/task_deps.go`
  - `internal/cli/services_global.go`
- Files to create:
  - `internal/services/entity_relationship_service_test.go` (if not existing)

## Acceptance Criteria

See spec.md REQ-1 for full acceptance criteria.

- AC-T1: `EntityRelationshipService` gains `GetTaskRelationships`, `GetTaskBlockedBy`, and `GetTaskBlocks` methods accepting `context.Context` and `taskID int64`
- AC-T2: `TaskByIDResolver` interface defined in `entity_relationship_service.go` (see spec.md Section 3.1)
- AC-T3: `NewEntityRelationshipService` updated to accept optional `TaskByIDResolver` parameter
- AC-T4: `runTaskDeps`, `runTaskBlockedBy`, `runTaskBlocks` delegate to service methods
- AC-T5: Private helpers removed from `task_deps.go`
- AC-T6: `GetEntityRelationshipService()` in `services_global.go` injects `taskRepo` (see spec.md Section 3.6)

## Test Cases

See test-plan.md service test cases: `GetTaskRelationships_NoRelationships`, `GetTaskRelationships_WithTypeFilter`, `GetTaskRelationships_SkipsNonTaskRelationships`, `GetTaskRelationships_ResolverReturnsError`, `GetTaskBlockedBy_ReturnsDependencies`, `GetTaskBlocks_ReturnsIncomingAndOutgoing`.

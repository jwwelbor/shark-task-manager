# Task: EntityRepository Interface and Adapters

## Goal

Define the EntityRepository interface in `internal/services/entity_repository.go` with 6 methods and create adapter implementations for all 5 entity types that wrap existing typed repositories.

## Success Criteria

- [ ] `EntityRepository` interface defined with: GetByKey, GetByID, UpdateStatus, Update, GetContextData, UpdateContextData
- [ ] All methods accept/return `models.Entity` (polymorphic)
- [ ] 5 adapter files created: Epic, Feature, Task, Bug, ChangeCard
- [ ] Compile-time checks: each adapter satisfies EntityRepository
- [ ] GetByKey/GetByID delegate to typed repo and return models.Entity
- [ ] UpdateStatus converts string to typed status per entity
- [ ] Update rejects wrong concrete type with clear error message
- [ ] Feature/Task adapters use get-set-update pattern for UpdateStatus
- [ ] Bug/ChangeCard adapters use get-set-update for GetContextData/UpdateContextData
- [ ] No changes to existing typed repository interfaces required
- [ ] `internal/services/entity_adapter_test.go` passes with full coverage
- [ ] `make fmt && make lint && make test` passes

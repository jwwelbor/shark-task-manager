# Code Review: T-E21-F01-001 ChangeCard Type Normalization

**Reviewer:** TechLead
**Date:** 2026-03-19
**Status:** APPROVED

## Summary

This task normalizes `ChangeCard.Slug` and `ChangeCard.FilePath` from `string` to `*string`, bringing ChangeCard in line with the Epic, Feature, Task, and Bug models which already use pointer types for these optional fields.

## Detailed Findings

### Correctness

1. **Model layer** (`change_card.go` line 47-48): Both fields are `*string` with `json:"...,omitempty"` and `db:"..."` tags. Consistent with Bug, Task, Feature, and Epic models.

2. **Service creation** (`change_card_service.go` line 128): `Slug` assigned as `&slugVal` (pointer to local variable). This is safe because the local variable lives in the enclosing function scope and the pointer is immediately stored in the struct that outlives the function.

3. **Service creation** (`change_card_service.go` line 152): `FilePath` assigned as `&filePath` -- same pattern, safe.

4. **Delete guard** (`change_card_service.go` line 288): `card.FilePath != nil && *card.FilePath != ""` -- correct double-check prevents nil dereference and empty-string file deletion.

5. **Markdown generation** (`change_card_service.go` line 375-377): `if card.Slug != nil` guard before dereferencing. Correct.

6. **Update method** (`change_card_service.go` line 261-263): `updates.FilePath` is `*string` in the DTO (`change_dto.go` line 32), and it is assigned directly to `card.FilePath`. Since both are `*string`, this is type-safe.

7. **CLI display** (`change_card_commands.go` line 95-97): `card.FilePath != nil && *card.FilePath != ""` guard before display. Correct and consistent with other entity display patterns.

8. **View service** (`view/service.go` line 115-118): `card.FilePath == nil || *card.FilePath == ""` guard with error message. Correct.

9. **Template placeholders** (`template_helpers.go` line 271-276): Both `card.FilePath` and `card.Slug` conditionally added to map only when non-nil. Matches the pattern used for Task, Feature, Epic, and Bug placeholders.

10. **Repository layer** (`change_card_repository.go` line 43, 63, 150): `*string` is passed directly to `database/sql` Scan and Exec. The SQLite driver correctly maps `NULL` to `nil` and vice versa for `*string`. No changes needed in repository.

### Test Coverage

- `TestChangeCardService_CreateChangeCard` (line 249): Verifies `card.Slug == nil || *card.Slug == ""` -- tests the nil case properly.
- `TestChangeCardService_UpdateChangeCard_FilePath` (line 442-449): Verifies pointer assignment round-trip: sets `*string`, checks `card.FilePath == nil || *card.FilePath != newPath`, and validates the captured card in the mock.

### No Missed References

Grep search for `card.Slug` and `card.FilePath` across the entire codebase confirms all access sites use pointer semantics. No remaining code treats these fields as plain `string`.

### Consistency

The change follows the established pattern used by:
- `models.Task` -- `Slug *string`, `FilePath *string`
- `models.Feature` -- `Slug *string`, `FilePath *string`
- `models.Epic` -- `Slug *string`, `FilePath *string`
- `models.Bug` -- `Slug *string`, `FilePath *string`

# Task: Admission gate: admit-scenario.sh

## Goal
Implement `bench/scripts/admit-scenario.sh`, the REQ-F-012 execution gate
running all six named checks against a real checkout, and prove its
rejection logic against seven test-time-mutated copies of
`py-bug-due-date-boundary`. Run it once for real against that seed to write
its first genuine `admission` block — the gate's own verdict, not a
hand-authored one. Also create the shared TC-036 script and its first
(`f2p_p2p`) subtest, using T-E40-F05-008's repro test and reference patch;
T-E40-F05-010, -011, and -013 each append their own family's subtest.

## Scope
- Files to create: `bench/scripts/admit-scenario.sh`; `bench/scripts/tests/tc033_admission_rejection_test.sh`; `bench/scripts/tests/tc036_final_predicate_test.sh` (shared script, `f2p_p2p` subtest)
- Files to modify: `bench/scenarios/packages/py-bug-due-date-boundary/package.yaml` (this task's own real admission run writes its `admission` block); `bench/scripts/tests/run-all.sh` (register both new tests)

## Acceptance Criteria
See spec.md REQ-F-012, REQ-F-013; AC-006 (partial, one family), AC-007.
- AC-T1: seven candidates, each a copy of `py-bug-due-date-boundary` mutated at test time for exactly one trigger, are each rejected naming exactly its own check — (a) build, (b-empty)/(b-fail) both name check (b) despite differing triggers, (c) stage matrix, (d) predicate true at base, (e) predicate false after reference, (f) resource policy field.
- AC-T2: none of the seven mutated candidates appears in any admitted-set output; a candidate accidentally passing all checks fails the test loudly.
- AC-T3: the real, unmutated `py-bug-due-date-boundary` is admitted, and this run writes its `admission` block (`status: admitted`, `base_outcome: false`, `reference_outcome: true`, `toolchain_identity`) into its committed `package.yaml`.
- AC-T4: own TC-036 states for `f2p_p2p` — base (repro fails, false), reference-applied (repro passes + `p2p_selection` green, true), and a dedicated P2P-regression mutation with the repro passing but one `p2p_selection` entry broken (false).

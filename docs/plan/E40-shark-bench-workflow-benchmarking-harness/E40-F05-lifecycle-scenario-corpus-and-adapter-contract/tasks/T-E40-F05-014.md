# Task: Freeze base_sha and authoritative admission

## Goal
With all four seed subjects committed to `bench/fixture-py`, freeze its
final commit as the one shared `base_sha`, update all four packages'
`fixture.base_sha`, write `bench/scripts/verify-fixture-py-base.sh`
confirming the fixture's full unfiltered test suite is green at that SHA,
and re-run `admit-scenario.sh` for real over all four packages so every
`admission` block reflects the frozen SHA — superseding each seed task's
interim run. This spans all four prior seed tasks' committed artifacts, the
workflow's stated TDD exception for a verification suite that cannot be
co-located with a single implementation file.

# Provider-neutral worker adapter and bounded result handoff

## Goal
Provide the narrow host adapter that transports Shark’s rendered prompt unchanged and returns a bounded semantic worker result without leaking credentials, transcripts, or workflow authority.

## Scope
- Files to create and own: `bench/scripts/lifecycle-worker-adapter.sh`, `bench/scripts/tests/tc060_lifecycle_runner_contract_test.sh`, adapter fixtures under `bench/scripts/testdata/lifecycle/`, and the real-binary argv canary used by TC-002/TC-004.
- Files to modify: none.

## Acceptance Criteria
- See `spec.md` AC-002, AC-003, AC-009, and AC-010; see `test-plan.md` TC-002, TC-003, TC-010, and TC-012.
- The adapter preserves worker identity, Shark session identity, control-envelope kind, recommended outcome, bounded evidence, and prompt digest/size while redacting sensitive content.

## Test Cases
See `test-plan.md` TC-002, TC-003, TC-010, and TC-012 and the host-adapter Caller-Path Contracts.

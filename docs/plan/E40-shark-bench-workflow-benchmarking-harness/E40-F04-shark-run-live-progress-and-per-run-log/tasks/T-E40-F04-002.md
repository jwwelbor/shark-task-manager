# LivenessRecorder: plain-mode renderer and per-run log writer

## Goal
Extend `internal/runner/liveness.go` with the plain-mode text renderer (D3's
fixed-column format) and the `run.log` file sink: per-event
open-append-write-close durability (D4), permissions matching
`transcript.go` (0o755/0o644), fail-soft handling matching
`file_jsonl_exporter.go` (`slog.Debug` + swallow), and empty-root no-op
mirroring `NewFileJSONLExporter("")`.

## Scope
- Modify: `internal/runner/liveness.go`, `internal/runner/liveness_test.go`
- REQ-N-004: zero diff to `controller.go`/`transcript.go` (same as T-E40-F04-001).

## Acceptance Criteria
See spec.md AC-04, AC-07 (partial), AC-09, REQ-N-005; test-plan.md TC-014,
TC-019, TC-022, TC-023, TC-028.
- AC-T1: `jsonMode=false` lines (stderr and `run.log`, same renderer) match D3's `<ts>  <event>  <entity_key>  key=value...` format; empty-valued keys omitted entirely.
- AC-T2: writes are `os.OpenFile(path, O_APPEND|O_CREATE|O_WRONLY, 0o644)` per event, no `bufio.Writer`. `os.ReadFile` immediately after an `Observe` call, no flush/close, already contains that line (REQ-F-010).
- AC-T3: `LogPath()` is a real getter (not a stub) returning the resolved absolute `run.log` path used to open the file sink. Empty `projectRoot` disables the file sink only: stderr still fires, no error/panic, `LogPath()` resolves empty. T-E40-F04-003 only *prints* this value; it doesn't resolve it.
- AC-T4: `EACCES`-class write failure is swallowed — `Observe` returns no error, stderr still fires, `slog.Debug` records the failure.
- AC-T5: file mode `0o644`, dir mode `0o755` (skip on windows).

## Test Cases
TC-014 (plain-mode fields), TC-019 (read-before-close durability — no
close/flush before the disk read), TC-022 (empty root), TC-023 (`EACCES`
injection + `slog.Debug`, windows-skipped, perms restored via `t.Cleanup`),
TC-028 (perm bits). Also completes **TC-011's file-content half** deferred
from T-E40-F04-001.

# I-03/X-08 contract tests: liveness producer shape and stdout purity

## Goal
Create `tests/contracts/e40_i03_liveness_contract_test.go` with the two
fixed-name contract tests spec.md D7 requires: `TestTC001_I03LivenessContract`
(I-03 producer shape + per-event durability) and `TestTC002_X08StdoutPurity`
(X-08 stdout purity, two halves). These are the durable, CI-gated artifacts
that discharge this feature's cross-feature and cross-epic obligations —
neither depends on a spawned agent, a scratch project, or the live database.

## Acceptance Criteria
See spec.md AC-02 (full), AC-03 (source-guard half), AC-07 (contract half),
D7, and test-plan.md TC-001, TC-002.
- AC-T1 (TC-001): drive `runner.RunController.Run` in process with the reused
  stub fixtures, `RunOptions{Progress: rec.Observe, ProjectRoot: t.TempDir(),
  RunID: ...}`, capturing stderr via an `os.Pipe` swap. Every captured line
  unmarshals into spec.md D3's schema with `event` in the closed enum.
  `<tmp>/.shark/runs/<run_id>/run.log`, **read from disk before `Finish()` is
  ever called**, already contains the open stage's `stage_start` and its
  latest `heartbeat` — this is the proof of REQ-F-010 durability, not a
  flush-at-end shortcut.
- AC-T2 (TC-002 runtime half): with `os.Stdout` swapped for an `os.Pipe` and
  `cli.GlobalConfig.JSON = true`, the captured byte stream from
  `outputRunResult(result)` decodes via one `json.Decoder.Decode` into exactly
  one `runner.RunResult`; a second `Decode` call returns `io.EOF`.
- AC-T3 (TC-002 source-guard half, widened per test-plan.md's explicit
  strengthening of D7): parse `internal/cli/commands/run.go` with `go/parser`
  and assert every call expression in the following widened class lies
  lexically inside `outputRunResult`'s function body: `fmt.Print`/`Printf`/
  `Println`; `fmt.Fprint*` targeting `os.Stdout`; `os.Stdout.Write`; and any
  call naming `cli.Success`, `cli.Warning`, `cli.Info`, `cli.OutputTable`, or
  `cli.Title`. Do not narrow this back to D7's literal `fmt.Print*`-only
  wording — the widened set is what actually defends X-08 against a future
  `cli.Warning(...)` call landing on the dispatch path (verified during test
  planning: `internal/cli/root.go` shows `Success`/`Warning`/`Info` have no
  `GlobalConfig.JSON` gate, unlike `Error`).
- AC-T4: the source guard also confirms AC-03's specific instance — the
  `--worktree` cleanup `defer`'s warning call is `fmt.Fprintf(os.Stderr, ...)`.

# Preflight fail-closed status and blocker reporting

## Goal
Implement REQ-F-004: make preflight return `status: pass` only when every
selected scenario resolves successfully and every required runtime input is
present and valid, removing `pass_with_dry_run_limitations` from the status
vocabulary so a scenario stuck at `unresolved_gate` can never be reported
provider-ready again.

## Scope
- Files to modify: `bench/scripts/lib/e40_benchmark.py` (`runtime_readiness`
  1596-1627: check replay results, fixture checkout identity, evaluator
  collection, provider command; `_cmd_preflight_locked` 1962-2060: consume the
  structured `resolution-ledger.jsonl` instead of the `re.findall` scrape at
  2004; narrow `status` to `pass`|`blocked`|`preview_failed`; add `blockers[]`,
  `diagnostics[]`; non-zero exit on `status == "blocked"`).
- Files to create: `bench/scripts/tests/tc103_preflight_fail_closed_test.sh`,
  `bench/scripts/tests/tc104_preflight_skipped_scenario_blocker_test.sh`.

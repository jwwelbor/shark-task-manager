# Route resolution separated from live stage evidence

## Goal
Implement REQ-F-005: add a deterministic `resolve-route` mode tracing the
configured success route without live-worker-only artifacts, emit a
structured resolution ledger, and ensure its records are never mistaken for
live I-05 stage evidence.

## Scope
- Modify: `bench/scripts/run-lifecycle.sh` (add `--mode resolve-route`),
  `bench/scripts/run-lifecycle-batch.sh` (emit `resolution-ledger.jsonl`;
  `continue` paths emit `resolution: "skipped"`; invoke `--mode
  resolve-route`), `bench/scripts/verify-stage-evidence.sh` (reject
  `route_resolution_only`).
- Create: `bench/scripts/tests/tc105_route_resolution_without_live_artifacts_test.sh`.

## Acceptance Criteria
spec.md AC-F11-13, AC-F11-14, AC-F11-15 (§Part 1, REQ-F-005).

# Generalize pilot, aggregation, and reporting for six families

## Goal
Implement REQ-F-013: make every downstream lifecycle-v2 consumer (pilot
attestation, aggregation, reports) work with the six-family matrix without a
private family list, keeping zero findings distinct from missing measurements.

  section per selected family; "0 findings" vs "not measured" rendered
  distinctly with the upstream contract gap named), `bench/scripts/aggregate-lifecycle.sh`

  change expected per spec.md §2.5, `require(package, "entity_family", ...)`

  expected; add the `tc112` assertion for six-family derivation).

## Notes for Agent
AC-F11-41/41a are proven by **syscall observation** (`strace -f -qq -y -e
trace=openat,open,unlink,rename`), never by hashing the live database —
hashing reads every byte of the file whose non-reading AC-F11-41a asserts,
which is itself the violation (spec.md §1.2/§7.7.2, third rework,
2026-09-04; this supersedes the `(mtime_ns, size, SHA-256)` before/after
approach this note previously described). No trace record may name
`shark-tasks.db` or its `-wal`/`-shm` siblings; an independent dummy
database created by the test at a scratch path is the required positive
control. The negative case mutates a **disposable copy**, never the live
file. All 17 scrubbed env names must be absent from every child
environment; every resolved `--db` path must lie outside `REPO_ROOT`.

# Task: Native Copilot command assembly and sandbox confinement

## Goal
Implement native command construction for GitHub Copilot CLI in lifecycle-worker-adapter.sh, binding requested model, reasoning effort, and non-interactive flags while enforcing strict scenario scratch root containment.

## Scope
- Implementation files: bench/scripts/lifecycle-worker-adapter.sh
- Test files: bench/scripts/tests/tc120_copilot_adapter_test.py

## Specification & Test Plan References
- spec.md: Part 1 REQ-F-001, REQ-F-002, REQ-F-007, REQ-NF-001; Part 2 §2.3.1-2.3.3, §2.7; AC-F13-01, AC-F13-02, AC-F13-12
- test-plan.md: §3 (AC-F13-01, AC-F13-02, AC-F13-12); §4.1 TC-F13-01, TC-F13-02, TC-F13-12; §5.1 ISO 25010 Matrix

## Acceptance Criteria
- command_for() detects provider aliases copilot, github-copilot, github_copilot, and github.
- Constructs Copilot CLI argv with --output-format json, --stream off, --model, --disallow-temp-dir, --no-custom-instructions, --no-ask-user, --allow-all-tools, --disable-builtin-mcps, and --no-color.
- Model matches request model exactly; reasoning effort is appended when request effort is specified.
- Appends -C with scenario scratch root from LIFECYCLE_SCRATCH_ROOT or request scratch_root.
- Raises AdapterError when model is missing or empty.

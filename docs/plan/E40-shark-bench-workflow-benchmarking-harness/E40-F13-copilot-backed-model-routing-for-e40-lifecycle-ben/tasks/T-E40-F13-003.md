# Task: Copilot provider usage measurement extraction and cost honesty

## Goal
Extract token usage, active model identifiers, durations, session ID, and credit metrics from Copilot JSONL event streams in provider_measurements() while strictly omitting synthetic USD costs.

## Scope
- Implementation files: bench/scripts/lifecycle-worker-adapter.sh
- Test files: bench/scripts/tests/tc120_copilot_adapter_test.py

## Specification & Test Plan References
- spec.md: Part 1 REQ-F-004, REQ-F-005; Part 2 §2.4.1, §2.5.2, §2.6.1-2.6.2; Part 5 Q012; AC-F13-05, AC-F13-06
- test-plan.md: §3 (AC-F13-05, AC-F13-06); §4.1 TC-F13-05, TC-F13-06

## Acceptance Criteria
- Extracts cumulative prompt_tokens, cache_read, and cache_write from the final session.usage_checkpoint event.
- Extracts duration metrics from result.usage.totalApiDurationMs and sessionDurationMs, and session ID from result.sessionId.
- Collects active models from assistant.message.data.model and lastActiveModel into a sorted model_ids list.
- Preserves raw total_nano_aiu and premium_requests under provider measurements without financial synthesis.
- Strictly omits cost_usd and total_cost_usd, asserting zero USD cost fabrication.

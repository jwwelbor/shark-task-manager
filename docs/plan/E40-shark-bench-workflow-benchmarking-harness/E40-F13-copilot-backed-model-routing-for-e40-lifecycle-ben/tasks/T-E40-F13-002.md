# Task: Copilot JSONL stream parsing and control envelope normalization

## Goal
Implement streaming JSONL event parsing in lifecycle-worker-adapter.sh to decode worker control envelopes from assistant.message events, supporting both structured JSON envelopes and prose outcome fallbacks.

## Scope
- Implementation files: bench/scripts/lifecycle-worker-adapter.sh
- Test files: bench/scripts/tests/tc120_copilot_adapter_test.py

## Specification & Test Plan References
- spec.md: Part 1 REQ-F-003, REQ-NF-003, REQ-NF-004; Part 2 §2.4.1-2.4.2; AC-F13-03, AC-F13-04
- test-plan.md: §3 (AC-F13-03, AC-F13-04); §4.1 TC-F13-03, TC-F13-04; §5.2 TC-F13-14, TC-F13-15

## Acceptance Criteria
- decode_envelope() parses multi-line JSONL streams emitted by copilot --output-format json without unbounded memory buffering.
- Locates assistant.message events and extracts data.content to decode inner JSON control envelope.
- Parses unstructured assistant prose ending with RECOMMENDED OUTCOME: outcome into a valid control envelope.
- Fails closed with AdapterError when neither structured JSON nor outcome pattern is found.
- Safely tolerates malformed intermediate events and ignores irrelevant streaming events.

# Task: Offline determinism and language-neutrality proof

## Goal
Prove, mechanically rather than by convention, that every guard, resolver, and adapter script this
feature built produces byte-identical verdicts across repeated runs with the network disabled and zero
provider calls, and that no generic script branches on language. TDD same-task exception: this is a
feature-level suite exercising multiple already-built scripts, not co-locatable with any single
implementation file (workflow's stated exception).

## Scope
- Create: `bench/scripts/tests/tc059_replay_offline_determinism_test.sh`

## Acceptance Criteria
See spec.md REQ-NF-001, REQ-NF-004; AC-016, AC-019.
- AC-T1: `replay-answer.sh`, `verify-replay-result.sh`, `verify-replay-isolation.sh`, and
  `run-prelude.sh`'s non-dispatch paths each invoked twice with the network disabled (`unshare --net`, or
  the portable `GOPROXY=off` fallback per F05's TC-039/F06's TC-051) produce byte-identical stdout/exit
  code.
- AC-T2: a PATH-stubbed provider's invocation log is empty across both runs of every guard/script.
- AC-T3: `grep -rE 'python|pytest|pip|go test|golangci-lint|go build'` over `run-prelude.sh`,
  `replay-answer.sh`, `verify-replay-result.sh`, and `verify-replay-isolation.sh` returns zero hits.

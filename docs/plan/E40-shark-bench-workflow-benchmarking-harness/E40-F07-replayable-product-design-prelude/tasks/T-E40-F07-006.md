# Task: Bundle-disclosure guard extension

## Goal
Extend `verify-replay-isolation.sh` with the REQ-F-012 bulk-disclosure guard — proving the replay bundle
and any content-digest-identical copy are absent from both agent-visible roots at every dispatch, while a
single entry-at-a-time supply remains permitted.

## Scope
- Modify: `bench/scripts/verify-replay-isolation.sh`. Create:
  `bench/scripts/tests/tc056_bundle_disclosure_test.sh`, planted-leak and clean-roots fixtures under
  `bench/scripts/testdata/replay/`

## Acceptance Criteria
See spec.md REQ-F-012; AC-009.
- AC-T1: `verify-replay-isolation.sh <bundle_path> <fixture_checkout> <scratch_project>` fails naming
  root/path for a bundle planted in the fixture checkout, and independently for a same-content-digest
  renamed copy planted in the scratch project.
- AC-T2: clean roots exit `0` while the resolver still supplies one entry in place, one entry at a time.
- AC-T3: a PATH-stubbed dispatcher records zero invocations on the failing path, proving the check runs
  before any dispatch.

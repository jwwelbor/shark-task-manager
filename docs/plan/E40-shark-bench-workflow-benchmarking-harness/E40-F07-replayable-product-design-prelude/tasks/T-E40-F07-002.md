# Task: entry_digest join-key computation and mutation detection

## Goal
Fix `entry_digest`'s `sha256` computation in `i06-schema.yaml` and extend TC-052 to prove it recomputes
from the stored bundle alone and that a result's lineage-facing digests are a subset of the bundle's
recomputed set — the single join key to I-05.

## Scope
- Modify: `tests/contracts/e40_i06_product_design_replay_contract_test.go`,
  `tests/contracts/testdata/e40_i06/{valid,invalid}/**` (new fixtures only), `bench/replay/i06-schema.yaml`
  (digest computation rule)

## Acceptance Criteria
See spec.md REQ-F-003; AC-002.
- AC-T1: every entry's `entry_digest` recomputes from the stored bundle, excluding the digest field
  itself.
- AC-T2: a one-byte edit to any entry field yields `replay_bundle_mutated` naming the entry.
- AC-T3: a result fixture whose `stages[].consumed_entries[].entry_digest` values are not a subset of the
  bundle's recomputed set is rejected naming the offending digest.

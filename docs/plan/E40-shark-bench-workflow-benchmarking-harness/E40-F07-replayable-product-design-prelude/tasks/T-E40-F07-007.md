# Task: Lineage reconciliation (verify-replay-result.sh scaffold)

## Goal
Stand up `verify-replay-result.sh` — the single named owner of I-06 result arithmetic that later tasks
extend — and implement its first portion: reconciling every artifact's claimed consumption against the
resolver's own ledger, keeping `unresolved_gate` and `unattributed_artifact` distinguishable.

## Scope
- Create: `bench/scripts/verify-replay-result.sh`, `bench/scripts/tests/tc055_lineage_reconciliation_test.sh`,
  lineage-case fixtures under `bench/scripts/testdata/replay/`

## Acceptance Criteria
See spec.md REQ-F-009; AC-006.
- AC-T1: an artifact claiming a consumption absent from the resolver ledger is rejected
  `unattributed_artifact` naming the entry.
- AC-T2: a stage producing an artifact having consumed zero `required: true` entries is rejected
  `unattributed_artifact` naming the stage.
- AC-T3: a run that stopped for a missing entry is reported `unresolved_gate` — never
  `unattributed_artifact`, and never the reverse.

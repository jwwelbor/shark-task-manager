Create `bench/scripts/testdata/aggregate/gen_fixtures.py`: a python3 generator that reads both committed I-02 goldens **fresh at test-run time** and emits derived fixture records for the `tc018`/`tc019` suites, per REQ-N-006/ADR-F03-08's rewrite/preserve contract — never a hand-authored or pre-committed static fixture.

## Scope

## Acceptance Criteria

# Task: Batch runner: matrix driver, resume, and quarantine

## Goal
Implement `run-batch.sh`: enumerate every admitted corpus item × the default variant × N reps, classify each target directory (pending / already-complete / `incomplete_prior_attempt`), invoke `run-one.sh` for pending pairs only, quarantine stale attempts under `--reclaim-incomplete`, and emit a JSON summary naming every pair's classification. One pair's failure never aborts the batch.

## Scope
- Create: `bench/scripts/run-batch.sh`, `bench/scripts/tests/tc017_run_batch_test.sh`, `bench/scripts/testdata/stubs/run-one` (env-var-configurable stub: canned record file, exit status, JSONL invocation log, echo-capture mode)
- Modify: `bench/scripts/tests/run-all.sh` (register `tc017`)

## Acceptance Criteria
See spec.md AC-01..AC-05; REQ-F-001..006, REQ-N-001/002.
- Item list comes from `corpus.yaml`'s `items:` only — `negative_items:` are never dispatched (REQ-F-005).
- "Directory present, `record.jsonl` absent" is its own `incomplete_prior_attempt` classification, never folded into "not yet run" (REQ-F-003) — the ADR-F03-07 defense against E40-F02's F-3/F-5 gaps.
- Quarantine is a **move** to `.incomplete/<item>/<variant>/rep-<n>-<seq>/`, byte-identical contents, never a delete (REQ-F-006).
- `RUN_ONE_BIN` defaults to `$SCRIPT_DIR/run-one.sh` (sibling path) when unset — never a bare `PATH`-resolved name (TD-077's defect class; binding decision note).

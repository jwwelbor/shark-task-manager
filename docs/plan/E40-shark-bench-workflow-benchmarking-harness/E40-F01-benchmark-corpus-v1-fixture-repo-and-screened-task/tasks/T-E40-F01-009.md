# Task: Ledger diff and toolchain-guard tool

## Goal
Implement `diff-ledgers.sh`, the single tool E40-F02 will invoke instead of re-deriving REQ-F-011's diff semantics: multiset lint-issue diffing floored at zero, test regression/removed classification, and a toolchain-guard mode that is the sole named owner of REQ-F-010's fail-closed comparison.

## Scope
- Files to create: `bench/scripts/diff-ledgers.sh` with two invocation shapes — `--kind=<lint|test> --base=<f> --post=<f>` and `--toolchain-guard --base=<f>`; committed synthetic ledger fixtures for TC-009/TC-010 under `bench/scripts/testdata/` (kept outside the shark module's own `./...`, same as held-back F2P sources); `bench/scripts/tests/tc008_lint_position_shift_test.sh`; `bench/scripts/tests/tc009_lint_diff_boundary_test.sh`; `bench/scripts/tests/tc010_test_diff_transitions_test.sh`; `bench/scripts/tests/tc011_toolchain_guard_test.sh`
- Files to modify: `bench/scripts/tests/run-all.sh` (register all four new test scripts, per the T-E40-F01-005 convention)

## Acceptance Criteria
See spec.md AC-007, AC-008, AC-009, AC-010; REQ-F-010, REQ-F-011.
- AC-T1: `--kind=lint` computes the multiset difference over the `(from_linter, path, issue text)` identity, floored at zero; a duplicated identity in the base ledger is preserved at its own depth, not collapsed to one.
- AC-T2: `--kind=test` reports `pass`→`fail` as a regression, a base-present/post-absent entry as removed (never as a regression, never silently dropped), and never reports `fail`→`fail` or `skip`→`fail` as a regression.
- AC-T3: `--toolchain-guard` reads the ledger's recorded toolchain block and the live environment, and exits non-zero naming the specific mismatched axis (Go version, `golangci-lint` version, `GOOS`/`GOARCH`, `.golangci.yml` hash) before either diff mode runs; `build-ledgers.sh` never performs this comparison.
- AC-T4: Editing the fixture to shift an existing issue's line, then its column, independently, each reports zero new issues (identity excludes both).

## Test Cases
TC-008 (`tc008_lint_position_shift_test.sh`; real fixture edit + real `golangci-lint`, line and column shift independently); TC-009 (`tc009_lint_diff_boundary_test.sh`; synthetic lint ledgers, 0/1/N/duplicate/net-negative boundary set, pure JSON in/out, no subprocess); TC-010 (`tc010_test_diff_transitions_test.sh`; synthetic test ledgers, all five base/post transition pairs); TC-011 (`tc011_toolchain_guard_test.sh`; toolchain-guard, all four mismatch axes via a stub `go`/`golangci-lint` on `PATH`, real subprocess invocation — do not mock the version string).

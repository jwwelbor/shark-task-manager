# Task: Admission gate reproducibility and offline hardening

## Goal
Extend `admit.sh` (T-E40-F01-006) with the two remaining non-functional guarantees the corpus's Success Metric depends on: byte-identical verdicts across two independently provisioned checkouts of the same base SHA, and a loud, no-fallback failure when run offline without the pinned `golangci-lint` present.

## Scope
- Files to modify: `bench/scripts/admit.sh` (no behavioral change to the five checks themselves; add/confirm deterministic sort order and tool-presence checking before any subprocess call); `bench/scripts/tests/run-all.sh` (register the two new test scripts, per the T-E40-F01-005 convention)
- Files to create: `bench/scripts/tests/tc006_admit_reproducibility_test.sh`; `bench/scripts/tests/tc013_admit_offline_test.sh`

## Acceptance Criteria
See spec.md AC-005; REQ-F-005, REQ-F-012, REQ-NF-005.
- AC-T1: Running `admit.sh` over the full candidate set (admitted + negative + the two transient TC-005 candidates) twice, against two separately provisioned `checkout-fixture.sh` temp checkouts, produces byte-identical verdict output both times.
- AC-T2: With the Go module cache warm and network access blocked, a full-corpus run with the pinned `golangci-lint v2.9.0` present completes; with the pinned binary absent from `PATH`, the run fails naming the missing tool and never falls back to `Makefile:108`'s `curl`-based installer.
- AC-T3: No outbound network connection attempt occurs in either offline case.

## Test Cases
TC-006 (`tc006_admit_reproducibility_test.sh`; state transition, re-run stability across two independent checkouts — do not memoize or cache verdicts between invocations); TC-013 (`tc013_admit_offline_test.sh`; attack-class enumeration, offline + missing pinned tool — real network isolation via `unshare --net` on Linux or a `GOPROXY=off`/poisoned-proxy fallback, not a code-level "offline mode" flag).

# Task: Fixture repo scaffold and submodule wiring

## Goal
Create the standalone fixture Go repository (separate from shark), commit an initial base state, and wire it into this repo as a git submodule at `bench/fixture-repo/`, with a real test suite exercising all three terminal test outcomes ledgers must record. This is the foundation every later E40-F01 task builds against.

## Scope
- Files to create: `.gitmodules`; `bench/fixture-repo/` (submodule pointer at this task's initial fixture commit)
- The standalone fixture repo's own `go.mod`, `Makefile`, `.golangci.yml`, service source, and test suite (owned by that separate repository, referenced here only by its commit SHA)
- No files touched under `internal/` or `cmd/`

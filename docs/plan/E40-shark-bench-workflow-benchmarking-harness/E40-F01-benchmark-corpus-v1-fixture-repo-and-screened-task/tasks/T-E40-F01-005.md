# Task: Checkout and clean-checkout verification scripts

## Goal
Implement `checkout-fixture.sh` (clone-and-checkout the fixture at a given base SHA into a temp dir, shared by every later Tier 2 script) and `verify-clean-checkout.sh` (proves held-back tests never leak into a checkout), with `checkout-fixture.sh`'s own exit path invoking the verifier unconditionally so the invisibility guarantee reaches every current and future caller structurally.

## Scope
- Files to create: `bench/scripts/checkout-fixture.sh` (`checkout-fixture.sh <base_sha> <dest_dir>`); `bench/scripts/verify-clean-checkout.sh` (`verify-clean-checkout.sh <checkout_dir> <corpus_yaml_path>`); `bench/scripts/tests/tc003_clean_checkout_test.sh` (the TC-003 test, invoking both scripts against a real checkout); `bench/scripts/tests/run-all.sh` (the Tier 1b/Tier 2 self-test runner every later script task's own `tc0NN_*_test.sh` registers into)

**Tier 1b/Tier 2 test convention (binding for T-E40-F01-006 through -009):** every Tier 1b/Tier 2 TC is a standalone, executable bash script at `bench/scripts/tests/tc0NN_<slug>_test.sh` that exits non-zero on failure; `run-all.sh` invokes each in sequence and is the "bench self-test wrapper" test-plan.md's Test tiers table names.

## Acceptance Criteria
See spec.md AC-001; REQ-F-001, REQ-F-004.
- AC-T1: `verify-clean-checkout.sh` derives every held-back F2P file name and test name across all admitted and negative items in `<corpus_yaml_path>`, greps `<checkout_dir>` for each, fails naming the first hit, and prints `CLEAN` on success.
- AC-T2: `checkout-fixture.sh` invokes `verify-clean-checkout.sh` unconditionally on every checkout it produces — not merely available for manual use.
- AC-T3: A deliberately-seeded copy of one held-back file into a checkout is detected and named on a direct re-invocation of `verify-clean-checkout.sh`.

## Test Cases
TC-003 (test-plan.md AC test matrix): `bench/scripts/tests/tc003_clean_checkout_test.sh` runs `checkout-fixture.sh <base_sha> <dest_dir>` then `verify-clean-checkout.sh <dest_dir> bench/corpus/corpus.yaml`, asserting `CLEAN`; also asserts `checkout-fixture.sh` itself invokes the verifier (not merely that it exists), and that a seeded leak is caught on direct re-invocation.

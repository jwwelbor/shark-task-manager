# I-05 bundle writer scaffold: CLI option, bundle.json triad, and reset

## Goal
Add `--i05-bundle-dir` and stand up the `I05BundleWriter` scaffold inside
`run-lifecycle.sh`'s dispatch loop: the `bundle.json` triad (initial write,
per-dispatch rewrite, termination rewrite), the producer-owned reset, and
REQ-F-014's additive join-field emission (`run_id`, `scenario_id`,
`scenario_version`, `roots`, `dispatches`) from the same in-process objects
the loop already holds. This task owns that emission surface for
AC-019/TC-021 — TC-021's end-to-end proof runs in T-E40-F12-007, not here.

# TD-132: content_root and walk-based digest scheme

`shark_content_digest` with a walk-based digest of a real `content_root`,
and mark the scheme change so pre/post-change baselines are never mixed.

## Brownfield Context
TD-132 is a design decision (Finding 5): `content_digest()` hashes
directory contents; the legacy scheme hashes the whole-repo git tree.
ADR-F12-03 targets the installed Shark-data tree.

## Notes for Agent
A half-wiring (`content_root` declared, legacy digest kept) is forbidden
(spec.md §1.4): it guarantees `identity_mismatch` every run. A record
lacking `content_digest_scheme` is treated as legacy, never as `walk_v1`.

# pilot-ledger.sh attestation recorder and verifier

## Goal
Build the offline pilot-inspection attestation ledger: `--record` writes one
operator attestation per scenario family (inspected run reference, checklist
results, operator identity, inspected-artifact digests) into
`pilot-ledger.jsonl`; `--verify` re-checks recorded digests against retained
artifacts and reports per-family pass/fail, wired into `--mode baseline`'s
whole-command refusal via `spend-gate.sh`.

## Scope
- Files to create: `bench/scripts/pilot-ledger.sh`;
  `bench/scripts/tests/tc081_pilot_ledger_gate_test.sh`.
- Files to modify: `bench/scripts/lib/spend-gate.sh` (wire the pilot-ledger
  check into the `--mode baseline` refusal path).

## Acceptance Criteria
See spec.md REQ-F-005, ADR-F10-09. Reference AC-004.
- AC-T1: `--mode baseline` refuses as a whole command (not per-family
  dispatch filtering) when any requested family lacks a verified,
  digest-current attestation, naming every failing family.
- AC-T2: Mutating a retained artifact after attestation invalidates a
  previously-verified attestation on the next `--verify`.

The gate is an artifact-digest attestation, not a boolean flag — a run-id
reference alone cannot detect a later change to retained evidence
(ADR-F10-09).

## UAT Rejection (2026-08-21)

**Classification:** AC Violation
**Defect class:** Required retained artifacts with no source are materialized as placeholders and accepted as complete instead of failing closed.
**Unmet criteria:** AC-004 — baseline requires a verified attestation of the inspected retained artifacts.

**What happened:** The schema instructs the ledger to treat an empty `source_path` on a required artifact as present, allowing attestations over fabricated placeholder evidence.

**Fix required:**

1. Sweep every ledger completeness and digest-verification branch for empty or absent required source provenance.
2. Refuse record/verify and baseline gating when any required artifact lacks a real source provenance.
3. Add per-family tests covering all required missing-source variants.

## UAT Rejection (2026-08-21)

**Classification:** AC Violation
**Defect class:** treating a present file, digest field, or non-empty provenance string as proof of verified source derivation
**Unmet criteria:** AC-005 — "each damaged root fails naming the artifact and reason"

**What happened:** `pilot-ledger.sh` verifies retained-artifact provenance in two places, and neither closes the loop against a forged manifest:
- `:336-348` verifies only that a manifest entry's `source_path` is a non-empty string — it never recomputes or compares the manifest's recorded digest against the actual source content.
- `:539-557` compares retained bytes against the ledger's recorded digest, but still accepts a fabricated or nonexistent non-empty `source_path` as valid provenance, since it never independently verifies the source itself existed and produced that digest.

A forged manifest carrying a non-empty fake `source_path` and a digest that happens to match the retained bytes can therefore pass pilot-ledger verification.

**Fix required:**
1. Enumeration sweep FIRST: search `pilot-ledger.sh` for every place a manifest field (source path, digest, or other provenance claim) is accepted without independent verification against the actual source or retained bytes; fix all of them; list the swept sites in the completion note.
2. At `:336-348`, verify `source_path` refers to a real, reachable source location at record time (not just a non-empty string), consistent with UAT-R3-01's "refuse fabricated placeholder" fix already applied to `lib/retain_pair`.
3. At `:539-557`, in addition to the existing bytes-vs-ledger-digest comparison, cross-check that the manifest's claimed `source_path` is consistent with the retention producer's own recorded provenance (i.e., don't accept a digest match alone as proof the file was legitimately sourced).

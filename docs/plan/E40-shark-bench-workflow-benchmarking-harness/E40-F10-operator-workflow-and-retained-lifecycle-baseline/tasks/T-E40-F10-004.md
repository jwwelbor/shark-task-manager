# run-lifecycle-batch.sh operator batch driver

## Goal
Build the operator batch driver: `--mode preview|pilot|baseline` (with
`--dry-run` as a preview alias), matrix enumeration, `run-batch.sh`-style
non-aborting classification, `spend-gate.sh` sourcing, per-pair invocation of
`run-lifecycle.sh` and `evaluate-lifecycle.sh`, and byte-preserving retention
under the operator-declared `--retention-root`. Also builds the shared
PATH-shim provider/network-denial harness used by TC-079/TC-080/TC-090.

## Scope
- Files to create: `bench/scripts/run-lifecycle-batch.sh`;
  `bench/scripts/tests/tc079_operator_preview_zero_spend_test.sh` (batch
  half); `bench/scripts/tests/lib/path-shim-denial.sh` (shared harness,
  backed by the schema's enumerated binary list from T-001).

## Acceptance Criteria
See spec.md REQ-F-001 through REQ-F-004, REQ-F-007 (v1 refusal is
T-E40-F10-008's aggregator concern, not this driver's), REQ-NF-007,
ADR-F10-01. Reference AC-002 (batch half), AC-003 (batch half), AC-004
(retention half), AC-005 (retention-writing half).
- AC-T1: Preview mode invokes `run-lifecycle.sh --mode dry-run` for stage
  resolution and dispatches nothing else; it prints matrix, stages, planned
  calls, root, ceilings, and pilot-ledger state.
- AC-T2: A repeat of an already-retained (scenario, rep) is classified and
  skipped; `--reclaim-incomplete` quarantines rather than deletes.

## UAT Rejection (2026-08-21)

**Classification:** AC Violation
**Defect class:** Required retained artifacts with no source are materialized as placeholders and accepted as complete instead of failing closed.
**Unmet criteria:** AC-005 — retained artifacts are byte-identical to their sources; REQ-F-004 — every required artifact is retained.

**What happened:** The batch driver calls the shared retention helper, which returns success after replacing absent package, lifecycle, evaluation, oracle, evidence, transcript, or entity-history sources with empty retained artifacts.

**Fix required:**

1. Enumerate every retention-helper call and every batch artifact source before fixing the cited batch path.
2. Supply real required sources, including entity history and the held-back oracle, or fail the pair with a schema-owned invalidity before retention and publication.
3. Add end-to-end counterfactual tests proving each absent required source prevents pilot attestation and baseline dispatch.

## UAT Rejection (2026-08-21)

**Classification:** AC Violation
**Defect class:** treating a present file, digest field, or non-empty provenance string as proof of verified source derivation
**Unmet criteria:** AC-005 — "each damaged root fails naming the artifact and reason"

**What happened:** `run-lifecycle-batch.sh`'s "already retained, skip dispatch" reuse fast path (`pair_provenance_ok`, `:872-878`) classifies a pair complete from `evaluation.jsonl` plus an identity-bearing `manifest.json` alone — it does not verify that every required retained artifact is present or that its manifest-recorded digest matches the retained bytes. A forged or partially-copied retention directory with a superficially valid manifest can therefore be treated as complete and skipped rather than refused.

**Fix required:**
1. Enumeration sweep FIRST: search `run-lifecycle-batch.sh` for every reuse/skip/fast-path branch that reads retained-artifact state before dispatch (not just `pair_provenance_ok`); fix all of them; list the swept sites in the completion note.
2. Extend the reuse fast path to verify presence of every artifact enumerated in `bench/reports/lifecycle-baseline-schema.yaml`'s `retention_required_artifacts`, and recompute each artifact's digest against the manifest-recorded value rather than trusting the manifest's own `sha256` field.
3. On any missing artifact or digest mismatch, refuse the reuse and re-dispatch (or fail closed with a named reason), never silently treat the pair as complete.
4. Add a MEDIUM finding to the same sweep: `lib/retain_pair` (`:238-247`) walks source directories with `os.walk`/`shutil.copyfile`, which follows symlinks — a file symlink inside `i05_bundle_dir` can copy content from outside the declared evidence tree into retention. Enforce source-tree containment (reject or resolve-and-verify symlinks) before copying.

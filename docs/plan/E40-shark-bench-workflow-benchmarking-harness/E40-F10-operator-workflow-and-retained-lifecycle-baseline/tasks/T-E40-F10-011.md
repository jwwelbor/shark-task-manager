# report-lifecycle.sh headline view

## Goal
Build the pure renderer's primary product result: `--view headline`, printing
one markdown document to stdout from `aggregate.json` alone — eligibility
verdict, offline-reachable oracle/gate-lineage evidence, time/cost
partitions, review-value block, artifact-use/replay-proxy block, and
three-dimension (quality/time/cost) paired-delta rendering with "no
detectable effect" handling. Renders inline from shell heredoc/template
strings inside `report-lifecycle.sh` itself — no separate
`bench/reports/templates/*` files, so later static scans (T-014,
TC-086/TC-088) target this script directly.

## Scope
- Files to create: `bench/scripts/report-lifecycle.sh` (headline view only;
  stage_diagnostic is T-012); `bench/scripts/tests/tc083_failed_oracle_diagnosis_test.sh`;
  `bench/scripts/tests/tc085_review_value_report_test.sh` (report half, same
  file as T-009's aggregator half); `bench/scripts/tests/tc086_artifact_use_and_replay_proxy_test.sh`
  (report half); `bench/scripts/tests/tc088_dimension_separation_and_noise_band_test.sh`
  (report half, target (ii): scans this script for `forbidden_composite_fields`).

## Acceptance Criteria
See spec.md REQ-F-006, REQ-F-009, REQ-F-012, REQ-F-013, REQ-F-016,
ADR-F10-06, ADR-F10-10. Reference AC-006, AC-008 (report half), AC-009
(report half), AC-011 (report half).
- AC-T1: A completed-workflow/failed-oracle fixture renders as not correct,
  not a false pass inferred from terminal status.
- AC-T2: `precision`/`recall` render as exactly `unavailable`, never `0`;
  every printed value traces to a field already in `aggregate.json` — this
  script computes no new statistic.

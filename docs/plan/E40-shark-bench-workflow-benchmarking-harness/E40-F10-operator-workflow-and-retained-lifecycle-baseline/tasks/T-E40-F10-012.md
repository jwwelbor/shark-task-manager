# report-lifecycle.sh stage_diagnostic view

## Goal
Add the explicitly subordinate `--view stage_diagnostic` to
`report-lifecycle.sh`: full stage-category/interval-category time-cost
partitions, refusing to render without the headline eligibility verdict for
the same scenario and printing that verdict in its own header so a stage
report can never circulate as a standalone product baseline.

## Scope
- Files to modify: `bench/scripts/report-lifecycle.sh` (adds the
  stage_diagnostic view to the file T-011 started).
- Files to create: `bench/scripts/tests/tc084_time_reconciliation_test.sh`
  (report half, same file as T-008's aggregator half).

## Acceptance Criteria
See spec.md REQ-F-009, REQ-F-010, ADR-F10-07. Reference AC-007 (report
half).
- AC-T1: `--view stage_diagnostic` refuses to render if the headline
  eligibility verdict for the same scenario is unavailable, and carries that
  verdict in its header when it does render.
- AC-T2: Both stage-category and interval-category partitions print with an
  explicit `unattributed` line, even at zero.

## UAT Rejection (2026-08-21)

**Classification:** AC Violation
**Defect class:** Required retained artifacts with no source are materialized as placeholders and accepted as complete instead of failing closed.
**Unmet criteria:** AC-001 — retention layout and artifact semantics must support the feature's required byte-preserved evidence contract.

**What happened:** The schema explicitly treats `source_path == ""` for required artifacts as an accepted not-yet-wired state and directs attestation consumers to accept it, contradicting REQ-F-004 through REQ-F-006.

**Fix required:**

1. Sweep every required-artifact schema rule and remove any rule that permits missing source provenance to satisfy retention, attestation, or publication.
2. Define a schema-owned invalidity/refusal for absent required sources.
3. Add contract fixtures proving each required artifact with absent provenance fails.

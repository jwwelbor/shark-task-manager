# aggregate-lifecycle.sh quality, review_value, and artifact_use blocks

## Goal
Extend the aggregator with `quality`, `review_value`, and `artifact_use`
blocks: verbatim I-08 structural/judge/execution_oracle verdicts, the seven
per-gate finding measures by severity/defect class, and produced/consumed/
reused/orphan artifact counts plus labelled replayed D01-D05 proxies.

## Scope
- Files to modify: `bench/scripts/aggregate-lifecycle.sh` (adds these three
  blocks to the file T-008 started).
- Files to create: `bench/scripts/tests/tc085_review_value_report_test.sh`
  (aggregator half); `bench/scripts/tests/tc086_artifact_use_and_replay_proxy_test.sh`
  (aggregator half).

## Acceptance Criteria
See spec.md REQ-F-012, REQ-F-013, ADR-F10-04, ADR-F10-10. Reference AC-008
(aggregator half), AC-009 (aggregator half).
- AC-T1: A gate with no seeded truth set carries `precision`/`recall` as
  `unavailable` in the aggregate, never `0` or an inferred substitute.
- AC-T2: A zero-finding gate and a collection-failure gate are distinguished
  as separate aggregate states, not collapsed.
- AC-T3: Every replay-proxy field in `artifact_use` carries a replayed-proxy
  label at the data level, consumed verbatim by the report task (T-011).

## Round 2 (code-review kickback, REQ-F-008)
`review_value.gates[].elapsed_seconds/provider_cost_usd/resolution_cost_usd`
previously rendered the bare `unavailable` string forever — indistinguishable
from the legitimate no-truth-set case (`precision`/`recall`). Fixed:
- The three fields now render a distinct, schema-owned reason,
  `review_value_gate_time_cost_upstream_gap_reason` in
  `bench/reports/lifecycle-baseline-schema.yaml`, read via
  `schema.get(...)` in `aggregate-lifecycle.sh` (never a private literal —
  REQ-F-018), never the bare `unavailable` string.
- The reason text distinguishes the two actual upstream gap shapes:
  `elapsed_seconds`/`provider_cost_usd` have whole-evaluation
  `elapsed_time`/`provider_cost` sums with no per-gate breakdown; there is no
  `resolution_cost` concept in I-08 at all.
- TC-085's aggregator- and report-half assertions read the same schema key
  and fail if the bare `unavailable` string reappears for these three
  fields.

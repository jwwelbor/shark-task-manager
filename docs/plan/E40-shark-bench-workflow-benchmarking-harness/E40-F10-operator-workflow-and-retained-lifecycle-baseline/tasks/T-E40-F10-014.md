# static safety and scope-boundary scan

## Goal
Build the shared static-scan helper and its four enumerated scans (write-path
assignment-chain tracing, forbidden-path grep, language-branch grep,
content-disclosure pattern list) over every committed F10 script and the
schema file, proving no write outside the declared retention root, no
`internal/`/`cmd/`/`.sharkconfig.json`/`migrations/` change, no
fixture-language branch, and no credential/prompt-body/unbounded-transcript
disclosure.

## Scope
- Files to create: `bench/scripts/tests/lib/static-scan.sh` (shared helper,
  reused by TC-086's and TC-088's scans already written in T-009/T-010/T-011);
  `bench/scripts/tests/tc091_static_safety_language_neutrality_test.sh`.

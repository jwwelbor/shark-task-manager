# offline determinism and 100 MB retention-fixture scale test

## Goal
Prove `aggregate-lifecycle.sh` and `report-lifecycle.sh` are byte-identical,
denial-safe, streaming pure functions, including at REQ-NF-004's 100 MB
scale. No committed 100 MB retention fixture exists anywhere in the
repository today (confirmed by search) and F09's fixture directory holds
only `i08-schema.yaml`/`review-truth-set.json`, not a retention-shaped
tree — so this task **generates** a retention-shaped 100 MB fixture via a
committed generator script rather than reusing or committing a binary blob,
run once at test-fixture setup time, not regenerated per test run.

## Scope
- Files to create: `bench/scripts/tests/tc090_offline_determinism_and_scale_test.sh`;
  `bench/scripts/tests/testdata/gen-100mb-retention-fixture.sh` (deterministic
  generator: same seed produces the same retention tree byte-for-byte).

## Acceptance Criteria
See spec.md REQ-NF-002, REQ-NF-003, REQ-NF-004. Reference AC-013.
- AC-T1: Two runs against the same retention root produce byte-identical
  `aggregate.json` and report markdown output.
- AC-T2: Zero denied calls occur across provider, network, DB, and
  live-working-tree denial surfaces.
- AC-T3: The 100 MB fixture run completes within 60 seconds; peak RSS does
  not exceed 25 MB (or largest-single-file-size + 5 MB if a single retained
  file exceeds 25 MB).

## Test Cases
See test-plan.md TC-090 full body, including the `/usr/bin/time -v` peak-RSS
measurement and the fake-clock injection negative case.

## Integration Contracts
N/A — this task exercises the aggregator/reporter under denial and scale
conditions; it reads no new I-05/I-07/I-08 field beyond what T-008/T-009/
T-011/T-012 already consume.

## Design Reference
See spec.md REQ-NF-004 ("F09 REQ-NF-004 precedent") and Test Infrastructure
section's "New fixtures/helpers required" 100 MB-fixture item.

## Brownfield Context
Reuses the PATH-shim denial harness built in T-004 for the provider/network
legs; adds the DB and live-working-tree denial legs new, matching
`report-baseline.sh`/`aggregate-runs.sh`'s "consults no clock, invokes no
subprocess" header contract.

## Notes for Agent
Streaming, not full-payload loading, is what the 25 MB RSS bound proves — do not read the entire retention tree into memory to compute the aggregate.

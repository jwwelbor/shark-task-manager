## UAT Rejection (2026-08-21)

**Classification:** AC Violation
**Defect class:** treating a present file, digest field, or non-empty provenance string as proof of verified source derivation
**Unmet criteria:** AC-005 — "each damaged root fails naming the artifact and reason"

**What happened:** `aggregate-lifecycle.sh`'s retention-root validation (`:656-707`) checks only that four files (package, lifecycle, evaluation, manifest) are present — it copies the manifest's recorded `sha256` strings into the aggregate without recomputing them against the actual retained artifact bytes. A manifest with a stale or fabricated digest that no longer matches its artifact would pass aggregation and silently propagate an unverified digest into the published aggregate.

**Fix required:**
1. Enumeration sweep FIRST: search `aggregate-lifecycle.sh` for every place a manifest-recorded digest or provenance field is copied into aggregate output without recomputation against the source artifact (not just `:656-707`); fix all of them; list the swept sites in the completion note.
2. At `:656-707`, recompute each retained artifact's digest from the actual file bytes and compare against the manifest's recorded value; refuse (with a named reason, consistent with the "damaged root" acceptance boundary) on mismatch rather than trusting the manifest's own claim.
3. Note this is the same defect class as T-E40-F10-006 and T-E40-F10-007's rejections (pilot-ledger.sh, verify-retention-root.sh) — coordinate the digest-recomputation approach across all three so the aggregate's guarantee is at least as strong as the offline validator's.
4. Also address a paired MEDIUM finding in this file's scope: `aggregate-lifecycle.sh`'s `require()` (`:514-517`) checks only presence/non-empty values at runtime, weaker than the wrong-type rejections the committed contract-test fixtures exercise — crafted aggregates with wrong-typed nested eligibility or lineage values can render instead of failing closed. Tighten runtime validation to match the committed fixture contract.

# Task: Candidate identity check (code/review snapshots)

## Goal
Add `candidate` block validation to `verify-stage-evidence.sh` so a
`code`/`review` snapshot's identity always rests on tree, diff, path, and
test-suite digests together — never on `base_commit` alone.

## Scope
- Modify: `bench/scripts/verify-stage-evidence.sh`
- Create: `bench/scripts/tests/tc045_candidate_identity_test.sh`,
  candidate-case fixtures under `bench/scripts/testdata/evidence/`

## Acceptance Criteria
See spec.md REQ-F-006, REQ-F-007; AC-005.
- AC-T1: a snapshot missing any one of `tree_digest`, `binary_diff_digest`,
  `changed_path_digest`, `dirty_untracked_manifest`, or `test_suite_digest`
  is rejected naming that field (five independent cases).
- AC-T2: two snapshots sharing `base_commit` but differing `tree_digest` are
  reported as distinct candidates, never merged.
- AC-T3: `test_suite_digest` is computed from the adapter's normalized
  `<module-or-package>::<test-name>` id set plus adapter name/version and
  `toolchain_identity` — never from test file contents or language branching.

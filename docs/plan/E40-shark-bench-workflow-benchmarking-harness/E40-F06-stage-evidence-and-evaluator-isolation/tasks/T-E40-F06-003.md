## UAT Rejection (2026-08-15, round 4)

**Classification:** AC Violation
**Defect class:** isolation guards that approximate a declared normalized test identity with a filename-derived token leave renamed semantic leaks undetected.
**Unmet criteria:** AC-009 — the guard must reject every evaluator-only test identity in a fresh checkout and in either live worker-visible root (REQ-F-010, REQ-F-011).

**What happened:** `verify-evidence-roots.sh`'s `test_identity` match kind (`bench/scripts/verify-evidence-roots.sh:212-217,243-261`) derives its search target from the `oracle_tests[]` file's *basename stem* (e.g. `test_recurring` from `test_recurring.py`), not from the actual normalized test identity the file defines (e.g. `test_recurring.py::test_add_task_accepts_recurrence_rule`). A file renamed to something unrelated (`renamed_oracle_identity.py`) that still contains `def test_add_task_accepts_recurrence_rule(): pass` matches none of the three check kinds (filename, content_digest, test_identity) and the guard exits `0` / `CLEAN` — a real held-back oracle test identity leaks into an agent-visible root undetected.

**Reproduction (UAT round 4):** planted `renamed_oracle_identity.py` containing the real `py-feature-recurring-tasks` oracle test function in a clean fixture root; `verify-evidence-roots.sh` exited `0`.

**Fix required:**
1. Before fixing the cited instance, sweep the touched module for every other place a declared identity is approximated by a filename-derived token rather than the actual identity, and list swept sites in the completion note.
2. Derive the normalized test identity(ies) each `oracle_tests[]` file defines through the package's adapter/I-04 identity contract (e.g. `bench/adapters/python/adapter.sh`'s own identity derivation), not via filename/stem heuristics in the generic guard — REQ-F-007 language-neutrality still applies: the generic guard must not itself parse language-specific syntax; delegate identity derivation to the adapter.
3. Reject a match on the derived identity string appearing in either agent-visible root, independent of the file's name or digest.
4. Add a negative test: a renamed, content-different file carrying a held-back test's real identity must be rejected, naming the identity. Preserve existing clean-root and false-positive (AC-T3 rename-changes-target, word-boundary) coverage — do not regress tc043's existing cases.
5. Preserve the report at `docs/review/E40-shark-bench-workflow-benchmarking-harness/E40-F06-stage-evidence-and-evaluator-isolation/uat-20260815T144821Z-E40-F06.md`.

# Task: Offline determinism and language-neutrality proof

## Goal
Prove, mechanically rather than by convention, that every guard this feature
built produces byte-identical verdicts across repeated runs with the network
disabled and zero provider calls, and that no generic guard branches on
fixture language. TDD same-task exception: this is a feature-level suite
exercising multiple already-built guard scripts, not co-locatable with any
single implementation file (workflow's stated exception).

## Scope
- Create: `bench/scripts/tests/tc051_evidence_offline_determinism_test.sh`

## Acceptance Criteria
See spec.md REQ-NF-004, REQ-F-007; AC-016, AC-019.
- AC-T1: `verify-evidence-roots.sh`, `verify-stage-evidence.sh`,
  `replay-stage-evidence.sh`, and `canary-usagemapping.sh` each invoked
  twice with the network disabled (`unshare --net`, or the portable
  `GOPROXY=off` fallback per F05's TC-039) produce byte-identical
  stdout/exit code.

  of all four guards.
- AC-T3: `grep -rE 'python|pytest|pip|go test|golangci-lint|go build'` over
  every generic evidence/isolation/replay script and `tcNNN` test (excluding
  this task's own script and `bench/adapters/*/`) returns zero hits.

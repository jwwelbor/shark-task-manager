# Task: Snapshot replay and immutability guard

## Goal
Build the replay guard that re-evaluates a stored bundle against its named
roots with no worker rerun and no provider call, detecting four independent
drift kinds and proving snapshot content-address immutability.

## Scope
- Create: `bench/scripts/replay-stage-evidence.sh`,
  `bench/scripts/tests/tc049_snapshot_replay_test.sh`, a stored-bundle
  fixture and its four drift-mutation variants under
  `bench/scripts/testdata/evidence/`

## Acceptance Criteria
See spec.md REQ-F-013, REQ-F-015; AC-012, AC-013.
- AC-T1: an edited tracked file is reported `tracked_file_changed`; an added
  untracked file is reported `untracked_file_changed` — both naming the path.
- AC-T2: a changed adapter test-id set is reported `test_suite_changed`
  naming the id; a deleted artifact `consumers` key is reported
  `artifact_consumption_record_missing` naming the artifact.
- AC-T3: a PATH-stubbed provider records zero invocations across all four
  replays.
- AC-T4: recomputing `snapshot_digest` over an unmodified snapshot reproduces
  the recorded value (computation excludes the digest field itself); a
  one-byte edit yields `snapshot_mutated` naming the stage.

## Test Cases
tc049 — test-plan.md AC test matrix rows AC-012, AC-013; Caller-Path
Contracts row tc049.

## Integration Contracts
None — reads only I-05's stored-bundle format and I-04's real `test`
capability, already covered by TC-030.

## Design Reference
spec.md "Stage snapshot (I-05)" `snapshot_digest` row; REQ-F-013 drift
kinds; REQ-F-015.

## Brownfield Context
- Read `bench/evidence/i05-schema.yaml` (T-E40-F06-001) for the stored-bundle
  shape; invoke `bench/adapters/<name>/adapter.sh test` read-only for the
  test-suite-drift case.
- The replay must never shell out to a real worker/provider "to be sure" —
  the stubbed-provider zero-invocation count is the proof, not an assumption.
- Do not implement `verify-stage-evidence.sh`'s live-bundle portions here.

## Notes for Agent
Recomputing the digest **including** `snapshot_digest` itself is the exact
bug AC-013's unmodified-reproduces-recorded case catches.

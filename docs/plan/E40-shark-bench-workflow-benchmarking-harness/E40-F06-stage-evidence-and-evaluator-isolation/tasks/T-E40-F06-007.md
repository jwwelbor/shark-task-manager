# Task: Evaluator access ordering guard

## Goal
Add evaluator-access ordering validation to `verify-stage-evidence.sh` so
held-back oracle material is readable only after its authorized boundary,
through I-04's real `adapter.sh inject-tests`, with every access recorded.

## Scope
- Modify: `bench/scripts/verify-stage-evidence.sh`
- Create: `bench/scripts/tests/tc048_evaluator_access_ordering_test.sh`,
  access-ordering fixtures under `bench/scripts/testdata/evidence/`

## Acceptance Criteria
See spec.md REQ-F-012; AC-011.
- AC-T1: `inject-tests` invoked before terminal status is rejected as
  `isolation_violation`.
- AC-T2: the same invocation after terminal status is accepted, appending
  one `evaluator_access` event `{accessor, artifact_path, digest, phase,
  granted_at}` to `access.jsonl`.
- AC-T3: an in-place oracle read after terminal status is accepted with the
  same event-append guarantee.
- AC-T4: the same read via a pre-completion copy into the worker checkout is
  rejected naming the violation.

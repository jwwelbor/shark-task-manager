# Implement resume-safe results and execution diagnostics

## Goal
Make scheduler state durable and diagnosable through attempt-aware resume, bounded safe evidence/events, complete result conversion, and idempotent terminal recording without owning root routing.

## Scope

- Test in the same task: `internal/team/scheduler_test.go`

# Add durable team-run schema and repository

## Goal
Add the normalized, additive persistence foundation for confirmed team plans and item membership so later scheduling and resume work has an auditable ledger.

## Scope
- Modify: `internal/db/db.go`
- Create: `internal/repository/teamrun/repository.go`, `internal/repository/teamrun/repository_test.go`, `internal/db/team_run_migration_test.go`

- See `spec.md` AC-F01-006 and AC-F01-007; NFR-002 and NFR-007.

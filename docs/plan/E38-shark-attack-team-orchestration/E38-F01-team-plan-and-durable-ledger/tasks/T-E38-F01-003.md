# Build read-only team planner and dependency graph

## Goal
Produce a complete, deterministic, side-effect-free team plan for an epic or feature, including every direct child, normalized dependencies, waves, exclusions, resolved worker metadata, capability mode, and stable hash.

## Scope
- Create: `internal/team/models.go`, `internal/team/interfaces.go`, `internal/team/plan.go`, `internal/team/plan_test.go`, `internal/team/dependency_adapter_test.go`
- Modify: `internal/services/cascade_service.go`, `internal/services/cascade_service_test.go` for the broader child snapshot seam; T001 does not modify these files

## Acceptance Criteria
- See `spec.md` AC-F01-001, AC-F01-002, AC-F01-003, AC-F01-004, AC-F01-005, and AC-F01-008; NFR-001 and NFR-003.
- See `test-plan.md` TC-001, TC-002, TC-003, TC-004, TC-005, TC-008, and TC-013.
- Plans include terminal, claimed, gated, excluded, and dependency-ineligible children exactly once; cycles, missing references, malformed legacy dependencies, and unresolved workflow steps fail typed validation.
- Equivalent input permutations preserve the canonical SHA-256 hash; material state, mode, or capability changes produce drift; planning performs no mutation.

## Test Cases
Write mock-based planner tests first from `test-plan.md` TC-001, TC-002, TC-003, TC-004, TC-005, TC-008, and TC-013. Verify caller-path contracts and forbidden mutation seams rather than testing only private graph helpers.

# Protect role-filtered selection and claim boundaries

## Goal
Lock in the audited role-filtered selection, thin CLI forwarding, and ordinary live-claim conflict behavior through focused owner-seam tests and the smallest correction only if those tests expose a defect.

## Scope
- Modify if a focused test disproves the audit: `internal/services/sprint_service.go`, `internal/cli/commands/sprint.go`, or `internal/services/claim_service.go`.
- Modify: `internal/services/sprint_service_test.go`, `internal/cli/commands/sprint_test.go`, and focused `internal/services/claim_service_test.go` coverage.
- Do not add a claim-next command, scheduler, role store, migration, or alternate workflow engine.

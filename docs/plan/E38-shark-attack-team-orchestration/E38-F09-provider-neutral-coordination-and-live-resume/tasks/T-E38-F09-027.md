**Defect class:** A repair requirement is specified as an executable workflow, but implementation ships only detection and leaves the repair operation absent or unnamed.

**What happened:** `compareParity` detects byte drift, but neither a sync helper nor a named manual synchronization command exists in the implementation, task record, Makefile, or scripts. An operator cannot perform the required drift-repair-and-recheck path.

**Fix required:**

1. Enumeration sweep FIRST: inspect every authored/embedded skill-mirror pair and every parity-gate user for an assumed but undocumented repair operation; list all swept sites in the completion note.
2. Add one runnable, documented synchronization mechanism with explicit source and destination direction, scoped to `skills/shark-attack/` and its embedded mirror.
3. Add a regression test that introduces fixture drift, applies that mechanism (or its factored implementation), and proves the real parity check is clean afterward.

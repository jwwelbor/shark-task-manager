# Define worker control envelope and capability_profile roster schema

## Goal
Define the ephemeral control-envelope contract (`final|question|
needs_council|blocked_external|failed`) and extend the roster schema with a
non-authoritative `capability_profile`, provider-neutral and opaque to the parent.

## Scope
- Create `internal/sharkdata/default_data/skills/shark-attack/context/worker-control-schema.yaml`.
- Modify `internal/sharkdata/default_data/skills/shark-attack/context/roster-schema.yaml` (add
  `capability_profile: fast|balanced|deep` + optional `requirements`; keep
  `model_tier` deprecated) and `internal/sharkdata/embed.go` (allowedMember
  map :1169 + deprecation warning at the `ModelTier` check :987/:1133 — no mapping).
- Append `tests/contracts/e38_f09_interactions_test.go` — TC-003-01..07.

## Notes for Agent

  mints `Q###`, never the worker.

  `model_tier` producing no provider mapping.

  `IssueLevelError` — the default roster still ships `model_tier:` and

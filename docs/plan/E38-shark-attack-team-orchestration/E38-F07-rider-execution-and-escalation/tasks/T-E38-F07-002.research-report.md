# Research report

## Scope

T-E38-F07-002 adds embedded execution guidance only; it does not add a runtime.

## Capability map

| Capability | Source | Decision |
| --- | --- | --- |
| Parent-owned dispatch loop | Shark Rider `run.md` | REUSE |
| Workflow-resolved role selection | `pull-by-role.md` | REUSE |

| Chair execution recipe | F07 specification | NEW |

## Ubiquitous vocabulary

- Chair: council coordinator with escalation authority, never workflow authority.
- Self-pull: selection by resolved workflow role returns a key to ordinary
  `/shark-rider run`; that loop obtains the claimable canonical dispatch response.
- Council record: bounded handoff, decision, or escalation artifact.

## Findings

The embedded skill already supplies all primitives except a single composition
recipe. Its new execution workflow can link the Rider loop to existing role,
escalation, and refresh procedures without duplicating their behavior.

## Decisions

Add `execute.md`, link it from `SKILL.md`, and keep absent-policy escalation on
the existing `council-review` route. No command, provider, or state store changes.

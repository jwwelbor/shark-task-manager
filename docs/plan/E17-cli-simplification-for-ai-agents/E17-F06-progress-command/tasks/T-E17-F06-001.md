# Task: Implement progress command

## Goal

Create `internal/cli/commands/progress.go` -- a new CLI command `shark progress [EPIC] [FEATURE]`
that provides a dedicated, unambiguous entry point for viewing entity progress rollups, health
indicators, task breakdowns, and action items.

This is a near-copy of `status.go` with updated command metadata and renamed internal functions.
No new service logic is required. All computation is already provided by `StatusService.GetDashboard()`.

## Requirements

### Functional Requirements

- [ ] `shark progress` (no args) shows full project progress dashboard
- [ ] `shark progress E05` shows progress filtered to epic E05
- [ ] `shark progress E05 F02` shows progress filtered to feature E05-F02
- [ ] `shark progress E05-F02` handles combined-format feature key (single positional arg)
- [ ] `--epic=E05` flag works as alternative to positional arg
- [ ] `--recent=7d` flag passes RecentWindow to StatusRequest
- [ ] `--include-archived` flag passes IncludeArchived to StatusRequest
- [ ] `--json` routes to `outputProgressJSON`, producing identical structure to `shark status --json`
- [ ] Terminal (no --json) routes to `outputProgressTerminal`, using `status.FormatDashboard()`
- [ ] Positional arg takes precedence over `--epic` flag (matches status.go behavior)
- [ ] `enrichEpicSummaries` is called (from status.go, same package) -- NOT duplicated
- [ ] Error from `GetDashboard` wrapped with `"failed to get progress: %w"`
- [ ] Context nil guard: if `cmd.Context()` is nil, create a 5-second timeout context

### Non-Functional Requirements

- [ ] Thin wrapper: parse -> call service -> format output. Zero business logic in command.
- [ ] No direct repository calls. Only `cli.GetStatusService()` and `cli.GetDisplayService()`.
- [ ] `make fmt && make lint && make test` pass green after implementation.
- [ ] Command completes in < 200ms average.

#### Command definition (verbatim from technical design)

```go
package commands

import (
    "context"
    "encoding/json"
    "fmt"
    "time"

    "github.com/jwwelbor/shark-task-manager/internal/cli"
    "github.com/jwwelbor/shark-task-manager/internal/status"
    "github.com/spf13/cobra"
)

var progressCmd = &cobra.Command{
    Use:     "progress [EPIC] [FEATURE]",
    Short:   "Show progress, health indicators, and task breakdown",
    GroupID: "status",
    Long: `Display a progress dashboard showing project progress, health indicators,
active tasks, and blocked items.

Positional Arguments:
  (no args)       Show full project progress dashboard
  EPIC            Show progress for specific epic (e.g., E04)
  EPIC FEATURE    Show progress for specific feature (e.g., E04 F01 or E04-F01)

Examples:
  shark progress                     Show full project progress dashboard
  shark progress E05                 Show progress for epic E05
  shark progress E05 F02             Show progress for feature E05-F02
  shark progress E05-F02             Show progress for feature E05-F02 (combined format)
  shark progress --epic=E05          Flag syntax (still supported)
  shark progress --recent=7d         Include recent completions (7 days)
  shark progress --json              Output as JSON`,
    RunE: runProgress,
}

func init() {
    cli.RootCmd.AddCommand(progressCmd)
    progressCmd.Flags().String("epic", "", "Filter by epic key")
    progressCmd.Flags().String("recent", "", "Recent completion window (24h, 7d, 30d, 90d)")
    progressCmd.Flags().Bool("include-archived", false, "Include archived epics/features")
}
```

#### Command handler

```go
func runProgress(cmd *cobra.Command, args []string) error {
    req, err := parseProgressRequest(cmd, args)
    if err != nil {
        return err
    }

    ctx := cmd.Context()
    if ctx == nil {
        var cancel func()
        ctx, cancel = context.WithTimeout(context.Background(), 5*time.Second)
        defer cancel()
    }

    dashboard, err := cli.GetStatusService().GetDashboard(ctx, req)
    if err != nil {
        return fmt.Errorf("failed to get progress: %w", err)
    }

    enrichEpicSummaries(dashboard.Epics, cli.GetDisplayService())

    if cli.GlobalConfig.JSON {
        return outputProgressJSON(dashboard)
    }
    return outputProgressTerminal(dashboard)
}
```

#### Argument parsing helper

```go
func parseProgressRequest(cmd *cobra.Command, args []string) (*status.StatusRequest, error) {
    _, positionalEpic, _, err := ParseListArgs(args)
    if err != nil {
        return nil, err
    }

    epicKeyFlag, _ := cmd.Flags().GetString("epic")
    recentWindow, _ := cmd.Flags().GetString("recent")
    includeArchived, _ := cmd.Flags().GetBool("include-archived")

    epicKey := epicKeyFlag
    if positionalEpic != nil {
        epicKey = *positionalEpic
    }

    return &status.StatusRequest{
        EpicKey:         epicKey,
        RecentWindow:    recentWindow,
        IncludeArchived: includeArchived,
    }, nil
}
```

#### Output formatters

```go
func outputProgressJSON(dashboard *status.StatusDashboard) error {
    data, err := json.MarshalIndent(dashboard, "", "  ")
    if err != nil {
        return fmt.Errorf("failed to marshal progress: %w", err)
    }
    fmt.Println(string(data))
    return nil
}

func outputProgressTerminal(dashboard *status.StatusDashboard) error {
    output := status.FormatDashboard(dashboard, cli.GlobalConfig.NoColor)
    fmt.Print(output)
    return nil
}
```

# Task: Split FeatureService into focused services

## Goal

Reduce `feature_service.go` from 1,400 lines to ~450 lines by extracting a progress/analytics sub-service and wiring to the shared `EntityDocumentService` created in T-E17-F14-001.

## Requirements

### Functional Requirements

- [ ] Create `feature_progress_service.go` (~200 lines) — extract: GetProgress, calculateProgressForFeature, RecalculateAndSetProgress, RecalculateAndSetProgressByKey, GetTaskCounts, GetTaskStatusBreakdown, GetTaskStatusBreakdownByFeatureID, GetEnrichedTaskStatusBreakdown, GetStatusBreakdownBatch, GetHealth, GetWorkBreakdown, GetActionItems

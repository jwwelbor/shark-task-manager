# Task: Split TaskService into focused services

## Goal

Reduce `task_service.go` from 2,279 lines to ~450 lines by extracting four sub-services and creating the shared `EntityDocumentService`. The core TaskService retains CRUD and lifecycle methods, delegating everything else to focused sub-services.

## Requirements

### Functional Requirements

- [ ] Create `entity_document_service.go` (~150 lines) — shared service parameterized by entity type, replacing duplicate document Link/Unlink/List methods across Task/Feature/EpicService
- [ ] Create `task_dependency_service.go` (~250 lines) — extract: ValidateDependencies, detectCircularDependency, GetDependencyTree, AddDependency, RemoveDependency, ListDependencies, CreateTypedRelationship, UnlinkFile, UnlinkRelationships, GetTaskRelationships, GetTaskBlockedBy, GetTaskBlocks
- [ ] Create `task_history_service.go` (~150 lines) — extract: GetTaskHistory, ListHistory, GetWorkSessions, GetSessionAnalytics
- [ ] Create `task_query_service.go` (~200 lines) — extract: ListTasks, ListTasksWithPagination, sortTasks, GetTasksByStatus, GetTasksByAgent, GetBlockedTasks, SearchByFile, GetTaskDisplayData
- [ ] Remove `document_helpers.go` — its helpers are absorbed into EntityDocumentService
- [ ] TaskService retains: CreateTask, GetTask, UpdateTask, DeleteTask, StartTask, CompleteTask, ApproveTask, ReopenTask, BlockTask, UnblockTask, TransitionStatus, GetNextStatus, ValidateStatus, GetNextTask, executeStatusTransition, recalculateFeatureProgress, resolveAction
- [ ] TaskService delegates document methods to EntityDocumentService via thin wrapper
- [ ] Update `internal/cli/service_accessors.go` GetTaskService() to wire new sub-services
- [ ] Update `cmd/server/services.go` WireServices() to wire new sub-services

### Non-Functional Requirements

- [ ] task_service.go ≤ 500 lines after extraction
- [ ] All extracted files ≤ 500 lines
- [ ] Zero changes to CLI command files
- [ ] Zero changes to HTTP handler files
- [ ] All existing TaskService method signatures preserved (delegation)

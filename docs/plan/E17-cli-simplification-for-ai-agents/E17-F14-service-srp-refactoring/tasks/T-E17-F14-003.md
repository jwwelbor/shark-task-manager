# Task: Split EpicService into focused services

## Goal

Reduce `epic_service.go` from 1,386 lines to ~450 lines by extracting an analytics/display sub-service and wiring to the shared `EntityDocumentService` created in T-E17-F14-001.

## Requirements

### Functional Requirements

- [ ] Create `epic_analytics_service.go` (~250 lines) — extract: CalculateProgress, GetProgress, GetFeatureRollup, GetTaskStatusRollup, GetImpediments, GetBlockedTasks, GetHealth, GetEpicDisplayData, deriveEpicStatusFromFeatures, unmarshalJSONArray, resolveEpicPathFromLoaded
- [ ] EpicService retains: CRUD (CreateEpic, GetEpic, UpdateEpic, DeleteEpic, ListEpics), lifecycle transitions (TransitionStatus, GetNextStatus, ValidateStatus, resolveAction), CompleteEpic, RecalculateStatus, CascadeStatusToFeaturesAndTasks, key/path resolution (RenameKey, ResolveEpicPath, nextEpicKey, resolveEpicFilePath), GetFeatures, setter delegation
- [ ] EpicService delegates document methods (LinkDocument, UnlinkDocument, GetRelatedDocuments, ListRelatedDocumentsByKey) to shared EntityDocumentService
- [ ] Update `internal/cli/service_accessors.go` GetEpicService() to wire EpicAnalyticsService and EntityDocumentService
- [ ] Update `cmd/server/services.go` WireServices() accordingly

### Non-Functional Requirements

- [ ] epic_service.go ≤ 500 lines after extraction
- [ ] epic_analytics_service.go ≤ 500 lines
- [ ] Zero changes to CLI command files
- [ ] Zero changes to HTTP handler files
- [ ] All existing EpicService method signatures preserved (delegation)

## Implementation Plan

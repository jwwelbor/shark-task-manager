# Task: Field Flag (--field) for Targeted JSON Extraction

## Goal

Add a global `--field <name>` persistent flag that extracts a single named field from any JSON output and prints only that value. For object responses, the field value is printed bare (no JSON wrapping). For array responses, one value per line is printed. Dot-notation paths (e.g., `progress.weighted_pct`) are supported for one level of nesting.

This enables AI agents to extract specific values without piping through `jq`:
```
shark task next --field key          # prints: E07-F01-003
shark get E07-F01-001 --field status # prints: in_progress
shark status E07-F01 --field progress.weighted_pct  # prints: 75.5
```

This task is implemented last in E17-F08 because it builds on the stable JSON output infrastructure from T-003. The key design decision -- making `OutputJSON()` field-aware -- means zero per-command changes are required.

## Requirements

### Functional Requirements

- [ ] `--field <name>` is a global persistent flag available on all commands
- [ ] When `--field` is set, JSON mode is automatically implied (no need to also pass `--json`)
- [ ] For object responses: prints the field value directly (no JSON wrapping)
- [ ] For array responses: prints the extracted field from each element, one per line
- [ ] Strings are printed bare (no quotes): `in_progress` not `"in_progress"`
- [ ] Integers are printed without decimal point: `42` not `42.0`
- [ ] Floats with fractional parts are printed as-is: `78.5`
- [ ] Booleans are printed as `true` or `false`
- [ ] Null values are printed as `null`
- [ ] Nested objects and arrays are printed as compact JSON: `{"a":1,"b":2}`
- [ ] Dot-notation paths traverse one level of nesting: `--field=progress.weighted_pct`
- [ ] When the requested field does not exist in an object, a `FieldNotFoundError` is returned (exit code 4)
- [ ] When extracting from an array, elements missing the field are silently skipped (no error)
- [ ] `CLIError` responses bypass field extraction -- errors always output their full JSON body
- [ ] When `--field` is set and the field is not found, the error is output as JSON (since JSON mode is implied by `--field`)

### Exit Code for Field Not Found

Exit code 4 is used for field-not-found, distinguishing it from:
- Exit code 0: success
- Exit code 1: entity not found
- Exit code 2: database error
- Exit code 3: invalid state

### Behavior with List Commands

List commands returning `{"results": [...], "count": N}`:
- `--field=results` returns the full JSON array
- `--field=count` returns the integer count
- `--field=title` returns `FieldNotFoundError` (title is not a top-level field; no auto-traversal into `results`)

This deliberate design avoids surprising auto-traversal. Agents should use `--field=results` to get the array.

### Non-Functional Requirements

- [ ] Zero per-command changes required (all commands gain `--field` through modified `OutputJSON()`)
- [ ] `make fmt && make lint && make test` passes
- [ ] No regression in commands that do not use `--field`

### Step 5: Add field extraction functions

Add to `internal/cli/root.go` or new `internal/cli/field_output.go`:

```go
// OutputField extracts a named field from data and prints the value.
// For objects: prints the field value.
// For arrays: prints the extracted field from each element, one per line.
// Supports dot-notation: "progress.weighted_pct" traverses nested objects.
func OutputField(data interface{}, fieldPath string) error {
    b, err := json.Marshal(data)
    if err != nil {
        return fmt.Errorf("failed to serialize data: %w", err)
    }
    var parsed interface{}
    if err := json.Unmarshal(b, &parsed); err != nil {
        return fmt.Errorf("failed to parse serialized data: %w", err)
    }
    return extractAndPrintField(parsed, fieldPath)
}

func extractAndPrintField(data interface{}, fieldPath string) error {
    switch v := data.(type) {
    case map[string]interface{}:
        val, err := lookupField(v, fieldPath)
        if err != nil {
            return err
        }
        printFieldValue(val)
        return nil
    case []interface{}:
        for _, item := range v {
            if obj, ok := item.(map[string]interface{}); ok {
                val, err := lookupField(obj, fieldPath)
                if err != nil {
                    continue // Skip array elements that lack the field
                }
                printFieldValue(val)
            }
        }
        return nil
    default:
        return &FieldNotFoundError{Field: fieldPath}
    }
}

// lookupField retrieves the value at fieldPath from obj.
// Supports one level of dot-notation: "parent.child"
func lookupField(obj map[string]interface{}, fieldPath string) (interface{}, error) {
    parts := strings.SplitN(fieldPath, ".", 2)
    val, ok := obj[parts[0]]
    if !ok {
        return nil, &FieldNotFoundError{Field: fieldPath}
    }
    if len(parts) == 2 {
        nested, ok := val.(map[string]interface{})
        if !ok {
            return nil, fmt.Errorf("field %q is not an object, cannot traverse to %q", parts[0], parts[1])
        }
        return lookupField(nested, parts[1])
    }
    return val, nil
}

// printFieldValue prints a field value in a script-friendly format.
// Strings are printed bare (no quotes). Numbers, bools, null use their natural form.
// Nested objects and arrays are re-serialized as compact JSON.
func printFieldValue(val interface{}) {
    switch v := val.(type) {
    case string:
        fmt.Println(v)
    case float64:
        // JSON numbers are float64; print as integer when there is no fractional part
        if v == float64(int64(v)) {
            fmt.Println(int64(v))
        } else {
            fmt.Printf("%g\n", v)
        }
    case bool:
        fmt.Println(v)
    case nil:
        fmt.Println("null")
    default:
        // Arrays and objects: re-serialize as compact JSON
        b, _ := json.Marshal(v)
        fmt.Println(string(b))
    }
}
```

### Step 6: Modify `OutputJSON()` to be field-aware in `internal/cli/root.go`

Replace the existing `OutputJSON()` function with:

```go
// OutputJSON outputs data in JSON format.
// If GlobalConfig.Field is set, extracts and prints only that field value.
// CLIError values bypass field extraction and are always output in full.
func OutputJSON(data interface{}) error {
    // Never apply field extraction to error responses
    if _, isError := data.(*CLIError); isError {
        return outputJSONRaw(data)
    }
    if GlobalConfig.Field != "" {
        return OutputField(data, GlobalConfig.Field)
    }
    return outputJSONRaw(data)
}

// outputJSONRaw writes data as indented JSON to stdout without field filtering.
func outputJSONRaw(data interface{}) error {
    encoder := json.NewEncoder(os.Stdout)
    encoder.SetIndent("", "  ")
    return encoder.Encode(data)
}
```

### Step 7: Handle `FieldNotFoundError` with exit code 4 in `cmd/shark/main.go`

```go
if err := cli.RootCmd.Execute(); err != nil {
    // Check for field not found (exit code 4)
    var fieldErr *cli.FieldNotFoundError
    if errors.As(err, &fieldErr) {
        if cli.GlobalConfig.JSON {
            _ = cli.OutputJSON(&cli.CLIError{
                Error:   true,
                Code:    "FIELD_NOT_FOUND",
                Message: err.Error(),
            })
        } else {
            fmt.Fprintln(os.Stderr, "Error:", err)
        }
        os.Exit(4)
    }

    // Other errors (from T-003)
    if cli.GlobalConfig.JSON {
        _ = cli.OutputJSON(&cli.CLIError{
            Error:   true,
            Code:    cli.ErrCodeCommandError,
            Message: err.Error(),
        })
    } else {
        fmt.Fprintln(os.Stderr, "Error:", err)
    }
    os.Exit(1)
}
```

## Notes

- The key architectural decision: making `OutputJSON()` field-aware means zero per-command changes. Every command in the codebase that calls `cli.OutputJSON(data)` automatically gains `--field` support.
- The `*CLIError` type check in `OutputJSON()` ensures error responses are never field-filtered. Even when `--field=message` is set, a `CLIError` response outputs its full JSON body. Agents need the full error context.
- Dot-notation supports exactly one level: `parent.child`. Deep nesting like `a.b.c` requires two lookups which the recursive `lookupField()` handles. Three levels would require two calls to `SplitN` -- the current implementation handles arbitrary depth via recursion.
- For list commands returning `{"results":[...], "count":N}`: `--field=results` returns the full JSON array (useful for further processing). There is no auto-traversal into array elements at the top level.
- Exit code 4 (`FIELD_NOT_FOUND`) is new and distinguishable from exit code 1 (`ENTITY_NOT_FOUND`). Agents checking the exit code can differentiate between "the task doesn't exist" and "the task exists but doesn't have that field".
- If `root.go` becomes large with all the field extraction functions, they can be extracted to `internal/cli/field_output.go`. This is an implementation-time decision.
- Estimated code change: ~80 lines across 2 files.

# Task: Flag Normalization -- --order and --all as primary flag names

## Goal

Add `--order` as an alias for `--execution-order` on feature commands (task commands already have `--order` as the primary flag), and add `--all` as an alias for `--show-all` on all list commands. Mark the old flag names as deprecated so Cobra prints a deprecation warning to stderr when they are used.

This is a mechanical change with zero logic change. Cobra's `MarkDeprecated()` handles warning output automatically -- no custom suppression needed.

## Requirements

### Functional Requirements

- [ ] `--order` accepted on `feature create` and `feature update` with the same behavior as `--execution-order`
- [ ] `--execution-order` on feature commands continues to work but emits a deprecation warning to stderr: `Flag --execution-order has been deprecated, use --order instead`
- [ ] `--execution-order` on task commands (`task create`, `task update`, `create task`) continues to work but emits a deprecation warning to stderr
- [ ] `--all` accepted on `task list`, `feature list`, and `list` (smart dispatcher) with the same behavior as `--show-all`
- [ ] `--show-all` continues to work on all list commands but emits a deprecation warning to stderr: `Flag --show-all has been deprecated, use --all instead`
- [ ] Deprecation warnings go to stderr only -- never mixed into stdout JSON output
- [ ] `--help` output shows `--order` and `--all` as the primary names; `--execution-order` and `--show-all` do not appear in help
- [ ] Using both `--all` and `--show-all` together produces no error (OR semantics; same result as either alone)

### Non-Functional Requirements

- [ ] All existing tests pass without modification
- [ ] No change to flag semantics, values, or JSON output format
- [ ] `make fmt && make lint && make test` passes after changes


### Sub-task 1b: `--execution-order` on feature commands

**File**: `internal/cli/commands/feature.go`

For `featureCreateCmd` (in `init()`, around line 145): add `--order` alongside `--execution-order`, then mark `--execution-order` deprecated:
```go
featureCreateCmd.Flags().IntVar(&featureCreateExecutionOrder, "execution-order", 0, "Execution order")
featureCreateCmd.Flags().Int("order", 0, "Execution order (shorthand for --execution-order)")
_ = featureCreateCmd.Flags().MarkDeprecated("execution-order", "use --order instead")
```

For `featureUpdateCmd` (around line 165): same pattern:
```go
featureUpdateCmd.Flags().Int("execution-order", -1, "New execution order (-1 = no change)")
featureUpdateCmd.Flags().Int("order", -1, "New execution order (shorthand for --execution-order)")
_ = featureUpdateCmd.Flags().MarkDeprecated("execution-order", "use --order instead")
```

**File**: `internal/cli/commands/feature_helpers.go`

Update `parseFeatureCreateInput()` (or equivalent) to read `--order` with fallback:
```go
execOrder := featureCreateExecutionOrder  // from --execution-order IntVar binding
if orderFlag, _ := cmd.Flags().GetInt("order"); orderFlag != 0 && execOrder == 0 {
    execOrder = orderFlag
}
```

Update the `featureUpdateCmd` handler to merge both flags:
```go
execOrder, _ := cmd.Flags().GetInt("execution-order")
if orderFlag, _ := cmd.Flags().GetInt("order"); orderFlag != -1 && execOrder == -1 {
    execOrder = orderFlag
}
```

**File**: `internal/cli/commands/create.go`

For `createFeatureCmd` (the `shark create feature` alias, around line 108): mark `--execution-order` deprecated and add `--order` alias following the same pattern.

### Sub-task 1c: `--show-all` to `--all` alias

**Pattern for each registration site** -- register both flags, mark old one deprecated:
```go
cmd.Flags().Bool("show-all", false, "Show all tasks including completed")
cmd.Flags().Bool("all", false, "Show all items including completed")
_ = cmd.Flags().MarkDeprecated("show-all", "use --all instead")
```

**Pattern for each read site** -- combine with OR:
```go
showAll, _ := cmd.Flags().GetBool("show-all")
if allFlag, _ := cmd.Flags().GetBool("all"); allFlag {
    showAll = true
}
```

**Registration sites to update**:
- `internal/cli/commands/task_helpers.go` - `registerListFlags()` function
- `internal/cli/commands/feature.go` - `featureListCmd` flags in `init()`
- `internal/cli/commands/list.go` - `listCmd` flags in `init()`

**Read sites to update**:
- `internal/cli/commands/task.go` - `runTaskList()` (around line 105)
- `internal/cli/commands/feature_helpers.go` - `runFeatureList()` / `parseFeatureListFlags()` (around line 1106)
- `internal/cli/commands/list.go` - `runList()` (around line 50)

**Note on propagation in list.go**: The smart dispatcher propagates `--show-all` to child commands via `Flags().Set("show-all", ...)` at lines 89 and 101. After adding `--all`, update the propagation to also set `--all` when the merged value is true.

## Notes

- Cobra's `MarkDeprecated()` automatically hides the flag from `--help` output and writes the deprecation message to `os.Stderr`. No custom suppression code is needed.
- The `--order` alias on task create already exists and the merge logic in `parseCreateTaskInput()` is correct. For task commands, the work is only adding `MarkDeprecated()` calls.
- Deprecation warnings go to stderr by Cobra design. In JSON mode, stdout is clean JSON and stderr may contain the warning. This is acceptable per TC-001-12.
- Estimated code change: ~30 lines across 6 files.

# Task: SHARK_OUTPUT Environment Variable

## Goal

Add support for a `SHARK_OUTPUT=json` environment variable that sets JSON output mode globally for an entire agent session. This eliminates the need for AI agents to pass `--json` on every shark command invocation.

This task was converted from feature E17-F04. Full requirements are documented in `docs/plan/E17-cli-simplification-for-ai-agents/E17-F04-shark-output-environment-variable/feature.md`.

## Requirements

### Functional Requirements

- [ ] Read `SHARK_OUTPUT` environment variable during root command initialization
- [ ] If `SHARK_OUTPUT=json`, set `cli.GlobalConfig.JSON = true` globally
- [ ] `--json` flag takes precedence over env var (flag overrides env var)
- [ ] `SHARK_OUTPUT=table` explicitly selects table output (the default)
- [ ] Invalid values for `SHARK_OUTPUT` are silently ignored (fall through to default)
- [ ] Also read `PM_OUTPUT` as a fallback; `SHARK_OUTPUT` takes precedence over `PM_OUTPUT`
- [ ] Document the env var in the root command's `--help` output

### Non-Functional Requirements

- [ ] Zero latency impact (env var read is negligible)
- [ ] 100% backward compatibility -- no change to default behavior when env var is unset
- [ ] All existing tests pass without modification (`make test` green)

## Implementation Plan

### Steps

1. [ ] Open `internal/cli/root.go`
2. [ ] Locate `PersistentPreRunE` or `initConfig()` where global config is initialized
3. [ ] Add env var check after flag parsing:
   ```go
   // Support SHARK_OUTPUT=json environment variable
   if !cmd.Flags().Changed("json") {
       if val := os.Getenv("SHARK_OUTPUT"); val == "" {
           val = os.Getenv("PM_OUTPUT")
       }
       if val == "json" {
           cli.GlobalConfig.JSON = true
       }
   }
   ```
4. [ ] Update root command `Long` description to document the env var
5. [ ] Run `make fmt && make lint && make test`

### Technical Approach

- Modify `internal/cli/root.go` only -- no other files require changes
- Use `cmd.Flags().Changed("json")` to detect explicit flag usage before reading env var
- `SHARK_OUTPUT` takes precedence over `PM_OUTPUT` (check SHARK_OUTPUT first)
- Cobra flag parsing happens before `PersistentPreRunE`, so `--json` flag value is available when env var is read

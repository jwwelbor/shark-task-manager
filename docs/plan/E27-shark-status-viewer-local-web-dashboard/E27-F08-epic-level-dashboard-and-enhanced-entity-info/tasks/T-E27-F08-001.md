# Rename Info tab to Spec and rewrite properties panel

## Goal

Update `viewer.html` to rename the "Info" toggle-bar button label to "Spec"
(internal ID `ev-tab-info` is preserved) and rewrite `renderPropertiesPanel`
using a dispatch-by-type pattern so every entity type shows its full field
set from cached hierarchy data, including a collapsible orchestrator-action
disclosure block and new CSS rules.

## Scope

- Files to modify:
  - `internal/viewer/assets/viewer.html`

## Acceptance Criteria

See spec.md §1.1 REQ-F-002 (AC-002.1, AC-002.2, AC-002.3) and REQ-F-003
(AC-003.1 through AC-003.10). See spec.md §1.2 REQ-NF-002.
See spec.md §2.7 for line references (Spec label at line 2668, panel at 2399).

- AC-T1: Button inner text reads `Spec`; string `>Info<` is absent.
- AC-T2: `id="ev-tab-info"` preserved; `renderMarkdownPane` still wired.
- AC-T3: `renderPropertiesPanel` uses `pushRow`, `monoCell`, `statusBadgeCell`.
- AC-T4: All five type appenders defined: `appendEpicFields`,
  `appendFeatureFields`, `appendTaskFields`, `appendBugFields`,
  `appendChangeCardFields`.
- AC-T5: `renderOrchestratorDetails` defined; emits `<details class="orch-action">`
  without `open` attribute; `<summary>Orchestrator Action</summary>` present.
- AC-T6: `pushRow` guards null/undefined/empty — no blank rows rendered.
- AC-T7: `copyBtn` helper called for `file_path` and `linked_content_path`.
- AC-T8: CSS for `.orch-action` and `.orch-instruction` appended per spec.md §2.3.

# Add Mermaid CDN, init, and post-render transform with per-block error isolation

## Goal

Wire Mermaid into viewer.html so mermaid fenced blocks render as inline SVGs after marked.parse(), with graceful per-block fallback on syntax error and graceful whole-feature degradation when the CDN is unavailable.

## Scope

- Files to modify: internal/viewer/assets/viewer.html

Five additive edits per spec.md Section 2.5 (no existing logic modified):
- Edit 1: pinned mermaid CDN script tag immediately after marked.min.js (D1, D7)
- Edit 3: initMermaid() + async renderMermaidIn(rootEl) helpers above renderMarkdownFromString (D2, D3, D4, D6)
  - initMermaid: mermaid.initialize with startOnLoad:false, dark theme, securityLevel:strict; typeof guard for CDN-blocked path (REQ-F-004)
  - renderMermaidIn: querySelectorAll pre>code.language-mermaid, per-block mermaid.render(id, source) with try/catch; catch replaces block with escaped raw source + mermaid-error-banner (REQ-F-003); reuse existing escapeHtml at viewer.html:2084
- Edit 4: call renderMermaidIn(mdDiv) after mdDiv.innerHTML is set in renderMarkdownFromString (REQ-F-005, REQ-F-006)
- Edit 5 (confirm no-op): enterEditMode/cancelEdit/saveEdit require no changes (D8)

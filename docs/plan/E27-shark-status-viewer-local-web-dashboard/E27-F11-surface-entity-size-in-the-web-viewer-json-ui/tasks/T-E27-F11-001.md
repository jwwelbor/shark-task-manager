# Add Size field to FlatEntity and populate from bug/change-card/idea models

## Goal

Add `Size *int` with `json:"size,omitempty"` to the `FlatEntity` struct in
`internal/services/viewer_service.go` and populate it at the three existing
`&FlatEntity{...}` construction sites for bug, change-card, and idea. This
closes the gap where the hierarchy JSON silently stripped size for these three
entity families while epics/features/tasks already exposed it via their
embedded models. Write failing tests first (TDD), then implement to pass.

## Scope

- Files to modify:
  - `internal/services/viewer_service.go` (struct + 3 construction sites)
  - `internal/services/viewer_service_test.go` (new tests, written before impl)

## Acceptance Criteria

See spec.md AC-01, AC-02, AC-03, AC-04, AC-09, AC-10.

Additional task-specific criteria:
- AC-T1: `FlatEntity.Size` is `*int` (pointer) so `omitempty` omits nil, not zero.
- AC-T2: Bug size sourced from `b.Size` (BaseEntity embed); ChangeCard from `cc.Size`
  (same); Idea from `idea.Size` (direct field — Idea has no BaseEntity embed).
- AC-T3: No new database queries, no new imports beyond `encoding/json` in tests.

# Render size badge and Size row in viewer.html SPA

## Goal

Update `internal/viewer/assets/viewer.html` to render a t-shirt size badge in
the sidebar tree and a "Size" row in the entity detail panel Info tab for all
six entity families. Adds the `.size-badge` CSS rule, two JS helpers
(`formatSizeLabel`, `buildSizeBadgeHtml`), a new `appendIdeaFields` function,
a `case 'idea':` dispatcher branch, and inserts `buildSizeBadgeHtml(item.size)`
into all four tree-node builders. Front-end coverage is manual smoke (no JS
unit-test harness per REQ-NF-004). Verification is the smoke checklist in
test-plan.md Section 4.2.

## Scope

- Files to modify:
  - `internal/viewer/assets/viewer.html` (CSS, JS helpers, tree builders, Info tab)

## Acceptance Criteria

See spec.md AC-05, AC-06, AC-07, AC-08, AC-09.

Additional task-specific criteria:
- AC-T1: `buildSizeBadgeHtml(size)` returns empty string for `null`/`undefined`;
  guards cover both via `if (size == null)` (JS abstract equality).
- AC-T2: `SIZE_LABELS` map `{1:'XS',2:'S',3:'M',5:'L',8:'XL',13:'XXL'}` matches
  `internal/models/size.go` canonical set exactly.
- AC-T3: `appendIdeaFields` is both defined and wired via `case 'idea':` in the
  switch at line 3472; ideas without size show no Size row.
- AC-T4: All integer values passed through `escapeHtml(String(n))` before DOM
  insertion (XSS defense per spec §2.5 edit 2).

## Test Cases

See test-plan.md Section 4.2 (manual front-end smoke), cases TC-AC05-1,
TC-AC06-1, TC-AC07-1, TC-AC07-2, TC-AC08-1, TC-AC09-1.

Run smoke checklist: `make build && ./bin/shark web`, verify sidebar badges
and Info tab rows for all six entity types with and without size. Use
DevTools Network intercept to test non-canonical size = 7 (AC-08).

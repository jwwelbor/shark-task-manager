# Expose navigation folders through the viewer API

## Goal

Wire the completed folder service into the existing read-only viewer server so the SPA can discover its navigation data without a parallel configuration path.

## Scope

- Files to modify: `internal/api/viewer/service.go`, `internal/api/viewer/handler.go`, `internal/api/viewer/handler_test.go`
- Files to modify: `internal/viewer/server/wire.go`, `docs/cli-reference/configuration.md`

## Acceptance Criteria

Reference: `spec.md` REQ-F-005–007, REQ-NF-003 and §4.2, §4.5, §4.8.
- AC-T1: Register and serve the documented read-only navigation-folder endpoint with existing CORS and error conventions.
- AC-T2: Load configured folders once at viewer-service wiring and pass them through the documented optional setter.
- AC-T3: Document the configuration shape and rejection boundary without moving security validation into config loading.

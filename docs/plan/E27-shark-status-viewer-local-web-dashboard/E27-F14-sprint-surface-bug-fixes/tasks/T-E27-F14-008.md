# Task: Add Assigned Scope Snapshot bar to Overview

## Goal

The wireframe specifies an "Assigned Scope Snapshot" row at the bottom of the Overview showing a quick status distribution: `todo 4 | in_progress 12 | review 3 | blocked 4 | done 17`. This gives the PM a single-line at-a-glance view of sprint composition without scrolling through the full backlog list. The data is already in the overview payload's `backlog.groups` — this is a pure display addition.

## Implementation

Add `renderScopeSnapshot(payload)` and append it at the end of `renderSprintOverview()`:

```js
function renderScopeSnapshot(payload) {
  const groups = sprintBacklogGroups(payload);
  if (!groups.length) return '';

  // Map each API group to a display bucket using SPRINT_BUCKET_MAP (from T-E27-F14-002)
  const tally = {};
  for (const group of groups) {
    const cat = group?.status_category || 'other';
    const bucket = SPRINT_BUCKET_MAP[cat] || cat;
    tally[bucket] = (tally[bucket] || 0) + (Array.isArray(group.items) ? group.items.length : 0);
  }

  // Render in a fixed order
  const order = ['ready', 'in_progress', 'blocked', 'done'];
  const pills = order
    .filter(b => tally[b])
    .map(b => {
      const color = b === 'done' ? 'var(--status-green)'
                  : b === 'blocked' ? 'var(--status-red)'
                  : b === 'in_progress' ? 'var(--status-yellow)'
                  : 'var(--fg-dim)';
      const label = SPRINT_BUCKET_LABELS[b] || b;
      return `<span style="color:${color}"><strong>${escapeHtml(String(tally[b]))}</strong> ${escapeHtml(label)}</span>`;
    });

  if (!pills.length) return '';

  return `
    <section class="ov-section">
      <div class="ov-section-header">Assigned Scope Snapshot</div>
      <div style="display:flex;gap:20px;flex-wrap:wrap;padding:10px 4px;font-size:13px">
        ${pills.join('<span style="color:var(--fg-dim)"> · </span>')}
      </div>
    </section>`;
}
```

Append `${renderScopeSnapshot(payload)}` as the last section inside `renderSprintOverview()`, after "Recent Changes".

Note: depends on T-E27-F14-002 (`SPRINT_BUCKET_MAP`, `SPRINT_BUCKET_LABELS`) and T-E27-F14-006 (shared active-category logic) being present in the file before this is added.

## Acceptance Criteria

- [ ] Overview bottom shows a "Assigned Scope Snapshot" row with status distribution
- [ ] Each bucket shows a count and label in matching status color (green=done, red=blocked, yellow=active, gray=ready)
- [ ] Buckets with 0 items are omitted
- [ ] Total of all bucket counts equals the sprint item count shown in the sidebar header
- [ ] Section is absent when sprint has no assigned items

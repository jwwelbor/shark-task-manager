# Add Assigned Scope Snapshot bar to Overview

## Goal

Add an "Assigned Scope Snapshot" section at the bottom of the Overview tab showing a one-line status distribution of assigned sprint items. Data is already in `payload.backlog.groups` — this is a pure display addition using `SPRINT_BUCKET_MAP` (from T-E27-F14-002). The section must be absent when the sprint has no assigned items.

## Scope

- Files to modify: `internal/viewer/assets/viewer.html`
  - Add `renderScopeSnapshot(payload)` function (~line 6181)
  - Append call to `renderScopeSnapshot(payload)` at end of `renderSprintOverview()`, after the recent-changes section

## Acceptance Criteria

See spec.md AC-020, AC-021.

Additional task-specific criteria:
- AC-T1: Section heading text is exactly `"Assigned Scope Snapshot"`.
- AC-T2: Buckets with zero items are omitted from the rendered output — no zero-count pills.
- AC-T3: The section element is entirely absent from the DOM when `sprintBacklogGroups(payload)` returns an empty array.

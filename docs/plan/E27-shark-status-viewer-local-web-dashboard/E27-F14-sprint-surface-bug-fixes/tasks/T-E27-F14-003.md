# Task: Fix sprint date range format strip time component

## Goal

Sprint date ranges display as `"May 7 19:00:00 → May 21 19:00:00"` instead of `"May 7 → May 21"`. Sprint start/end dates are midnight UTC timestamps; showing the local-timezone time component adds noise. The `sprintFormatRange()` function calls `formatDate()` which always appends `HH:MM:SS`. Add a date-only formatter and use it for sprint range display.

## Root Cause

`internal/viewer/assets/viewer.html`, `sprintFormatRange()`:

```js
function sprintFormatRange(sprint) {
  const start = formatDate(sprint.start_date || ...);  // returns "May 7 19:00:00"
  const end = formatDate(sprint.end_date || ...);
  ...
}
```

`formatDate()` always builds a time string and appends it. Sprint dates don't need time precision.

## Implementation

Add `formatDateOnly()` adjacent to `formatDate()`:

```js
function formatDateOnly(isoString) {
  if (!isoString) return '';
  if (typeof isoString === 'object' && isoString !== null) {
    if (!isoString.Valid) return '';
    isoString = isoString.Time;
  }
  if (!isoString) return '';
  try {
    // Parse as UTC date to avoid timezone shifting the day
    const parts = isoString.split('T')[0].split('-');
    if (parts.length !== 3) return '';
    const months = ['Jan','Feb','Mar','Apr','May','Jun',
                    'Jul','Aug','Sep','Oct','Nov','Dec'];
    const year = parseInt(parts[0], 10);
    const mon = months[parseInt(parts[1], 10) - 1];
    const day = parseInt(parts[2], 10);
    const now = new Date();
    if (year !== now.getFullYear()) {
      return `${mon} ${day}, ${year}`;
    }
    return `${mon} ${day}`;
  } catch {
    return '';
  }
}
```

Update `sprintFormatRange()` to use it:

```js
function sprintFormatRange(sprint) {
  if (!sprint) return 'No sprint selected';
  const start = formatDateOnly(sprint.start_date || sprint.startDate || sprint.start || '');
  const end = formatDateOnly(sprint.end_date || sprint.endDate || sprint.end || '');
  if (!start && !end) return 'Date range unavailable';
  return `${escapeHtml(start || '—')} → ${escapeHtml(end || '—')}`;
}
```

Note: parse from the ISO string's date part directly (split on `T`) rather than constructing a `Date` object to avoid local-timezone day-shift on midnight UTC values.

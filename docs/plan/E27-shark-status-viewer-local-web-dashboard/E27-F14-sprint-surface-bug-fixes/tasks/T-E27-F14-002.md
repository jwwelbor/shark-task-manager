# Task: Fix sidebar sprint bucket key mismatch

## Goal

The sidebar "Active Sprint" section always shows 0 items in all four buckets (Ready, In Progress, Blocked, Done) even when the sprint has assigned work. The cause: `sprintBucketGroups()` maps to hardcoded keys `{ready, in_progress, blocked, done}` but the API returns `status_category` values like `ready_for_approval`, `ready_for_development`, `completed`, `draft`, `resolved` — none of which match.

The sprint total count next to "Active Sprint" also shows 0 because `sprintTreeItemCount` counts from `sprintBacklogItems` which iterates the raw groups — this part works — but the sidebar header pulls from the bucketed view.

## Root Cause

`internal/viewer/assets/viewer.html`, `sprintBucketGroups()` function:

```js
const SPRINT_BUCKET_LABELS = {
  ready: 'Ready',
  in_progress: 'In Progress',
  blocked: 'Blocked',
  done: 'Done',
};

function sprintBucketGroups(payload) {
  const map = new Map();
  for (const group of sprintBacklogGroups(payload)) {
    if (group?.status_category) {
      map.set(group.status_category, group);  // keys like "ready_for_approval" go in
    }
  }
  return Object.keys(SPRINT_BUCKET_LABELS).map(key => ({
    key,
    label: SPRINT_BUCKET_LABELS[key],
    items: Array.isArray(map.get(key)?.items) ? map.get(key).items : [],
    // map.get("ready") is always undefined — the key never matches
  }));
}
```

## Implementation

Replace `SPRINT_BUCKET_LABELS` with a mapping from API status categories to display buckets. Collect all items that match each bucket; fall through any unmapped categories into the closest bucket.

```js
const SPRINT_BUCKET_MAP = {
  ready_for_development: 'ready',
  ready_for_refinement_tech: 'ready',
  ready_for_refinement_ba: 'ready',
  todo: 'ready',
  draft: 'ready',
  in_development: 'in_progress',
  in_progress: 'in_progress',
  in_refinement: 'in_progress',
  in_review: 'in_progress',
  in_qa: 'in_progress',
  ready_for_approval: 'in_progress',   // active, awaiting human — counts as WIP
  blocked: 'blocked',
  completed: 'done',
  resolved: 'done',
  archived: 'done',
};

const SPRINT_BUCKET_LABELS = {
  ready: 'Ready',
  in_progress: 'In Progress',
  blocked: 'Blocked',
  done: 'Done',
};

function sprintBucketGroups(payload) {
  const buckets = { ready: [], in_progress: [], blocked: [], done: [] };
  for (const group of sprintBacklogGroups(payload)) {
    const cat = group?.status_category || '';
    const bucket = SPRINT_BUCKET_MAP[cat] || 'ready';  // unmapped → ready
    buckets[bucket].push(...(Array.isArray(group.items) ? group.items : []));
  }
  return Object.keys(SPRINT_BUCKET_LABELS).map(key => ({
    key,
    label: SPRINT_BUCKET_LABELS[key],
    items: buckets[key],
  }));
}
```

Also fix `sprintTreeItemCount` to use `sprintBacklogItems` (raw groups) so the total count is always correct regardless of bucket mapping:

```js
function sprintTreeItemCount(payload) {
  return sprintBacklogItems(payload).length;  // already correct — verify this is used in header
}
```

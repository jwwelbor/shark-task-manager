# Fix sidebar sprint bucket key mismatch

## Goal

The sidebar "Active Sprint" section always shows 0 items in all four buckets (Ready, In Progress, Blocked, Done) even when the sprint has assigned work. The cause is that `sprintBucketGroups()` uses hardcoded bucket key names that don't match the `status_category` values returned by the API. Introduce `SPRINT_BUCKET_MAP` as the single source of truth mapping API status categories to the four display buckets.

This task also establishes `SPRINT_BUCKET_MAP` which is reused by T-E27-F14-006 (Active counter). Both tasks depend on this constant being defined first.

## Scope

- Files to modify: `internal/viewer/assets/viewer.html`
  - Add `SPRINT_BUCKET_MAP` constant (~line 5782)
  - Replace `SPRINT_BUCKET_LABELS` with the new map-driven version
  - Rewrite `sprintBucketGroups()` to aggregate items by bucket using `SPRINT_BUCKET_MAP`

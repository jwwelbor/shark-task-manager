# Fix WIP counter to include active workflow categories

## Goal

The "WIP" metric card in the Overview always shows 0 because it filters a hardcoded set of status categories that doesn't match the actual workflow. Fix by deriving `ACTIVE_SPRINT_CATEGORIES` from `SPRINT_BUCKET_MAP` (introduced in T-E27-F14-002) rather than a second hardcoded list. Rename the metric card label from "WIP" to "Active".

## Scope

- Files to modify: `internal/viewer/assets/viewer.html`
  - Add `ACTIVE_SPRINT_CATEGORIES` constant derived from `SPRINT_BUCKET_MAP` (~line 6181)
  - Update `renderSprintOverview()` to use `ACTIVE_SPRINT_CATEGORIES` for the active count
  - Change metric card label from `"WIP"` to `"Active"`

## Acceptance Criteria

See spec.md AC-013.

Additional task-specific criteria:
- AC-T1: `ACTIVE_SPRINT_CATEGORIES` is derived from `SPRINT_BUCKET_MAP` (no second hardcoded list of status strings).
- AC-T2: The metric card label text is exactly `"Active"`.
- AC-T3: Blocked and Done items are not counted in the Active metric.

# Task: Add Capacity and Blockers panels to Overview tab

## Goal

The wireframe (Wireframe 01) specifies a two-column zone below the metric pills showing: left — per-agent Capacity rows + readiness driver bullets; right — enumerated Blockers with age and unsized task warnings. The current Overview shows only the Sprint Backlog grouped list. Add these two panels between the metrics row and the backlog section.

## Data Available in Overview Payload

The `/api/v1/viewer/sprint/overview` response already includes:
- `capacity[]` — per-agent rows with `agent_type`, `capacity_points`, `allocated_points`
- `readiness.factors[]` — array of readiness factor objects with `name`, `score`, `max_score`, `detail`
- `readiness.unsized_entities[]` — list of items missing size estimates
- `backlog.groups[]` — filtered for `blocked` gives individual blocker items with `days_blocked`

No new API endpoints needed.

## Implementation

Add a `renderSprintHealthColumns(payload)` function and insert it between the metrics section and the Sprint Backlog section in `renderSprintOverview()`:

```js
function renderSprintHealthColumns(payload) {
  const capacity = payload?.capacity || [];
  const readiness = payload?.readiness || {};
  const factors = Array.isArray(readiness.factors) ? readiness.factors : [];
  const unsized = Array.isArray(readiness.unsized_entities) ? readiness.unsized_entities : [];

  // Capacity rows
  const capacityRows = capacity.length
    ? capacity.map(row => {
        const pct = row.capacity_points > 0
          ? Math.round((row.allocated_points / row.capacity_points) * 100)
          : 0;
        const indicator = pct > 100 ? 'OVER' : pct > 85 ? 'HIGH' : 'OK';
        const color = pct > 100 ? 'var(--status-red)' : pct > 85 ? 'var(--status-yellow)' : 'var(--status-green)';
        return `<div class="sprint-item-row" style="cursor:default">
          <span class="sprint-item-key">${escapeHtml(row.agent_type)}</span>
          <span class="sprint-item-title">${escapeHtml(String(row.allocated_points))} / ${escapeHtml(String(row.capacity_points))}</span>
          <span style="color:${color};font-size:11px">${indicator}</span>
        </div>`;
      }).join('')
    : '<div class="content-placeholder">No capacity configured for this sprint.</div>';

  // Readiness drivers
  const driverRows = factors
    .filter(f => f.score < f.max_score)  // only show failing/partial factors
    .map(f => `<div class="sprint-item-row" style="cursor:default">
      <span class="sprint-item-key">${escapeHtml(String(f.score))}/${escapeHtml(String(f.max_score))}</span>
      <span class="sprint-item-title">${escapeHtml(f.detail || f.name)}</span>
    </div>`).join('');

  // Blockers
  const blockedItems = sprintBacklogGroups(payload)
    .find(g => g?.status_category === 'blocked');
  const blockerRows = Array.isArray(blockedItems?.items) && blockedItems.items.length
    ? blockedItems.items.map(item => {
        const age = item.days_blocked != null ? `${item.days_blocked}d` : '';
        return `<div class="sprint-item-row" role="button" tabindex="0" data-sprint-item-key="${escapeHtml(item.key || '')}">
          <span class="sprint-item-key">${escapeHtml(item.key || '')}</span>
          ${age ? `<span class="status-badge status-badge-sm" style="background:var(--status-red);color:#fff">${age}</span>` : ''}
          <span class="sprint-item-title">${escapeHtml(item.title || '')}</span>
        </div>`;
      }).join('')
    : '<div class="content-placeholder">No blockers.</div>';

  return `
    <div class="sprint-health-columns">
      <section class="ov-section">
        <div class="ov-section-header">Capacity by Agent</div>
        <div class="sprint-item-list">${capacityRows}</div>
        ${driverRows ? `<div class="ov-section-header" style="margin-top:12px">Readiness Gaps</div>
        <div class="sprint-item-list">${driverRows}</div>` : ''}
      </section>
      <section class="ov-section">
        <div class="ov-section-header">Blockers & Risks</div>
        <div class="sprint-item-list">${blockerRows}</div>
        ${unsized.length ? `<div class="sprint-item-row" style="cursor:default;color:var(--fg-dim)">
          <span class="sprint-item-title">${escapeHtml(String(unsized.length))} unsized items — add estimates to improve readiness score</span>
        </div>` : ''}
      </section>
    </div>`;
}
```

# Fix Report tab 500 for planning and active sprints

## Goal

Make `GET /api/v1/viewer/sprint/report` return HTTP 200 for sprints in any status. Currently `SprintReport()` propagates the `GetSummary` error for planning/active sprints, causing HTTP 500. The fix makes the summary error non-fatal: return `summary: null` rather than failing the whole response.

## Scope

- Files to modify: `internal/services/viewer_service.go` (~line 817, `SprintReport()` method)
- Files to modify: `internal/services/viewer_service_test.go` (add 2 new test cases)

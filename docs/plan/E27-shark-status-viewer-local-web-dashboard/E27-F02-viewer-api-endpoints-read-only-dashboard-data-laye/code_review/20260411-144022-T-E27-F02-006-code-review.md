## Required Fixes

The following test cases must be added to `handler_test.go` to bring coverage above 85%:

1. **TC-H-012: Hierarchy service error → 500**
   Add a subtest inside `TestHandler_Hierarchy` where `HierarchyFunc` returns an error; assert `rec.Code == 500` and that the body contains an `error` field.

2. **TC-H-062: WorkflowMeta service error → 500**
   Add a subtest inside `TestHandler_WorkflowMeta` where `WorkflowMetaFunc` returns an error; assert `rec.Code == 500`.

3. **TC-H-045: FeatureTasks service error → 500**
   Add a subtest inside `TestHandler_FeatureTasks` where `FeatureTasksFunc` returns a non-not-found error; assert `rec.Code == 500`.

4. **TC-H-046: FeatureTasks zero/default limit forwarded correctly**
   Add a subtest where the `limit` query parameter is absent (default) and verify the captured `opts.Limit` is the expected default value (confirms the `parseIntClamp` zero-value branch).

5. **TC-H-028: History internal error → 500** (distinct from TC-H-026 not-found)
   Add a subtest where `HistoryFunc` returns a generic (non-not-found) error; assert `rec.Code == 500` to cover the `slog.Error` branch.

These five additions are the minimum to cross the 85% bar. The `respondJSON` encode-error path and the `isLocalOrigin` URL-parse path are unreachable in practice and do not need to be tested.

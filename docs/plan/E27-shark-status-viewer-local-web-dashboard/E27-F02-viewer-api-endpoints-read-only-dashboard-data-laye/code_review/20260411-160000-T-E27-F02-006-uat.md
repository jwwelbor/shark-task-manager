The test uses `T-E27-F01-001` as the key. `validateAndNormalizeAnyKey` accepts both `T-E##-F##-###` (IsTaskKey) and `E##-F##-###` (IsShortTaskKey). A T-prefixed key is accepted by `IsTaskKey`. Confirmed by reading `validateAndNormalizeAnyKey` (handler.go lines 291–310). No issue.

TC-H-026 and TC-H-043 both verify this path by returning errors containing "not found". TC-H-028 and TC-H-045 verify the fallback (non-matching error → 500). All branches are exercised.

# Task: Write handler tests and repository tests (httptest + MockViewerServicer; real DB for entityhistory)

## Goal

Create two test files: (1) `internal/api/viewer/handler_test.go` — handler and CORS middleware tests using `httptest` and `MockViewerServicer` (no real DB); (2) extend `internal/repository/entityhistory/repository_test.go` with TC-R-001 through TC-R-007 for `ListRecentAcrossEntities` (real test DB with cleanup).

## Requirements

### Functional Requirements

**Handler tests (`internal/api/viewer/handler_test.go`):**
- [ ] Declare `MockViewerServicer` with `Func` fields for all 7 methods; each method returns a descriptive error if its `Func` is nil
- [ ] Write TC-H-001 through TC-H-003 (`GET /summary` — happy path populated, happy path empty, service error → 500)
- [ ] Write TC-H-010 through TC-H-011 (`GET /hierarchy` — 1 epic 2 features, empty project)
- [ ] Write TC-H-020 through TC-H-027 (`GET /history/{key}` — 5 entity-type happy paths, invalid key → 400, not found → 404, lowercase normalized)
- [ ] Write TC-H-030 through TC-H-036 (`GET /file/{key}` — exists, missing→200 exists:false, path traversal→403, too large→413, invalid key→400, not found→404, T-prefix accepted)
- [ ] Write TC-H-040 through TC-H-044 (`GET /features/{key}/tasks` — happy path, limit clamp, invalid key→400, not found→404, blocked=invalid→400)
- [ ] Write TC-H-050 through TC-H-055 (`GET /recent-activity` — no filters, entity_type filter, since filter, invalid entity_type→400, malformed since→400, limit clamp)
- [ ] Write TC-H-060 through TC-H-061 (`GET /workflow-meta` — happy path 5 levels, missing level emitted as empty object)
- [ ] Write TC-H-070 through TC-H-074 (CORS middleware directly — localhost→CORS echoed, 127.0.0.1→CORS echoed, external→no CORS header, OPTIONS preflight→204, no Origin→no CORS header)
- [ ] Each handler test uses `httptest.NewRecorder()` and `httptest.NewRequest(...)`; handler is constructed with `MockViewerServicer`
- [ ] Assert: HTTP status code, `Content-Type: application/json`, required top-level JSON keys

**Repository tests (`internal/repository/entityhistory/repository_test.go`):**
- [ ] Write TC-R-001: seed 1 entity per type (5 total), 2 history rows each (10 total); with `Limit=5` verify exactly 5 rows returned DESC by `changed_at`
- [ ] Write TC-R-002: `EntityType="task"` filter — only task rows returned
- [ ] Write TC-R-003: `Since` filter — half the rows are before the cutoff; verify only rows after cutoff returned
- [ ] Write TC-R-004: orphan omission — seed task + 2 history rows, delete task, verify 0 rows returned
- [ ] Write TC-R-005: mixed entity types carry correct `entity_type` labels
- [ ] Write TC-R-006: `Limit=0` or negative — no panic; safe behavior (empty or capped)
- [ ] Write TC-R-007: combined filter — entity_type + since + limit all applied together

### Non-Functional Requirements

- [ ] Handler tests: no real database, no file system access
- [ ] Repository tests: use `test.GetTestDB()`, use `TEST-` prefixed keys, clean before each test, defer cleanup after
- [ ] CORS tests test `withLocalCORS` directly (not through full handler stack) for isolation

### Technical Approach

- For handler tests with `{key}` path parameters: look at how existing handler tests in `internal/api/` (e.g., `task_handler_test.go`) extract path params. If the server uses chi, use `chi.NewRouteContext` to inject `URLParam` values into the request context. If using `net/http` Go 1.22 patterns, use `http.NewServeMux()` with `Handle` and make requests to the full path.
- For CORS OPTIONS test (TC-H-073): create the middleware-wrapped handler; make a `OPTIONS` request with `Origin: http://localhost:5173`; assert 204 status and `Access-Control-Allow-Methods` header; assert the downstream handler body was NOT written (check response body is empty).
- For TC-R-004 (orphan omission): the DELETE must remove the task row from the `tasks` table to trigger the INNER JOIN omission. Use `db.ExecContext(ctx, "DELETE FROM tasks WHERE key = ?", key)` directly in the test.
- For TC-R-003 (since filter): use `time.Now().UTC()` minus some offsets to create deterministic timestamps in test data; avoid relying on wall clock between inserts.

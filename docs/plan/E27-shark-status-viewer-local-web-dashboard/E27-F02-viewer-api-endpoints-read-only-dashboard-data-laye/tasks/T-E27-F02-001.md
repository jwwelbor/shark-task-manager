# Task: Add ListRecentAcrossEntities to EntityHistoryRepository

## Goal

Add a new `ListRecentAcrossEntities` method to the `EntityHistoryRepository` in `internal/repository/entityhistory/repository.go`. This is the only new repository method required by E27-F02 and must be completed before the ViewerService can be implemented (T-E27-F02-002 depends on this).

## Requirements

### Functional Requirements

- [ ] Add `ListRecentAcrossEntitiesOptions` struct to `internal/repository/entityhistory/repository.go` with fields: `Limit int`, `EntityType string` (empty = all), `Since *time.Time`
- [ ] Add `RecentActivityRow` result struct with fields: `EntityType string`, `Key string`, `Title string`, `FromStatus string`, `ToStatus string`, `ChangedAt time.Time`
- [ ] Implement `ListRecentAcrossEntities(ctx context.Context, opts ListRecentAcrossEntitiesOptions) ([]*RecentActivityRow, error)` on `*EntityHistoryRepository`
- [ ] Query performs a UNION ALL across all entity history tables (epics, features, tasks, bugs, change_cards), JOINing each to its parent entity table to retrieve `key` and `title`
- [ ] Orphaned history rows (entity deleted) are omitted via INNER JOIN (not LEFT JOIN)
- [ ] Results ordered DESC by `changed_at`
- [ ] `Limit` of 0 or negative must not panic; return empty slice or use a safe default

### Non-Functional Requirements

- [ ] Method is purely read-only — no writes, no transactions
- [ ] Follows existing repository pattern: `(r *EntityHistoryRepository)`, returns `error` as second value, wraps errors with `fmt.Errorf`
- [ ] Caller (ViewerService) is responsible for clamping `Limit` before calling; repository treats 0 as "return nothing" or enforces a documented max

## Implementation Plan

### Steps

1. [ ] Define `ListRecentAcrossEntitiesOptions` and `RecentActivityRow` types in `internal/repository/entityhistory/repository.go` (or a new `types.go` in same package)
2. [ ] Write the UNION ALL SQL query joining epic/feature/task/bug/change_card history tables to their parent entity tables via INNER JOIN to exclude orphans; include `entity_type` as a literal column in each SELECT arm
3. [ ] Add `ListRecentAcrossEntities` method that applies `WHERE entity_type = ?` when `opts.EntityType` is non-empty, and `WHERE changed_at > ?` when `opts.Since` is non-nil
4. [ ] Add `LIMIT ?` clause using `opts.Limit`
5. [ ] Verify test DB has all required tables (epics, features, tasks, bugs, change_cards and their history tables) — cross-reference with `internal/db/db.go` schema

### Technical Approach

- The existing `ListByEntity` method queries a single entity's history. The new method queries across all entity types in a single SQL round-trip via UNION ALL.
- Each SELECT arm must emit: `entity_type` (literal string), `key` (from parent table), `title` (from parent table), `from_status`, `to_status`, `changed_at` (from history table).
- Use parameterized placeholders for all filter values (never string interpolation — see input-sanitization.md).
- Check existing table and column names in `internal/db/db.go` before writing the query to ensure exact column names match.

## Deliverables

- [ ] `ListRecentAcrossEntities` method implementation in `internal/repository/entityhistory/repository.go`

## UAT Rejection (2026-04-11)

**Unmet AC:** Interface contract with ViewerService consumer (implicit in task spec §Technical Approach)

**Classification:** AC Violation — the repository method signature does not satisfy the `ViewerEntityHistoryRepository` interface in `internal/services/viewer_service.go`.

**Required fix:** Reconcile the type contract between the repository implementation and the consumer interface. Three options:
- **Option A (preferred):** Change the repository signature/types to match `ViewerEntityHistoryRepository` (`RecentActivityOptions` param, `[]*models.EntityHistory` return).
- **Option B:** Update `ViewerEntityHistoryRepository` interface to match the concrete implementation.
- **Option C:** Add an adapter at the wiring layer in `cmd/server/services.go`.

Additionally, add a compile-time interface assertion `var _ services.ViewerEntityHistoryRepository = (*EntityHistoryRepository)(nil)` to the repository package to prevent regression.

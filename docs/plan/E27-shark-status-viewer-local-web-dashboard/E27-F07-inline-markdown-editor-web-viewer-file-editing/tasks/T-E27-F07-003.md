# Wire EditService and EditHandler into viewer server

## Goal

Register the `PUT /api/v1/edit/file` route and its OPTIONS preflight in the
viewer server. Add `EditService` to `ServiceContainer`. Update the CORS
middleware to include `PUT` in `Access-Control-Allow-Methods`.

## Scope

- Files to modify:
  - `internal/viewer/server/wire.go` — construct `EditService`; add to `ServiceContainer`
  - `internal/viewer/server/server.go` — register PUT and OPTIONS routes under `/api/v1/edit/file`
  - `internal/api/viewer/cors.go` — add `"PUT"` to `Access-Control-Allow-Methods` (two locations ~lines 33, 55)

## Acceptance Criteria

See spec.md §1.3 AC-08 and Architecture §2.6, §2.7.

- AC-T1: `EditService *services.EditService` field added to `ServiceContainer` in `wire.go`.
- AC-T2: `NewEditService(projectRoot)` called in `WireServices`.
- AC-T3: PUT route registered with `WithLocalCORS` wrapper.
- AC-T4: OPTIONS preflight route registered at same path returning 204.
- AC-T5: `Access-Control-Allow-Methods` header includes `"PUT"` after cors.go change.
- AC-T6: `make build` succeeds; existing viewer routes unchanged.

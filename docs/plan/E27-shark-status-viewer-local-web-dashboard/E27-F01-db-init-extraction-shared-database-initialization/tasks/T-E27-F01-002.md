# Task: Migrate internal/cli/db_init.go to delegate to dbinit package

## Goal

Reduce `internal/cli/db_init.go` to a thin delegate that calls `dbinit.Init`,
preserving the `initDatabase(ctx context.Context) (*repository.DB, error)` signature
consumed by `internal/cli/db_global.go`. All existing CLI tests must pass unchanged.

## Prerequisite

T-E27-F01-001 must be complete (`internal/dbinit` package exists and compiles).

## Files to Modify

- `internal/cli/db_init.go` — reduce to delegate (target: ≤15 non-comment lines)
- `internal/cli/db_helper.go` — keep `GetDatabaseConfig` / `InitializeDatabaseFromConfig` /
  `GetDatabasePathForBackup` as thin wrappers forwarding to `dbinit` internals (Option A
  from spec). This avoids touching `cloud.go` and other callers.

## Files NOT to Modify

- `internal/cli/db_global.go` — must compile unchanged
- `internal/cli/db_helper_test.go` — must pass unchanged (no test deletions)
- `internal/cli/db_global_test.go` — must pass unchanged

## Implementation

### `internal/cli/db_init.go` (after refactor)

The entire file becomes approximately:

```go
package cli

import (
    "context"

    "github.com/jwwelbor/shark-task-manager/internal/dbinit"
    "github.com/jwwelbor/shark-task-manager/internal/repository"
)

// initDatabase is retained for backwards-compat with db_global.go's GetDB.
// It delegates to dbinit.Init; project-root discovery is handled by dbinit
// using the same walk-up algorithm as the previous implementation.
func initDatabase(ctx context.Context) (*repository.DB, error) {
    return dbinit.Init(ctx, dbinit.Options{})
}
```

Remove ALL previous implementation code. The ~82 lines collapse to ~15.

### `internal/cli/db_helper.go` (Option A — thin wrappers)

Inspect the existing functions in `db_helper.go` and determine if they rely on
logic that now lives in `dbinit`. For each:

- `GetDatabaseConfig(projectRoot string)` — if this duplicates `loadDatabaseConfig`,
  forward to `dbinit.LoadDatabaseConfig(configPath, projectRoot)`. Export
  `LoadDatabaseConfig` from `internal/dbinit` if not already exported.
- `InitializeDatabaseFromConfig(ctx, cfg)` — can forward to `dbinit.Init` with
  `Options{ProjectRoot: ...}` if mapping is clean; otherwise leave a minimal
  local implementation.
- `GetDatabasePathForBackup()` — likely stays unchanged if it does not depend on
  the extracted logic.

Do NOT delete these functions even if they become minimal — `cloud.go` and other
callers depend on them.

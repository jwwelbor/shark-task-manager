# Task: Migrate cmd/server/main.go to use dbinit.Init

## Goal

Replace the hardcoded `db.InitDB("shark-tasks.db")` call in `cmd/server/main.go`
with `dbinit.Init(ctx, dbinit.Options{})` so the HTTP server inherits full
cloud-aware database initialization (Turso support, `.sharkconfig.json` discovery,
auth-token loading, skip_migrations fast-path).

## Prerequisite

T-E27-F01-001 must be complete (`internal/dbinit` package exists and compiles).
(Can be done in parallel with T-E27-F01-002.)

## Files to Modify

- `cmd/server/main.go` — swap DB init call and update integrity-check call

## Files NOT to Modify

- `cmd/server/services.go` — receives `*repository.DB`, no change needed
- `cmd/server/main_test.go` — all existing tests must pass unchanged

## Implementation

### Current code in `cmd/server/main.go` (locate and replace this block)

The current file (~143 lines) contains something like:

```go
database, err := db.InitDB("shark-tasks.db")
if err != nil {
    slog.Error("Failed to initialize database", "error", err)
    os.Exit(1)
}
repoDB := repository.NewDB(database)
defer repoDB.Close()
slog.Info("Database initialized successfully")

if err := db.CheckIntegrity(database); err != nil {
    slog.Error("Database integrity check failed", "error", err)
    os.Exit(1)
}
slog.Info("Database integrity check passed")

svcs := WireServices(repoDB, ".")
```

### Replacement code

```go
repoDB, err := dbinit.Init(context.Background(), dbinit.Options{})
if err != nil {
    slog.Error("Failed to initialize database", "error", err)
    os.Exit(1)
}
defer repoDB.Close()
slog.Info("Database initialized successfully")

// CheckIntegrity needs the underlying *sql.DB.
// If *repository.DB does not have a DB() or SQL() accessor yet, add one
// in internal/repository/repository.go as part of this task.
if err := db.CheckIntegrity(repoDB.SQL()); err != nil {
    slog.Error("Database integrity check failed", "error", err)
    os.Exit(1)
}
slog.Info("Database integrity check passed")

svcs := WireServices(repoDB, ".")
```

### Accessor on `*repository.DB` (if missing)

Inspect `internal/repository/repository.go`. If `*repository.DB` does not expose
the underlying `*sql.DB`, add one. Check for name collision with embedded fields:

```go
// SQL returns the underlying *sql.DB. Named SQL() to avoid collision with
// any embedded field named DB.
func (d *DB) SQL() *sql.DB {
    return d.DB  // or d.sqlDB, depending on the field name
}
```

If the field is named `DB` and `DB()` would collide, use `SQL()` or `Underlying()`.
Update the `cmd/server/main.go` call accordingly.

### Add import

Add to `cmd/server/main.go` imports:
```go
"github.com/jwwelbor/shark-task-manager/internal/dbinit"
```

Remove the now-unused import of `internal/db` for `db.InitDB` (keep `internal/db`
if still needed for `db.CheckIntegrity`).

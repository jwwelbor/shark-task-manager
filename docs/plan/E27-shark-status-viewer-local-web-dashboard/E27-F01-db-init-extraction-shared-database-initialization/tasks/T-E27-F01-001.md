# Task: Create internal/dbinit package with cloud-aware DB initialization

## Goal

Create the new `internal/dbinit` package that extracts cloud-aware DB initialization
logic from `internal/cli/db_init.go` into an entry-point-agnostic shared package.
This is the core deliverable of E27-F01 and unblocks all subsequent E27 features.

## Files to Create

- `internal/dbinit/init.go` — public API (`Init`, `MustInit`, `Options`) plus
  unexported helpers (`loadDatabaseConfig`, `initLocal`, `initTurso`)
- `internal/dbinit/project_root.go` — unexported `findProjectRoot` (duplicated
  from `cli.FindProjectRoot` — do NOT import `internal/cli`)

## Implementation

### Public API (`internal/dbinit/init.go`)

```go
package dbinit

import (
    "context"
    "github.com/jwwelbor/shark-task-manager/internal/repository"
)

// Options configures how Init locates and opens the database.
type Options struct {
    // ProjectRoot is the project root directory. If empty, Init walks up
    // from cwd looking for .sharkconfig.json, shark-tasks.db, or .git/.
    ProjectRoot string

    // ConfigPath overrides the config file path. Defaults to
    // <ProjectRoot>/.sharkconfig.json when empty.
    ConfigPath string
}

func Init(ctx context.Context, opts Options) (*repository.DB, error)
func MustInit(ctx context.Context, opts Options) *repository.DB
```

### Internal helpers

**`resolveProjectRoot(opts Options) (string, error)`**
- If `opts.ProjectRoot` is non-empty, return it unchanged.
- Otherwise, walk up from `os.Getwd()` looking for:
  1. `.sharkconfig.json` (primary)
  2. `shark-tasks.db` (secondary)
  3. `.git/` directory (fallback)
- Return error with message `"dbinit: project root: could not locate project root"` if nothing found.

**`resolveConfigPath(opts Options, projectRoot string) string`**
- Return `opts.ConfigPath` if set.
- Otherwise return `filepath.Join(projectRoot, ".sharkconfig.json")`.

**`loadDatabaseConfig(configPath string, projectRoot string) (db.DatabaseConfig, error)`**
- Load `.sharkconfig.json` via `internal/config.Manager.Load` (or direct JSON parse).
- If file missing or no `database` section → return default: `Backend="sqlite"`, URL=`<projectRoot>/shark-tasks.db`.
- Apply `os.ExpandEnv` to URL and `auth_token_file` fields.
- If `url` is empty → default to `<projectRoot>/shark-tasks.db`.
- Wrap errors with prefix `"dbinit: load config: "`.

**`initLocal(cfg db.DatabaseConfig, projectRoot string) (*repository.DB, error)`**
- Resolve DB path: if `cfg.URL` is relative, join with `projectRoot`.
- Call `db.InitDB(dbPath)` → get `*sql.DB`.
- Wrap in `repository.NewDB(sqlDB)`.
- Wrap errors with prefix `"dbinit: init local db: "`.

**`initTurso(ctx context.Context, cfg db.DatabaseConfig) (*repository.DB, error)`**
- Load auth token: if `cfg.AuthTokenFile` set → `db.LoadAuthToken(cfg.AuthTokenFile)`.
  Otherwise if `TURSO_AUTH_TOKEN` env var set → use that. Otherwise proceed with URL as-is.
- Build connection string via `db.BuildTursoConnectionString(url, token)`.
- Call `db.InitDatabase(connStr)` → get `db.Driver`.
- Type-assert to `*db.TursoDriver`; return error `"dbinit: expected TursoDriver, got %T"` on failure.
- Extract `*sql.DB` via `tursoDriver.GetSQLDB()`.
- Apply schema: if `cfg.SkipMigrations` → `db.ApplySchemaIfNeeded(sqlDB)`;
  else → `db.ApplySchemaAndMigrations(sqlDB)`.
- Wrap in `repository.NewDB(sqlDB)`.
- Wrap all errors with prefix `"dbinit: "`.

**`Init` dispatch logic:**
```
switch strings.ToLower(cfg.Backend) {
case "", "sqlite", "local":
    return initLocal(cfg, projectRoot)
case "turso":
    return initTurso(ctx, cfg)
default:
    return nil, fmt.Errorf("dbinit: unsupported database backend: %q", cfg.Backend)
}
```

**`MustInit`:**
```go
func MustInit(ctx context.Context, opts Options) *repository.DB {
    db, err := Init(ctx, opts)
    if err != nil {
        panic(fmt.Sprintf("dbinit: MustInit failed: %v", err))
    }
    return db
}
```

# Task: Write unit tests for internal/dbinit package

## Goal

Achieve ≥80% line coverage on `internal/dbinit` by writing table-driven unit tests
covering all documented test cases from `test-plan.md`. All tests must use `t.TempDir()`
for isolation — no shared state, no real credentials required.

## Prerequisite

T-E27-F01-001 must be complete (`internal/dbinit` package exists and compiles).

## Files to Create

- `internal/dbinit/init_test.go` — tests for `loadDatabaseConfig`, `Init`, `MustInit`
- `internal/dbinit/project_root_test.go` — tests for `findProjectRoot` / `resolveProjectRoot`
- `internal/dbinit/init_integration_test.go` — Turso integration tests (build tag `integration`,
  skipped unless `TEST_TURSO_URL` env var is set)

## Unit Tests: `init_test.go`

### `loadDatabaseConfig` tests (TC-U-003 through TC-U-011)

Use `t.TempDir()` to create isolated directories. Write minimal JSON config files with
`os.WriteFile`. Cover:

| Test ID | Scenario | Config content | Expected |
|---------|----------|---------------|----------|
| TC-U-003 | Missing config file | (no file) | Default local config, URL = `<projectRoot>/shark-tasks.db` |
| TC-U-004 | Valid JSON, no `database` key | `{"workflow_config":"x"}` | Default local config |
| TC-U-005 | Local backend explicit | `{"database":{"backend":"local","url":"./mydb.db"}}` | `Backend="local"`, URL matches |
| TC-U-006 | SQLite backend alias | `{"database":{"backend":"sqlite","url":"./mydb.db"}}` | `Backend="sqlite"` |
| TC-U-007 | Turso backend | `{"database":{"backend":"turso","url":"libsql://x","auth_token_file":"./tok"}}` | Turso config populated |
| TC-U-008 | Env-var in URL | URL = `${HOME}/.shark/db` | URL has `$HOME` expanded |
| TC-U-009 | Env-var in auth_token_file | `auth_token_file` = `${HOME}/.turso/tok` | Field is expanded |
| TC-U-010 | Empty backend | `{"database":{"url":"./mydb.db"}}` | `Backend` defaults to `"sqlite"` |
| TC-U-011 | Empty URL | `{"database":{"backend":"local"}}` | URL = `<projectRoot>/shark-tasks.db` |

### `Init` local path tests (TC-U-018 through TC-U-023)

For each test: write `.sharkconfig.json` to `t.TempDir()`, pass `Options{ProjectRoot: dir}`,
assert return value.

| Test ID | Scenario | Setup | Expected |
|---------|----------|-------|----------|
| TC-U-018 | Happy path, explicit root | Valid local config + empty `shark-tasks.db` | Non-nil `*repository.DB`, `Ping()` succeeds |
| TC-U-019 | No URL in config | Config missing `url` | Opens `<projectRoot>/shark-tasks.db` successfully |
| TC-U-020 | `sqlite` backend alias | `backend: "sqlite"` | Opens successfully |
| TC-U-021 | Empty backend string | No `backend` key | Treated as local, opens successfully |
| TC-U-022 | Relative DB path | `url: "./mydir/test.db"` | Resolved relative to project root, opens |
| TC-U-023 | Unsupported backend | `backend: "postgres"` | Error containing `"unsupported database backend"` |

### `MustInit` tests (TC-U-024 through TC-U-025)

## Notes

  in which case use `package dbinit` (white-box). Prefer black-box where possible.

  via `Init` for black-box, or use `package dbinit` for direct testing.

  (`os.WriteFile(filepath.Join(dir, "shark-tasks.db"), nil, 0600)`).

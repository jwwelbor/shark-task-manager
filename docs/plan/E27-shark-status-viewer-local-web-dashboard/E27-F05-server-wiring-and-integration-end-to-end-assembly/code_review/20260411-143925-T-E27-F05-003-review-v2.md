## Implementation Correctness

### TC-011b fix (primary blocker)

The OPTIONS short-circuit is now implemented with an `else if` guard that
fires when the request is OPTIONS but the origin is NOT local:

```go
if isLocalOrigin(origin) {
    // ... set CORS headers ...
    if r.Method == http.MethodOptions {
        // ... set preflight headers, write 204, return
    }
} else if r.Method == http.MethodOptions {
    // OPTIONS from a non-local origin: short-circuit without CORS headers.
    w.WriteHeader(http.StatusNoContent)
    return
}

next.ServeHTTP(w, r)
```

This correctly satisfies:
- Local origin OPTIONS: 204 + CORS headers, no `next` call.
- External origin OPTIONS: 204, no CORS headers, no `next` call.
- Local origin non-OPTIONS: CORS headers set, `next` called.
- External origin non-OPTIONS: no CORS headers, `next` called.
- No origin: falls through the `if origin == ""` early-return, `next` called.

Note: The spec reference implementation in §3.3 uses a slightly different
structure (OPTIONS check after the `isLocalOrigin` block, not inside an
`else if`), but the behavioral outcome is identical. The `else if` variant
is equally correct and arguably clearer.

### `isLocalOrigin` helper

Clean, uses `net/url.Parse` and `u.Hostname()` per spec requirement. Returns
`false` on parse failure (safe default). No external dependencies.

### `Vary: Origin` header

Uses `w.Header().Add("Vary", "Origin")` (not `Set`), which is correct — it
allows accumulation with other `Vary` directives that downstream handlers
may set.

### No external dependencies

Stdlib only: `net/http`, `net/url`. PASS per spec.

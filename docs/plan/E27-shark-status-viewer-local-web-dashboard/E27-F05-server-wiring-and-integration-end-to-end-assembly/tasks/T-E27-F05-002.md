# Task: Wire ViewerService into ServiceContainer and register viewer routes with SPA and CORS in cmd/server

## Goal

Add `ViewerService` to `ServiceContainer` in `cmd/server/services.go`, construct it inside
`WireServices()`, and register the seven viewer routes plus the embedded SPA on the existing
`net/http.ServeMux` in `cmd/server/main.go`. CORS wrapping for viewer routes is applied here
(using `WithLocalCORS` from task T-E27-F05-003).

## Files to Modify

- `cmd/server/services.go` — add `ViewerService *services.ViewerService` field; construct it in `WireServices()`
- `cmd/server/main.go` — register viewer routes with CORS wrapping; replace placeholder `GET /` with SPA

## Requirements

### Functional Requirements

- [ ] `ServiceContainer` gains `ViewerService *services.ViewerService` field
- [ ] `WireServices(db, projectRoot)` constructs `ViewerService` using existing repos (`epicRepo`, `featureRepo`, `taskRepo`, `historyRepo`, `noteRepo`, `bugRepoAdapter`, `changeCardRepoAdapter`), `workflow.Service`, and `status.CalculationService`
- [ ] All existing `ServiceContainer` fields remain unchanged
- [ ] Seven viewer routes registered on the mux via `viewer.NewHandler(svcs.ViewerService).RegisterRoutes(viewerMux)`
- [ ] Viewer routes wrapped with `viewer.WithLocalCORS` and mounted at `/api/v1/viewer/`
- [ ] Placeholder `GET /` handler replaced with `viewer_assets.RegisterStaticRoutes(mux)`
- [ ] `GET /` serves `viewer.html` with `Content-Type: text/html; charset=utf-8`
- [ ] `GET /static/` serves embedded vendor JS

### Non-Functional Requirements

- [ ] CORS middleware applied ONLY to `/api/v1/viewer/*` routes, NOT to CRUD routes
- [ ] Existing CRUD endpoints (`/api/v1/tasks/`, `/api/v1/features/`, `/api/v1/epics/`) unaffected

## Implementation Plan

### Steps

1. [ ] In `cmd/server/services.go`: add `ViewerService *services.ViewerService` to `ServiceContainer`
2. [ ] In `WireServices()`: instantiate `services.NewViewerService(...)` with existing repos and assign to container
3. [ ] In `cmd/server/main.go`: import `internal/api/viewer` and `internal/viewer/assets`
4. [ ] Replace the placeholder `GET /` handler with `viewer_assets.RegisterStaticRoutes(mux)`
5. [ ] Create a `viewerMux := http.NewServeMux()`; call `viewerHandler.RegisterRoutes(viewerMux)`
6. [ ] Mount: `mux.Handle("/api/v1/viewer/", viewer.WithLocalCORS(viewerMux))`
7. [ ] Run `go build ./cmd/server/...` and `make test`

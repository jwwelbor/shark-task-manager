# Task: Replace hardcoded DB init in cmd/server/main.go with dbinit package

## Goal

Replace the hardcoded `db.InitDB("shark-tasks.db")` call at line 44 of
`cmd/server/main.go` with the cloud-aware `dbinit.Init(ctx, dbinit.Options{})` from
`internal/dbinit` (produced by F01). The server must honor `.sharkconfig.json`, support
both local SQLite and Turso backends, and respect `skip_migrations`.

## Files to Modify

- `cmd/server/main.go` — swap the DB init call; preserve the integrity-check log lines
  and `defer db.Close()`

## Requirements

### Functional Requirements

- [ ] Remove `db.InitDB("shark-tasks.db")` call from `cmd/server/main.go`
- [ ] Call `dbinit.Init(ctx, dbinit.Options{ProjectRoot: "."})` instead (or pass through `opts.ProjectRoot` once StartServer is wired in task 4)

### Non-Functional Requirements

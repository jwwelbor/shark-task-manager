# Task: Implement WithLocalCORS middleware in internal/api/viewer/cors.go

## Goal

Create `internal/api/viewer/cors.go` exporting `func WithLocalCORS(next http.Handler) http.Handler`.
This middleware echoes the `Origin` header back in `Access-Control-Allow-Origin` only when the origin
hostname is `localhost` or `127.0.0.1` (any port, any scheme). It short-circuits OPTIONS preflight
requests with 204. External origins receive no ACAO header.

## New File

- `internal/api/viewer/cors.go` (new file in the existing `internal/api/viewer` package)
- `internal/api/viewer/cors_test.go` (new test file)

## Requirements

### Functional Requirements

- [ ] Export `func WithLocalCORS(next http.Handler) http.Handler`
- [ ] Use `net/url.Parse` on the `Origin` header; check `u.Hostname() == "localhost"` or `u.Hostname() == "127.0.0.1"`
- [ ] When origin is localhost/127.0.0.1: set `Access-Control-Allow-Origin` to the raw `Origin` value
- [ ] Set `Access-Control-Allow-Methods: GET, OPTIONS`
- [ ] Set `Access-Control-Allow-Headers: Content-Type`
- [ ] Set `Vary: Origin`
- [ ] For OPTIONS requests: return `http.StatusNoContent` (204) and do NOT call `next.ServeHTTP`
- [ ] For all non-OPTIONS requests: call `next.ServeHTTP(w, r)` regardless of origin validity
- [ ] For external origins: do NOT set `Access-Control-Allow-Origin`

### Non-Functional Requirements

- [ ] No external dependencies (stdlib only: `net/http`, `net/url`)
- [ ] Scoped to localhost/127.0.0.1 per ADR-E27-007

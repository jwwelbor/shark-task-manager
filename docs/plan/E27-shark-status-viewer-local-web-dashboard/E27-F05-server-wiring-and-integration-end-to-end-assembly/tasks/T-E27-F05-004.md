# Task: Implement StartServer entry point in internal/viewer/server/server.go for shark web CLI integration

## Goal

Create `internal/viewer/server/server.go` exporting `StartServer(ctx context.Context, opts Options) error`.
This importable entry point is shared by `cmd/server/main.go` (thin wrapper) and `internal/cli/commands/web.go`
(F04 `shark web` command). It accepts a pre-bound listener and optional pre-initialized DB, wires all routes,
signals readiness via `opts.Ready`, and performs graceful 30-second shutdown on context cancellation.

## New Files

- `internal/viewer/server/server.go` (new package `server`)
- `internal/viewer/server/server_test.go` (new test file)

## Required Types and Signatures

```go
package server

type Options struct {
    Listener    net.Listener    // pre-bound; if nil, bind Addr
    Addr        string          // e.g. "127.0.0.1:7777"; defaults to ":8080" if empty and no Listener
    ProjectRoot string          // overrides auto-detected project root
    DB          *repository.DB  // if nil, StartServer calls dbinit.Init
    Ready       chan<- struct{}  // closed after listener bound, before Serve blocks
}

func StartServer(ctx context.Context, opts Options) error
```

## Requirements

### Functional Requirements

- [ ] If `opts.DB` is nil: call `dbinit.Init(ctx, dbinit.Options{ProjectRoot: opts.ProjectRoot})`
- [ ] Call `db.CheckIntegrity` on the underlying `*sql.DB`; return error on failure
- [ ] Call `WireServices(db, projectRoot)` to get `ServiceContainer`
- [ ] Build `http.ServeMux` with: viewer routes + CORS, SPA at `GET /`, existing CRUD routes, `/health`
- [ ] Wrap mux in `otelhttp.NewHandler(mux, "shark-api")`
- [ ] If `opts.Listener` is non-nil: use it; otherwise bind `opts.Addr` (default `":8080"`)
- [ ] Close `opts.Ready` (if non-nil) after listener is bound and BEFORE `srv.Serve` blocks
- [ ] On `ctx.Done()`: call `srv.Shutdown(shutdownCtx)` with 30-second timeout
- [ ] Return nil when shutdown is graceful (`http.ErrServerClosed` treated as nil)
- [ ] `cmd/server/main.go` collapses to: init observability, signal context, call `server.StartServer(ctx, server.Options{Addr: ":8080"})`
- [ ] When `opts.DB` is non-nil (caller-provided): do NOT call `db.Close()` in `StartServer`

### Non-Functional Requirements

- [ ] Lives in `internal/viewer/server` (NOT `cmd/server`) so it is importable from CLI
- [ ] No circular import: `internal/viewer/server` must not import `internal/cli/...`
- [ ] Server ready signal within 500ms of invocation (TC-018)
- [ ] 30-second graceful shutdown timeout preserved (REQ-NF-003)

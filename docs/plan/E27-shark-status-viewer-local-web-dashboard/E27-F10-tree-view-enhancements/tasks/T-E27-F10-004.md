# Task: Persist show-all checkbox state in localStorage

## What to build

Persist the "Show all items" checkbox state across page reloads using `localStorage` (not cookies — no existing cookie usage in the viewer). Key: `shark.viewer.showAllItems`. All access is wrapped in `try/catch` for privacy-mode resilience.

**Depends on**: T-E27-F10-002 (the checkbox now controls both completed and cancelled).

**Single file changed**: `internal/viewer/assets/viewer.html`

## Implementation

### 1. Replace the `showCompleted` declaration (~line 2239)

Find:

```js
let showCompleted = false;
```

Replace with:

```js
// showCompleted: when true, shows ALL items regardless of terminal status.
// Persisted in localStorage as 'shark.viewer.showAllItems'.
let showCompleted = (function() {
  try { return localStorage.getItem('shark.viewer.showAllItems') === 'true'; }
  catch (e) { return false; }
})();
```

This IIFE runs before `renderSidebar()` so the first paint already reflects the stored state.

### 2. Update the checkbox's initial `checked` state

In `renderSidebar()`, where the checkbox `<input>` is rendered, ensure it uses the current `showCompleted` value for the `checked` attribute:

```html
<input type="checkbox" id="show-completed-cb" ${showCompleted ? 'checked' : ''}>
```

(It likely already uses a template literal — just verify the variable reference is correct.)

### 3. Write to localStorage in the change handler (~lines 4860+)

Find the `showCompletedCb.onchange` handler. After setting `showCompleted = this.checked;`, add:

```js
try { localStorage.setItem('shark.viewer.showAllItems', String(this.checked)); } catch (e) {}
```

Full handler becomes:

```js
showCompletedCb.onchange = function() {
  showCompleted = this.checked;
  try { localStorage.setItem('shark.viewer.showAllItems', String(this.checked)); } catch (e) {}
  renderSidebar();
};
```

## Acceptance criteria (from spec REQ-F-004)

- AC-004.1: Toggling checkbox calls `localStorage.setItem('shark.viewer.showAllItems', 'true'/'false')`.
- AC-004.2: On page load, `showCompleted` reads from `localStorage.getItem('shark.viewer.showAllItems') === 'true'`.
- AC-004.3: No stored value → defaults to `false` (current behavior).
- AC-004.4: Stored `"true"` → checkbox renders checked and terminal entities are visible on first paint.
- AC-004.5: Any value other than `"true"` (including `null`) is treated as `false`.
- AC-004.6: All `localStorage` access is in `try/catch`; `SecurityError` does not break the viewer.

## Verification

1. Toggle checkbox on, reload — checkbox should be checked and terminal items visible.
2. Toggle off, reload — checkbox unchecked, terminal items hidden.
3. Open browser in private/incognito mode — viewer should still render; toggle should work for the session even though it won't persist.

# Task: Cancelled items respect show-all flag; rename checkbox to 'Show all items'

## What to build

The existing `show-completed` checkbox only hides `completed` entities. Cancelled entities are always shown. Broaden the predicate so both completed and cancelled (and all other terminal statuses) are hidden when the checkbox is off. Rename the label to "Show all items".

**Single file changed**: `internal/viewer/assets/viewer.html`

## Implementation

### 1. Rename the checkbox label (~line 4823)

Find the `<label>` element for the show-completed checkbox. Change:

```html
Show completed
```

to:

```html
Show all items
```

The `id` and JS variable name (`showCompleted`) stay unchanged.

### 2. Broaden the filter predicate at four call sites

The existing predicate `status !== 'completed'` (or the equivalent `!showCompleted && status === 'completed'` guard) appears at approximately lines 4720, 4762, 4790, 4837.

**After T-E27-F10-005 lands**, these will be replaced by `isHiddenTerminalStatus(status, entityType)`. If working on this task first, broaden the predicate manually at each site to also check for cancelled status:

```js
// Before
if (!showCompleted && item.status === 'completed') continue;

// After (temporary until T-E27-F10-005 adds the helper)
if (!showCompleted && (item.status === 'completed' || isCancelledStatus(item.status))) continue;
```

If T-E27-F10-005 has already landed, simply ensure `isHiddenTerminalStatus` covers cancelled statuses (it does by design).

### 3. Add a code comment on the `showCompleted` variable (~line 2239)

```js
// showCompleted: when true, shows ALL items regardless of terminal status.
// User-facing label: "Show all items". Variable name kept for diff minimization.
let showCompleted = false; // (will be replaced by T-E27-F10-004's localStorage init)
```

## Acceptance criteria (from spec REQ-F-002)

- AC-002.1: Label text is "Show all items".
- AC-002.2: With checkbox **off**, neither completed nor cancelled entities are rendered in any section (tree, flat sections).
- AC-002.3: With checkbox **on**, all entities render regardless of status.
- AC-002.4: JS variable name may remain `showCompleted`; comment documents new semantics.
- AC-002.5: The second checkbox "Show all files" is unaffected.

## Verification

Build and run `./bin/shark web`. Toggle the checkbox on a project with both completed and cancelled entities. Confirm both appear/disappear together.

Run `make fmt && make lint && make test` before marking complete.

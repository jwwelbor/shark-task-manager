# Task: Fix idea terminal-status filter; introduce isHiddenTerminalStatus helper

## What to build

The filter predicate `status !== 'completed'` is hardcoded at 4 call sites in `viewer.html`. Ideas use `converted`/`archived` as terminal statuses (not `completed`), so they always pass through the filter regardless of the toggle. Fix this by introducing a single `isHiddenTerminalStatus(status, entityType)` helper with per-entity-type status maps, and replace all four call sites.

This is the foundational fix for the whole filter system — T-E27-F10-002 builds on it.

**Single file changed**: `internal/viewer/assets/viewer.html`

## Implementation

### 1. Add the `HIDDEN_TERMINAL_BY_TYPE` map and helper (after `isCancelledStatus`, ~line 1674)

```js
const HIDDEN_TERMINAL_BY_TYPE = {
  epic:        new Set(['completed', 'cancelled', 'closed', 'wont_fix', 'rejected']),
  feature:     new Set(['completed', 'cancelled', 'closed', 'wont_fix', 'rejected']),
  task:        new Set(['completed', 'done', 'cancelled', 'closed', 'wont_fix', 'rejected']),
  bug:         new Set(['completed', 'done', 'verified', 'closed', 'wont_fix', 'rejected']),
  change_card: new Set(['completed', 'done', 'approved', 'rejected', 'closed']),
  idea:        new Set(['converted', 'archived']),
};

/**
 * Returns true if the status should be hidden when "Show all items" is OFF.
 * Falls back to TERMINAL_STATUSES ∪ CANCELLED_STATUSES for unknown entity types.
 */
function isHiddenTerminalStatus(status, entityType) {
  const s = (status || '').toLowerCase();
  const set = HIDDEN_TERMINAL_BY_TYPE[entityType];
  if (set) return set.has(s);
  return TERMINAL_STATUSES.has(s) || CANCELLED_STATUSES.has(s);
}
```

## Acceptance criteria (from spec REQ-F-005)

- AC-005.1: With toggle **off**, ideas with `status === 'converted'` are hidden.
- AC-005.2: With toggle **off**, ideas with `status === 'archived'` are hidden.
- AC-005.3: With toggle **off**, ideas with `status === 'new'` or `'on_hold'` remain visible.
- AC-005.4: With toggle **on**, all ideas are visible.
- AC-005.5: Tasks with `status === 'done'` are now hidden when toggle is off (intentional — aligns with REQ-F-002).
- AC-005.6: Bugs with `status === 'resolved'`/`'verified'`/`'closed'`/`'wont_fix'`/`'rejected'` are hidden when toggle is off.
- AC-005.7: All four original `status !== 'completed'` call sites replaced with `isHiddenTerminalStatus(status, entityType)`.

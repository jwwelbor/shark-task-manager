# Task: Add 'Collapse all' button to tree view

## What to build

Add a "Collapse all" button to the sidebar filter bar. Clicking it clears `expandedEpics` and `expandedFeatures` (both are `Set` instances) and re-renders the sidebar. "Expand all" is out of scope.

**Single file changed**: `internal/viewer/assets/viewer.html`

## Implementation

### 1. CSS — style the button (near line 232, in the `.sidebar-filter-bar` block)

```css
.sidebar-filter-bar button {
  padding: 2px 8px;
  font-size: 0.85em;
  cursor: pointer;
}
```

Match the visual weight of the existing checkbox controls — small, secondary.

### 2. HTML — add the button in `renderSidebar()` (~lines 4820-4829)

Find the `.sidebar-filter-bar` HTML template string inside `renderSidebar()`. Add the button after the "Show all items" checkbox label block:

```html
<button id="collapse-all-btn" type="button">Collapse all</button>
```

### 3. JS — wire the click handler (after the sidebar is injected into the DOM, ~lines 4860+)

In the post-render wiring block where the checkbox change handler is attached, add:

```js
const collapseAllBtn = document.getElementById('collapse-all-btn');
if (collapseAllBtn) {
  collapseAllBtn.onclick = function() {
    expandedEpics.clear();
    expandedFeatures.clear();
    renderSidebar();
  };
}
```

The `if (collapseAllBtn)` guard makes it safe to call even if the element hasn't rendered yet (e.g., if `renderSidebar` is called early).

## Acceptance criteria (from spec REQ-F-003)

- AC-003.1: `<button id="collapse-all-btn">Collapse all</button>` is rendered in `.sidebar-filter-bar`.
- AC-003.2: Clicking calls `expandedEpics.clear(); expandedFeatures.clear(); renderSidebar()`.
- AC-003.3: After click, every previously-expanded epic and feature is collapsed (no `▼` arrows, no children visible).
- AC-003.4: The button does not change `showCompleted` or `showAllFiles`.
- AC-003.5: Clicking when nothing is expanded is a no-op with no errors.

## Verification

Build and run `./bin/shark web`. Expand 3+ epics and several features, then click "Collapse all". Confirm everything collapses. Confirm button does nothing to the checkbox states.

Run `make fmt && make lint && make test` before marking complete.

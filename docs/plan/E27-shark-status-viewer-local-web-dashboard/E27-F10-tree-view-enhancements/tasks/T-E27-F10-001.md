# Task: Improve completed item visibility for colorblind users

## What to build

Add a `.entity-completed` CSS class to tree nodes and table rows whose status is `completed`, so the "done" state is communicated without relying on color alone. Completed = dimmed (opacity 0.55). Cancelled = dimmed + struck (existing `.entity-cancelled`).

**Single file changed**: `internal/viewer/assets/viewer.html`

## Implementation

### 1. CSS — add `.entity-completed` rule (after line 322, before line 324)

```css
.entity-completed .tree-node-key,
.entity-completed .tree-node-title {
  opacity: 0.55;
}
tr.entity-completed td {
  opacity: 0.55;
}
```

Do NOT add `text-decoration: line-through` — that is reserved for `.entity-cancelled`.

### 2. JS — apply class in tree node builder

Find where `entity-cancelled` is added to tree node `<div>` class strings in the sidebar render functions. For each tree node with `status === 'completed'`, also add `entity-completed` (but cancelled takes priority — check `isCancelledStatus()` first).

### 3. JS — apply class in content-area table rows (lines 4132, 4246)

Today's pattern (look for existing `.entity-cancelled` conditional):

```js
const rowClass = isCancelledStatus(f.status) ? ' class="entity-cancelled"' : '';
```

Replace with:

```js
let rowClass = '';
if (isCancelledStatus(f.status))           rowClass = ' class="entity-cancelled"';
else if ((f.status || '') === 'completed') rowClass = ' class="entity-completed"';
```

There are two such blocks — one for feature table rows (~line 4132) and one for task table rows (~line 4246).

## Acceptance criteria (from spec REQ-F-001)

- AC-001.1: A tree node with `status === 'completed'` has class `entity-completed` on the outer `<div class="tree-node …">`.
- AC-001.2: `.entity-completed` CSS rule sets `opacity: 0.55` and no `text-decoration`.
- AC-001.3: Cancelled nodes continue to render with `entity-cancelled` and `text-decoration: line-through` (regression check).
- AC-001.4: If a node is cancelled, `entity-cancelled` wins (check cancelled first).
- AC-001.5: `<tr class="entity-completed">` applied to feature-list and task-list table rows.

- A cancelled item is dimmed AND struck through.
- No layout shifts or regressions in the tree.

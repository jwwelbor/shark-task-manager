# Task: Dashboard: Active Transitions table + Stale Entities filter section

## Goal

Implement the remaining two dashboard sections: Active Transitions (table of last 25 transitions from `recentActivity`) and Stale Entities (client-side filter of non-terminal entities with `updated_at > 7 days ago`). Completes the full Dashboard view.

## Spec References

- spec.md §2.5.3 Active Transitions, §2.5.4 Stale Entities, §6 Task 5
- status-viewer-ui.md §Content area — Dashboard sections 3 and 4
- Test cases: TC-VIS-06, TC-VIS-07, TC-STALE-01, TC-STALE-02, TC-STALE-03

## Requirements

### Functional Requirements

- [ ] **Active Transitions section** — `renderActiveTransitions()`:
  - Section title "Active Transitions"
  - Table of last 25 transitions from `recentActivity` array, newest first (array already sorted by API)
  - Per-row: `[formatted date] [key — mono accent blue, clickable] → [from-badge] → [to-badge] [note text truncated] [Open button if linked content exists]`
  - from-badge and to-badge: pill badges with `background: getStatusColor(status)`, white text, status name
  - "Open" button: only shown if the transition entry has `linked_content_path` or `content_exists: true`; click → `navigateToEntity(key)`
  - Click key → `navigateToEntity(key)`
  - If `recentActivity` is empty or null: show "No recent transitions" placeholder
- [ ] **Stale Entities section** — `renderStaleEntities()`:
  - Section title "Stale Entities"
  - Client-side filter applied to `treeData`: walk all epics, features, tasks, bugs, ideas, change-cards
  - Filter predicate: `!isTerminalStatus(node.status) && daysSince(node.updated_at) > 7`
  - Sort: descending by `updated_at` (oldest first = highest `daysSince` first)
  - Per-row: `[key — clickable] [status badge] [title] ["N days ago"]`
  - Status badge: pill with `background: getStatusColor(status)`
  - Click key → `navigateToEntity(key)`
  - If no stale entities found: show "No stale entities found" placeholder
- [ ] Wire both section renderers into `renderDashboard()` orchestrator (replacing stubs from T-E27-F03-004)

### Non-Functional Requirements

- [ ] Stale Entities filter is pure client-side — no additional API calls
- [ ] `isTerminalStatus()` and `daysSince()` helpers from T-E27-F03-001 are used
- [ ] Guard with `?.` on `node.updated_at` — nodes without `updated_at` are excluded from stale list

# Task: App shell, CSS dark theme, status color mapping, Pick Folder screen

## Goal

Create `internal/viewer/assets/viewer.html` as a skeleton HTML file (~600 LOC) with the full dark theme CSS, the complete `STATUS_COLORS` mapping table, all utility helpers, the Pick Folder screen UI, and the state machine scaffold. The result is a loadable HTML file that renders the Pick Folder screen with the correct dark slate theme — no API calls yet.

### Technical Notes

- The `STATUS_COLORS` table is the highest-risk item per test-plan.md (TC-COLOR-01..21): it MUST include the full shark long-form workflow statuses, not just the basic ones listed in status-viewer-ui.md. A `getStatusColor()` fallback of `#666666` is the safety net.
- The shark workflow config uses statuses like `ready_for_development`, `in_development`, `in_decomposition`, `ready_for_decomposition`, etc. Any status not in the table silently falls back to gray — this is acceptable behavior.
- Color suggestions for unmapped shark statuses: `ready_for_*` → similar to `todo` (#4d4dbb range), `in_*` → similar to `in_progress` (#e7b30e range), `completed` → same as `done` (#4d4269), `on_hold` → similar to `blocked` (#8c5700), `active` → same as `in_progress`

# Task: History drawer, cross-view navigation (key clicks), Escape key, Doc View, Go embed smoke tests

## Goal

Complete the SPA by implementing: the transition history drawer (Transitions toggle in Entity View), the `navigateToEntity(key)` cross-view navigation function (find tree node, expand ancestors, scroll, select), the Escape key handler, the Doc View state, and the Go-side embed files with smoke tests. After this task the SPA is fully functional end-to-end.

## Requirements

### Functional Requirements

- [ ] **History drawer** — `renderHistoryDrawer(key)` in `// === HISTORY ===` section:
  - Fetches `GET /api/v1/viewer/history/{key}` on "Transitions" toggle click
  - Shows loading spinner while fetching
  - Renders reverse-chronological table of transitions
  - Per-row: `[formatted date] [from-badge → to-badge] [note text]`
  - from-badge and to-badge: pill badges with `background: getStatusColor(status)`, white text
  - "Open" button at top of drawer: switches back to Info view (calls `renderMarkdownPane()`)
  - Empty state: "No transition history." placeholder
  - Wires "Transitions" toggle button in Entity View content toolbar (replacing stub from T-E27-F03-006)

- [ ] **Cross-view navigation** — `navigateToEntity(key)` in `// === NAVIGATION ===` section:
  - Parse key type from format (epic = `E##`, feature = `E##-F##`, task = `E##-F##-###`, bug = `B###`, etc.)
  - Find the node in `treeData` by key
  - If epic: expand that epic (add to `expandedEpics`)
  - If feature: expand its parent epic (add epic key to `expandedEpics`), expand the feature (add to `expandedFeatures`)
  - If task: expand parent epic and parent feature
  - Set `selectedKey = key`
  - Set `appState = 'entity_view'`
  - Call `render()`
  - After render, call `scrollSidebarToKey(key)` to scroll the sidebar to the selected node
  - Used by: dashboard feature key clicks, Active Transitions key clicks, Stale Entities key clicks, any entity key click anywhere in the SPA

- [ ] **Keyboard handler** — `Escape` key:
  - If `appState === 'entity_view'` or `appState === 'doc_view'`: set `appState = 'dashboard'`, clear `selectedKey`, call `render()`
  - If a drawer is open within entity view (Transitions pane active): switch back to Info pane first, second Escape goes to dashboard
  - Register via `document.addEventListener('keydown', ...)`

- [ ] **Doc View** — `renderDocView()` in `// === DOC VIEW ===` section:
  - Triggered when a doc node (italic in sidebar) is clicked: set `selectedKey = doc.key`, `appState = 'doc_view'`
  - Content area: plain markdown rendering only — no Properties panel, no Info/Transitions toggle
  - Reuse `renderMarkdownPane(key)` for markdown rendering
  - Show doc title prominently
  - Minimal properties: path, parent entity
  - `Escape` returns to dashboard (same keyboard handler)

- [ ] **Header navigation wiring** (may have been stubbed in earlier tasks):
  - "Dashboard" title click: set `appState = 'dashboard'`, clear `selectedKey`, `render()`
  - "Refresh" button: re-fetch `summary`, `recent-activity`, `hierarchy`; re-render (do not clear expansion state)
  - "Pick Folder" button: set `appState = 'pick_folder'`, clear all caches, `render()`

- [ ] **Go embed files**:
  - Create `internal/viewer/assets.go`:
    ```go
    package viewer

    import _ "embed"

    //go:embed assets/viewer.html
    var ViewerHTML []byte
    ```
  - Create `internal/viewer/assets_test.go` with smoke tests:
    - `TestViewerHTMLEmbedded`: asserts `len(viewer.ViewerHTML) > 0`; asserts contains `<!DOCTYPE html>`, `<script>`, `STATUS_COLORS`
    - `TestViewerHTMLContainsRequiredIDs`: greps for `id="sidebar"`, `id="content"`, `id="header"`
    - `TestViewerHTMLContainsRequiredClasses`: greps for `.status-badge`, `.status-dot`, `.markdown-body`
  - Run `go test ./internal/viewer/...` and verify all smoke tests pass

### Non-Functional Requirements

- [ ] History drawer fetches fresh data each time "Transitions" toggle is clicked (not cached)
- [ ] `go:embed` requires file at `internal/viewer/assets/viewer.html` exactly

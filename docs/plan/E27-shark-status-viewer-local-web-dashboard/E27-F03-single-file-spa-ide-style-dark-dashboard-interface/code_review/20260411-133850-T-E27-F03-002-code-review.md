### `workflow-meta` supplements `STATUS_COLORS` requirement

Spec §3 states workflow-meta should supplement `STATUS_COLORS` for unknown statuses, using `#666666` as fallback. Implementation at lines 1441–1444 matches exactly:

```javascript
for (const [status, info] of Object.entries(meta.statuses)) {
  if (!(status in STATUS_COLORS)) {
    STATUS_COLORS[status] = (info && info.color) ? info.color : '#666666';
  }
}
```

### AC-7: `isTerminalStatus('done')` returns true; `isTerminalStatus('in_progress')` returns false

**Evidence from lines 1090–1096:**

```javascript
function isTerminalStatus(status) {
  const TERMINAL = new Set([
    'done', 'cancelled', 'closed', 'wont_fix',
    'verified', 'rejected', 'promoted', 'approved', 'completed',
  ]);
  return TERMINAL.has(status);
}
```

- `isTerminalStatus('done')` → `TERMINAL.has('done')` → `true`. PASS.
- `isTerminalStatus('in_progress')` → `TERMINAL.has('in_progress')` → `false`. PASS.

**Note on spec divergence:** `docs/status-viewer-ui.md` lists 8 terminal statuses (omitting `completed`). The task spec at line 42 explicitly requires 9 including `completed`. The implementation correctly follows the task spec. This is not a defect — the task spec supersedes the UI reference doc for this specific requirement.

**Result: PASS.**

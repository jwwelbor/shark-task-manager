## Exploratory Testing Notes

- **Async contract confirmed:** `cmd.Start()` (not `cmd.Run()`) is used at web.go:84. Fire-and-forget is correctly implemented — the server does not wait for the browser process to exit.
- **Port fallback logic:** `findFreePort(7777, 7790)` correctly probes and closes before returning. The TOCTOU window is minimal and acceptable per code review.
- **Signal handling:** `signal.NotifyContext` handles both `os.Interrupt` (SIGINT) and `syscall.SIGTERM`. Context cancellation flows through to `StartServer` via the ctx parameter. Server goroutine is awaited before returning.
- **Windows path:** `exec.Command("cmd", "/c", "start", url)` — shell invocation for Windows `start` command is correctly implemented per spec.
- **No new Go module dependencies:** Implementation uses `os/exec`, `os/signal`, `runtime`, `syscall` — all stdlib. Confirmed.

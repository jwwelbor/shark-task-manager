# Task: Implement shark web command with port detection and server startup

## Goal

Create `internal/cli/commands/web.go` — the Cobra command registration for `shark web`. This task covers the core command structure, port availability detection (7777–7790), and calling `startServer(addr, db)` from E27-F05 in-process. Browser auto-open and output formatting are handled in T-E27-F04-002.

## Requirements

### Functional Requirements

- [ ] Register `shark web` Cobra command with `--port` (default 7777) and `--no-open` (bool) flags
- [ ] Implement `findFreePort(start, end int) (int, error)` that tries TCP listen on each port from start to end, returns first available or error if all in use
- [ ] Call `startServer(addr string, db *repository.DB)` from E27-F05 (server wiring feature) with the resolved `host:port` address
- [ ] Command registers via `init()` into `cli.RootCmd` following existing command patterns
- [ ] Use `cli.GetDB(cmd.Context())` to get the database connection

### Non-Functional Requirements

- [ ] Follow thin-wrapper CLI pattern: parse args/flags, call service/server, format output
- [ ] No new Go module dependencies introduced
- [ ] Port detection must not leave dangling listeners

## Implementation Plan

### Steps

1. [ ] Create `internal/cli/commands/web.go` with package declaration and imports
2. [ ] Declare `webCmd` `*cobra.Command` with Use, Short, Long, RunE fields
3. [ ] Declare `webPort int` and `webNoOpen bool` package-level flag vars
4. [ ] Implement `init()` to register flags and add to `cli.RootCmd`
5. [ ] Implement `runWeb(cmd *cobra.Command, args []string) error`:
   - Call `findFreePort(webPort, 7790)` or use `webPort` directly if user set it explicitly
   - Get DB via `cli.GetDB(cmd.Context())`
   - Call `server.StartServer(fmt.Sprintf("127.0.0.1:%d", port), db)` (non-blocking, returns error channel or blocks — see E27-F05 contract)
   - Print URL and open browser (T-E27-F04-002)
6. [ ] Implement `findFreePort(start, end int) (int, error)` using `net.Listen("tcp", fmt.Sprintf(":%d", p))` and immediately closing listener to check availability

### Technical Approach

- Follow `internal/cli/commands/cloud.go` pattern: flag vars at package level, `init()` registers, `runX` function is the handler
- `startServer` from E27-F05 will block (HTTP ListenAndServe). The CLI must print URL and open browser BEFORE calling the blocking server start, or `startServer` must accept a ready callback/channel.
- If `startServer` blocks, use a goroutine + ready signal pattern: start server in goroutine, wait for ready signal on a channel, then print URL and open browser on the main goroutine, then block waiting for OS signal (SIGINT/SIGTERM) to shut down.
- Import path for server package: `github.com/jwwelbor/shark-task-manager/cmd/server` (verify actual export from E27-F05)

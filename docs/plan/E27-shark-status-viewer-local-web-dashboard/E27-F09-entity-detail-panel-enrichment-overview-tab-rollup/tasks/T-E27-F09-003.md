# Add Notes and RelatedDocs handler functions, routes, and service interface extension

## Goal
Expose the two new viewer API endpoints by implementing `Notes` and `RelatedDocs` handler
functions in `handler.go`, registering the routes in `RegisterRoutes`, and extending the
`ViewerServicer` interface in `service.go` with the two new method signatures. This satisfies
REQ-F-020 and REQ-F-021 at the HTTP layer.

## Scope
- Files to modify:
  - `internal/api/viewer/handler.go` — `Notes` and `RelatedDocs` handler funcs + route registration
  - `internal/api/viewer/service.go` — extend `ViewerServicer` interface with `Notes`, `RelatedDocs`

## Acceptance Criteria
See spec.md REQ-F-020 AC-020.4–AC-020.5; REQ-F-021 AC-021.4.
- AC-T1: Routes registered as `GET /api/v1/viewer/notes/{key}` and `GET /api/v1/viewer/related-docs/{key}`.
- AC-T2: Malformed key returns 400; unknown entity returns 404; success returns 200 with correct JSON shape.
- AC-T3: Handler delegates key normalisation to `validateAndNormalizeAnyKey` (no inline key parsing).
- AC-T4: CORS and auth behaviour matches existing viewer endpoints.

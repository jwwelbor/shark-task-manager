# Frontend: Notes and Related Docs async fetch pipeline with caching and skeleton loaders

## Goal
Add the client-side fetch pipeline for notes and related docs to `viewer.html`: session-scoped
`Map` caches (`notesCache`, `relatedDocsCache`), `fetchNotes` / `fetchRelatedDocs` promise
wrappers, `loadNotesInto` / `loadRelatedDocsInto` render functions with skeleton loaders and
`isConnected` guard, the `notesPlaceholder` / `relatedDocsPlaceholder` generators used by
`renderOverviewPane`, and note-type color mappings. Delivers REQ-F-010 and REQ-F-011.

## Scope
- Files to modify:
  - `internal/viewer/assets/viewer.html` — fetch helpers, render functions, placeholder
    generators, note-type color map, notes/docs CSS additions

## Acceptance Criteria
See spec.md REQ-F-010 AC-010.1–AC-010.7; REQ-F-011 AC-011.1–AC-011.5; REQ-NF-001 AC-NF-001.2.
- AC-T1: Repeat Overview visits for the same entity key issue only one fetch (cache hit).
- AC-T2: Overview sync sections render before notes/docs fetch completes (skeleton shown first).
- AC-T3: `Show N more` button appears when `total > 5`; clicking reveals remaining rows inline.
- AC-T4: On fetch error, docs section shows dim `Failed to load docs` message; notes section
  omitted silently; neither breaks the rest of the Overview.

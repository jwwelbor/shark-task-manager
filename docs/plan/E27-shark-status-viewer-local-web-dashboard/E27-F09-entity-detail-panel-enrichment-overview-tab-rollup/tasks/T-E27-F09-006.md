# Frontend: Epic Overview pane - feature rollup, task rollup, and features table

## Goal
Implement the epic-specific sections of `renderOverviewPane` in `viewer.html`: the Feature
Status Rollup (colored pills from `treeData`), the Task Status Rollup (aggregated across
all features using `collectEpicTasks`) with segmented progress bar and weighted-progress
percentage, and the clickable Features table. All data sourced from cached `treeData`
with no new network requests. Delivers REQ-F-004, REQ-F-005 (epic), and REQ-F-008 (epic).

## Scope
- Files to modify:
  - `internal/viewer/assets/viewer.html` — `renderFeatureRollupSection`, `renderTaskRollupSection`,
    `renderFeaturesTableSection`, shared helpers (`countByStatus`, `collectEpicTasks`,
    `weightedProgress`, `statusMeta`), rollup/table CSS

## Acceptance Criteria
See spec.md REQ-F-004 AC-004.1–AC-004.5; REQ-F-005 AC-005.1–AC-005.4; REQ-F-008 AC-008.1–AC-008.5.
- AC-T1: Zero-count statuses are omitted from pills.
- AC-T2: `NN%` label uses `weightedProgress` helper (not raw completion count).
- AC-T3: Features table KEY cells have `data-navigate-key` and `.clickable` class.
- AC-T4: Table body scrolls inside `max-height: 420px` container when >10 rows; header row sticky.

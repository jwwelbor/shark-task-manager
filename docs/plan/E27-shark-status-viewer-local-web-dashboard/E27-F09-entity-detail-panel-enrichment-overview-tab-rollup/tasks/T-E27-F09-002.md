# Add Notes and RelatedDocs service methods, DTOs, and viewer interfaces

## Goal
Implement `ViewerService.Notes(ctx, key)` and `ViewerService.RelatedDocs(ctx, key)` in the
viewer service, add the DTOs (`NoteDTO`, `NotesResponse`, `RelatedDocDTO`, `RelatedDocsResponse`),
define the two narrow repository interfaces, and wire the optional note/doc-by-entity repos
with `WithNoteRepo` / `WithDocByEntityRepo` setters. This delivers the backend data layer
for REQ-F-020 and REQ-F-021.

## Scope
- Files to modify:
  - `internal/services/viewer_service.go` — new DTOs, interfaces, methods, optional fields
  - `internal/viewer/server/wire.go` — wire `WithNoteRepo` and `WithDocByEntityRepo`

## Acceptance Criteria
See spec.md REQ-F-020, AC-020.1–AC-020.5; REQ-F-021, AC-021.1–AC-021.4.
- AC-T1: `Notes` returns notes ordered `created_at DESC` server-side (not relying on client sort).
- AC-T2: `Notes` returns `{Notes: []NoteDTO{}}` (not null) when `noteRepo` is nil or entity has no notes.
- AC-T3: `RelatedDocs` returns `{Docs: []RelatedDocDTO{}}` (not null) when no docs exist.
- AC-T4: Both methods delegate key normalisation to existing `validateAndNormalizeAnyKey` helper.

# Frontend: Feature Overview pane - task rollup, work breakdown, action items, and tasks table

## Goal
Implement the feature-specific sections of `renderOverviewPane`: Task Status Rollup (for
the feature's tasks only), Work Breakdown (Agent/Human/QA Team mini-bars), Action Items
(tasks with `blocks_feature === true` grouped with accent border), and clickable Tasks table.
All computed client-side from `treeData` + `workflowMeta`. Delivers REQ-F-005 (feature),
REQ-F-006, REQ-F-007, and REQ-F-008 (feature).

## Scope
- Files to modify:
  - `internal/viewer/assets/viewer.html` — `renderWorkBreakdownSection`, `renderActionItemsSection`,
    `renderTasksTableSection`, `workBreakdown`, `actionItems` helpers, work-breakdown/
    action-items CSS

## Acceptance Criteria
See spec.md REQ-F-005 AC-005.1–AC-005.4; REQ-F-006 AC-006.1–AC-006.4; REQ-F-007 AC-007.1–AC-007.4;
REQ-F-008 AC-008.1–AC-008.5.
- AC-T1: `actionItems` never references literal status name strings (grep assertion).
- AC-T2: Work-breakdown section hidden when all three counts are zero.
- AC-T3: Action Items section omitted (not empty) when no tasks match `blocks_feature`.
- AC-T4: Tasks table ORDER column reflects `execution_order` from `treeData`.

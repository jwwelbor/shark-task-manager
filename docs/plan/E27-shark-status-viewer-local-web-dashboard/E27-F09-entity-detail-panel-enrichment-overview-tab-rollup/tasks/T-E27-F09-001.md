# Audit hierarchy payload and extend task DTO with dependency fields

## Goal
Verify that `hierarchyData.treeData` task objects include `depends_on`, `blocked_by`, and
`blocks` fields. If absent, extend the viewer service task projection so the dependency block
section (REQ-F-009) works without extra network calls, satisfying AC-NF-003.1.

## Scope
- Files to modify:
  - `internal/services/viewer_service.go` — extend task DTO projection if fields absent
- Files to read:
  - `internal/services/viewer_service.go` — locate existing task DTO struct and Hierarchy method

## Acceptance Criteria
See spec.md §2.5 audit table; REQ-F-009, AC-009.2; REQ-NF-003, AC-NF-003.1.
- AC-T1: Confirm by grep whether `depends_on` is already serialized in task projection.
- AC-T2: If absent, task DTO struct gains `DependsOn`, `BlockedBy`, and `Blocks` string-slice fields.
- AC-T3: No new per-entity GET endpoint is introduced.

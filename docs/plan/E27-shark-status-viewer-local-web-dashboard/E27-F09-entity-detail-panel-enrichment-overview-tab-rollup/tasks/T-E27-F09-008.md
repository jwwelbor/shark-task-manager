# Frontend: Task Overview pane - dependency block with clickable navigation

## Goal
Implement the task-specific section of `renderOverviewPane`: the dependency block showing
`Depends On`, `Blocked By`, and `Blocks` groups. Each group resolves keys via
`findEntityByKey`, renders clickable entries with `data-navigate-key` for resolved entities,
and `(unresolved)` for unresolved keys. `Blocked By` always carries a 2px red left border
accent. Empty groups show `(none)`. Delivers REQ-F-009.

## Scope
- Files to modify:
  - `internal/viewer/assets/viewer.html` — `renderDependencyBlockSection`, `renderDepRow`
    helper, dependency CSS rules

## Acceptance Criteria
See spec.md REQ-F-009 AC-009.1–AC-009.5; REQ-NF-002 AC-NF-002.1.
- AC-T1: Data sourced from cached task object's `depends_on`, `blocked_by`, `blocks` arrays
  (from T-E27-F09-001 audit); no new fetch.
- AC-T2: `Blocked By` group accent (`border-left: 2px solid #c0392b`) renders even when the
  group is empty.
- AC-T3: Unresolved keys render as plain mono text with dim `(unresolved)` suffix, no click handler.
- AC-T4: Every resolved clickable entry has `tabindex="0"` and `role="button"`.

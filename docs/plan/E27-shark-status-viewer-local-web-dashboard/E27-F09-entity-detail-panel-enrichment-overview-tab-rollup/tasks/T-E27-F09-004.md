# Frontend: Add Overview tab, change default tab, move Edit button to Spec pane

## Goal
Modify `viewer.html` to add the `Overview` tab button to the toggle bar for epic/feature/task
entities, set `'overview'` as the default `entityViewTab` in `navigateToEntity()`, wire the
pane switch in `renderEntityView()`, guard against `'dashboard'` on non-epic entities, and
move the Edit toggle out of the toggle bar and into `renderMarkdownPane()`. Delivers
REQ-F-001 and REQ-F-002.

## Scope
- Files to modify:
  - `internal/viewer/assets/viewer.html` — toggle bar, `navigateToEntity`, `renderEntityView`
    pane switch, `renderMarkdownPane` inline edit toggle, Overview CSS additions from spec §2.4

## Acceptance Criteria
See spec.md REQ-F-001 AC-001.1–AC-001.5; REQ-F-002 AC-002.1–AC-002.4.
- AC-T1: `navigateToEntity()` sets `entityViewTab = 'overview'` unconditionally (replaces E27-F08 branching).
- AC-T2: Toggle bar prepends Overview button; removes `editBtnHtml` concat from toggle bar.
- AC-T3: Pane switch adds `overview` case before `info`; guards `dashboard` coercion for non-epic.
- AC-T4: `renderMarkdownPane()` gains `spec-pane-header` row with inline Edit toggle.

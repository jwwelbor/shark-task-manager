# Frontend: Breadcrumb component and properties panel status accent

## Goal
Add the `renderBreadcrumb(entity)` helper to `viewer.html` that builds the parent-chain
breadcrumb from `hierarchyData` without a network call, insert it between the entity title
and the properties panel in `renderEntityView()`, wire the global `keydown` handler for
keyboard navigation, and add the status left-border accent to `.props-grid`. Delivers
REQ-F-003 and REQ-F-012.

## Scope
- Files to modify:
  - `internal/viewer/assets/viewer.html` — `renderBreadcrumb` helper, `renderEntityView` insertion
    point, global `keydown` handler, `renderPropertiesPanel` status accent, breadcrumb CSS

## Acceptance Criteria
See spec.md REQ-F-003 AC-003.1–AC-003.4; REQ-F-012 AC-012.1–AC-012.3; REQ-NF-002 AC-NF-002.1.
- AC-T1: Epic breadcrumb renders a single non-linked `.current` segment.
- AC-T2: Feature breadcrumb renders `E## › E##-F##` with parent as `data-navigate-key`.
- AC-T3: Task breadcrumb renders `E## › E##-F## › E##-F##-###` with both parents clickable.
- AC-T4: Global `keydown` handler is added once; `Enter`/`Space` on `[data-navigate-key][role="button"]`
  calls `navigateToEntity`.

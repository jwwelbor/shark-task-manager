# Task: Info pane header polish — reorder breadcrumb, remove redundant rows, add key copy button

## Goal

Four small header-area changes that together produce a cleaner, more usable info pane:

1. **Move breadcrumb to the top** — currently the breadcrumb sits below the title and key link; move it to the first line of the detail pane.
2. **Remove redundant KEY row** from the properties box — the key is already shown as the blue link directly below the title.
3. **Remove redundant PARENT row** from the properties box — the parent is already shown in the breadcrumb.
4. **Add a copy button** next to the blue key link (`entity-view-key`) so users can copy the entity key to the clipboard with one click.

**Before** (current):
```
<title>                       ← h2
T-E27-F09-011                 ← blue key link
E27-F09 > T-E27-F09-011       ← breadcrumb (below title)

[ KEY        T-E27-F09-011 ]  ← redundant
[ STATUS     draft         ]
[ TYPE       task          ]
[ PARENT     E27-F09       ]  ← redundant
[ AGENT      ...           ]
```

**After** (target):
```
E27-F06 > T-E27-F06-001       ← breadcrumb (top row)
<title>                       ← h2
T-E27-F06-001  📋             ← blue key link + copy button

[ STATUS     draft   ]
[ TYPE       task    ]
[ AGENT      ...     ]
```

## Requirements

- [ ] Breadcrumb is rendered as the **first element** inside the entity detail pane, above the `h2` title
- [ ] Remove the KEY row from the properties table for all entity types
- [ ] Remove the PARENT row from the properties table for all entity types
- [ ] Add a small copy-to-clipboard icon button immediately after the `entity-view-key` element
- [ ] Copy button copies the entity key text to `navigator.clipboard`
- [ ] Copy button gives brief visual confirmation on success (e.g. icon swaps to a checkmark for 1.5 s, or a tooltip "Copied!")
- [ ] Copy button is visually unobtrusive — icon-only, same line as the key, no border/background in rest state
- [ ] No other property rows are removed

## Implementation

All changes in `internal/viewer/assets/viewer.html`.

**Breadcrumb position**: find where `renderBreadcrumb` output is inserted relative to the title `h2`. Move the breadcrumb HTML to be emitted before the `h2` (or restructure the container order).

**Remove rows**: find the section that builds properties table rows and delete the `KEY` and `PARENT` push calls:
```js
// delete:
rows.push({ label: 'KEY', value: entity.key, ... })
rows.push({ label: 'PARENT', value: entity.parentKey, ... })
```

**Copy button**: locate where `entity-view-key` is rendered (the blue `<a>` or `<span>` showing the key). Append an inline `<button>` after it:
```html
<button class="copy-key-btn" title="Copy key" onclick="copyEntityKey(entity.key)">
  <svg ...clipboard icon.../>
</button>
```
Implement `copyEntityKey(key)`:
```js
function copyEntityKey(key) {
  navigator.clipboard.writeText(key).then(() => {
    // swap icon to checkmark briefly
  });
}
```

## Acceptance Criteria

- [ ] Breadcrumb appears above the title `h2` for every entity type
- [ ] No KEY row in the properties box
- [ ] No PARENT row in the properties box
- [ ] Copy button appears immediately after the blue key text
- [ ] Clicking copy button writes the key to clipboard
- [ ] Copy button shows brief visual confirmation after click
- [ ] `make test` passes (assets_test.go smoke tests)

# Task: Implement `shark impact record` CLI command

## Goal

Add the thin CLI wrapper registering `shark impact record <entity-key>
<content-or-@file>` and prove happy-path/not-found/persistence behavior end
to end, per spec.md's "Component changes" (`impact_cmd.go` row) and Key
technical decision #1.

## Scope

- Create: `internal/cli/commands/impact_cmd.go` (`runImpactRecord` — parses
  args, resolves `@file` content, calls `services.ImpactService.RecordImpact`,
  formats `--json`/success output per `note.go`)
- Create: `internal/cli/commands/impact_cmd_test.go`

## Acceptance Criteria

See spec.md AC-4 (command-level half). Task-specific: exits non-zero on a
nonexistent target key; `@file` reads real file bytes (not the literal
`@path` string) and fails clearly on a missing/unreadable file, zero repo calls.

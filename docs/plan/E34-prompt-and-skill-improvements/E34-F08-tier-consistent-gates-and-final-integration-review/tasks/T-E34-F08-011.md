# Interaction-map completeness checker (TC-014)

## Goal
Add the shared structural guard proving every I-## row in
`E34-interaction-map.md`'s Interaction Contracts table names a producer,
consumer(s), shape-source link, payload, and style — kept structurally
separate from the table parser so a shared defect between parser and
checker cannot hide behind one green test. Distinct from, and does not
duplicate, the pre-existing `TestI01ReadinessContract_TC_I_01_READINESS_SYMMETRY`
in `internal/cli/commands/interaction_prompts_test.go` (E34-F02/F03's I-01
ReadinessEvidence field-symmetry test — a different table, document, and
owning feature).

## Scope
- Create: `internal/sharkdata/interaction_map_readiness.go`
- Modify: `internal/sharkdata/embed_test.go` (add
  `TestInteractionMapCompleteness`; ordered after T-E34-F08-010, which also
  extends this file)
- Uses `ParseInteractionMapTable` from T-E34-F08-001; does not modify it.

## Acceptance Criteria
Reference spec.md AC-8.
- AC-T1: `CheckInteractionMapCompleteness(rows []InteractionRow) []error` is
  a distinct function from `ParseInteractionMapTable` — the checker's
  fixture subtests construct `[]InteractionRow` directly, bypassing the
  parser, so a parser bug cannot mask a checker bug or vice versa.
- AC-T2: The checker resolves each shape-source link against
  architecture.md's actual `## I-0X ...` headings (a second, explicit
  document input) — an empty field (missing) and a non-empty link whose
  anchor doesn't resolve (unresolved) are two distinct error classes.

## Test Cases
See test-plan.md TC-014: (a) run against the real, parsed
`E34-interaction-map.md` table — assert it passes for all five rows. (b) a
subtest per required field (producer, consumer, shape-source, payload,
style) with a test-local copy missing that field — assert failure naming
the field and row. (c) a shape-source link whose anchor doesn't match any
architecture.md heading — assert a distinct "unresolved anchor" error.

## Integration Contracts

### Cross-feature
None — a structural bundle-completeness guard over
`E34-interaction-map.md`'s own table, not a cross-feature interface itself.

# Fail-closed base/history handling: rebase, squash, interleaved commits, dirty and untracked paths

## Goal
Close the remaining REQ-F-004/REQ-F-005 history and inventory gaps: fail
closed on a missing/unreachable base, handle rebased/squashed feature
branches and unrelated interleaved commits without silently rewriting or
hiding scope, and record digests for dirty tracked and untracked candidate
paths so the review's full-diff inventory is complete.

## Scope
- Modify: `internal/integration/candidate.go` (tracked/untracked path
  digest fields), `internal/integration/backfill.go` (base-reachability and
  history validation, shared with steady-state capture per spec.md's "one
  correctness argument" decision)
- Create: `internal/integration/history.go` (rebase/squash/interleaved-
  commit detection and explicit replacement-record creation)

## Acceptance Criteria
Per feature.md:124-141 and architecture.md:296-303:
- AC-T1: A missing or unreachable base fails closed (typed error), never
  silently inferred from `merge-base HEAD main`.
- AC-T2: A rebase or squash-merge is detected and creates an explicit
  replacement record linked by `prior_record_digest`; the base is never
  silently rewritten.
- AC-T3: Unrelated interleaved commits remain visible in the full
  base-to-candidate inventory and are flagged as requiring a disposition,
  not silently included or excluded.
- AC-T4: Dirty tracked files and untracked candidate paths each get a
  recorded digest in the candidate; the review (T-E34-F08-010) reads these
  for its full-diff/path-digest inventory check.

## Test Cases
Pinned-base histories: independently squash-merged features, unrelated
interleaved commits, rebases, a missing base, dirty tracked files, and
untracked candidate paths (feature.md's verification plan, one subtest
each). Assert no case infers scope from `merge-base HEAD main`.

## Integration Contracts

### Cross-feature

`integration_review` (T-E34-F08-010).

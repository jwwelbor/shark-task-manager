### AC5: Command registers via `init()` and appears in `shark --help`
PASS — `init()` calls `cli.RootCmd.AddCommand(webCmd)`. Verified: `./bin/shark --help` lists `web` command.

### AC6: Code follows thin-wrapper CLI pattern (no business logic in command)
PASS — Command parses flags, calls `viewerserver.StartServer`, formats output. No business logic. `findFreePort` is a utility helper (not business logic) appropriately co-located. `openBrowserForOS` is infrastructure-level OS dispatch, correctly separated.
